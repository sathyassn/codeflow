# EPC-028: Hosted runs are reused and admitted without waste, and the beta is installed

## Summary

The full gate takes 25 to 35 minutes locally and longer on hosted CI. This epic works toward the operator's aim of about 10 minutes with partitioned hosted runs, a daily Windows run and changed-file coverage, proves a hosted line pull request run well under the operator's 32 minute target (TSK-1273 AC-8), and ends with the beta binary installed on this host. It is one of the feature epics the operator approved on 2026-11-03, when the 4.0.0 milestone epic (EPC-022) and the 4.1.0 epic (EPC-023) were regrouped by outcome. Planned version: 4.0.0. Why that version: Operator 2026-11-01 14:33 (10-minute gate), 2026-11-02 19:35 and 19:48 (beta minimal, deliver faster); 352 to 360 and 370 in this release (2026-10-18).
