# EPC-058: Host-state tools work through narrow routes in every shipped preset

## Summary

Agent sessions need tools that use host state, such as `gh`, `git` over the network, and the seat CLIs. This epic gives each regular tool a narrow route, or a clear report that it is unavailable and why. It then sets every shipped Claude preset to rely on those routes. It serves adopters who run agent sessions with CodeFlow's presets, and this workspace, which runs the same presets. The operator decided the direction on 2026-11-12 ("make sure there are exemptions for genuine and regular operational use cases including things like gh, git, orca, herdr (hc and other)"; RELEASE-PLAN.md).

## Outcome

after this merges, an adopter's agent session can run the regular host-state work it needs through narrow, documented routes, and every shipped preset relies on those routes by default.

## Deliverables

- the routes, their doctor and orient reports, and their tests: TSK-1482
- the shipped preset change, the `codeflow update` rule, the opt-back docs, the ADR-0029 successor and the release note: TSK-1483
- the seat broker for hc, with its install, update and doctor surface: TSK-1484
- the task records: `project-management/tasks/`
