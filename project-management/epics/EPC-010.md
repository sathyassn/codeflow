# EPC-010 — same-PR release metadata and deliberate publication

## Summary

Keep reviewed impact, curated notes and warranted version changes in the work
PR itself. The operator rejected Plan v1's automatic second release PR before
main merge. Plan v2 removes that machinery and uses cumulative pending impact
from reviewed changelog content, with deterministic state checks and deliberate
publication. cargo-dist remains the publisher. Consumers retain their own
adopted release process; the same-PR approach is offered, not imposed.

      release dry runs and independent cross-lineage reviews support only the
      scoped behaviors actually exercised.

## Out of scope

No tag move, public release, artifact upload, visibility/plan change, credential
provisioning, consumer deployment or global release engine. Do not replace
cargo-dist, add a release queue or wrapper ref service, add general prerelease,
backport or multipackage orchestration, or treat CI as complete semantic proof.

CodeFlow PR checks, release preparation and publication workflows, git-cliff and
