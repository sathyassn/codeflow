# EPC-051: Hooks, harness tools and outward commands are judged safely

## Summary

A substituted hook binary, the Monitor tool, global installers and cloud-changing commands are not judged the way shell commands are, an agent has no sanctioned way to make a sample repository, and diagnostics can print project values. It was split out of EPC-029 on 2026-11-04 by the stricter consolidation pass (the operator's rule, relayed by the Director at 21:5x: epics of "around 5 - 10" tasks that reach `main` "in very few days", with "medium to hard" tasks). Planned version: 4.0.0, the version of EPC-029, whose placement reasons carry over.

Value line: an operator trusts that no tool or binary outside the shell path slips past the guards, and that what the guards print names places, never values.

## Outcome

After this merges, an operator can rely on the hook binary, the Monitor tool, global installers and cloud-changing commands being judged, an agent can make a disposable sample repository by a sanctioned path, and diagnostics never print a project's values.
