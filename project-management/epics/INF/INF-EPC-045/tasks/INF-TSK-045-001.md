# INF-TSK-045-001: QA Report: show all project-wide coverage exceptions from test-config.json

## Description

The current QA Report Exempted Files table only shows files that fell below threshold during a specific test run. It should instead show ALL project-wide exceptions configured in test-config.json, so reviewers can see the full exception policy at a glance — not just the ones triggered in this run.

**Expected Outcome:** QA Reports always include all configured exceptions from test-config.json, not just those triggered in the current run.

**Deployment:** Documentation changes take effect immediately. Any Rust changes compiled into `codeflow` binary.

## Stage Reports

### DEV Report

**Implementation Summary:**

Changed `validate()` in `validation.rs` to build `exempted_files` from ALL `config.conventions.exceptions[]` entries, not just those matching modified files. Previously, exceptions only appeared in `exempted_files` if the file was in the `modified_files` list. Now all exceptions are always included regardless of whether they were modified or even present in coverage data.

Key changes:
- `validate()`: Builds `exempted_files` by iterating ALL config exceptions. Files not in coverage data get coverage=-1.0 (rendered as "N/A").
- `format_markdown()`: Always renders the "Exempted Files (below 85%)" section with a description. Empty exceptions show "No exceptions configured." instead of hiding the section.
- Added `warnings: Vec<String>` field to `TestValidationResult` for validation warnings (e.g., if exempted files count < exceptions count).
- Also updated `cli/src/cmd/test.rs` test constructors for the new `warnings` field.

**Files Changed:**
- `codeflow-cli/core/src/testing/validation.rs` — primary Rust logic + 5 new tests
- `codeflow-cli/cli/src/cmd/test.rs` — added `warnings` field to 2 test constructors
- `project-management/templates/task-template.md` — updated description text
- `.claude/agents/cf-quality-assurance.md` — updated WS-QA SOP and template
- `.claude/CLAUDE.md` — staged edit at `/tmp/claude/codeflow/managed/protected-edits/CLAUDE.md` (requires protected-path cp)

**Test Results:** 27/27 tests pass. 5 new tests added:
1. `test_validate_exempted_files_all_config_exceptions` — verifies all 3 config exceptions appear even with no modified files
2. `test_format_markdown_all_exceptions_including_na` — verifies N/A rendering for missing coverage
3. `test_validate_no_warning_when_all_exceptions_present` — verifies no spurious warnings
4. `test_validate_empty_exceptions_empty_exempted` — verifies empty config produces empty exempted list
5. `test_format_markdown_empty_exceptions` — verifies "No exceptions configured." message

**Deviations:** None. CLAUDE.md edit requires protected-path staged edit workflow — staged copy ready at `/tmp/claude/codeflow/managed/protected-edits/CLAUDE.md`.
