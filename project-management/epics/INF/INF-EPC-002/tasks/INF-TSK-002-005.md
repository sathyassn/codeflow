# INF-TSK-002-005: Fix PF6 verify-pr-and-sync: add wait-for-merge and pull-main

## Description

The current `verify-pr-and-sync` SOP in `cf-git-operations.md` verifies CI and determines the merge mode (auto-merge, notify-user, or CI-failed) but does not explicitly include steps to wait for the PR to be merged and then pull `main` to sync the local repo. This means after PF6-COMPLETE, the local repo is still on the feature branch and main is not up to date.

This task fixes that by updating all 3 modes in `verify-pr-and-sync` to include:

- Waiting for PR merge confirmation (Mode 1: after auto-merge; Mode 2: notification to user)
- Pulling main after merge to sync the local repo

Also commits pending metadata that should have been part of PR #58: `pr_number=58` in `work-graph.jsonl` and `INF-TSK-002-004.md`.
