# INF-TSK-044-008: State File Write Protection — CLI Abstraction and Enforcement

> **MANDATORY VALIDATION:** Files created from this template MUST be validated against the task validation command before committing:
> `codeflow validate task <file-path>`
> Fix all errors (exit code 1) before requesting a commit. Warnings are advisory.

## Description

Five deliverables that close the gap between agent definitions that directly write to `.state/` paths and the Rust CLI that should be the sole authorized write path:

1. **EditWriteGuard — block `.state/` writes** — extend `EditWriteGuard` in `pre_tool_use.rs` to add `.state` to its `blocked_directories` list. Any Edit or Write tool call targeting a `.state/` path will be blocked with a clear error directing the caller to use the appropriate CLI command.

2. **ProtectionGuard — expand `.state/` subdir patterns** — update `enforcement-policy.json` to add patterns covering all `.state/` subdirectories (ledger, db, logs, coordination, worktrees) for Bash redirect and direct database command blocking. The `codeflow ledger append` path must remain allowed.

3. **`codeflow db exec` / `codeflow db query` subcommands** — extend `codeflow-cli/cli/src/cmd/db.rs` with two new subcommands: `exec --query <SurrealQL>` for write statements (INSERT, UPDATE, DELETE, CREATE, RELATE) and `query --query <SurrealQL>` for read queries (SELECT) returning JSON. These replace direct SurrealDB file access.

4. **`codeflow state set-active-task` / `clear-active-task` subcommands** — add a new `codeflow-cli/cli/src/cmd/state.rs` module with two subcommands that manage `active-task.json`: `set-active-task` writes the file with all required fields from CLI flags; `clear-active-task` removes it. These replace direct file writes to `.state/runtime/active-task.json`.

5. **Agent definition updates** — update `cf-knowledge-layer.md` and `cf-git-operations.md` to replace all direct `.state/` write instructions with the corresponding CLI commands (`codeflow ledger append`, `codeflow db exec`, `codeflow db query`, `codeflow state set-active-task`, `codeflow state clear-active-task`). Add an explicit `NO DIRECT .state/ WRITES` constraint to both agent definitions.
