# INF-TSK-044-010: Status Dashboard Live Refresh & Unified Layout

## Description

Fix three related issues in the status dashboard TUI:

1. **Live refresh gap** — New interactive sessions created after `codeflow interactive status --watch` was started did not appear until the command was restarted. The session list was loaded once at startup rather than re-queried on each refresh tick.

2. **Missing task_id column** — The `InteractiveSession` model lacked a `task_id` field, so the status dashboard could not display which task a session is working on.

3. **Inconsistent column order** — The interactive and autorun detail pane tables used different column orderings, making it hard to compare sessions across the two views.

## Deliverables

| Deliverable | Type | Location | Integration Point |
|-------------|------|----------|-------------------|
| Live session refresh | fix | `core/src/tui/data.rs` | `codeflow interactive status --watch` |
| task_id field on InteractiveSession | fix | `core/src/models/interactive_session.rs` | TUI data layer, session_start hook |
| Unified column order | fix | `core/src/tui/widgets/detail_pane.rs` | Both interactive and autorun detail panes |
| Session ID abbreviation | fix | `cli/src/cmd/interactive.rs`, `cli/src/cmd/autorun.rs` | TUI display |
| task_id population at session start | fix | `core/src/hooks/session_start.rs`, `core/src/hooks/post_tool_use.rs` | active-task.json bridge |

**Expected Outcome:** Running `codeflow interactive status --watch` shows new sessions as they start (within 2s), displays the active task name, uses a consistent column order with autorun status, and abbreviates long session IDs for readability.

**Deployment:** PR #289 merge to main.

## Approach

1. Add `task_id: Option<String>` to `InteractiveSession` model
2. Populate `task_id` from `active-task.json` in session_start hook and post_tool_use hook
3. Move session DB query from startup to per-tick refresh in `tui/data.rs`
4. Update `detail_pane.rs` to use TASK|SESSION|BRANCH|TYPE|STATUS|PHASE|DURATION column order for both views
5. Add session ID abbreviation helper (head+tail format)
6. Add unit tests for abbreviation helper and task_id population
