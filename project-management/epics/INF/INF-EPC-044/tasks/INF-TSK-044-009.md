## Description

PR #285 (INF-TSK-044-008) added `.state/` write protection and cleaned up SQLite references across the codebase. This follow-up addresses items that were identified as out-of-scope or missed during that session:

1. **ProtectionGuard `./ prefix` bypass** — `normalize_path()` in `pre_tool_use.rs` does not strip the `./` prefix before pattern matching, so `echo >> ./.state/ledger/x.jsonl` evades the protection that blocks `echo >> .state/ledger/x.jsonl`. This was flagged as SEC-INFO-001 in the INF-TSK-044-008 SEC Report and deferred.

2. **Stale `.claude/plans/` files** — Legacy plan files from the Go CLI era or completed tasks remain in `.claude/plans/`. These are dead artifacts that create noise and may contain outdated references.

3. **Remaining SqliteStore references in markdown** — Two project-management markdown files still reference `SqliteStore` or the old SQLite-based store. These should be updated to reflect the current SurrealDB-based architecture.

4. **`cf-go-standards` skill** — If no Go code remains in the repo, the Go standards skill is a dead artifact. If Go is absent, delete it; if present, this item is N/A.
