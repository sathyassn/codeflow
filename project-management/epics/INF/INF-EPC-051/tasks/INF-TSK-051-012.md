## Expected Outcome

1. **`codeflow workflows list` enumerates the configured pipelines.** An operator can run `codeflow workflows list` and see the workflow pipelines (the 10 work-type pipelines from `pipelines.config`) printed, with `run` and `build` available as sibling subcommands.
   - Verify: `codeflow workflows list` exits 0 and prints the pipelines; `codeflow workflows run` executes a pipeline and `codeflow workflows build` composes one (subcommands wired and dispatchable).
2. **A `Workflows` variant exists in the `Command` enum and dispatches the new subcommand.** The new subcommand is reachable through the top-level `codeflow` CLI (no panic, no "unknown subcommand").
   - Verify: `codeflow workflows --help` lists `build`, `run`, and `list`; the `Workflows` variant is present in the `Command` enum at `codeflow-cli/cli/src/main.rs` (enum spans 17-163).
3. **The Command enum holds 31 variants after the add (30 pre-add + 1), with no regression to existing arms.** Every prior subcommand still dispatches.
   - Verify: a reviewer re-reads the `Command` enum firsthand and confirms the variant count is 31 after the add; existing subcommands continue to resolve (no enum-arm regressions).

## Integration Requirements

1. **The `Workflows` variant integrates with the existing `Command` enum at `codeflow-cli/cli/src/main.rs` without breaking the 30 pre-existing variants.** The enum (spanning lines 17-163, close brace at 163) gains exactly one arm.
   - Verify: reviewer re-reads the `Command` enum firsthand and confirms the variant count is 31 (was 30); a full `cargo build` of `codeflow-cli/cli` succeeds with the match on `Command` still exhaustive.
2. **`codeflow workflows {build,run,list}` dispatch to the new `cmd/workflows.rs` handler** rather than colliding with any existing subcommand name.
   - Verify: `codeflow workflows list` / `run` / `build` each route to `codeflow-cli/cli/src/cmd/workflows.rs`; no existing `codeflow <subcommand>` changes behavior (run each prior subcommand's `--help` to confirm it still resolves).
3. **No enum-arm regressions across the existing CLI surface.** Adding the variant does not shadow, reorder, or remove any of the 30 prior variants.
   - Verify: diff the `Command` enum before/after -- the 30 prior variants are byte-for-byte intact and only the `Workflows` arm is added.
