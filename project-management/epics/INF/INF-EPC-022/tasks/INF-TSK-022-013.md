# INF-TSK-022-013: Implement workgraph operations

## Description

Port the Go `internal/workgraph/` package to Rust. The workgraph module provides the API for task and epic CRUD operations. The key design principle: all data access flows through the `DataStore` trait, not the `SurrealStore` implementation directly. This enables unit tests to use `MockStore` without requiring a database.

Status transitions use enum state machines with compile-time validation. The Go implementation uses string comparisons for status checks; Rust replaces these with exhaustive pattern matching.

## Approach

1. Create `workgraph/mod.rs` with sub-modules (epic, task, query)
2. Define `TaskStatus` and `EpicStatus` enums with transition validation
3. Implement CRUD operations that take `&dyn DataStore` parameter
4. Implement format ID generation (AREA-EPC-NNN, AREA-TSK-NNN-NNN)
5. Emit JSONL events via `LedgerWriter` for all mutations
6. Write tests using `MockStore`
