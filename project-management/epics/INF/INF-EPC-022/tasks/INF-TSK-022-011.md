# INF-TSK-022-011: Implement session and state management

## Description

Port the Go `internal/session/`, `internal/workstate/`, and `internal/config/` packages into a unified Rust session module. The key improvement: `SessionStatus` is an enum with a state machine that validates transitions at compile time. The session builder pattern replaces Go's multi-parameter constructor functions.

This task consolidates three Go packages (`session`, `workstate`, `config`) into one cohesive Rust module. The Go separation was an artifact of incremental development; the Rust redesign merges them because they share state and dependencies.

## Approach

1. Create `session/mod.rs` with sub-modules (state, builder, env, active_task)
2. Implement `SessionStatus` state machine with transition validation
3. Implement `SessionBuilder` using the builder pattern
4. Port session ID generation from `internal/session/session.go`
5. Port active-task.json management from `internal/workstate/`
6. Port codeflow-env.sh management from `internal/session/`
7. Port config loading from `internal/config/`
8. Write comprehensive unit tests
