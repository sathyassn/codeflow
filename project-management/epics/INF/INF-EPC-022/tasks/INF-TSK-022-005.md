# INF-TSK-022-005: Initialize Rust workspace

## Description

Create the Rust workspace at `codeflow-rs/` with a modular crate structure: `codeflow-core` (library crate containing all business logic) and `codeflow-cli` (binary crate containing Clap CLI dispatch). The workspace Cargo.toml defines shared dependencies used across crates. The Clap skeleton mirrors the existing Go CLI subcommand tree so that future implementation tasks fill in the command handlers.

The Rust binary builds ONLY within `codeflow-rs/` during Phases 0A-0F. It is NEVER installed globally until Phase 0G cutover. The Go binary continues to serve all production hooks and commands.

## Approach

1. Create `codeflow-rs/Cargo.toml` workspace definition with shared dependencies
2. Create `codeflow-rs/codeflow-core/Cargo.toml` and `src/lib.rs` with module stubs
3. Create `codeflow-rs/codeflow-cli/Cargo.toml` and `src/main.rs` with Clap CLI skeleton
4. Define Clap subcommand tree matching Go CLI: hooks, db, workgraph, state, ledger, test, doctor, cleanup, validate, sentinel, pathflow, config, internal
5. Set up Clippy lint configuration in workspace Cargo.toml
6. Set up rustfmt.toml for consistent formatting
7. Verify `cargo build`, `cargo test`, `cargo clippy`, `cargo fmt --check` all pass
8. Add placeholder unit tests in both crates
