# INF-TSK-022-019: Rust Test Hardening (proptest, insta, edge cases)

## Description

Harden Rust test coverage in `codeflow-core` and `codeflow-cli` with proptest property-based testing, insta snapshot tests, and thorough edge case coverage. This builds on the 220+ tests already in place from task 018 and the testability patterns established in earlier tasks.

The goal is per-file 85% coverage across all non-excepted source files — not a count-based parity target. Property-based testing with `proptest` covers serialization roundtrips, and snapshot testing with `insta` covers JSON output format stability. Exception management in `test-config.json` is part of the deliverable.

## Approach

1. Inventory codeflow-core source files and categorize coverage gaps
2. Add proptest strategies for all serde-annotated types not yet covered
3. Harden inline tests in codeflow-cli/src/ modules (edge cases, error paths)
4. Add `insta` snapshots for hook JSON input/output and workgraph responses
5. Verify per-file coverage via `cargo-llvm-cov` per-file report
6. Update `test-config.json` exceptions as each file reaches threshold
7. Run `cargo nextest run` for parallel execution
8. Verify all non-excepted files meet 85% threshold
