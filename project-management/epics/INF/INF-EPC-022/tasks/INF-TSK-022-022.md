# INF-TSK-022-022: Set up CI pipeline for Rust binary

## Description

Update `.github/workflows/test-suite.yml` to add a `test-rust` job that builds, tests, lints, and checks coverage for the Rust binary. The Go `test-go` job remains active alongside the new Rust job -- both binaries are validated in parallel during the coexistence period. The Go jobs are removed during cutover (task 025).

The Rust CI job mirrors the Go CI job structure but uses Rust-specific tooling: `cargo nextest` (parallel test runner), `cargo clippy` (linting), `cargo fmt` (formatting), and `cargo-llvm-cov` (coverage with threshold gate).

## Approach

1. Add `test-rust` job to `.github/workflows/test-suite.yml`
2. Set up Rust toolchain (`actions-rust-lang/setup-rust-toolchain`)
3. Configure cargo caching (`Swatinem/rust-cache`)
4. Add build step: `cargo build --release`
5. Add test step: `cargo nextest run`
6. Add lint step: `cargo clippy -- -D warnings`
7. Add format step: `cargo fmt --check`
8. Add coverage step: `cargo llvm-cov --fail-under 85`
9. Add conformance step: run conformance test suite
10. Add shell integration step: run bridge script
11. Ensure Go and Rust jobs run in parallel (not `needs:`)
