# INF-TSK-022-008: Set up shell integration test bridge

## Description

Create the Rust equivalent of `.codeflow/testing/cli/test-go-cli.sh` -- a bridge script that builds the Rust binary and runs the existing shell integration test suite against it. The key property: the existing ~1,555 shell tests must pass UNCHANGED against the Rust binary. These tests exercise the frozen external interface (subcommands, JSON output, exit codes).

The bridge script temporarily prepends the Rust binary location to PATH so that `codeflow` resolves to the Rust binary during the test run, then restores the original PATH afterward. This ensures no global installation of the Rust binary occurs.

Reference: `.codeflow/testing/cli/test-go-cli.sh` for the existing pattern.

## Approach

1. Read `.codeflow/testing/cli/test-go-cli.sh` for the bridge script pattern
2. Create `.codeflow/testing/cli/test-rust-cli.sh` following the same structure
3. Build step: `cd codeflow-rs && cargo build --release`
4. PATH override: `export PATH="$REPO_ROOT/codeflow-rs/target/release:$PATH"`
5. Coverage step: `cd codeflow-rs && make test-cover`
6. Source existing test framework libraries for integration test support
7. Set executable permission
8. Verify test-go-cli.sh is unchanged
