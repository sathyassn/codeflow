# INF-TSK-022-027: Final validation and cleanup

## Description

Final validation of the complete Rust CLI migration. This task verifies that every acceptance criterion in the epic is met, removes migration-specific artifacts (conformance tests that compared Go vs Rust, temporary bridges), and marks the epic as complete.

This is the last task in Epic 0. Upon completion, the repository contains a pure Rust CLI at `codeflow-cli/` with no Go dependencies, full test coverage, CI pipeline, and cross-platform release builds. Epic A (Parallel Execution Core) can then begin.

## Approach

1. Run full validation suite:
   - Shell test suite: `bash .codeflow/testing/run-all-tests.sh --mode standard`
   - Rust unit tests: `cd codeflow-cli && cargo nextest run`
   - Coverage: `cd codeflow-cli && cargo llvm-cov nextest --workspace --fail-under-lines 85`
   - Lint: `cd codeflow-cli && cargo clippy -- -D warnings`
   - Format: `cd codeflow-cli && cargo fmt --check`
   - Doctor: `codeflow doctor`
2. Remove migration artifacts:
   - Conformance test suite (compared Go vs Rust -- Go binary no longer exists)
   - Any temporary bridge scripts or compatibility shims
3. Verify no migration artifacts remain:
   - `find . -name "codeflow-rs" -o -name "test-go-cli*"` returns empty
   - `grep -r "codeflow-rs\|test-go-cli\|go.mod\|go.sum" --include="*.yml" --include="*.sh" --include="*.toml"` returns empty
   - `grep -r "unsafe\|SAFETY" codeflow-cli/` returns empty (zero unsafe blocks; any exceptions require SAFETY comment per cf-rust-standards)
4. Review epic acceptance criteria (INF-EPC-022.md) -- verify every checkbox
5. Update all 27 task documents to final status
