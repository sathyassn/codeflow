# INF-TSK-022-003: Create cf-rust-standards skill

## Description

Create the `cf-rust-standards` skill at `.claude/skills/cf-rust-standards/SKILL.md`, parallel to the existing `cf-go-standards` skill. This skill provides the authoritative reference for all Rust development within the CodeFlow project. All agents producing Rust code (cf-development, cf-quality-assurance) must follow these standards.

The skill must cover 17 areas: workspace structure, error handling, trait patterns, serde conventions, async patterns, testing conventions, naming conventions, Clippy lint config, unsafe policy, approved crate list, builder patterns, module visibility, code organization, borrow vs clone guidance, lifetime annotations, heap allocation avoidance, and `Cow<'a, str>` string handling.

Reference: `.claude/skills/cf-go-standards/SKILL.md` for format (decision tree, operations table, operation details).

## Approach

1. Read `.claude/skills/cf-go-standards/SKILL.md` for the complete skill format and structure
2. Read `.claude/skills/cf-shell-standards/SKILL.md` for additional format reference
3. Create the Rust skill with the same structure: Type, Purpose, Responsibilities, Decision Tree, Operations table, Operation Details
4. Define operations: apply-structure, apply-conventions, apply-patterns, apply-async, apply-testing, validate-crate
5. Populate each operation with Rust-specific standards, patterns, and anti-patterns
6. Include the approved crate list with version constraints and justifications
7. Include Clippy configuration with specific lint rules
