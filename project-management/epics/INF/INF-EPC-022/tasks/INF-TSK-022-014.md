# INF-TSK-022-014: Implement config, doctor, and utility modules

## Description

Port the remaining Go utility packages that don't fit into the core trait-based modules. This includes: `internal/doctor/` (infrastructure diagnostics), `internal/validate/` (markdown validation), `internal/idgen/` (ULID generation), `internal/sentinel/` (sentinel file operations), `internal/pathflow/` (checkpoint state), `internal/settings/` (settings.json handling), and other small utilities.

These modules are consolidated into fewer Rust modules based on functional cohesion. The sentinel and pathflow packages merge into a single pathflow module since they share checkpoint state management concerns.

## Approach

1. Port `internal/doctor/` -> `doctor/mod.rs` (infrastructure checks, repair)
2. Port `internal/validate/` -> `validate/mod.rs` (markdown validation)
3. Port `internal/idgen/` -> `idgen.rs` (ULID generation)
4. Port `internal/sentinel/` + `internal/pathflow/` -> `pathflow/mod.rs` (checkpoints, sentinels)
5. Port `internal/settings/` -> `settings/mod.rs` (settings.json handling)
6. Write unit tests for each module
