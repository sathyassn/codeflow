# INF-TSK-022-012: Implement worktree manager

## Description

Port the Go `internal/worktree/` package to Rust. The key improvement: git operations use the `git2` crate (libgit2 bindings) instead of shelling out to `git` via `exec.Command`. This eliminates subprocess overhead and provides type-safe git operations. Worktree states are represented as an enum instead of string-based status checks.

Per Decision #15, the worktree base directory is `.git-worktrees/` (not `.claude/worktrees/`).

## Approach

1. Create `worktree/mod.rs` with sub-modules
2. Implement git operations via `git2` crate (Repository, Worktree)
3. Port worktree registry (worktrees.yaml) management
4. Port setup and cleanup operations
5. Define `WorktreeState` enum (Active, Stale, Orphaned)
6. Write unit tests with temporary git repos

## Files

### To Create

- `codeflow-rs/codeflow-core/src/worktree/mod.rs` -- worktree module root, WorktreeManager, WorktreeState enum, public API
- `codeflow-rs/codeflow-core/src/worktree/registry.rs` -- worktrees.yaml read/write/deregister via serde_yaml
- `codeflow-rs/codeflow-core/src/worktree/setup.rs` -- worktree creation, symlinks, and local state directories
