# INF-TSK-022-021: Validate shell test suite passes

## Description

Run the full existing shell integration test suite (~1,555 tests) against the Rust binary and validate that all tests pass without modification. These tests exercise the frozen external interface (CLI subcommands, exit codes, file I/O, JSON contracts) and are the ultimate validation that the Rust binary is a drop-in replacement for Go.

The shell tests call the `codeflow` binary externally -- they do not import Go code. They should work against any binary that implements the same external interface. If any test fails, it indicates a contract violation in the Rust implementation that must be fixed before proceeding to Phase 0G cutover.

## Approach

1. Build Rust binary: `cd codeflow-rs && cargo build --release`
2. Configure bridge script (from task 008) to point to the Rust binary
3. Run full test suite: `bash .codeflow/testing/run-all-tests.sh --mode standard`
4. Capture and analyze failures
5. For each failure: identify the contract violation, fix in `codeflow-core`, re-run
6. Iterate until all tests pass
7. Run with `--mode extended` to include slow tests
8. Generate final test report
