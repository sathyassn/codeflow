# INF-TSK-022-021: Pre-cutover Rust binary validation

## Description

Validates the Rust binary as a drop-in replacement for Go before cutover. This task has two parts:

**Part A — Fix 3 remaining Rust stub handlers** so conformance reaches 93/93 (zero ignored tests):

1. `session-start init` — must output JSON env vars to stdout (Go: `internal/hooks/session/start.go` `StartInit`; Rust: `codeflow-rs/codeflow-core/src/hooks/session_start.rs` `SessionStartInit`)
2. `session-start instructions` — must output instruction text to stdout (Go: `internal/hooks/session/instructions.go` `RunInstructions`; Rust: `codeflow-rs/codeflow-core/src/hooks/session_start.rs` `SessionStartInstructions`)
3. `user-prompt-submit validate` — must output context reminders to stderr (Go: `codeflow-cli/internal/hooks/prompt/validate.go` `PromptValidator.Validate`; Rust stub currently produces no output)

**Part B — Run the full test suite with the Rust binary on PATH** to verify zero regressions.

### Test landscape (post-INF-EPC-021)

INF-EPC-021 retired ~24,000 lines of shell hooks and replaced all Claude hook implementations with Go. As a result:

- **Shell tests (~206 assertions across 14 scripts)** test: git hook wrappers (commit-msg, pre-commit, pre-push), protection scripts, and config consistency. They do NOT test Claude hook behavior.
- **Go unit tests (~3,722)** test Go packages via import — they cannot run against the Rust binary.
- **Rust unit tests (~1,207)** exist and pass already.
- **Conformance tests (90 tests + 3 ignored stubs)** are the primary Go-vs-Rust behavioral comparison. Only 5 shell test scripts invoke the `codeflow` binary directly (via `GO_BIN="codeflow"` from PATH).

This task completes the conformance (fixing 3 stubs) and validates the full test infrastructure works with the Rust binary.

## Approach

1. Fix `SessionStartInit` to output JSON env vars to stdout matching Go's `StartInit` output format
2. Fix `SessionStartInstructions` to output instruction text to stdout matching Go's `RunInstructions` output
3. Fix `UserPromptSubmitValidate` to output context reminders to stderr matching Go's `PromptValidator.Validate`
4. Write inline tests for each fix in the same source file (`#[cfg(test)] mod tests`) per cf-rust-standards — do NOT create separate test files
5. Remove conformance `#[ignore]` markers and verify all 93 conformance tests pass (0 ignored)
6. Build Rust binary: `cd codeflow-rs && cargo build --release`
7. Swap binary on PATH: `export PATH="$(pwd)/codeflow-rs/target/release:$PATH"`
8. Run full test suite: `bash .codeflow/testing/run-all-tests.sh --mode full`
9. For each failure: identify contract violation, fix in `codeflow-core` or `codeflow-cli`, add inline tests
10. Verify `codeflow test` self-orchestration works from Rust binary
11. Any Rust file receiving real implementation must have its coverage exception removed from `codeflow-rs/config/testing/test-config.json` and meet the 85% per-file threshold
12. `cargo clippy -- -D warnings` and `cargo fmt --check` must pass
