# INF-TSK-022-006: Define core types and error domains

## Description

Define the foundational domain type system for the Rust CLI. This is the most critical design task -- every subsequent module depends on these types. The Rust implementation is an **idiomatic redesign**, not a mechanical port: raw strings are replaced with newtype wrappers, categorical values become enums, and state machines use sum types with exhaustive pattern matching.

**Newtype wrappers** prevent ID confusion at compile time: `SessionId`, `TaskId`, `EpicId` are distinct types -- passing a `TaskId` where a `SessionId` is expected is a compile error. Go uses bare `string` for all IDs, leading to runtime bugs when IDs are mixed up.

**Categorical enums** replace Go's stringly-typed constants: `WorkType`, `AreaType`, `HookEvent`, `PipelineType`, `TaskStatus`, `EpicStatus`, `DomainType`, `DecisionTier`. Adding a new variant to an enum triggers compiler errors at every `match` site, ensuring all code paths are updated.

**`From`/`TryFrom` traits** provide idiomatic type conversions: `TryFrom<&str>` for parsing strings from external input (JSON, CLI args), `From<T>` for infallible conversions between related types.

The `LedgerEvent` tagged union uses serde's `#[serde(tag = "event")]` attribute to deserialize JSON events into strongly typed variants based on the `event` field. This eliminates the manual JSON parsing and validation currently done in Go's `schema.go`.

Error types use `thiserror` for compile-time error message generation and automatic `Display` impl. Each domain gets its own error enum. `anyhow` is used ONLY at the CLI binary boundary (`codeflow-cli/src/main.rs`), never in `codeflow-core`.

1. Create `codeflow-rs/codeflow-core/src/types/mod.rs` with module declarations and re-exports

## Notes

The `LedgerEvent` serde tagged union must handle both the canonical schema AND legacy formats identified in `schema-standardization.md`. Use `#[serde(alias = "...")]` for backward-compatible deserialization of non-canonical event names. The phase transition validation method prevents invalid state machine transitions at runtime.

**Rust-idiomatic design principles for this task:**
- No bare `String` in any public API signature -- use newtype wrappers for IDs and `BranchName`
- No stringly-typed categorical values -- use enums with exhaustive `match`
- `From`/`TryFrom` for all conversions instead of ad-hoc string parsing functions
- `Option<T>` for nullable fields instead of Go's zero-value patterns
- `#[must_use]` on conversion methods that return `Result`
- Derive macros for repetitive trait implementations (serde, Display, FromStr)

Reference: Go's stringly-typed patterns to replace include `session.go` status strings, `hooks.go` event name strings, `workgraph.go` status strings, `pathflow.go` phase strings.
