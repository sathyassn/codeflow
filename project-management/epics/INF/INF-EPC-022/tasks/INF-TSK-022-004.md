# INF-TSK-022-004: Configure MCP servers and create cf-surrealdb-standards skill

## Description

Two deliverables in this task:

1. **MCP Configuration**: Add Context7 and rust-analyzer MCP servers to the development environment. Context7 provides up-to-date crate documentation for `surrealdb`, `loro`, `clap`, `tokio`, `serde`, `thiserror`, `anyhow`, `git2`, `ort`, `proptest`, `insta`, and `cargo-nextest`. rust-analyzer MCP bridges Claude with rust-analyzer for type info, trait resolution, and diagnostics. Neither MCP connects directly to the project SurrealDB instance.

2. **cf-surrealdb-standards skill**: Create a SurrealDB-specific development standards skill covering embedded mode patterns, SurrealQL conventions, graph relations, vector indices, schema migration, connection management, testing patterns, and data model conventions.

## Approach

1. Run `claude mcp add context7 -- npx -y @upstash/context7-mcp@latest`
2. Run `claude mcp add rust-analyzer -- npx -y rust-analyzer-mcp`
3. Verify both MCPs respond correctly
4. Read `.claude/skills/cf-go-standards/SKILL.md` for skill format reference
5. Create `cf-surrealdb-standards` skill covering all 8 areas
6. Document the explicit anti-pattern: no direct SurrealDB MCP connection to project DB

## Post-Completion Findings

### Post-Completion Findings (2026-03-08)

**Issue discovered during INF-TSK-022-005 session:**

Criteria 2 (rust-analyzer MCP configured) and 3 (both MCPs respond correctly) were marked PASS during REV based on config entry presence in `~/.claude.json`, but:

1. **rust-analyzer binary was NOT installed** — `rustup component add rust-analyzer` had never been run. The `rust-analyzer-mcp` npm wrapper depends on this binary and would fail at startup.
2. **rust-analyzer-mcp is redundant** — Claude Code has a built-in `rust-analyzer-lsp` plugin (at `~/.claude/plugins/.../rust-analyzer-lsp/`) that provides LSP tool integration directly. The MCP wrapper is unnecessary.
3. **No active MCP config found** — `~/.claude.json` mcpServers was empty. The `rust-analyzer-mcp` entry referenced in the REV report was either never successfully added or was subsequently removed.

**Resolution:**
- Installed `rust-analyzer` binary via `rustup component add rust-analyzer` (v1.94.0)
- LSP functionality now available via built-in plugin — no MCP wrapper needed
- Criteria 2 status corrected: the MCP wrapper approach was superseded by the built-in LSP plugin
- Criteria 3 QA gap: runtime testing of MCP servers should have been performed, not just config presence check
