# INF-TSK-022-004: Configure MCP servers and create cf-surrealdb-standards skill

## Description

Two deliverables in this task:

1. **MCP Configuration**: Add Context7 and rust-analyzer MCP servers to the development environment. Context7 provides up-to-date crate documentation for `surrealdb`, `loro`, `clap`, `tokio`, `serde`, `thiserror`, `anyhow`, `git2`, `ort`, `proptest`, `insta`, and `cargo-nextest`. rust-analyzer MCP bridges Claude with rust-analyzer for type info, trait resolution, and diagnostics. Neither MCP connects directly to the project SurrealDB instance.

2. **cf-surrealdb-standards skill**: Create a SurrealDB-specific development standards skill covering embedded mode patterns, SurrealQL conventions, graph relations, vector indices, schema migration, connection management, testing patterns, and data model conventions.

## Approach

1. Run `claude mcp add context7 -- npx -y @upstash/context7-mcp@latest`
2. Run `claude mcp add rust-analyzer -- npx -y rust-analyzer-mcp`
3. Verify both MCPs respond correctly
4. Read `.claude/skills/cf-go-standards/SKILL.md` for skill format reference
5. Create `cf-surrealdb-standards` skill covering all 8 areas
6. Document the explicit anti-pattern: no direct SurrealDB MCP connection to project DB
