## Description

Implement the autorun integration branch lifecycle and serialized merge queue. This task encompasses:

1. Integration branch auto-creation from batch name with ULID suffix (so each batch has its own integration branch)
2. Merge queue enforcement scoped to the target/integration branch (serialize PRs from worker branches)
3. Epic file orchestrator update — defer epic file writes to post-batch orchestrator instead of individual workers
4. Environment variable propagation: `AUTORUN_TARGET`, `AUTO_MERGE`, `EPIC_UPDATE` passed to workers
5. Batch file defaults: target branch auto-generated if absent, `auto_merge` inferred from environment
6. Agent definition updates for autorun-aware branching and PR creation (cf-git-operations.md, cf-knowledge-layer.md, CLAUDE.md)

Autorun integration branch naming convention: `autorun/{batch_name}-{last_8_chars_of_session_id}`. Workers create PRs targeting this branch. After all workers complete, the orchestrator updates epic markdown (single writer), commits reports, and creates a final PR from integration branch to main.
