# INF-TSK-022-010: Implement LedgerWriter trait and JsonlWriter

## Description

Define the `LedgerWriter` trait for append-only JSONL event logging and implement `JsonlWriter`. This is the Rust equivalent of `internal/ledger/` in the Go CLI. The `LedgerWriter` trait abstracts event persistence behind a typed interface, with `JsonlWriter` providing the concrete implementation using flock-based file locking and serde serialization.

Key improvement over Go: the `LedgerEvent` tagged union (from task 006) provides compile-time schema validation. Events that don't match any variant fail at deserialization time, eliminating the runtime `ValidateEvent()` checks in Go's `schema.go`.

Event routing: events are routed to the correct JSONL file based on their type, matching the Go `routing.go` logic (sessions.jsonl for session events, work-graph.jsonl for task/epic events, memory-events.jsonl for memory events, config.jsonl for config events).

## Approach

1. Define `LedgerWriter` trait in `traits/ledger.rs`
2. Implement `JsonlWriter` in `ledger/jsonl.rs`
3. Port flock-based locking from Go `writer.go:74-119`
4. Port event routing from Go `routing.go`
5. Use serde for serialization (replace manual JSON construction)
6. Write comprehensive unit tests for append, routing, validation, locking
