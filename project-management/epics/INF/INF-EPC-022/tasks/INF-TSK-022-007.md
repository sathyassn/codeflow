# INF-TSK-022-007: Set up Rust unit testing infrastructure

## Description

Configure the complete Rust testing infrastructure for the `codeflow-rs/` workspace. This is a Phase 0B deliverable that MUST be in place BEFORE any code migration in Phase 0C begins. The test harness includes coverage enforcement (85% threshold matching Go), property-based testing (proptest), snapshot testing (insta), and parallel execution (cargo-nextest).

The test-config.json follows the same JSON format as `codeflow-cli/config/testing/test-config.json` for consistency across the Go and Rust test suites.

## Approach

1. Add `proptest` and `insta` as dev-dependencies in `codeflow-core/Cargo.toml`
2. Install and configure `cargo-llvm-cov` for code coverage with `--fail-under 85`
3. Install and configure `cargo-nextest` for parallel test execution
4. Create `codeflow-rs/config/testing/test-config.json` with coverage threshold and business crate list
5. Update `codeflow-rs/Makefile` with `test-cover` target that enforces 85% threshold
6. Update `codeflow-rs/Makefile` with `test-race` target (uses sanitizer flags)
7. Write one proptest example: serde roundtrip for a domain type
8. Write one insta snapshot test: JSON output verification
9. Verify all infrastructure works end-to-end
