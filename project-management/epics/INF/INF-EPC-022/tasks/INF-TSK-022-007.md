# INF-TSK-022-007: Set up Rust unit testing infrastructure

## Description

Configure the Rust testing infrastructure for the `codeflow-rs/` workspace. This is a Phase 0B deliverable that MUST be in place BEFORE any code migration in Phase 0C begins. The test harness includes coverage enforcement (85% threshold), property-based testing (proptest), snapshot testing (insta), and parallel execution (cargo-nextest).

Note: proptest and insta are already configured as dev-dependencies from TSK-005. Proptest roundtrip tests already exist from TSK-006. This task focuses on the remaining infrastructure: cargo-nextest configuration, coverage tooling setup, test-config.json, and one insta snapshot test.

## Approach

1. Verify proptest and insta dev-dependencies exist (pre-configured by TSK-005)
2. Configure `cargo-llvm-cov` for code coverage with `--fail-under-lines 85`
3. Configure `cargo-nextest` with `.config/nextest.toml` for parallel test execution
4. Create `codeflow-rs/config/testing/test-config.json` with coverage threshold and business crate list
5. Verify existing proptest roundtrip tests work (pre-existing from TSK-006)
6. Write one insta snapshot test: JSON output verification for `LedgerEvent`
7. Verify all infrastructure works end-to-end: `cargo nextest run` and `cargo llvm-cov nextest --workspace --fail-under-lines 85`
