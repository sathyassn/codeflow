# INF-TSK-022-026: Update test infrastructure references

## Description

After the Go-to-Rust cutover (task 025), update all test infrastructure and documentation to reference the final Rust binary at `codeflow-cli/`. This includes the shell test bridge script, the `codeflow test` orchestrator, `codeflow doctor` diagnostics, and CLAUDE.md sections that reference the Go CLI.

The existing `test-go-cli.sh` bridge script is replaced with a Rust-specific bridge (or adapted). All Go-specific testing references (go test, make test-cover, test-race) are replaced with Rust equivalents (cargo test, cargo nextest, cargo-llvm-cov).
