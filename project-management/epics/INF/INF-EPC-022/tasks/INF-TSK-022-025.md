# INF-TSK-022-025: Cutover: Go removal and Rust installation

## Description

Execute the atomic cutover from Go to Rust. This is the point of no return -- after this task, the Go CLI no longer exists in the repository. The cutover includes: removing `codeflow-cli/` (Go), renaming `codeflow-rs/` to `codeflow-cli/`, updating all internal references, and validating the Rust binary at its final location.

This task MUST only execute after all Phase 0F testing passes (tasks 019-021). The cutover is atomic within a single PR to prevent any intermediate state where neither binary works.

## Approach

1. Pre-cutover validation: confirm all shell tests pass, conformance tests pass, CI green
2. Remove `codeflow-cli/` (Go source): go.mod, go.sum, internal/, cmd/, Makefile, .golangci.yml
3. Rename `codeflow-rs/` to `codeflow-cli/`
4. Update all references:
   - `.github/workflows/test-suite.yml` -- update paths, remove test-go job
   - Root `Makefile` (if exists) -- update build targets
   - `.codeflow/testing/cli/test-rust-cli.sh` -- update binary path
   - Documentation referencing `codeflow-rs/` or `codeflow-cli/internal/`
   - `CLAUDE.md` references to Go CLI paths
   - Agent definitions referencing Go source paths
5. Rebuild: `cd codeflow-cli && cargo build --release`
6. Install: copy binary to PATH location
7. Post-cutover validation: run full shell test suite at new location
8. Verify `codeflow doctor` works
9. Verify `codeflow test` works
10. Grep for any remaining Go references and remove

## Notes

This is the highest-risk task in the epic. The cutover must be atomic within a single PR. If anything fails after Go removal, the binary must be rebuilt from Rust source at the new `codeflow-cli/` location. There is no rollback path other than reverting the PR. Pre-cutover validation (tasks 019-021 all passing) is the safety net. The Go conformance tests (task 020) become dead code after cutover since there is no Go binary to compare against -- they can be removed or converted in task 027.

**Shell test context:** The "~1,555 shell tests" referenced in the original epic plan was a pre-Go-migration count. After INF-EPC-021 retired shell hooks, the shell test suite now contains ~206 assertions across 14 scripts testing git hook wrappers, protection scripts, and config consistency. The conformance test suite (task 020) and Rust unit tests (task 019) provide the primary behavioral validation. Task 021 is now titled "Pre-cutover Rust binary validation" and covers both the 3 stub fixes and full test suite validation.
