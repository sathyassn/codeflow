## Description

Fix worktree cleanup to actually delete directories from `.git-worktrees/` and remove `WorktreeStatus::Removed` tombstone state. Currently, cleanup marks entries as `Removed` but does not delete the actual directory on disk, leading to accumulation of orphaned directories. The `Removed` status is an unrecoverable dead-end — once set, there is no code path that handles it productively.

**Implementation Summary:**
Eliminated WorktreeStatus::Removed tombstone variant. worktrees.yaml is now a live registry: cleanup deletes entries from the array instead of marking them. Directory removal is unconditional via fs::remove_dir_all when the directory exists. Deregistration happens only after directory is confirmed gone, so failed deletions leave the entry for retry.
