# INF-TSK-035-002: fix: consolidate worktree cleanup/prune/purge into single command with liveness checks and branch safety

## Description

Consolidate the `codeflow worktree cleanup`, `codeflow worktree prune`, and `codeflow worktree purge` subcommands into a single idiomatic command. The current proliferation of similar subcommands causes confusion — users don't know which to use. Additionally, the cleanup logic lacks proper liveness checks (is the session still running?) and branch safety checks (is the branch unmerged?).

## Approach

1. Audit current `codeflow worktree` subcommands (cleanup, prune, purge) — understand what each does and where they overlap
2. Design consolidated command API with flags for force/dry-run
3. Implement liveness check: verify session PID is alive before treating worktree as stale
4. Implement branch safety: warn/block if worktree branch has unmerged commits
5. Update `session_end.rs` and `worker.rs` callers to use consolidated API
6. Update CLI help text and remove deprecated subcommand aliases
