# INF-TSK-010-003: Update pathflow-config.json and settings.json

## Description

Apply the config sweep findings from the design analysis to pathflow-config.json and register the two new checkpoint hooks in settings.json.

## Approach

### pathflow-config.json changes

1. **Remove PF1-TSK-02**: Delete the orphaned deferred placeholder task from PF1-INIT. Renumber remaining tasks. Update task_tracker.per_task.
2. **Add PF4-TSK-05 condition**: Add `"condition": "if_pipeline_includes_qa"` to PF4-TSK-05.
3. **Align max_qa_retries**: Change global `rework.max_qa_retries` from 2 to 3.
4. **Add required_tasks per phase**: Add a `required_tasks` array to each phase listing the expected PF{N}-TSK-{NN} IDs. The checkpoint hooks read this to know which tasks must complete before creating the phase sentinel.

### settings.json changes

1. Add PostToolUse hook entry for `cf-post-tool-use-phase-checkpoint.sh` matching TaskCreate
2. Add TaskCompleted hook entry for `cf-task-completed-phase-checkpoint.sh`
