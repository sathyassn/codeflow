# INF-TSK-010-002: Modify existing sentinel hook to remove phase triggers

## Description

Modify `cf-post-tool-use-pathflow-sentinel.sh` to remove the phase sentinel creation triggers (pf-1, pf-2, pf-3, pf-6). Phase sentinel creation is now handled by the checkpoint system (INF-TSK-010-001). Stage sentinel creation (ws-dev, ws-rev, ws-qa, etc.) via the STAGE-COMPLETE message pattern remains unchanged.

## Approach

1. Read the existing sentinel hook to identify all phase triggers
2. Remove the following pattern-based triggers:
   - TeamCreate --> pf-1
   - Task(cf-knowledge-layer) --> pf-2
   - git checkout -b --> pf-3
   - gh pr create --> pf-6
3. Keep the following message-based triggers:
   - STAGE-COMPLETE: WS-DEV --> ws-dev
   - STAGE-COMPLETE: WS-REV --> ws-rev
   - STAGE-COMPLETE: WS-QA --> ws-qa
   - STAGE-COMPLETE: WS-PLAN --> ws-plan
   - STAGE-COMPLETE: WS-DOCS --> ws-docs
   - STAGE-COMPLETE: WS-TEST --> ws-test
4. Verify existing stage sentinel tests still pass
