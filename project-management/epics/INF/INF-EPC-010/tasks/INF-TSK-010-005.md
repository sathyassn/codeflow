# INF-TSK-010-005: Write tests for checkpoint enforcement

## Description

Write comprehensive tests covering all aspects of the checkpoint enforcement system. Tests should cover the happy path (registration, completion, sentinel creation), edge cases (conditional tasks, dependency ordering), and failure modes (missing files, corrupted JSON, missing config).

## Approach

1. **Checkpoint initialization tests**: Verify checkpoint file created with correct structure from pathflow-config.json
2. **Registration tests**: Verify PostToolUse hook registers PF tasks, ignores non-PF tasks
3. **Completion tests**: Verify TaskCompleted hook marks tasks complete, ignores non-PF tasks
4. **Sentinel creation tests**: Verify sentinel created only when ALL phase tasks are complete
5. **Conditional task tests**: Verify skipped tasks do not block sentinel creation
6. **Dependency ordering tests**: Verify blockedBy constraints enforced (exit 2 on violation)
7. **Graceful degradation tests**: Verify missing/corrupted checkpoint blocks sentinel creation
8. **Session scoping tests**: Verify checkpoint isolation between sessions
