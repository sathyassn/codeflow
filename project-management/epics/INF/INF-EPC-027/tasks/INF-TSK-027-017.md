# INF-TSK-027-017: Change Request Integration

## Description

Implement the "Request Change" button flow that allows users to request config modifications through Claude Code. Clicking the button opens a modal dialog with a pre-filled prompt referencing the specific config file, a "Copy to Clipboard" button, and instructional text. If an active Claude Code PTY stream exists, an additional "Send to Claude Code" button appears that writes the prompt directly to the PTY stdin via the `write_stream()` Tauri command. The modal closes with a success toast notification after either action. The config view itself remains strictly read-only.

## Approach

1. Create `RequestChangeModal.svelte` component with a modal overlay and dialog
2. Generate a prompt template based on the active config file, e.g., "Please update the {config_name} configuration at {config_path}. Specifically, I want to change: [describe your change here]"
3. Render the prompt in a `<textarea>` for user editing before copying/sending
4. Implement "Copy to Clipboard" using Tauri's clipboard API (`@tauri-apps/plugin-clipboard-manager`) or `navigator.clipboard.writeText()` as fallback
5. Check for active Claude Code PTY streams via the streams store; if any active stream exists, show the "Send to Claude Code" button
6. Implement "Send to Claude Code" by calling `write_stream(stream_id, prompt_text)` Tauri command to write the prompt to the PTY stdin
7. Create a `Toast.svelte` shared component for success notifications (auto-dismiss after 3 seconds)
8. Close the modal after either action and show the success toast
9. Ensure the config view remains read-only (no direct editing of config values)
10. Write component tests for modal rendering, clipboard interaction, and prompt generation
