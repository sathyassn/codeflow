# INF-TSK-027-021: Knowledge Graph Explorer

## Description

Implement an interactive knowledge graph (KG) explorer as a sub-route under the Search tab. The explorer renders entities as nodes (16 types) and relationships as edges (18 types) in a force-directed graph using D3.js. Nodes are color-coded by entity type, edges display relationship type labels (toggleable), and users can expand nodes to load 1-hop connected entities. A right-click context menu opens a detail panel showing all entity properties. Filtering by entity and relationship types is supported via checkbox controls. A search input highlights matching nodes in the graph.

Data is sourced from the daemon SurrealDB via `get_kg_entities()` and `get_kg_relationships()` Tauri commands. This task depends on Epic C (Global Intelligence Layer) Phase C3-C4 for the KG storage and query infrastructure.

## Approach

1. Create the SvelteKit route at `src/routes/search/kg/+page.svelte` as a sub-route under the Search tab
2. Create the `KnowledgeGraphExplorer.svelte` component wrapping a D3.js force-directed graph
3. Add `get_kg_entities(filters)` and `get_kg_relationships(entity_ids)` Tauri commands in `src-tauri/src/commands/search.rs`
4. Initialize the graph with a seed set of entities (e.g., top-level entities or user-selected starting point)
5. Apply node styling: color by entity type using a 16-color palette, with a legend showing type-to-color mapping
6. Render edges as directed lines with relationship type labels; add a toggle to show/hide edge labels (labels can cause visual clutter)
7. Implement node expansion: on click, load 1-hop connected entities via `get_kg_relationships(clicked_entity_id)`, add new nodes and edges to the graph, and re-run the force simulation
8. Implement right-click context menu that opens a detail panel (side drawer) showing all entity properties in a key-value table
9. Add entity type filter checkboxes (16 types) and relationship type filter checkboxes (18 types) in a collapsible sidebar
10. Add a search input that highlights matching nodes by name or property (matching nodes get a glowing ring, non-matching nodes become semi-transparent)
11. Implement zoom, pan, and node drag using D3's `d3.zoom()` and `d3.drag()` behaviors
12. Tune force simulation parameters for stabilization within 2 seconds for 100 nodes
13. Write component tests with mock entity/relationship data and interaction tests
