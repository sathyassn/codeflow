# INF-TSK-027-010: Stream Controls (Pause/Resume, Search, Copy)

## Description

Implement stream controls for the terminal view: pause/resume output rendering, terminal search (using xterm.js Search addon), text copy, scrollback clear, stream stop (kill), and stream restart. Controls appear in the stream header action bar. Keyboard shortcuts provide quick access to common operations.

## Approach

1. Create `src/lib/components/terminal/StreamControls.svelte`:
   - Props: `streamId: StreamId`, `terminal: Terminal` (xterm.js instance), `config: StreamConfig`, `isPaused: boolean`
   - Action buttons (left to right):
     - Pause/Resume toggle: pause icon when running, play icon when paused
     - Search: magnifying glass icon, opens inline search bar
     - Copy: clipboard icon, copies terminal selection
     - Clear: eraser icon, clears scrollback
     - Stop: square icon, kills stream (red when active)
     - Restart: refresh icon, kills + respawns
     - Raw/Rich toggle: toggle switch (disabled, grayed out for future implementation)
   - All buttons disabled when `streamId` is null (no active stream)
2. Implement Pause/Resume:
   - Pause: set `isPaused = true`, buffer incoming `stream_output` events without writing to terminal
   - Resume: set `isPaused = false`, flush buffered events to terminal in order
   - Buffer uses a simple array: `pauseBuffer: Uint8Array[]`
   - Visual indicator: pulsing yellow dot in header when paused
3. Implement Search via xterm.js Search addon:
   - Load `@xterm/addon-search` in TerminalView
   - Toggle search bar: `Cmd+F` or search button click
   - Search bar: text input with next/prev buttons and close button
   - `searchAddon.findNext(query)` on Enter or next button
   - `searchAddon.findPrevious(query)` on Shift+Enter or prev button
   - Highlights matches in terminal
   - Close search: Escape key or close button
4. Implement Copy:
   - `Cmd+C`: if terminal has selection, copy to clipboard via `navigator.clipboard.writeText(terminal.getSelection())`
   - If no selection, pass Cmd+C through to PTY (SIGINT behavior)
   - Copy button always copies current selection
5. Implement Clear:
   - `Cmd+K`: clear terminal scrollback via `terminal.clear()`
   - Does NOT kill the PTY process — only clears the visual buffer
6. Implement Stop:
   - Click Stop button: show confirmation dialog "Kill this stream?"
   - On confirm: call `killStream(streamId)`
   - Stream tab updates to show "Killed" status
7. Implement Restart:
   - Click Restart button: kill current stream, then spawn new stream with same `config`
   - New StreamId generated, same tab position
   - Scrollback reset
8. Raw/Rich toggle:
   - Present in UI but disabled (grayed out, tooltip: "Coming soon")
   - Placeholder for future rich markdown rendering vs raw terminal output
9. Wire keyboard shortcuts in TerminalView:
   - `Cmd+F`: toggle search bar
   - `Cmd+C`: copy selection (or pass SIGINT if no selection)
   - `Cmd+K`: clear scrollback
   - Prevent default browser behavior for these shortcuts when terminal is focused
10. Integrate StreamControls into StreamHeader:
    - Render StreamControls component in the right side of StreamHeader

## Notes

- Cmd+C behavior must distinguish between "copy selection" and "send SIGINT": if terminal has a selection, copy it; otherwise, forward the keystroke to the PTY as SIGINT (Ctrl+C).
- The pause buffer should have a maximum size (e.g., 10MB) to prevent memory exhaustion if the stream produces output faster than it can be consumed after resume.
- The Search addon's `findNext`/`findPrevious` methods highlight matches within the current scrollback. Search does not query the backend or filter output.
- Clear (Cmd+K) matches the standard terminal shortcut. It calls `terminal.clear()` which removes scrollback but keeps the current viewport.
- The Raw/Rich toggle is a deferred feature — the toggle UI exists but does nothing. This avoids feature scope creep while establishing the UI pattern.
