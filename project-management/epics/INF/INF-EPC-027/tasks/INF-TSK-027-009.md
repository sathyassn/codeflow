# INF-TSK-027-009: Sub-Stream Inline Embedding

## Description

Implement delegation detection and sub-stream inline embedding within the parent terminal view. When the PTY output of a parent stream contains delegation markers (indicating a model CLI has spawned a sub-agent or delegated to another model), the app detects this pattern, emits a `SubStreamDetected` event, and renders a collapsible inline panel within the parent terminal showing the delegated model's output in real-time. This provides visibility into the multi-model delegation chain without switching tabs.

## Approach

1. Define delegation marker patterns in `src-tauri/src/pty/bridge.rs`:
   - Pattern-match common delegation markers in PTY output:
     - `[DELEGATING to {model_name}]` -- generic delegation marker
     - `[DELEGATION COMPLETE]` -- delegation end marker
     - tmux session spawn patterns (model-{ulid} naming from Epic D)
   - When detected, emit `AppEvent::SubStreamDetected { parent_id, child_id, model, stage }`
   - Track sub-stream association in `PtySession`: `sub_streams: Vec<StreamId>`
2. Create `src/lib/components/terminal/SubStreamPanel.svelte`:
   - Props: `parentStreamId: StreamId`, `childStreamId: StreamId`, `model: string`, `stage: string`
   - Header bar:
     - Chevron icon (toggles collapse)
     - Model name badge (e.g., "Codex CLI")
     - Stage label (e.g., "WS-DEV")
     - Status dot (running/completed)
   - Body:
     - Mini terminal view (xterm.js instance, smaller font, reduced scrollback 1000 lines)
     - Subscribe to `stream_output` events filtered by `childStreamId`
   - Styling:
     - Darker background than parent (`--bg-tertiary`)
     - Left border accent (2px `--accent-primary`)
     - Rounded corners
     - Indented from parent terminal content
3. Implement collapsible behavior:
   - Click chevron or header to toggle body visibility
   - Smooth height animation via CSS `transition: max-height`
   - Default: expanded when first detected, collapsed after completion
4. Handle multiple concurrent sub-streams:
   - Each `SubStreamPanel` is independent
   - Rendered in order of detection within the parent terminal area
   - Stacked vertically below the parent terminal output
5. Sub-stream lifecycle:
   - Created when `SubStreamDetected` event received
   - Active while child stream is running
   - Completed when child stream ends (status dot changes to green/gray)
   - Remains visible (collapsed) after completion for reference
6. Wire sub-stream detection into existing `TerminalView`:
   - Listen for `SubStreamDetected` events matching parent stream
   - Render `SubStreamPanel` components below terminal
   - Maintain list of sub-streams in component state

## Notes

- Delegation detection is heuristic-based — the patterns depend on how model CLIs signal delegation. The initial implementation should support the most common patterns and be extensible.
- Sub-stream xterm.js instances use reduced scrollback (1000 lines vs 10,000 for parent) to limit memory usage when multiple sub-streams are active.
- The CSS `max-height` transition for collapse/expand is preferred over JavaScript animation for 60fps smoothness.
- Sub-streams that complete should auto-collapse after a brief delay (e.g., 3 seconds) to reduce visual clutter while preserving access to the output.
- The parent-child stream relationship is tracked in both the Rust backend (PtySession.sub_streams) and the frontend (TerminalView component state).
