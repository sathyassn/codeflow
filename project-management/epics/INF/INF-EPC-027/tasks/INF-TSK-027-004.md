# INF-TSK-027-004: App Shell, Navigation, and Theme System

## Description

Implement the app shell layout consisting of a sidebar (240px fixed width), main content area with tab bar, and status bar (22px). Build the tab system with `AppTab` enum routing to the 6 primary views. Define the design system CSS variables for the complete visual theme. Implement dark mode as default with light mode via `prefers-color-scheme`. Add status bar with daemon connection indicator, project name, and session count. Implement keyboard shortcuts (Cmd+1-6) for tab switching. Create native menu bar with standard macOS/Linux items. Use Svelte 5 runes for all reactive state.

## Approach

1. Define design system CSS variables in `app.css` `:root`:
   - Backgrounds: `--bg-primary: #1a1a2e`, `--bg-secondary: #16213e`, `--bg-tertiary: #0f3460`
   - Text: `--text-primary: #e4e4e7`, `--text-secondary: #a1a1aa`, `--text-muted: #71717a`
   - Accent: `--accent-primary: #3b82f6`, `--accent-success: #22c55e`, `--accent-warning: #f59e0b`, `--accent-error: #ef4444`
   - Status: `--status-active: #22c55e`, `--status-busy: #f59e0b`, `--status-inactive: #71717a`, `--status-error: #ef4444`
   - Borders, shadows, spacing, font sizes, transitions
   - `@media (prefers-color-scheme: light)` overrides for light mode
2. Create `AppTab` type in `src/lib/stores/navigation.ts`:
   - Values: `"terminal"`, `"tasks"`, `"pathflow"`, `"config"`, `"search"`, `"analytics"`
   - `activeTab` store using Svelte 5 `$state` rune
   - Tab metadata: label, icon, keyboard shortcut
3. Create `src/lib/components/layout/AppShell.svelte`:
   - CSS Grid layout: sidebar (240px) | main (1fr), with status bar at bottom (22px)
   - Render `<Sidebar />` in left column, `<TabBar />` + `<slot />` in main column
4. Create `src/lib/components/layout/TabBar.svelte`:
   - Horizontal tab strip with 6 tabs
   - Active tab: blue top border (2px `--accent-primary`), white text
   - Inactive tab: no border, muted text
   - Click handler updates `activeTab` store
5. Create `src/lib/components/layout/StatusBar.svelte`:
   - Height 22px, fixed at bottom
   - Left: daemon status dot (green/red) + connection text
   - Center: project name (from `projects` store)
   - Right: session count badge
   - Subscribe to `daemonStatus` store from Task 003
6. Create `src/lib/stores/theme.ts`:
   - `theme` store: `"dark" | "light" | "system"`
   - Default: `"system"` (respects `prefers-color-scheme`)
   - Apply `data-theme` attribute to `<html>` element
7. Implement keyboard shortcuts in `+layout.svelte`:
   - Cmd+1 through Cmd+6: switch to corresponding tab
   - Prevent default browser behavior for these shortcuts
   - Use `$effect` rune for event listener lifecycle
8. Create native menu bar in `src-tauri/src/main.rs`:
   - File: Quit (Cmd+Q)
   - Edit: Cut, Copy, Paste, Select All (standard shortcuts)
   - View: tab navigation items
   - Window: Minimize, Zoom, Close
   - Help: About CodeFlow
9. Update `src/routes/+layout.svelte` to use `<AppShell>` wrapper with tab-based content routing
10. Create `src/routes/+page.svelte` with conditional rendering based on `activeTab`:
    - Each tab renders a placeholder component (actual implementations in later tasks)
    - Placeholder shows tab name and "Coming soon" message

## Notes

- Svelte 5 runes: use `$state` for reactive variables, `$derived` for computed values, `$effect` for side effects. Do NOT use legacy `$:` reactive declarations.
- Tab transitions should use CSS `transition` on border/background properties, not JavaScript animation, to ensure 60fps.
- The 6 tabs are: Terminal, Tasks, PathFlow, Config, Search, Analytics. These map to the 6 primary views of the app.
- Native menu bar uses Tauri's `Menu` API (v2). On macOS, this replaces the default menu; on Linux, it integrates with the window manager.
- Status bar height is 22px to match macOS system status bars — small but readable.
