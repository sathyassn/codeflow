# INF-TSK-027-024: End-to-End Integration Test Suite

## Description

Implement a comprehensive integration test suite for the CodeFlow App covering all layers: Rust backend unit tests (>=85% coverage), Rust integration tests (PTY lifecycle, daemon IPC, config parsing, file watcher), SvelteKit frontend component tests (all major Svelte components), frontend store tests with mock Tauri API, and end-to-end tests via `tauri-driver` (app launch, daemon connection, stream lifecycle, tab navigation).

Additionally, enforce quality gates: `cargo clippy -p codeflow-app -- -D warnings` must pass with zero warnings, `npm run check` must pass TypeScript strict mode, `npm run lint` must pass ESLint with zero errors, `proptest` roundtrip tests for all newtype wrappers, and `insta` snapshot tests for config parsing output.

This is the testing task for the entire epic -- it validates that all previously implemented features work correctly together.

## Approach

1. **Rust backend unit tests:**
   - Write unit tests for each Tauri command module: streams, tasks, config, search, analytics, files
   - Test each command's happy path, error paths, and edge cases
   - Use `mockall` or manual mocks for daemon IPC calls
   - Target >=85% code coverage measured via `cargo llvm-cov`

2. **Rust integration tests:**
   - PTY lifecycle test: spawn a PTY, write input, read output, kill process, verify cleanup
   - Daemon IPC test: connect to daemon, send health check, receive response
   - Config parsing test: parse each of the 5 config file formats, verify output structure
   - File watcher test: modify a file externally, verify event is emitted

3. **Frontend component tests:**
   - Write Vitest component tests for all major Svelte components
   - Test rendering, user interactions (click, input, toggle), and reactive updates
   - Mock Tauri API calls using `@tauri-apps/api/core` mock
   - Cover: Sidebar, StreamViewer, TabBar, KanbanBoard, TaskDetail, ConfigViewer, SearchResults, DependencyGraph, AnalyticsDashboard, PlaygroundSidebar

4. **Frontend store tests:**
   - Test Svelte stores (streams, tasks, config, search) with mock Tauri API responses
   - Verify reactive updates propagate correctly
   - Test error state handling in stores

5. **E2E tests via tauri-driver:**
   - App launches and renders the main window
   - Connects to daemon (or shows connection error gracefully)
   - Shows project list in sidebar
   - Spawn a stream, verify output appears, kill the stream
   - Navigate through all tabs (Streams, Tasks, Config, Search, Analytics)

6. **Quality gates:**
   - `cargo clippy -p codeflow-app -- -D warnings` -- zero warnings
   - `npm run check` -- TypeScript strict mode passes
   - `npm run lint` -- ESLint zero errors
   - `proptest` roundtrip tests for AppStreamId, ProjectId, and other newtype wrappers
   - `insta` snapshot tests for config parsing output of all 5 config files

7. **CI integration:**
   - Add test jobs to `.github/workflows/` for Rust tests, frontend tests, and E2E tests
   - Configure coverage reporting and quality gate checks
