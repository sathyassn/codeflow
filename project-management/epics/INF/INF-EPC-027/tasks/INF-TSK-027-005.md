# INF-TSK-027-005: Multi-Project Sidebar and Session Navigator

## Description

Implement the sidebar project tree with expandable accordions showing registered projects and their sessions. Each session displays a status dot, branch name, PathFlow phase badge, and work type badge. The sidebar includes a playground section with launcher items. Project list data comes from the daemon via the `DaemonConnection`. Sessions are sorted with active sessions first, then by recency.

## Approach

1. Create `src/lib/stores/projects.ts`:
   - `projects` store: `$state<ProjectInfo[]>([])` -- list of registered projects
   - `selectedProject` store: `$state<ProjectInfo | null>(null)` -- currently selected project
   - `selectedSession` store: `$state<SessionInfo | null>(null)` -- currently selected session
   - `loadProjects()` function: invokes `get_projects` Tauri command, updates store
   - `loadSessions(projectPath)` function: invokes `get_project_sessions`, updates project sessions
   - Auto-refresh on daemon reconnection (subscribe to `daemonStatus` store)
2. Create `src/lib/components/badges/PhaseBadge.svelte`:
   - Renders PathFlow phase abbreviation (PF1-PF7) with color coding
   - PF1-PF3: gray (setup), PF4: blue (active), PF5-PF6: green (completing), PF7: dim (ended)
3. Create `src/lib/components/badges/WorkTypeBadge.svelte`:
   - Renders work type with color: FEAT=blue, FIX=red, RFCT=purple, DOCS=teal, TEST=amber, PLAN=indigo, CICD=orange, CHOR=gray, HTFX=crimson, SPKE=cyan
   - Small pill shape with abbreviation text
4. Create `src/lib/components/badges/StatusDot.svelte`:
   - Small circle (8px) with color based on status
   - Green (active/connected), yellow (busy), gray (inactive/ended), red (error/disconnected)
5. Create `src/lib/components/layout/Sidebar.svelte`:
   - Fixed width 240px, full height minus status bar
   - Header: "Projects" with reload button
   - Project accordions: chevron + project name + status dot
   - Expanded: list of sessions with indent
   - Each session row: status dot, branch name (truncated), phase badge, work type badge
   - Active session: left blue border (2px `--accent-primary`)
   - Click handler: update `selectedSession` store
   - Playground section at bottom: "Playground" header with "+" button
   - Scrollable when content exceeds viewport (`overflow-y: auto`)
6. Implement session sorting:
   - Active sessions first (status = "in_progress")
   - Then by recency (`started_at` descending)
7. Wire sidebar into `AppShell.svelte` sidebar slot
8. Load projects on app startup via `$effect` in `+layout.svelte`
