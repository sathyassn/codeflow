# INF-TSK-027-001: Tauri v2 + SvelteKit Project Scaffold

## Description

Initialize the `codeflow-app/` directory with a Tauri v2 + SvelteKit scaffold. Configure workspace integration so `codeflow-app/src-tauri/` is a Cargo workspace member alongside `codeflow-core` and `codeflow-cli`. Set up the build pipeline (`cargo build` for Rust backend, `vite build` for frontend, `tauri build` for bundled binary). Configure the static adapter for SvelteKit (no SSR). Set up TypeScript strict mode, ESLint, Prettier. Create the Tauri v2 config (`tauri.conf.json`) with window settings (title, size, resizable, decorations), app identifier, and bundle configuration. Ensure `cargo build` from workspace root includes the app crate. Set up dev script for hot-reload development (`tauri dev`).

## Approach

1. Create `codeflow-app/` directory structure:
   - `src-tauri/` for Rust backend with `Cargo.toml`, `src/main.rs`, `tauri.conf.json`
   - `src/` for SvelteKit frontend with `routes/`, `lib/`, `app.html`, `app.css`
   - `package.json` with Tauri v2, SvelteKit, and dev dependencies
2. Add `codeflow-app/src-tauri` to root `Cargo.toml` workspace members list
3. Configure `codeflow-app/src-tauri/Cargo.toml` with `codeflow-core` as workspace dependency
4. Create `tauri.conf.json` with:
   - Window: title "CodeFlow", width 1280, height 800, resizable true, decorations true
   - App identifier: `com.codeflow.app`
   - Bundle: macOS .dmg, Linux .AppImage/.deb
5. Configure SvelteKit:
   - `svelte.config.js` with `@sveltejs/adapter-static`, `prerender: { default: false }`, `ssr: false`
   - `vite.config.ts` with Tauri internal host configuration
6. Set up TypeScript strict mode in `tsconfig.json`
7. Configure ESLint (`eslint.config.js`) and Prettier (`.prettierrc`)
8. Create minimal `src/routes/+layout.svelte` and `src/routes/+page.svelte` with "CodeFlow" placeholder
9. Create minimal `src-tauri/src/main.rs` with Tauri app builder, empty command list
10. Add `npm run dev` script that runs `tauri dev` for hot-reload development
11. Add `npm run build` script that runs `tauri build` for production bundle
12. Verify `cargo build -p codeflow-app` compiles from workspace root
13. Verify `npm run build` from `codeflow-app/` produces bundled binary

## Notes

- Tauri v2 uses the `tauri` crate (not `tauri` v1). The `#[tauri::command]` macro syntax is the same.
- SvelteKit static adapter with `ssr: false` generates a pure client-side SPA suitable for Tauri.
- The `codeflow-core` dependency gives access to all shared types, traits, and utilities from the workspace.
- Window size 1280x800 is a reasonable default for a developer tool; minimum size should be enforced.
- The build.rs file is required by Tauri to generate the resource bindings.
