## Description

Replace the broken `lead_pid` liveness check (which uses `kill(pid, 0)` — unreliable due to PID reuse) with a heartbeat-based session detection mechanism. Also add the missing autorun `batches/` and `local/` directory structure that the autorun subsystem expects on startup.

## Approach

1. Identify where lead_pid liveness check occurs in worktree session detection
2. Design heartbeat file mechanism (write path, staleness threshold)
3. Implement heartbeat writer in session start path
4. Replace kill(lead_pid, 0) with heartbeat file recency check
5. Add autorun batches/ and local/ directory creation to session setup
