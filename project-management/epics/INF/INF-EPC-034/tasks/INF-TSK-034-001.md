## Description

Addresses the remaining worktree path resolution architecture gaps and autorun subsystem issues identified after PR #230. The core problem is that `detect_project_dir()` uses a shared env file fallback that creates race conditions in parallel worktree sessions. This task implements per-PID env files as the fix and delivers related autorun fixes.

## Approach

1. Implement per-PID env file write in `session/env.rs` (write `codeflow-env-{pid}.sh` alongside `codeflow-env.sh`)

3. Export `CLAUDE_ENV_FILE` in SessionStart hook pointing to per-PID file

## Notes

Per-PID env file approach: `codeflow-env-{pid}.sh` is written to `.state/runtime/` by SessionStart. `detect_project_dir()` checks for this file using the current process PID before falling back to the shared `codeflow-env.sh`. This eliminates the race condition in parallel worktree sessions where multiple sessions share the same fallback file path.
