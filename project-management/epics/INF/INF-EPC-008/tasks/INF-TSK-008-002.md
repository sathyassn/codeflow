# INF-TSK-008-002: Schema changes: status-removed status + deprecate auto_commit

## Description

Add `status-removed` as a valid task status to the SQLite schema. SQLite does not support altering CHECK constraints in place, so the migration must recreate the tasks table with the updated constraint. Also add a deprecation comment to the `auto_commit` column.

## Approach

1. Create migration file `002_add_status-removed_status.sql`
2. In migration: BEGIN TRANSACTION; CREATE tasks_new with updated CHECK; INSERT INTO tasks_new SELECT * FROM tasks; DROP TABLE tasks; ALTER TABLE tasks_new RENAME TO tasks; recreate all indexes; COMMIT
3. Update `schema.sql` to reflect the new CHECK constraint inline
4. Add deprecation comment to `auto_commit` column in schema.sql
5. Update schema version to 1.2.0

### To Modify
