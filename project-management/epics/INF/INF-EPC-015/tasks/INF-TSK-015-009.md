# INF-TSK-015-009: Init command (project wizard)

## Description

Implement the project initialization wizard that sets up a CodeFlow project. Supports three flows: new project (creates all directories and initializes DB), existing project (validates structure, inits DB if missing), and join project (sets up local state for a cloned repo). The wizard calls `db init` internally to create the SQLite database from the embedded schema.

## Approach

1. Create `cmd/init.go` registering the `init` cobra command
2. Implement `internal/init/wizard.go`:
   - `RunWizard()` detects project state and presents appropriate flow
   - `newProject()` -- creates .codeflow/ directory structure, .state/ directories, calls db.InitFromSchema()
   - `existingProject()` -- validates existing .codeflow/, .state/, inits DB if missing
   - `joinProject()` -- creates .state/ (gitignored), inits DB, sets up local state
   - Signal handler for Ctrl+C cleanup (remove partially-created directories)
3. Write tests using testutil.TempProject for isolated environments
