# INF-TSK-015-009: Init command (project wizard)

## Description

Implement the 7-step project initialization wizard per V4 spec. The wizard guides users through project location, prerequisite checks, Claude Code authentication, git provider setup, project configuration, CodeFlow directory/DB setup (with optional PathFlow mode), and verification. Claude Code and git provider are REQUIRED (not optional) since the CLI wraps Claude Code and needs git for branching. Handles cancellation gracefully with Ctrl+C cleanup.

## Approach

1. Create `cmd/init.go` registering the `init` cobra command
2. Implement `internal/init/wizard.go` with 7 steps:
   - **Step 1: Project location** -- choose or create directory, detect existing project
   - **Step 2: Prerequisites check** -- check git, sqlite3, Python; auto-install Claude Code if missing
   - **Step 3: Claude Code authentication** -- `claude login`, handle subscription vs API key
   - **Step 4: Git provider setup** -- detect GitHub/GitLab/Bitbucket; install `gh` if GitHub; `gh auth login`
   - **Step 5: Project configuration** -- prompt for name, description
   - **Step 6: CodeFlow setup** -- create `.codeflow/`, `.state/` dirs, call `db.InitFromSchema()`
   - **Step 6b: PathFlow mode** -- optional PathFlow configuration (default disabled)
   - **Step 7: Verification** -- run doctor health checks to validate setup
   - Signal handler for Ctrl+C cleanup (remove partially-created directories)
3. Write tests using testutil.TempProject for isolated environments
