# INF-TSK-015-002: Core CLI entry point and simple commands

## Description

Create the main entry point for the CodeFlow CLI using cobra. Implement the root command, version command (with ldflags version injection), and uninstall command. This establishes the command registration pattern used by all subsequent command tasks.

## Approach

1. Create `cmd/codeflow/main.go` with cobra root command setup
2. Create `cmd/version.go` with version command reading from `main.version` variable injected via ldflags
3. Create `cmd/uninstall.go` with uninstall command that removes `~/.local/bin/codeflow` with confirmation prompt
4. Write integration tests in `cmd/codeflow/main_test.go`
5. Verify `make build` produces binary and `make test` passes

## Files

### To Create

- `codeflow-cli/cmd/codeflow/main.go` -- Root cobra command, imports all subcommands
- `codeflow-cli/cmd/codeflow/main_test.go` -- Integration tests for CLI
- `codeflow-cli/cmd/version.go` -- Version command with ldflags injection
- `codeflow-cli/cmd/uninstall.go` -- Uninstall command

## Acceptance Criteria

1. `codeflow-cli/cmd/codeflow/main.go` defines root cobra command with Use="codeflow"
2. `go build ./cmd/codeflow/` produces binary successfully
3. `./codeflow --version` outputs version string from ldflags
4. `./codeflow --help` lists all registered subcommands
5. `codeflow-cli/cmd/version.go` injects version via `-ldflags "-X main.version=$(VERSION)"`
6. `codeflow-cli/cmd/uninstall.go` removes `~/.local/bin/codeflow` with confirmation prompt
7. `codeflow-cli/cmd/codeflow/main_test.go` has 4+ test cases: version output, help output, unknown command error, uninstall dry-run
8. Code coverage >= 85%
