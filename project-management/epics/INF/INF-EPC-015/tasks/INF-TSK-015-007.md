# INF-TSK-015-007: Welcome screen package (V3 base)

## Description

Implement the V3 base welcome screen that displays when the CodeFlow CLI launches. Uses Unicode box-drawing characters to render a structured display showing the CodeFlow version, Claude Code version, project name/status, active work (if any), and quick command hints. Gracefully degrades when project config or active work data is unavailable.

## Approach

1. Implement `internal/welcome/welcome.go`:
   - `Show()` function renders the full welcome screen
   - Read project name from `.codeflow/` config files
   - Read active work from DB (fallback to `.state/runtime/active-task.json`)
   - Detect Claude Code version from `claude --version` or similar
   - Use Unicode box-drawing characters for the frame
2. Write tests using string output capture and assertions

## Files

### To Create

- `codeflow-cli/internal/welcome/welcome.go` -- Welcome screen rendering
- `codeflow-cli/internal/welcome/welcome_test.go` -- Welcome screen tests

## Acceptance Criteria

1. `welcome.Show()` renders box-drawing welcome screen to stdout
2. Displays CodeFlow version and Claude Code version
3. Displays project name from project config
4. Displays active work (ID, title, branch) when present
5. Displays quick command hints (/cf-resume, /cf-plan)
6. Gracefully handles missing config (shows minimal display)
7. `welcome_test.go` has 6+ test cases: full display, no active work, missing config, version rendering, box-drawing correctness, output contains expected strings
8. Code coverage >= 85%
