# INF-TSK-015-003: Fix DB schema drift (migration 005)

## Description

Write migration 005 that aligns the live database with schema.sql. The schema.sql file has been updated with columns that no migration applies to existing databases. This migration fixes the drift by: (a) rebuilding epics table to add format_id column, (b) adding current_stage and team_name to active_work, (c) ensuring stage CHECK constraint on tasks, and (d) setting PRAGMA user_version=5.

## Approach

1. Analyze current live DB state vs schema.sql (see design analysis Section 4)
2. Write migration 005 in a single transaction:
   - Rebuild epics table to add `format_id TEXT UNIQUE NOT NULL` with backfill from `external_id` or `id`
   - `ALTER TABLE active_work ADD COLUMN current_stage TEXT DEFAULT NULL` with CHECK constraint
   - `ALTER TABLE active_work ADD COLUMN team_name TEXT`
   - Rebuild tasks table if stage CHECK constraint missing
   - `PRAGMA user_version = 5`
3. Test migration on fresh DB (from schema.sql) and on existing DB (with real data)
4. Write test script validating all criteria
5. Verify existing tests still pass
