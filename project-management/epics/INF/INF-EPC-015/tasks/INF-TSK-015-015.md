# INF-TSK-015-015: Doctor V4 health checks (3 new)

## Description

Add 3 new V4-specific health checks to the doctor command, bringing the total from 13 to 16. These checks are PathFlow-aware and only run when relevant context exists (pathflow-active flag, team configuration). The checks detect stuck phases, unhealthy teammates, and sentinel state drift.

## Approach

1. Modify `internal/doctor/checks.go` to add 3 new checks:
   - `pathflow-stuck` -- read pathflow-events.jsonl for latest phase_transition event, check if age > 30 minutes
   - `team-health` -- read team config, verify each member's tmux pane is alive via `tmux list-panes`
   - `sentinel-drift` -- compare sentinel files at `.state/sentinels/pathflow/{SID}/` against current phase from events
2. Add conditional execution: skip these checks when pathflow-active flag is absent or team does not exist
3. Extend `checks_test.go` with 2 test cases per new check (pass and fail scenarios)
