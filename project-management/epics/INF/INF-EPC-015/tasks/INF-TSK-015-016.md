# INF-TSK-015-016: Test infrastructure integration (bridge script + test-config + CI)

## Description

Update the existing Go CLI bridge script (`.codeflow/testing/cli/test-go-cli.sh`, 124 lines, created in an earlier task) to use the test-helpers.sh framework with coverage enforcement. The script currently works but uses inline `pass()`/`fail()` functions instead of `test_pass`/`test_fail` from test-helpers.sh, lacks `-coverprofile` flag, and has no 85% coverage threshold check.

Additionally, add a `cli-go` category to test-config.json (the script is already registered in priorities.medium but lacks a category entry), and add a Go test job to the GitHub Actions CI pipeline (`.github/workflows/test-suite.yml`) so Go tests run on every push and PR. Currently the CI workflow only has a shell/Python test job with NO Go job.

## Approach

1. Update existing `.codeflow/testing/cli/test-go-cli.sh` (NOT create -- it already exists):
   - Refactor to source `lib/test-helpers.sh` for `test_pass`/`test_fail` functions (replacing inline `pass()`/`fail()`)
   - Add `-coverprofile=coverage.out` flag to `go test` invocation
   - Add coverage percentage parsing and 85% threshold check
   - Preserve existing build smoke test and binary smoke tests (these add value)
   - Preserve existing Go-not-installed graceful skip behavior
2. Modify `.codeflow/testing/test-config.json`:
   - Add `cli-go` category entry in `categories` section with description (script is already registered in priorities.medium -- no change needed there)
3. Add `test-go` job to `.github/workflows/test-suite.yml`:
   - Use `actions/setup-go@v5` with `go-version-file: codeflow-cli/go.mod`
   - Cache Go modules via `go.sum`
   - Run `make test-cover` from `codeflow-cli/`
   - Run in parallel with existing shell/Python test job (no `needs` dependency)
4. Align `go.mod` Go version directive with actual minimum supported version
