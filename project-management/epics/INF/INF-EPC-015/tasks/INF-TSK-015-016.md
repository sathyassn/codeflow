# INF-TSK-015-016: Test infrastructure integration (bridge script + test-config)

## Description

Create the bridge between the Go CLI test suite and the existing CodeFlow test infrastructure. A shell script invokes `go test` with coverage and reports results using the existing test-helpers.sh framework. Register a new `cli-go` category in test-config.json so the Go CLI tests are discovered and run by `./codeflow test`.

## Approach

1. Create `.codeflow/testing/cli/test-go-cli.sh`:
   - Source `lib/test-helpers.sh` for `test_pass`/`test_fail` functions
   - Run `cd codeflow-cli && go test -coverprofile=coverage.out ./...`
   - Parse coverage percentage from output
   - If coverage >= 85%: `test_pass "Go CLI test coverage ${pct}%"`
   - If coverage < 85%: `test_fail "Go CLI coverage below 85% threshold: ${pct}%"`
   - Report individual test results if available
2. Modify `.codeflow/testing/test-config.json`:
   - Add `cli-go` category with description
   - Add `"cli/test-go-cli.sh"` to `priorities.medium.files` array
3. Set executable permissions on bridge script
4. Verify `./codeflow test --mode full` discovers and runs the bridge test
