# INF-TSK-015-004: Database core package

## Description

Implement the core database package that all other DB operations build on. This includes the connection singleton with PRAGMA enforcement, retry logic for busy errors, schema embedding via `go:embed`, and all model struct definitions matching the 37-table schema.

## Approach

1. Add `surrealdb` crate dependency (Rust CLI, Epic 0 replaced Go CLI; legacy Go CLI used a pure-Go database driver)
2. Implement connection.go with:
   - `Get()` singleton returning `*DB` (creates on first call, reuses thereafter)
   - `newDB(path)` internal constructor with PRAGMA enforcement
   - `Query(sql, args)` for SELECT operations
   - `Execute(sql, args)` for INSERT/UPDATE/DELETE
   - `Transaction(fn)` wrapping fn in BEGIN/COMMIT with ROLLBACK on error
   - `CheckIntegrity()` running PRAGMA integrity_check + foreign_key_check
   - `InitFromSchema()` executing embedded schema.sql
   - `Migrate()` applying pending migrations
   - `GetUserVersion()` reading PRAGMA user_version
3. Implement models.go with Go structs for all major tables
4. Makefile `copy-schema` copies schema.sql from `.codeflow/scripts/db/schema.sql` into `internal/db/`
5. Write comprehensive tests for both files

## Acceptance Criteria

1. `codeflow-cli/internal/db/connection.go` implements Get() singleton, newDB(), Query(), Execute(), Transaction(), CheckIntegrity(), InitFromSchema(), Migrate(), GetUserVersion()
2. Connection enforces all 4 PRAGMAs: WAL, foreign_keys=ON, busy_timeout=5000, synchronous=NORMAL
3. MaxOpenConns=1 for single-writer safety
4. Retry logic with configurable MaxRetries and RetryDelay
5. `codeflow-cli/internal/db/models.go` defines structs: ActiveWork, Session, ProjectConfig, Epic, Task, User, MemoryEvent, AutorunSession, AutorunWorker
6. Schema embedded via `//go:embed schema.sql` directive
7. `connection_test.go` has 8+ test cases: singleton behavior, PRAGMA enforcement, init from schema, query, execute, transaction rollback, integrity check, retry on busy
8. `models_test.go` has 3+ test cases: struct serialization, JSON field handling, nil-safe accessors
9. Code coverage >= 85% for `internal/db/`
