# INF-TSK-015-011: Config command

## Description

Implement the config management command for reading and writing CodeFlow settings. Supports list (show all), get (single key), and set (update with validation) operations. Reads from `.codeflow/config/` and `.claude/settings.json`. Validates values before writing to prevent invalid configuration.

## Approach

1. Create `cmd/config.go` registering `config` cobra command with `list`, `get`, `set` subcommands
2. Implement `internal/config/config.go`:
   - `List()` -- reads all config files, returns map of key-value pairs
   - `Get(key)` -- reads specific key with dot-notation support (e.g., `pathflow.max_rework_iterations`)
   - `Set(key, value)` -- validates and writes config value
   - Config file resolution: `.codeflow/config/{section}.json` files
3. Write tests covering happy paths and validation edge cases

## Files

### To Create

- `codeflow-cli/cmd/config.go` -- Config cobra command
- `codeflow-cli/internal/config/config.go` -- Config management logic
- `codeflow-cli/internal/config/config_test.go` -- Config tests

## Acceptance Criteria

1. `codeflow config list` displays all configuration keys and values
2. `codeflow config get <key>` returns specific configuration value
3. `codeflow config set <key> <value>` updates configuration with validation
4. Invalid values rejected with clear error message
5. `config_test.go` has 5+ test cases: list, get existing, get missing, set valid, set invalid
6. Code coverage >= 85%
