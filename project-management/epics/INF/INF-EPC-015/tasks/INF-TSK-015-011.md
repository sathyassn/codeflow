# INF-TSK-015-011: Config command

## Description

Implement the config management command for reading and writing CodeFlow settings. Supports list (show all), get (single key), and set (update with validation) operations. Reads from `.codeflow/config/` (project-local) and `~/.config/codeflow/` (global). Global config is merged with project-local, with local taking precedence. Validates values before writing to prevent invalid configuration.

## Approach

1. Create `cmd/config.go` registering `config` cobra command with `list`, `get`, `set` subcommands and `--global` flag
2. Implement `internal/config/config.go`:
   - `List(global bool)` -- reads config files, returns map of key-value pairs
   - `Get(key, global bool)` -- reads specific key with dot-notation support (e.g., `pathflow.max_rework_iterations`)
   - `Set(key, value, global bool)` -- validates and writes config value
   - Config file resolution: `.codeflow/config/{section}.json` (local) and `~/.config/codeflow/{section}.json` (global)
   - Merge strategy: global config provides defaults, project-local overrides
3. Write tests covering happy paths, validation edge cases, and global config operations

## Files

### To Create

- `codeflow-cli/cmd/config.go` -- Config cobra command
- `codeflow-cli/internal/config/config.go` -- Config management logic
- `codeflow-cli/internal/config/config_test.go` -- Config tests

## Acceptance Criteria

1. `codeflow config list` displays all configuration keys and values
2. `codeflow config get <key>` returns specific configuration value
3. `codeflow config set <key> <value>` updates configuration with validation
4. `codeflow config list --global` displays global config from `~/.config/codeflow/`
5. `codeflow config set --global <key> <value>` writes to global config
6. Invalid values rejected with clear error message
7. Global config merged with project-local config (local takes precedence)
8. `config_test.go` has 7+ test cases: list, get existing, get missing, set valid, set invalid, global list, global set
9. Code coverage >= 85%
