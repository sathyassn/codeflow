# INF-TSK-015-006: Session package and CLI commands

## Description

Implement the session management package and CLI commands. Session start generates a ULID-based session ID (`ses-{ulid}`), inserts into the sessions table, writes a canonical event to sessions.jsonl, and writes the session ID to `.state/runtime/current-session-id`. Session end updates the session record, writes an end event, and cleans up the current-session-id file.

## Approach

1. Add `oklog/ulid` dependency to go.mod for ULID generation
2. Implement `internal/session/session.go`:
   - `Start(claudeID string)` -- generate `ses-{ulid}`, INSERT, write JSONL, write current-session-id
   - `End()` -- read current-session-id, UPDATE with ended_at/duration, write JSONL, remove file
   - `Current()` -- read and return current session ID from file
3. Create `cmd/session.go` with cobra subcommands: `session start --claude-id=UUID`, `session end`
4. Write comprehensive tests covering happy paths, error paths, and edge cases

## Notes

- See `.codeflow/docs/analysis/inf-epc-015-go-cli-design.md` Section 3 (D1) for session ID format decision.
- ULID format: `ses-{ulid}` where ulid is a 26-character Crockford Base32 string, lexicographically sortable by creation time.
- The session start event must use the canonical JSONL format: `{"event":"session_start","session_id":"ses-{ulid}","timestamp":"..."}`.
- The `.state/runtime/current-session-id` file is read by shell hooks to determine the active session.
