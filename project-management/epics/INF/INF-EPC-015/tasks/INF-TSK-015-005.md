# INF-TSK-015-005: Database CLI commands (8 subcommands)

## Description

Implement all 8 `codeflow db` subcommands. The most complex is `sync`, which implements the tolerant JSONL parser that normalizes all known event variants to canonical form before rebuilding SQLite from the JSONL ledger files. This task also implements queries (JSON output), exec (parameterized writes), health checks, migration runner, backup, and version display.

## Approach

1. Create `cmd/db.go` registering 8 cobra subcommands under `codeflow db`
2. Implement `internal/db/queries.go` -- parameterized SELECT with JSON array output
3. Implement `internal/db/transactions.go` -- parameterized INSERT/UPDATE/DELETE in transactions
4. Implement `internal/db/health.go` -- integrity_check + foreign_key_check wrapper
5. Implement `internal/db/logging.go` -- DB audit/operation logging
6. Implement `internal/db/sync.go` -- tolerant JSONL parser (see design analysis D7):
   - Read all 4 JSONL files from `.state/ledger/`
   - Normalize each event to canonical form (event key, timestamp key, consistent field names)
   - Apply normalized events to rebuild SQLite tables
   - Handle all 4 structural patterns documented in D7
7. Implement `internal/db/migrate.go` -- migration runner using PRAGMA user_version
8. Write comprehensive tests for each package file (5+ test cases each)
9. sync_test.go must include test cases for all 4 JSONL variant patterns
