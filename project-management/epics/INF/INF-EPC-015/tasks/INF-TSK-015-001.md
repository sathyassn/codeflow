# INF-TSK-015-001: Go project initialization and build infrastructure

## Description

Foundation task for the Go CLI. Initialize the Go module, create the full directory structure for all internal packages, set up the Makefile with cross-compilation and coverage targets, create a testutil package with reusable test helpers, and populate test fixture directories.

## Approach

1. Run `go mod init github.com/codeflow/codeflow-cli` in `codeflow-cli/`
2. Create all internal package directories: `cmd/codeflow/`, `internal/{welcome,preflight,doctor,init,autorun,update,config,claude,db,session,testutil}/`
3. Create Makefile with targets: build, build-all, test, test-cover, test-race, lint, copy-schema, clean
4. Implement `internal/testutil/testutil.go` with TempProject (creates temp dir with .codeflow/ structure), CopyFixture (copies test fixtures), AssertNoError (test helper)
5. Write `internal/testutil/testutil_test.go` with tests for each helper
6. Create test fixture directories under `testdata/projects/{valid-project,missing-config,corrupted-db,no-claude}`, `testdata/configs/`, `testdata/batch/`
7. Verify `make test` passes

## Files

### To Create

- `codeflow-cli/go.mod` -- Go module definition
- `codeflow-cli/Makefile` -- Build, test, lint targets with cross-compilation
- `codeflow-cli/internal/testutil/testutil.go` -- Test helper functions
- `codeflow-cli/internal/testutil/testutil_test.go` -- Tests for testutil
- `codeflow-cli/testdata/projects/valid-project/.codeflow/` -- Valid project fixture
- `codeflow-cli/testdata/projects/missing-config/` -- Missing config fixture
- `codeflow-cli/testdata/projects/corrupted-db/` -- Corrupted DB fixture
- `codeflow-cli/testdata/projects/no-claude/` -- No Claude fixture
- `codeflow-cli/testdata/configs/` -- Config fixtures directory
- `codeflow-cli/testdata/batch/` -- Batch file fixtures directory
- `codeflow-cli/cmd/codeflow/` -- Main entry point directory
- All 13 `internal/` package directories

## Acceptance Criteria

1. `go mod init github.com/codeflow/codeflow-cli` succeeds, go.mod exists with Go 1.21+ version
2. All 13 internal package directories created (welcome, preflight, doctor, init, autorun, update, config, claude, db, session, testutil)
3. Makefile has targets: build, build-all (5 platforms), test, test-cover (85% threshold), test-race, lint, copy-schema, clean
4. `codeflow-cli/internal/testutil/testutil.go` provides TempProject, CopyFixture, AssertNoError functions
5. `codeflow-cli/internal/testutil/testutil_test.go` has 3+ test cases covering each helper function
6. Test fixtures exist under testdata/ with valid-project, missing-config, corrupted-db, no-claude directories
7. `make test` runs `go test ./...` and passes
8. `make test-cover` enforces 85% code coverage threshold
