# INF-TSK-015-012: Update command

## Description

Implement the CLI self-update command. Checks for newer versions against a remote source, downloads and replaces the binary atomically (write to temp file, rename over existing), and syncs .codeflow/ template files. Supports `--check` flag to check without updating.

## Approach

1. Create `cmd/update.go` registering `update` cobra command with `--check` and `--force` flags
2. Implement `internal/update/update.go`:
   - `Check()` -- compare local version against remote latest
   - `Update()` -- download new binary, atomic replacement
   - `SyncTemplates()` -- update .codeflow/ template files
   - Semver comparison using standard library or lightweight package
   - Atomic replacement: write to tempfile in same directory, then `os.Rename()`
3. Write tests covering version comparison and atomic replacement

## Files

### To Create

- `codeflow-cli/cmd/update.go` -- Update cobra command
- `codeflow-cli/internal/update/update.go` -- Update logic
- `codeflow-cli/internal/update/update_test.go` -- Update tests

## Acceptance Criteria

1. `codeflow update` checks for newer version and updates if available
2. `codeflow update --check` only checks without updating
3. `codeflow update --force` bypasses version compatibility check
4. Version comparison is semver-aware
5. Binary replacement is atomic (write temp, rename)
6. Template update syncs .codeflow/ files
7. `update_test.go` has 6+ test cases: check newer available, already latest, atomic replacement, template sync, version comparison, force bypass
8. Code coverage >= 85%

## Notes

- See `.codeflow/docs/analysis/inf-epc-015-go-cli-design.md` Section 3 (D8) for version injection.
- Spec alignment analysis: `.codeflow/docs/analysis/inf-epc-015-spec-alignment.md` (Section B5)
- Atomic binary replacement is critical: if the download fails mid-way, the existing binary must not be corrupted.
- Template sync compares local .codeflow/ files against bundled templates and updates only those that differ.
- `--force` flag bypasses version compatibility check, allowing downgrades or same-version reinstalls.
