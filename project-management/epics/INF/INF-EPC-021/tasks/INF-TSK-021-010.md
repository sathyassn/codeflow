# INF-TSK-021-010: Migrate session-start-init hook to Go binary

## Description

`cf-session-start-init.sh` (619 lines) is the largest hook script. It runs at session start to initialize all PathFlow state: session directory, pathflow-active flag, checkpoint file, session ID files, and environment setup. Currently it sources 5+ shell libraries on every invocation. The Go version consolidates all initialization into a single binary call, reducing startup latency from ~500ms to ~20ms.

## Approach

1. Create `codeflow-cli/internal/hooks/session/` package:
   - `start.go`:
     - `func StartInit(stdin io.Reader, projectDir string) error` -- main entry point, performs all steps:
       1. Parse stdin JSON to extract `session_id` (Claude's per-agent UUID) -- but use `CODEFLOW_SESSION_ID` env var as canonical session ID
       2. Create session directory: `os.MkdirAll("{projectDir}/.state/session/{SID}/pathflow/", 0755)`
       3. Create pathflow-active flag: `os.WriteFile("{sessionDir}/pathflow/is-pathflow-active", []byte("1"), 0644)`
       4. Initialize checkpoint: delegate to `pathflow.InitAllPhases(sessionDir)`
       5. Write session ID: `os.WriteFile("{projectDir}/.state/runtime/current-session-id", []byte(sessionID), 0644)`
       6. Generate `codeflow-env.sh`: write `CODEFLOW_SESSION_ID`, `CODEFLOW_PROJECT_DIR`, `CODEFLOW_STATE_DIR` exports
       7. Resume detection: if `is-pathflow-active` already exists, skip initialization, output resume info
       8. Write `session_start` event to session-events.jsonl via `ledger.AppendEvent()`
     - `func DetectResume(sessionDir string) (bool, string, error)` -- checks for existing pathflow state
   - `start_test.go`:
     - Table-driven using `t.TempDir()`: fresh session init (all files created), resume detection (flag exists), missing project dir (error), checkpoint init verification, session ID file content
2. Add CLI subcommand:
   - `codeflow hooks session-start init` -- reads stdin, runs StartInit, exits 0 or 1
3. Replace shell script:
   - `.claude/hooks/codeflow/session-start/cf-session-start-init.sh` (619 lines): `exec "$CODEFLOW_CLI" hooks session-start`
4. **settings.json hook entry change:**
   - Before: `"command": "bash \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/codeflow/session-start/cf-session-start-init.sh"`
   - After: `"command": "\"$CLAUDE_PROJECT_DIR\"/codeflow-cli/bin/codeflow hooks session-start"`

## Notes

- The SessionStart hook receives session context on stdin (session_id, tool_name, etc.).
- The existing shell script has the UUID session ID bug (uses per-agent UUID from stdin instead of CODEFLOW_SESSION_ID). The Go version MUST use CODEFLOW_SESSION_ID correctly (fixes INF-TSK-013-002 bug pattern).
- Hook output can set environment variables via JSON `{"env": {"CODEFLOW_SESSION_ID": "..."}}`.
- This is XL due to the script's size and the number of initialization steps it performs.
