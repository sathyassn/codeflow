# INF-TSK-021-020: Build Go CLI for DB migration script

## Description

This task builds the Go equivalent of the DB migration script (`migrate-to-dual-id.sh`) by adding its functionality into the Go CLI `codeflow db migrate` command. The shell script remains unchanged during this build task. The top-level `./codeflow` wrapper cutover and dead code deletion (`cf-hook-bypass.sh`, `shell-lib/index.sh`) are deferred to the dedicated cutover task (INF-TSK-021-022).

## Approach

1. Build Go equivalent of `migrate-to-dual-id.sh` (356 lines) into `codeflow db migrate`:
   - The existing `codeflow db migrate` command (from INF-EPC-015) should include the dual-ID migration as one of its migration steps
   - Add migration step in `codeflow-cli/internal/db/migrations/` that performs the same schema changes: adds `format_id` column to tasks/epics tables, backfills format IDs from existing data
