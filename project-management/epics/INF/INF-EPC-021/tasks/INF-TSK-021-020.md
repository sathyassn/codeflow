# INF-TSK-021-020: Migrate top-level codeflow wrapper and remove dead code

## Description

The top-level `./codeflow` script is a shell wrapper that dispatches to various subcommands. Once all subcommands are migrated to Go, this wrapper should simply delegate to the Go binary. Additionally, two known dead code files should be removed, and the DB migration script absorbed into the existing `codeflow db migrate` command.

## Approach

1. Update top-level `./codeflow` wrapper (277 lines):
   - Replace shell routing logic with a single delegation:

     ```bash
     #!/usr/bin/env bash
     SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
     exec "$SCRIPT_DIR/codeflow-cli/bin/codeflow" "$@"
     ```

   - All subcommands (`test`, `doctor`, `validate`, `mode`, etc.) route through Go binary
   - Preserves backward compatibility: `./codeflow test` and `./codeflow doctor` continue to work
2. Absorb `migrate-to-dual-id.sh` (356 lines) into `codeflow db migrate`:
   - The existing `codeflow db migrate` command (from INF-EPC-015) should include the dual-ID migration as one of its migration steps
   - Add migration step in `codeflow-cli/internal/db/migrations/` that performs the same schema changes: adds `format_id` column to tasks/epics tables, backfills format IDs from existing data
3. Delete dead code:
   - `.codeflow/scripts/security/enforcement/cf-hook-bypass.sh` (37 lines) -- zero callers confirmed via grep
   - `.codeflow/scripts/shell-lib/index.sh` (25 lines) -- unused module loader, concept disappears in Go
4. Verify no dangling references: `grep -r 'cf-hook-bypass' .codeflow/ .claude/` and `grep -r 'shell-lib/index' .codeflow/ .claude/`
