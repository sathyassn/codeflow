# INF-TSK-021-021: Update CLAUDE.md and agent definitions for Go CLI

## Description

**Parallel cutover task (Phase E, alongside INF-TSK-021-022).** CLAUDE.md and all 8 agent definitions contain references to shell scripts, hook paths, and shell-based workflow commands. This task updates `.claude/CLAUDE.md`, `.claude/agents/`, `.claude/skills/`, and `.claude/commands/` to reference Go binary invocations. This is a documentation task (DOCS pipeline) that ensures the team lead and all agent definitions reflect the new Go-based infrastructure.

**Must run simultaneously with INF-TSK-021-022** in the same cutover session — not after 022 completes. Both tasks target different files and can proceed in parallel: 022 handles hooks/scripts/settings, while this task handles `.claude/` documentation files.

   - Section 7 (Enforcement & Operations):
     - Update hook table: change script names to Go subcommand names (e.g., `cf-pre-tool-use-pathflow-gate.sh` -> `codeflow hooks pre-tool-use gate-check`)
     - Update "Sentinel System" subsection: reference Go checkpoint engine instead of shell scripts
     - Update "Git Operations" subsection: reference Go CLI commands
     - Update "Sandbox Bypass" subsection: Go binary handles local operations without sandbox bypass for file I/O; only network operations still need bypass
   - Section 8 (Capabilities):
     - Update hook count: still 22 hooks but now implemented as Go subcommands
     - Update hook script table: replace shell script names with Go subcommand names
     - Update CLI section: add new subcommands (validate, pathflow, sentinel, coordination, etc.)
   - Section 9 (Project Structure):

     - Update `.codeflow/scripts/` description: note most scripts retired, only protection scripts remain
2. Audit all 8 agent definitions for script references:
   - `cf-development.md`: update references to `./codeflow test`, build commands, Go CLI paths
   - `cf-git-operations.md`: update references to session start/end scripts, ledger operations
   - `cf-knowledge-layer.md`: update DB operation references (sqlite3 -> `codeflow db`), ledger references
   - `cf-security.md`: update security enforcement references (security-lib.sh -> `codeflow hooks security`)
   - `cf-planning.md`: update validation references (validate-task.sh -> `codeflow validate task`)
   - `cf-documentation.md`: update validation references similarly
   - `cf-review.md`: update review tool references
   - `cf-quality-assurance.md`: update test runner references
3. Update sandbox bypass rules: Go binary performs local file I/O natively; only `git push`, `gh pr`, and package manager commands still need `dangerouslyDisableSandbox: true`
