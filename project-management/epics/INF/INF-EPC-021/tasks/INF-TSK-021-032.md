## Description

The INF-EPC-021 epic tasks were originally written using "replace/migrate/eliminate" language that described the work as replacing existing shell scripts with Go CLI commands. PR #95 updated the acceptance criteria to use "build/implement" language (reflecting that the Go CLI is a new capability being built, not a replacement migration). This task completes that alignment by updating the narrative sections of the task files — titles, YAML descriptions, section headings, and approach text — to consistently use build/implement language throughout.

Files to update: INF-TSK-021-001 through INF-TSK-021-020 (20 build task files), with special attention to INF-TSK-021-014 which had criteria alignment done in PR #95.

## Approach

1. Identify all "replace/migrate/eliminate" language patterns in INF-TSK-021-001 through INF-TSK-021-020 task files
