## Description

The Go CLI migration plan has evolved since the original INF-EPC-021 task specs were written. This task aligns all task documentation with the revised decisions:

1. **shellutil→cliutil rename**: Tasks referencing `shellutil` package name must be updated to `cliutil` (the actual implemented package name).

3. **Settings validation consolidation**: A new task is needed for the settings-validate hook migration that consolidates settings template enforcement into Go.
4. **Git hooks Go migration**: A new task is needed for migrating git hooks (pre-commit, post-checkout, etc.) to Go binary calls.
5. **Protection scripts migration**: A new task is needed for migrating the protection scripts (`protection-guard`, `protected-resource`) to Go.
6. **Session-start instructions hook**: A new task is needed for migrating the session-start-instructions hook to Go binary.
7. **Epic doc scope update**: The epic's task table and scope description must reflect the revised plan.
8. **Migration analysis doc**: Update `.codeflow/docs/analysis/` migration analysis to reflect current state.
