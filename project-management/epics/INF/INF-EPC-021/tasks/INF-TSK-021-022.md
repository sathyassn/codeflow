# INF-TSK-021-022: Update command definitions, skills, and settings.json hook entries

## Description

The final Claude artifact update task. Command definitions reference shell scripts for their implementations. Skills reference shell and Python conventions. Most critically, settings.json contains the actual hook invocation commands that must change from `bash .claude/hooks/.../script.sh` to `codeflow-cli/bin/codeflow hooks <subcommand>`.

## Approach

1. Rewrite `.claude/settings.json` hook entries (CRITICAL -- this is the actual wiring):
   - For each of the 22 hook entries, change `command` value from:
     `"bash \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/codeflow/{event}/{script}.sh"`
     to:
     `"\"$CLAUDE_PROJECT_DIR\"/codeflow-cli/bin/codeflow hooks {event-type} {subcommand}"`
   - Complete mapping (22 entries):

     | Hook Script | Go Subcommand |
     |---|---|
     | `session-start/cf-session-start-init.sh` | `hooks session-start init` |
     | `session-start/cf-session-start-logging.sh` | `hooks session-start logging` |
     | `session-start/cf-session-start-instructions.sh` | `hooks session-start instructions` |
     | `session-end/cf-session-end-cleanup.sh` | `hooks session-end cleanup` |
     | `session-end/cf-session-end-logging.sh` | `hooks session-end logging` |
     | `pre-tool-use/cf-pre-tool-use-security.sh` | `hooks pre-tool-use security` |
     | `pre-tool-use/cf-pre-tool-use-pathflow-gate.sh` | `hooks pre-tool-use gate-check --event PreToolUse` |
     | `pre-tool-use/cf-pre-tool-use-edit-write.sh` | `hooks pre-tool-use edit-write-guard` |
     | `pre-tool-use/cf-pre-tool-use-gh-pr.sh` | `hooks pre-tool-use gh-pr-guard` |
     | `pre-tool-use/cf-pre-tool-use-protected-resource.sh` | `hooks pre-tool-use protected-resource` |
     | `pre-tool-use/cf-pre-tool-use-team-guard.sh` | `hooks pre-tool-use team-guard` |
     | `pre-tool-use/cf-pre-tool-use-webfetch.sh` | `hooks pre-tool-use webfetch-guard` |
     | `post-tool-use/cf-post-tool-use-logging.sh` | `hooks post-tool-use logging` |
     | `post-tool-use/cf-post-tool-use-pathflow-sentinel.sh` | `hooks post-tool-use sentinel-write` |
     | `post-tool-use/cf-post-tool-use-phase-checkpoint.sh` | `hooks post-tool-use checkpoint-register` |
     | `post-tool-use/cf-post-tool-use-settings-templates.sh` | `hooks post-tool-use settings-templates` |
     | `post-tool-use/cf-post-tool-use-tmp-workflow.sh` | `hooks post-tool-use tmp-workflow` |
     | `task-completed/cf-task-completed-phase-checkpoint.sh` | `hooks task-completed checkpoint-complete` |
     | `stop/cf-stop-logging.sh` | `hooks stop logging` |
     | `stop/cf-stop-pathflow-gate.sh` | `hooks stop gate` |
     | `user-prompt-submit/cf-user-prompt-submit.sh` | `hooks user-prompt-submit validate` |
     | `user-prompt-submit/cf-user-prompt-submit-logging.sh` | `hooks user-prompt-submit logging` |

   - Reduce timeout values: Go binary completes in < 50ms; suggest 5000ms timeout (down from 10000ms)
   - Preserve all matcher patterns unchanged (matchers control which tools trigger hooks, not how hooks run)
   - Validate resulting settings.json is valid JSON
2. Update all `.claude/commands/cf-*.md` files (14 files):
   - Replace any shell script invocations with Go CLI equivalents
   - Update paths from `.codeflow/scripts/` to `codeflow-cli/bin/codeflow`
3. Update `.claude/skills/` files:
   - `cf-shell-standards/SKILL.md`: note that new scripts should be Go, shell standards apply only to remaining protection scripts
   - `cf-python-standards/SKILL.md`: mark as archival -- no Python in codebase post-migration
   - `cf-sandbox-standards/SKILL.md`: update bypass rules for Go binary operations
   - `cf-markdown-standards/SKILL.md`: update validation references (`codeflow validate task` instead of `validate-task.sh`)
