# INF-TSK-021-022: Single-session cutover: wire Go hooks, retire shell/Python scripts, update settings

## Description

**This is the atomic cutover task (Phase E of the build-coexist-cutover strategy).** In a single session, ALL production wiring changes happen at once:

1. Update `settings.json` hook commands from shell to Go binary
2. Delete ALL retired shell scripts, Python scripts, and their test files
3. Update command definitions and skills to reference Go binary
4. Reduce hook timeouts for Go performance
5. Update the top-level `./codeflow` wrapper to delegate to Go binary

This task consolidates all cutover actions that were previously scattered across individual build tasks. The one-shot approach prevents the system from being in a half-migrated state where some hooks use shell and others use Go.

**This is NOT a build task.** The Go binary and all its subcommands must already exist and pass integration testing before this task begins.

**Parallel execution with INF-TSK-021-021:** INF-TSK-021-021 (CLAUDE.md and agent definitions update) MUST run simultaneously in the same cutover session. The two tasks are parallel, not sequential — 021 is NOT blocked by 022. Both tasks address different files (022 handles hooks/scripts/settings; 021 handles .claude/ documentation) and can proceed concurrently once all build prerequisites are met.

**Deletion categories (files removed in this task):**

1. Claude Code hook scripts (22 files in `.claude/hooks/codeflow/`)
2. State management scripts (`.codeflow/scripts/state/` — ledger.sh, memory.sh, cf-pathflow-state.sh, cf-work-state.sh, cf-tracking-generate.sh)
3. Shell library (`.codeflow/scripts/shell-lib/` — 7 files: common.sh, logging.sh, errors.sh, config.sh, validation.sh, ulid.sh, index.sh)
4. Security scripts (`.codeflow/scripts/security/` enforcement, library, and validation modules — if Go equivalents exist; NOT protection scripts)
5. Pathflow transition scripts (`.codeflow/scripts/pathflow/` — 5 cf-pathflow-*.sh files)
6. Python coordination/memory scripts (`.codeflow/scripts/coordination/` — 6 .py files; `.codeflow/scripts/memory/` — 1 .py file; `codeflow_py_lib/`)
7. Validation scripts (`.codeflow/scripts/validation/` — if Go equivalents exist)
8. DB utility scripts (generate-format-id.sh, migrate-to-dual-id.sh, normalize-jsonl.sh)

**NOT deleted:** Git hook thin wrappers in `.codeflow/scripts/git-hooks/` (these are retained as thin wrappers after INF-TSK-021-035 — only the original full shell implementations are replaced by thin wrappers in that task; no additional deletion of the wrapper files occurs here).
