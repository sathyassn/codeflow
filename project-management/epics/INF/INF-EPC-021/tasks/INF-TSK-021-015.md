# INF-TSK-021-015: Build Go CLI for shell-lib foundation

## Description

The shell-lib directory contains 6 foundation scripts (common.sh, logging.sh, errors.sh, config.sh, validation.sh, ulid.sh) sourced by nearly every other shell script. This task builds the Go equivalent of these shared utility functions as the Go `shellutil` package. The shell-lib scripts are retained as-is and remain unchanged during this build task; they continue to be used by shell scripts during the coexistence period.

## Approach

1. Create `codeflow-cli/internal/shellutil/` package:
   - `log.go`:
     - `func LogInfo(format string, args ...any)` -- writes to stderr: `[INFO] {timestamp} {message}`
     - `func LogWarn(format string, args ...any)` -- writes to stderr: `[WARN] {timestamp} {message}`
     - `func LogError(format string, args ...any)` -- writes to stderr: `[ERROR] {timestamp} {message}`
     - `func LogDebug(format string, args ...any)` -- writes to stderr only if `CODEFLOW_DEBUG=1`
     - Internal: uses `log/slog` with a custom `slog.Handler` that matches the shell-lib output format (timestamp prefix, level tag, no JSON)
     - Go equivalent of: `logging.sh` (200 lines) `log_info()`, `log_warn()`, `log_error()` functions
   - `config.go`:
     - `func LoadConfig(projectDir, name string) (map[string]any, error)` -- reads `.codeflow/config/{name}.json`, parses with `encoding/json`
     - `func LoadEnforcementPolicy(projectDir string) (*EnforcementPolicy, error)` -- typed wrapper for `enforcement-policy.json`
     - `func LoadPathflowConfig(projectDir string) (*PathflowConfig, error)` -- typed wrapper for `pathflow-config.json`
     - Go equivalent of: `config.sh` (143 lines) which used `python3 -c "import yaml..."` for YAML parsing
   - `validate.go`:
     - `func ValidateSessionID(id string) error` -- checks `ses-{13-digit-timestamp}{12-hex-chars}` or `ses-{ULID}` format via `regexp.MustCompile`
     - `func ValidateULID(id string) error` -- checks 26-character Crockford Base32 format
     - `func ValidateFilePath(path string) error` -- checks for path traversal (`..`), null bytes, absolute path requirements
     - `func ValidateFormatID(id string) error` -- checks `{AREA}-{TYPE}-{NNN}` pattern
     - Go equivalent of: `validation.sh` (215 lines) `validate_session_id()`, `validate_ulid()`, `validate_path()` functions
   - `errors.go`:
     - `type ExitError struct { Code int; Message string }` -- wraps exit code with descriptive message
     - `func Exit(code int, format string, args ...any)` -- prints to stderr and calls `os.Exit(code)`
     - `func ExitBlock(reason string)` -- exits with code 2 (hook block convention)
     - `func ExitAllow()` -- exits with code 0 (hook allow convention)
     - Exit code conventions: 0=allow/success, 1=error, 2=block (hook enforcement)
     - Go equivalent of: `errors.sh` (184 lines) `die()`, `warn_exit()` functions
2. All Go packages in codeflow-cli import shellutil for common operations
