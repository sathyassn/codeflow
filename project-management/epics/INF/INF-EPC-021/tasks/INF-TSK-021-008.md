# INF-TSK-021-008: Migrate webfetch, team-guard, and gh-pr hooks to Go binary

## Description

Three smaller PreToolUse hooks bundled together as they are each relatively simple enforcement checks. The webfetch hook validates URLs, the team-guard prevents accidental TeamDelete during active sessions, and the gh-pr hook blocks merging to protected branches. Combined, they represent ~300 lines of shell.

## Approach

1. Create `codeflow-cli/internal/hooks/webfetch/` package:
   - `webfetch.go`:
     - `type URLChecker struct { AllowedDomains []string; BlockedDomains []string }` -- loaded from enforcement-policy.json `url_validation` section
     - `func (c *URLChecker) Check(stdin io.Reader) (Verdict, error)` -- parses stdin JSON, extracts `tool_input.url`, validates domain against allow/block lists using `net/url.Parse()`
     - Blocks: internal IPs (127.0.0.1, 10.x, 192.168.x), file:// URLs, data: URLs
   - `webfetch_test.go` -- allowed domains, blocked domains, internal IPs, malformed URLs
2. Create `codeflow-cli/internal/hooks/team/` package:
   - `guard.go`:
     - `func CheckTeamDelete(stdin io.Reader, sessionDir string, sentinelDir string) (Verdict, error)`
     - Logic: if `pathflow-active` flag exists AND `pf-6` sentinel does NOT exist -> block TeamDelete (exit 2)
     - If `pf-6` sentinel exists -> allow (PF7-END in progress)
     - If no `pathflow-active` flag -> allow (no active session)
   - `guard_test.go` -- active session without pf-6 (block), with pf-6 (allow), no session (allow)
3. Create `codeflow-cli/internal/hooks/ghpr/` package:
   - `ghpr.go`:
     - `type PRChecker struct { ProtectedBranches []string }` -- loaded from enforcement-policy.json `merge_protection` section (default: `main`, `master`, `release/*`, `production`)
     - `func (c *PRChecker) Check(stdin io.Reader) (Verdict, error)` -- parses stdin JSON, extracts `tool_input.command`, checks if `gh pr merge` targets a protected branch via `--base` flag or default branch
   - `ghpr_test.go` -- merge to main (block), merge to feat/ (allow), protected pattern matching
4. Add CLI subcommands:
   - `codeflow hooks pre-tool-use webfetch-guard` -- reads stdin, validates URL, exits 0/2
   - `codeflow hooks pre-tool-use team-guard` -- reads stdin, checks TeamDelete safety, exits 0/2
   - `codeflow hooks pre-tool-use gh-pr-guard` -- reads stdin, checks PR target branch, exits 0/2
