# INF-TSK-021-028: Coverage audit: add remaining Go packages to business_packages

## Description

As INF-EPC-021 tasks create new Go packages (hooks, ledger, pathflow, sentinel, validate, etc.), each package needs to be registered in `codeflow-cli/config/testing/test-config.json` under the `business_packages` array to enable 85% per-file coverage enforcement. This task serves as the batch registration point after integration testing confirms which packages exist and meet the coverage threshold.

Note: The shared utility package is named `cliutil` (not `shellutil`). The dormant staging scripts (`cf-stage-manage.sh`, `cf-stage-transition.sh`) were not migrated; they are replaced by the `protection-guard` command in `internal/hooks/resource/`. Git hooks are migrated to Go via `internal/githooks/` (INF-TSK-021-035). Protection management scripts (`cf-promote-protection.sh`, `cf-reload-protection.sh`) remain as shell — INF-TSK-021-036 was cancelled; the protection subsystem stays cohesive in shell.
