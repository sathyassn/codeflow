# INF-TSK-021-004: Build Go CLI for active task state and memory operations

## Description

`cf-work-state.sh` manages the active task bridge file (`active-task.json`) used by hooks to identify the current task context. `memory.sh` handles memory event recording to the JSONL ledger. Both use shell-level JSON construction. This task builds Go equivalents with proper JSON marshaling, leveraging the ledger package (from INF-TSK-021-001) for validated writes.

## Approach

1. Create `codeflow-cli/internal/workstate/` package:
   - `activetask.go`:
     - `type ActiveTask struct { TaskID string; FormatID string; EpicFormatID string; Title string; Branch string; WorkType string; UpdatedAt string }` with JSON tags
     - `SetActiveTask(runtimeDir string, task ActiveTask) error` -- marshals to JSON, writes to `{runtimeDir}/active-task.json` atomically (write to tmp + rename)
     - `GetActiveTask(runtimeDir string) (ActiveTask, error)` -- reads and unmarshals; returns `ErrNoActiveTask` if file missing
     - `ClearActiveTask(runtimeDir string) error` -- removes bridge file via `os.Remove()`
   - `memory.go`:
     - `RecordMemoryEvent(ledgerDir string, event ledger.Event) error` -- delegates to `ledger.AppendEvent()` targeting `memory-events.jsonl`; event types: `memory_event`, `memory_store`, `memory_update`
     - Uses canonical field names: `event` (not `type`), `timestamp` (not `ts`)
2. Add CLI subcommands in `codeflow-cli/cmd/codeflow/state.go`:
   - `codeflow state active-task set --task-id <id> --format-id <fid> [--epic <eid>] [--title <t>] [--branch <b>]`
   - `codeflow state active-task get` -- outputs JSON to stdout
   - `codeflow state active-task clear` -- removes bridge file
   - `codeflow state memory record` -- reads event JSON from stdin, appends to memory-events.jsonl
