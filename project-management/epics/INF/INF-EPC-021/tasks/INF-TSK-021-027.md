# INF-TSK-021-027: Retire check-test-coverage-pairing.sh, add make build to CI, and auto-rebuild CLI on SessionStart

## Description

Post-cutover CI cleanup. Retires check-test-coverage-pairing.sh (obsolete — Claude Code hooks are now Go CLI subcommands with coverage enforced by test-config.json at 85%). Adds make build step before make test-cover in CI test-go job. Removes stale reference from cf-review agent definition. Adds auto-rebuild logic to SessionStart so the installed codeflow binary stays current after git pull/merge. Verifies all 5 git hook tests pass post-cutover.

## Approach

1. Delete `.codeflow/testing/ci/check-test-coverage-pairing.sh` (zero callers, obsolete)
2. Update `.claude/agents/cf-review.md` line 144: remove reference to check-test-coverage-pairing.sh from Testing checklist
3. Update `.github/workflows/test-suite.yml`: add make build step before make test-cover in test-go job
   - IMPORTANT: This file is HIGH-protected. Use Protected Resource Staging workflow.
4. Add auto-rebuild logic to `codeflow-cli/internal/hooks/session/start.go`:
   - In the SessionStart flow (after session ID is resolved), compare installed binary VCS revision vs `git rev-parse --short HEAD`
   - If they differ AND `codeflow-cli/go.mod` exists in the project dir, run `go install ./cmd/codeflow/` from `codeflow-cli/` subdir
   - Non-fatal: log warning on failure, never block session start
   - The existing post-commit hook (`postcommit.go autoRebuildCLI`) covers local commits; this catches remote merges pulled via git pull
5. Add tests for auto-rebuild in `start_test.go`
6. Verify (no modifications): all 5 git hook tests pass
7. Verify (no modifications): `cd codeflow-cli && make test-cover` passes with >= 85%
