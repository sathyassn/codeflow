# INF-TSK-021-027: Update git hooks and CI workflows for post-migration compatibility

## Description

After the atomic cutover (INF-TSK-021-022) retires shell scripts, the git hooks that have been migrated to Go thin wrappers (see INF-TSK-021-035) and CI workflows need updates to reflect the new file structure. Git hooks that reference deleted scripts or shell test paths will break. The CI workflow still has Python-specific steps that become dead weight. This task ensures the retained infrastructure works correctly in the post-migration environment.

Git hooks are being migrated to Go via INF-TSK-021-035 (commit-msg, post-commit, pre-push, prepare-commit-msg fully migrated; pre-commit hybrid). This task handles the post-cutover compatibility updates: pre-commit uses the hybrid Go+shell pattern, post-commit delegates to `codeflow git-hooks post-commit`, and coverage pairing checks are updated for Go source packages.

## Approach

1. Audit git hook thin shell wrappers (from INF-TSK-021-035) for post-cutover compatibility:
   - `pre-commit`: Update to hybrid Go+shell pattern — shell wrapper calls `codeflow git-hooks pre-commit-validate` for pure-logic checks, shell retains linting tool invocations (shellcheck, ruff, markdownlint)
   - `post-commit`: Update to delegate to `codeflow git-hooks post-commit` instead of direct JSONL echo
   - `commit-msg`, `pre-push`, `prepare-commit-msg`: Confirm thin wrappers correctly delegate to Go binary
2. Update `pre-commit` hook thin wrapper:
   - Hybrid pattern: invoke `codeflow git-hooks pre-commit-validate` for Go-implemented checks
   - Shell retains: shellcheck, ruff, markdownlint linting invocations (require shell subprocess)
3. Update `post-commit` hook thin wrapper:
   - Delegate to `codeflow git-hooks post-commit` (Go handles JSONL logging)
4. Update `check-test-coverage-pairing.sh`:
   - Remove expectations for .sh test files paired with migrated hook .sh files
   - Add validation that Go test coverage exists for migrated packages in `internal/githooks/`
5. Update `.github/workflows/test-suite.yml`:
   - Remove Python venv creation, pip install, and pytest steps
   - Retain and update Go test job (`make test-cover`)
6. Run all git hook tests to verify:
   - `bash .codeflow/testing/scripts/git-hooks/test-pre-commit.sh`
   - `bash .codeflow/testing/scripts/git-hooks/test-commit-msg.sh`
   - `bash .codeflow/testing/scripts/git-hooks/test-post-commit.sh`
   - `bash .codeflow/testing/scripts/git-hooks/test-pre-push.sh`
   - `bash .codeflow/testing/scripts/git-hooks/test-prepare-commit-msg.sh`
