# INF-TSK-021-027: Update git hooks and CI workflows for post-migration compatibility

## Description

After the Go CLI migration retires shell scripts (INF-TSK-021-025), the retained git hooks and CI workflows need updates to reflect the new file structure. Git hooks that reference deleted scripts or shell test paths will break. The CI workflow still has Python-specific steps that become dead weight. This task ensures the retained infrastructure works correctly in the post-migration environment.

## Approach

1. Audit git hooks for references to deleted scripts:
   - `pre-commit`: Check if it invokes any retired shell test paths or shellcheck on migrated hooks
   - `post-commit`: Check if it uses direct `echo >>` to JSONL (should use `codeflow ledger append`)
   - `commit-msg`, `pre-push`, `prepare-commit-msg`: Verify no references to deleted scripts
2. Update `pre-commit` hook:
   - Update test suite invocation paths (retired test files no longer exist)
   - Adjust shellcheck step to skip Go binary hooks (no .sh files to lint)
3. Update `post-commit` hook:
   - Replace any direct JSONL echo with `codeflow ledger append` call
4. Update `check-test-coverage-pairing.sh`:
   - Remove expectations for .sh test files paired with migrated hook .sh files
   - Add validation that Go test coverage exists for migrated packages
5. Update `.github/workflows/test-suite.yml`:
   - Remove Python venv creation, pip install, and pytest steps
   - Retain and update Go test job (`make test-cover`)
6. Run all git hook tests to verify:
   - `bash .codeflow/testing/scripts/git-hooks/test-pre-commit.sh`
   - `bash .codeflow/testing/scripts/git-hooks/test-commit-msg.sh`
   - `bash .codeflow/testing/scripts/git-hooks/test-post-commit.sh`
   - `bash .codeflow/testing/scripts/git-hooks/test-pre-push.sh`
   - `bash .codeflow/testing/scripts/git-hooks/test-prepare-commit-msg.sh`
