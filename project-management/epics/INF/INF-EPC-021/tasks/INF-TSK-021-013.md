# INF-TSK-021-013: Wire codeflow session start into SessionStart hook

## Description

Currently, the session ID is generated in shell and written to `.state/runtime/current-session-id`. The Go CLI already has `codeflow session start` which generates session IDs and records them in the database. This task wires the Go CLI session start into the SessionStart hook, eliminating the shell-generated ID and the runtime file.

## Approach

1. Modify `codeflow-cli/internal/hooks/session/start.go` (from INF-TSK-021-010):
   - Update `StartInit()` to call `codeflow session start` internally (Go function call, not subprocess):
     1. Generate session ID via `session.Start()` (INF-EPC-015 existing code): produces `ses-{ULID}` format
     2. Set `CODEFLOW_SESSION_ID` in the hook's environment output JSON: `{"env": {"CODEFLOW_SESSION_ID": "{ses-ULID}"}}`
     3. Record session in SQLite via `db.CreateSession(sessionID, ...)`
     4. Remove `current-session-id` file creation step (was `os.WriteFile("{projectDir}/.state/runtime/current-session-id", ...)`)
     5. Add backward compatibility fallback: if `CODEFLOW_SESSION_ID` env var is empty, read from `.state/runtime/current-session-id` (transitional)
   - `func ResolveSessionID() string` -- checks `CODEFLOW_SESSION_ID` env var first, falls back to reading `current-session-id` file, returns error if neither available
2. Audit and update hooks that read `current-session-id`:
   - All migrated Go hooks should use `os.Getenv("CODEFLOW_SESSION_ID")` with `ResolveSessionID()` fallback
   - Hooks affected: session-start-logging, session-end-logging, session-end-cleanup, stop-logging, user-prompt-submit-logging, post-tool-use-logging, team-guard, stop-pathflow-gate, protected-resource, user-prompt-submit
3. Update `start_test.go`:
   - Add test: session ID generated in `ses-{ULID}` format
   - Add test: environment output JSON contains CODEFLOW_SESSION_ID
   - Add test: `current-session-id` file NOT created
   - Add test: `ResolveSessionID()` prefers env var over file
   - Add test: `ResolveSessionID()` falls back to file when env var empty
