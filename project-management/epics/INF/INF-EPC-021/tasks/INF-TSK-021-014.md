# INF-TSK-021-014: Eliminate Python scripts and codeflow_py_lib

## Description

CodeFlow has 8 Python scripts and an 11-file Python library (`codeflow_py_lib/`) that handle claim coordination, CRDT operations, memory storage, and stage synchronization. Additionally, many shell scripts use inline `python3 -c` one-liners for timestamps, JSON validation, and YAML parsing. This task migrates all Python functionality to Go and removes the entire Python infrastructure.

The Python scripts are:

1. `cf-claim-acquire.py` -- acquire file claim lock
2. `cf-claim-check.py` -- check claim status
3. `cf-claim-list.py` -- list active claims
4. `cf-claim-release.py` -- release claim
5. `cf-claim-renew.py` -- renew claim TTL
6. `cf-crdt-rebuild.py` -- rebuild CRDT state (JSON dict fallback)
7. `cf-memory-store.py` -- store memory events
8. `cf-stage-sync.py` -- synchronize stage state

The library modules: `__init__.py`, `config.py`, `crdt.py`, `errors.py`, `jsonl.py`, `logging.py`, `paths.py`, `ulid.py`, `ulid_generator.py`, `validation.py`

## Approach

1. Create `codeflow-cli/internal/claim/` package:
   - `claim.go`:
     - `type Claim struct { File string; Owner string; AcquiredAt time.Time; ExpiresAt time.Time; Renewed int }` -- JSON-serialized claim record
     - `type Manager struct { ClaimDir string; DefaultTTL time.Duration }` -- manages claim lifecycle, `ClaimDir` = `.state/claims/`
     - `func (m *Manager) Acquire(file, owner string) (*Claim, error)` -- creates claim lock file at `{ClaimDir}/{sha256(file)}.json` with `os.O_CREATE|os.O_EXCL` (atomic); returns error if already claimed by different owner
     - `func (m *Manager) Check(file string) (*Claim, bool, error)` -- reads claim file, checks TTL expiry; returns (claim, isActive, err)
     - `func (m *Manager) List() ([]*Claim, error)` -- `os.ReadDir(ClaimDir)`, parses all `.json` files
     - `func (m *Manager) Release(file, owner string) error` -- verifies owner matches, then `os.Remove()`
     - `func (m *Manager) Renew(file, owner string) (*Claim, error)` -- reads claim, verifies owner, extends ExpiresAt, rewrites atomically (tmp+rename)
   - `claim_test.go`:
     - Table-driven: acquire (success), acquire conflict (different owner, error), check active, check expired, list empty, list with claims, release by owner, release by wrong owner (error), renew, renew expired (error)
2. Create `codeflow-cli/internal/memory/` package:
   - `store.go`:
     - `func StoreEvent(ledgerDir string, event ledger.Event) error` -- delegates to `ledger.AppendEvent()` with file routing to `memory-events.jsonl`
   - `store_test.go`:
     - Event written to correct file, correct JSON structure, append-only
3. Extend `codeflow-cli/internal/workstate/` package:
   - `stagesync.go`:
     - `func SyncStageState(dbPath, ledgerDir string) error` -- reads stage state from JSONL, reconciles with SQLite, writes updates. Replaces cf-stage-sync.py (782 lines)
     - `func DiffStageState(dbPath, ledgerDir string) ([]StageDiff, error)` -- dry-run mode showing what would change
   - `stagesync_test.go`:
     - Sync with matching state (no-op), sync with drift (corrects), sync with missing DB records
4. Extend `codeflow-cli/internal/db/` package:
   - `crdt.go`:
     - `func RebuildCRDT(jsonlPath, outputPath string) error` -- reads CRDT operations from JSONL, applies as JSON dict merge (not Loro), writes result. Replaces cf-crdt-rebuild.py (287 lines)
   - `crdt_test.go`:
     - Rebuild from empty, rebuild with operations, merge conflict resolution (last-writer-wins)
5. Add CLI subcommands (registered in `codeflow-cli/cmd/codeflow/`):
   - `codeflow coordination claim-acquire --file <path> --owner <name>` -- replaces cf-claim-acquire.py (170 lines)
   - `codeflow coordination claim-check --file <path>` -- replaces cf-claim-check.py (188 lines)
   - `codeflow coordination claim-list` -- replaces cf-claim-list.py (203 lines)
   - `codeflow coordination claim-release --file <path> --owner <name>` -- replaces cf-claim-release.py (178 lines)
   - `codeflow coordination claim-renew --file <path> --owner <name>` -- replaces cf-claim-renew.py (206 lines)
   - `codeflow coordination crdt-rebuild` -- replaces cf-crdt-rebuild.py (287 lines)
   - `codeflow memory store` -- replaces cf-memory-store.py (132 lines)
   - `codeflow state stage-sync` -- replaces cf-stage-sync.py (782 lines)
6. Audit shell scripts for `python3 -c` one-liners and replace:
   - `ulid.sh`: `python3 -c "import time; print(int(time.time()*1000))"` -> handled by INF-TSK-021-002
   - `config.sh`: `python3 -c "import yaml..."` -> handled by INF-TSK-021-015
   - `ledger.sh`: `python3 -m json.tool` -> `json.Valid()` in Go
   - `context-lib.sh`: `python3 -c "..."` for timestamps -> `time.Now().Unix()` in Go
7. Delete all Python files, pytest tests, and validation script
8. Update CI workflow

## Notes

- The CRDT module (`crdt.py`) uses Loro when available but falls back to a JSON dict merge. The Go version should implement the JSON dict merge only (Loro integration is out of scope for this epic).
- Common `python3 -c` one-liners to replace: `python3 -c "import datetime; print(datetime.datetime.utcnow().isoformat()+'Z')"` -> `date -u +%Y-%m-%dT%H:%M:%SZ` or `codeflow internal timestamp`.
- The 17 pytest test files need to be identified by globbing `.codeflow/testing/**/*test*.py`.
- See `.codeflow/docs/analysis/go-cli-migration-comprehensive.md` Section 5 (Python Elimination Strategy) and Section 4.3 (Python Source Files) for detailed mapping.
- **Go test conventions:** Go tests must achieve >= 85% coverage on new business packages per test-config.json. All test functions must use `t.Parallel()`. Do not use `context.Background()` (use `context.TODO()` or test-specific context). New packages registered in test-config.json business_packages (or noted in INF-TSK-021-028 for batch registration).
