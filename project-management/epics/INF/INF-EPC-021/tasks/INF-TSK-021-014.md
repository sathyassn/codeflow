# INF-TSK-021-014: Build Go equivalents for Python scripts and codeflow_py_lib

## Description

CodeFlow has 6 Python scripts requiring Go equivalents: 5 claim management scripts and 1 CRDT rebuild script. The memory store and stage sync are out of scope (memory store already exists as `workstate.RecordMemoryEvent()` with CLI command `codeflow state memory record`; `cf-stage-sync.py` is unused). This task builds Go equivalents for the remaining Python scripts (actual Python infrastructure removal happens during cutover task 022).

The Python scripts to migrate:

1. `cf-claim-acquire.py` -- acquire file claim lock
2. `cf-claim-check.py` -- check claim status
3. `cf-claim-list.py` -- list active claims
4. `cf-claim-release.py` -- release claim
5. `cf-claim-renew.py` -- renew claim TTL
6. `cf-crdt-rebuild.py` -- rebuild CRDT state (JSON dict fallback)

## Approach

1. Create `codeflow-cli/internal/claim/` package:
   - `claim.go`: Manager with Acquire, Check, List, Release, Renew operations
   - `claim_test.go`: Table-driven tests for lifecycle, conflicts, TTL, expiration
2. Extend `codeflow-cli/internal/db/` package:
   - `crdt.go`: RebuildCRDT function replaying claim events from sessions.jsonl
   - `crdt_test.go`: Rebuild, verify, dry-run tests
3. Extend `codeflow-cli/internal/ledger/` routing + schema:
   - Add claim_created, claim_released, claim_renewed event types
4. Add CLI subcommands in `codeflow-cli/cmd/codeflow/coordination.go`:
   - `codeflow coordination claim-acquire|check|list|release|renew|crdt-rebuild`
