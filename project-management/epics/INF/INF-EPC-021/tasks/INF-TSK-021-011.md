# INF-TSK-021-011: Build Go CLI for session-end-cleanup hook

## Description

This task builds a Go equivalent for `cf-session-end-cleanup.sh` (289 lines), which runs at session end to clean up session state, archive data, and validate proper shutdown. The Go implementation reuses the session and pathflow packages.

## Approach

1. Add to `codeflow-cli/internal/hooks/session/` package:
   - `end.go`:
     - `func EndCleanup(stdin io.Reader, projectDir string) error` -- main entry point:
       1. Parse stdin JSON for session context
       2. Read `CODEFLOW_SESSION_ID` from env (canonical, not stdin UUID)
       3. Remove pathflow-active flag: `os.Remove("{sessionDir}/pathflow/is-pathflow-active")`
       4. Validate PF7 completion: check if `pathflow-pf-7` sentinel exists; if not, log warning to stderr
       5. Archive session data: move `.state/session/{SID}/` to `.state/session/archive/{SID}/` (or leave in place with completed marker)
       6. Clean runtime files: `os.Remove("{projectDir}/.state/runtime/active-task.json")`
       7. Write `session_end` event to session-events.jsonl via `ledger.AppendEvent()` with duration, phase reached, final status
       8. Clean stale sentinel files if session was abnormally terminated
     - `func ValidatePF7(sentinelDir string) (bool, []string)` -- checks pf-7 sentinel, returns warnings for incomplete shutdown
   - `end_test.go`:
     - Table-driven: normal cleanup (all files removed), missing pathflow flag (idempotent), incomplete PF7 (warning logged), ledger event written, stale file cleanup
2. Add CLI subcommand:
   - `codeflow hooks session-end cleanup` -- reads stdin, runs EndCleanup, exits 0 (warning on incomplete PF7, not error)
