# INF-TSK-021-007: Build Go CLI for pathflow gate hook

## Description

The pathflow gate hook is the primary enforcement mechanism for PathFlow phase ordering. It blocks Edit/Write operations before PF3-CLASSIFY (preventing premature code changes) and blocks git push/PR before PF5-VERIFY (preventing premature shipping). Currently a ~200 line shell script that reads sentinel files and parses JSON from stdin. This task builds a Go equivalent that is faster, more robust, and easier to test.

## Approach

1. Create `codeflow-cli/internal/hooks/gate/` package:
   - `gate.go`:
     - `type GateChecker struct { SentinelDir string; SessionID string }`
     - `func (g *GateChecker) Check(stdin io.Reader, event string) (Verdict, error)` -- parses stdin JSON, applies gate rules per event type
     - Gate rules (hardcoded, matching current shell logic):
       - `Edit`, `Write` tools -> require `pf-3` sentinel
       - `Bash` with `git commit` -> require `pf-3` sentinel
       - `Bash` with `git push`, `gh pr` -> require BOTH `pf-5` AND `ws-rev` sentinels (dual gate)
       - `Task` tool spawning role teammates (`cf-development`, `cf-planning`, `cf-documentation`, `cf-review`, `cf-quality-assurance`) -> require `pf-3` sentinel
       - No pathflow-active flag -> allow all (non-PathFlow session)
     - `func (g *GateChecker) CheckStop(stdin io.Reader) (Verdict, error)` -- stop/subagent-stop event variant
   - `gate_test.go`:
     - Table-driven: Edit before pf-3 (block), Edit after pf-3 (allow), git push before pf-5 (block), git push after pf-5+ws-rev (allow), role spawn before pf-3 (block), non-PathFlow session (allow all), stop event gating
2. Add CLI subcommands:
   - `codeflow hooks pre-tool-use gate-check [--event PreToolUse|Stop|SubagentStop]` -- reads stdin, checks gate, exits 0 (allow) or 2 (block with reason)

**Implementation Summary:**
Created Go package `internal/hooks/gate/` implementing PathFlow phase gate enforcement. The package provides a `GateChecker` that classifies tool operations into gate types (edit_write, git_commit, git_push_pr, role_teammate_spawn, ungated) and checks sentinel files to enforce phase ordering.
