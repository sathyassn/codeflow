# INF-TSK-021-012: Migrate sentinel system script to Go binary

## Description

`cf-sentinel.sh` (751 lines) is the general sentinel management system. It handles creating, checking, listing, and deleting sentinel files for both PathFlow phase/stage sentinels and skills sentinels. While the hooks create sentinels automatically, this script provides the CRUD interface. The Go version consolidates sentinel operations into a single package reused by the hook implementations.

## Approach

1. Create `codeflow-cli/internal/sentinel/` package (extends base from INF-TSK-021-003):
   - `sentinel.go`:
     - `type Scope string` -- `const ScopePathFlow Scope = "pathflow"`, `const ScopeSkills Scope = "skills"`
     - `type Manager struct { BaseDir string }` -- manages all sentinel operations
     - `func (m *Manager) ResolveScopeDir(scope Scope, sessionID string) string` -- returns `.state/sentinels/pathflow/{SID}/` for PathFlow, `.state/sentinels/skills/` for skills
     - `func (m *Manager) Create(scope Scope, sessionID, name string) error` -- `os.MkdirAll(scopeDir)` then `os.WriteFile(filepath.Join(scopeDir, name), nil, 0644)` (empty file; name IS the sentinel)
     - `func (m *Manager) Check(scope Scope, sessionID, name string) (bool, error)` -- `os.Stat()` returns true if exists, false if `os.IsNotExist`
     - `func (m *Manager) List(scope Scope, sessionID string) ([]string, error)` -- `os.ReadDir(scopeDir)`, returns sorted names
     - `func (m *Manager) Delete(scope Scope, sessionID, name string) error` -- `os.Remove()`, idempotent (no error if already missing)
   - `sentinel_test.go`:
     - Table-driven using `t.TempDir()`: create then check (exists), check non-existent (false), list empty dir, list with sentinels (sorted), delete existing, delete non-existent (idempotent), PathFlow scope path resolution, skills scope path resolution, concurrent create (two goroutines), MkdirAll for missing parent
2. Add CLI subcommands (registered in `codeflow-cli/cmd/codeflow/sentinel.go`):
   - `codeflow sentinel create --scope <scope> --name <name> [--session <SID>]` -- creates sentinel file
   - `codeflow sentinel check --scope <scope> --name <name> [--session <SID>]` -- exits 0 if exists, 1 if not
   - `codeflow sentinel list --scope <scope> [--session <SID>]` -- prints sentinel names to stdout
   - `codeflow sentinel delete --scope <scope> --name <name> [--session <SID>]` -- removes sentinel
   - `--session` defaults to `CODEFLOW_SESSION_ID` env var (required for pathflow scope)
3. Replace shell script:
   - `.codeflow/scripts/security/sentinel/cf-sentinel.sh` (751 lines): thin wrapper calling `exec "$CODEFLOW_CLI" sentinel "$@"`
