# INF-TSK-021-012: Build Go CLI for sentinel system script

## Description

This task builds a Go equivalent for PathFlow sentinel CRUD operations from `cf-sentinel.sh` (751 lines). It handles creating, checking, listing, and deleting sentinel files for PathFlow phase/stage sentinels only (skill sentinels are dead infrastructure, removed in this task). The Go version consolidates sentinel operations into a single package reused by the hook implementations.

## Approach

1. Create `codeflow-cli/internal/sentinel/` package (extends base from INF-TSK-021-003):
   - `sentinel.go`:
     - `type Scope string` -- `const ScopePathFlow Scope = "pathflow"`
     - `type Manager struct { BaseDir string }` -- manages all sentinel operations
     - `func (m *Manager) ResolveScopeDir(scope Scope, sessionID string) (string, error)` -- returns `.state/sentinels/pathflow/{SID}/` for PathFlow
     - `func (m *Manager) Create(scope Scope, sessionID, name string) error` -- `os.MkdirAll(scopeDir)` then `os.WriteFile(filepath.Join(scopeDir, name), nil, 0644)` (empty file; name IS the sentinel)
     - `func (m *Manager) Check(scope Scope, sessionID, name string) (bool, error)` -- `os.Stat()` returns true if exists, false if `os.IsNotExist`
     - `func (m *Manager) List(scope Scope, sessionID string) ([]string, error)` -- `os.ReadDir(scopeDir)`, returns sorted names
     - `func (m *Manager) Delete(scope Scope, sessionID, name string) error` -- `os.Remove()`, idempotent (no error if already missing)
   - `sentinel_test.go`:
     - Table-driven using `t.TempDir()`: create then check (exists), check non-existent (false), list empty dir, list with sentinels (sorted), delete existing, delete non-existent (idempotent), PathFlow scope path resolution, concurrent create (two goroutines), MkdirAll for missing parent
2. Add CLI subcommands (registered in `codeflow-cli/cmd/codeflow/sentinel.go`):
   - `codeflow sentinel create --scope pathflow --name <name> --session <SID>` -- creates sentinel file
   - `codeflow sentinel check --scope pathflow --name <name> --session <SID>` -- exits 0 if exists, 1 if not
   - `codeflow sentinel list --scope pathflow --session <SID>` -- prints sentinel names to stdout
   - `codeflow sentinel delete --scope pathflow --name <name> --session <SID>` -- removes sentinel
   - `--session` defaults to `CODEFLOW_SESSION_ID` env var (required for pathflow scope)
   - `--scope` only accepts "pathflow" (no "skills")
3. Clean up skill sentinel dead code from session/ package (~140 lines):
   - Remove `cleanupExpiredSentinels()` from `start.go` (call site + implementation)
   - Remove `cleanSkillSentinels()` from `end.go` (call site + implementation)
   - Remove corresponding tests from `start_test.go` and `end_test.go`
   - Update `doc.go` to remove "skill sentinels" reference
