# INF-TSK-021-029: Align INF-EPC-021 task criteria with build-coexist-cutover strategy

## Description

The INF-EPC-021 epic ("Go CLI Integration & Script Retirement") implements Go CLI replacements for shell scripts. The current task criteria conflate two distinct phases: **build** (implement Go packages) and **cutover** (retire shell scripts). This conflation creates risk: a single task both builds the replacement and removes the original, with no coexistence or verification window.

This task aligns all 28 existing tasks and the epic overview with the correct **build-coexist-cutover** strategy:

- **Phase B (Build):** Tasks 001-020 implement Go packages. Criteria cover Go implementation and tests only. Shell scripts remain untouched.
- **Phase C (Coexist):** Shell scripts call Go binary. Both paths active. Shadow testing validates parity.
- **Phase E (Cutover):** Shell script retirement is consolidated into dedicated tasks after coexistence is verified.

## Approach

1. Audit all 28 existing task files (INF-TSK-021-001 through INF-TSK-021-028) to identify:
   - Cutover criteria mixed into build acceptance criteria
   - Missing Go test coverage criteria (>= 85%)
   - Missing shadow testing criteria
2. Update each build task (001-020) to:
   - Remove cutover/retirement acceptance criteria
   - Add Go test coverage criterion (>= 85% on new package)
3. Identify or create dedicated Phase E cutover tasks consolidating retirement criteria
4. Add shadow testing tasks for key integration points
5. Add post-cutover verification tasks
6. Update INF-EPC-021.md epic overview to reflect the phase structure
