# INF-TSK-021-019: Migrate worktree and report scripts to Go binary

## Description

The 4 worktree scripts manage isolated git worktree creation and cleanup. The tracking report generator creates progress markdown from the WorkGraph. These are medium-priority migrations as they are not in the critical hook path.

## Approach

1. Create `codeflow-cli/internal/worktree/` package:
   - `worktree.go`:
     - `type Worktree struct { Name string; Path string; Branch string; CreatedAt time.Time }`
     - `type Manager struct { ProjectDir string; WorktreeBaseDir string }` -- `WorktreeBaseDir` = `.claude/worktrees/`
     - `func (m *Manager) Setup(name, branch string) (*Worktree, error)` -- runs `git worktree add {WorktreeBaseDir}/{name} -b {branch}`, returns Worktree struct. Replaces cf-worktree-setup.sh (263 lines)
     - `func (m *Manager) Status(name string) (*WorktreeStatus, error)` -- runs `git worktree list --porcelain`, parses output, returns status for named worktree. Replaces cf-worktree-status.sh (360 lines)
     - `func (m *Manager) List() ([]*Worktree, error)` -- runs `git worktree list --porcelain`, returns all worktrees. Replaces cf-worktree-list.sh (199 lines)
     - `func (m *Manager) Cleanup(name string, force bool) error` -- runs `git worktree remove {path}` (or `--force` if force=true), removes branch if no other references. Replaces cf-worktree-cleanup.sh (569 lines)
   - `worktree_test.go`:
     - Table-driven: setup creates worktree (verify `git worktree list` output), status shows correct branch/commit, list returns all worktrees, cleanup removes worktree and branch, cleanup with force flag, setup with existing name (error), cleanup non-existent (error)
2. Create `codeflow-cli/internal/report/` package:
   - `report.go`:
     - `type EpicTracker struct { DB *sql.DB }` -- queries SQLite for epic and task status
     - `func (t *EpicTracker) Generate(epicID string) (string, error)` -- queries tasks for the given epic, generates markdown tracking table with columns: Task ID, Title, Status, Assignee, Branch, PR. Replaces cf-tracking-generate.sh (267 lines)
     - `func (t *EpicTracker) GenerateAll() (string, error)` -- generates tracking for all active epics
   - `report_test.go`:
     - Generate for epic with tasks (correct markdown table), generate for epic with no tasks (empty table), generate all (multiple epics)
3. Add CLI subcommands:
   - `codeflow worktree setup --name <name> --branch <branch>` -- create worktree
   - `codeflow worktree status [--name <name>]` -- show worktree status
   - `codeflow worktree list` -- list all worktrees
   - `codeflow worktree cleanup --name <name> [--force]` -- remove worktree
   - `codeflow report epic-tracker [--epic <id>]` -- generate tracking report
