# INF-TSK-021-019: Build Go CLI for worktree and report scripts

## Description

The 4 worktree scripts manage isolated git worktree creation and cleanup. The tracking report generator creates progress markdown from the WorkGraph. This task builds the Go equivalents of these scripts. The shell scripts remain unchanged during this build task.

## Approach

1. Create `codeflow-cli/internal/worktree/` package:
   - `doc.go`: Package documentation
   - `worktree.go`:
     - `type Worktree struct { Name, Path, Branch string; CreatedAt time.Time; Status string }`
     - `type Manager struct { ProjectDir, WorktreeBaseDir, WorktreeRegistryPath string }`
     - `func (m *Manager) Setup(name, branch string) (*Worktree, error)` -- git worktree add, copy settings.json + CLAUDE.md, create selective .state/ symlinks, register in worktrees.yaml. Go equivalent of cf-worktree-setup.sh (263 lines)
     - `func (m *Manager) Status(name string) (*WorktreeStatus, error)` -- branch, uncommitted changes, ahead/behind, JSON/text output. Go equivalent of cf-worktree-status.sh (360 lines)
     - `func (m *Manager) List(filter string) ([]*Worktree, error)` -- read worktrees.yaml, filter by status. Go equivalent of cf-worktree-list.sh (199 lines)
     - `func (m *Manager) Cleanup(name string, opts CleanupOpts) error` -- PathFlow guard, dry-run/force/prune modes, remove git worktree, update yaml, remove branch. Go equivalent of cf-worktree-cleanup.sh (569 lines)
     - `type CleanupOpts struct { Force, DryRun, Prune bool }`
   - `worktree_test.go`:
     - Table-driven: setup creates worktree, status shows correct data, list returns worktrees with filtering, cleanup removes worktree, cleanup with force flag, setup with existing name (error), cleanup non-existent (error)
2. Create `codeflow-cli/internal/report/` package:
   - `doc.go`: Package documentation
   - `report.go`:
     - `type EpicTracker struct { EpicsDir string }` -- scans filesystem for epic/task markdown
     - `func (t *EpicTracker) Generate(epicID string) (string, error)` -- walks project-management/epics/{AREA}/{epicID}/tasks/, parses YAML frontmatter via gopkg.in/yaml.v3, generates markdown tracking table. Go equivalent of cf-tracking-generate.sh (267 lines)
     - `func (t *EpicTracker) GenerateAll() (string, error)` -- walks all area directories
   - `report_test.go`:
     - Generate for epic with tasks (correct markdown table), generate for epic with no tasks (empty table), generate all (multiple epics)
3. Add CLI subcommands:
   - `codeflow worktree setup --name <name> --branch <branch>` -- create worktree
   - `codeflow worktree status [--name <name>]` -- show worktree status
   - `codeflow worktree list [--status <filter>]` -- list all worktrees
   - `codeflow worktree cleanup --name <name> [--force] [--dry-run] [--prune]` -- remove worktree
   - `codeflow report epic-tracker [--epic <id>]` -- generate tracking report
4. Register subcommands in `codeflow-cli/cmd/codeflow/main.go`:
   - `rootCmd.AddCommand(newWorktreeCmd())`
   - `rootCmd.AddCommand(newReportCmd())`
