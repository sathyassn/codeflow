# INF-TSK-023-009: Integrate worktree creation into SessionStart hook

## Description

This is the central integration task for worktree lifecycle. It wires `Manager.setup_detached()` into the SessionStart hook so that every new session gets its own isolated worktree. The worktree is created at Section 2b of the SessionStart flow (after session ID generation, before any state writes), ensuring all subsequent init steps operate within the worktree context.

Critical constraint: worktree creation happens ONLY on `source=startup`. On `compact` and `resume`, the existing worktree path is read from `codeflow-env.sh` and re-exported as `CODEFLOW_WORKTREE_PATH`.

## Approach

1. In `session_start.rs` SessionStart init handler, after session ID generation (Section 2a):
   a. If `source == "startup"`:
      - Call `Manager::setup_detached(&format!("worktree-{}", sid))`
      - Set `CODEFLOW_WORKTREE_PATH` in `result.env_vars`
      - All subsequent sections (3-12) use worktree path for state writes
   b. If `source == "compact"` or `source == "resume"`:
      - Read existing `codeflow-env.sh` from worktree `.state/runtime/`
      - Extract `CODEFLOW_WORKTREE_PATH` value
      - Re-export as environment variable
      - Skip worktree creation
2. Update all state write paths in Sections 3-12 to use worktree-relative paths:
   - `codeflow-env.sh` -> `{worktree}/.state/runtime/codeflow-env.sh`
   - PathFlow flag -> `{worktree}/.state/session/{SID}/pathflow/is-pathflow-active`
   - Checkpoint -> `{worktree}/.state/session/{SID}/pathflow/pathflow-phase-tasks.json`
3. Write integration test simulating full SessionStart with worktree creation

4. Create `WorktreePaths` struct in `worktree/paths.rs` with methods: `env_file(&self) -> PathBuf`, `active_task(&self) -> PathBuf`, `temp_dir(&self) -> PathBuf`, `team_config(&self) -> PathBuf` -- all singleton-scoping tasks (010, 011, 012, 013) MUST use this struct, no ad-hoc path construction

7. PathFlow flag and checkpoint created inside worktree .state/session/{SID}/
8. Compact/resume: reads CODEFLOW_WORKTREE_PATH from existing codeflow-env.sh and re-exports
9. Unit tests: startup creates worktree, compact reuses existing, resume reuses existing, WorktreePaths methods
10. Integration test: full SessionStart with worktree creation and env var export
