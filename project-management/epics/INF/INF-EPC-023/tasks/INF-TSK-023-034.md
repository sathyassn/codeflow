# INF-TSK-023-034: Pre-flight checks + CLI args

> **MANDATORY VALIDATION:** Files created from this template MUST be validated against the task validation script before committing:
> `bash .codeflow/scripts/validation/validate-task.sh project-management/epics/INF/INF-EPC-023/tasks/INF-TSK-023-034.md`

## Description

The current autorun command at `cli/src/cmd/autorun.rs:17-28` has a hardcoded batch path and no pre-flight checks. Users get confusing errors if tmux is missing, git is dirty, or the target branch does not exist.

This task adds:
1. `--batch <path>` CLI flag via clap
2. Pre-flight checks that fail fast with clear error messages
3. Preparation for future subcommands (status, cancel, etc.)

## Approach

1. Add `AutorunCommand` subcommand enum in `cmd/autorun.rs` with `Run` variant containing `--batch` flag via clap derive
2. Update `main.rs` Autorun variant from bare `Autorun` to `Autorun { command: Option<AutorunCommand> }`, update dispatch arm
3. Refactor `run()` from `pub async fn run() -> Result<()>` to `pub async fn run(command: Option<AutorunCommand>) -> Result<()>`, defaulting to Run when None
4. Refactor `run_with_dir()` to accept `batch_path: &Path` instead of hardcoding it
5. Add `preflight_checks(project_dir: &Path)` for tmux + git clean checks (runs before batch parse)
6. Add `check_target_branch(project_dir: &Path, target: &str)` for target branch validation (runs after batch parse, before execution)
7. Wire: `preflight_checks()` -> `parse_batch_file()` -> `check_target_branch()` -> existing orchestrator logic
8. Update existing tests that call `run_with_dir()` to pass `batch_path`
9. Add new tests for preflight (OK, tmux-missing, git-dirty, bad-branch)
