## Description

The current autorun command at `cli/src/cmd/autorun.rs:17-28` has a hardcoded batch path and no pre-flight checks. Users get confusing errors if tmux is missing, git is dirty, or the target branch does not exist.

This task adds:
1. `--batch <path>` CLI flag via clap
2. Pre-flight checks that fail fast with clear error messages
3. Preparation for future subcommands (status, cancel, etc.)

## Approach

1. Add `AutorunCommand` subcommand enum in `cmd/autorun.rs` with `Run` variant containing `--batch` flag via clap derive
2. Update `main.rs` Autorun variant to include the subcommand enum
3. Add `preflight_checks()` function that validates tmux, git status, and target branch
4. Call `preflight_checks()` before `parse_batch_file()` in the run function
5. Structure the enum to allow future subcommands without breaking existing behavior
