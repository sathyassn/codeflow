# INF-TSK-023-050: Scope codeflow-env.sh per worktree

## Description

`codeflow-env.sh` is one of three CRITICAL singletons blocking parallel execution. Currently, all sessions write to the same `.state/runtime/codeflow-env.sh`, causing later sessions to overwrite earlier ones' session IDs. This task scopes the file per worktree: each session writes to `{worktree}/.state/runtime/codeflow-env.sh`, and reads use `CODEFLOW_WORKTREE_PATH` to resolve the correct worktree-local path.

## Approach

1. Modify `session::write_env_file()` to accept a worktree path parameter:
   a. Write to `{worktree_path}/.state/runtime/codeflow-env.sh`
   b. Include `CODEFLOW_WORKTREE_PATH={worktree_path}` as an exported variable
   c. Keep existing exports: `CODEFLOW_SESSION_ID`, `CF_PROJECT_ROOT`
2. Modify `session::current()` to read from worktree-local path:
   a. Check `CODEFLOW_WORKTREE_PATH` env var first
   b. If set, read `{CODEFLOW_WORKTREE_PATH}/.state/runtime/codeflow-env.sh`
   c. If not set, fall back to main project `.state/runtime/codeflow-env.sh` (backward compat during migration)
3. Update all hook code that sources `codeflow-env.sh` to use the worktree-local resolution
4. Write concurrency test: two threads write env files to separate worktrees simultaneously
