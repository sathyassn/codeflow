# INF-TSK-023-037: Autorun session management commands

## Description

Currently `codeflow autorun` only has a single `run` function with no subcommand structure. Users cannot inspect running batches, attach to workers, view logs, cancel tasks, or query historical results.

This task implements 7 session management subcommands per the autorun spec.

## Approach

1. Extend `AutorunCommand` enum (from INF-TSK-023-034) with: Status, Attach, Logs, Cancel, Abort, Results, History variants
2. Each variant carries its own clap flags (e.g., `--batch`, `--follow`, `--limit`, `--since`, `--status`, `--batch-name`, `--all`)
3. Implement each command handler as a separate async function in `cmd/autorun.rs`
4. Status: query DB, verify tmux liveness, format table
5. Attach: lookup tmux session, exec attach
6. Logs: capture-pane, optional follow loop
7. Cancel: full cleanup sequence (see acceptance criteria)
8. Abort: abort marker + cancel all + skip pending
9. Results: query autorun_task_run, format table
10. History: query autorun_session with filters
