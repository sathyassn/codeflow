# INF-TSK-023-013: Scope team config by session

## Description

Claude Agent Teams stores config at `~/.claude/teams/{team-name}/config.json`. When two sessions use the same team name, their configs collide -- teammates from session A appear in session B's team list. This task implements session-scoped team naming per Decision #4.

For planned tasks (from an epic), the format is `{project}-{task-format-id}-{SID-short}` (e.g., `codeflow-INF-TSK-023-008-01kk0t08`). For adhoc tasks, the format is `{project}-{SID-short}` (e.g., `codeflow-01kk0t08`). SID-short is the first 8 characters of the session ULID.

## Approach

1. Add generate_team_name() to session/mod.rs:
   - Signature: pub fn generate_team_name(project: &str, task_format_id: Option<&str>, session_id: &str) -> String
   - If task_format_id is Some: return "{project}-{task_format_id}-{sid_short}" (lowercase)
   - If task_format_id is None: return "{project}-{sid_short}" (lowercase)
   - sid_short = session_id[4..12] (skip "ses-" prefix, take 8 ULID chars)
   - Validate: if session_id is too short or doesn't start with "ses-", use full session_id as fallback
   - Lowercase the task_format_id component (format IDs like INF-TSK-023-013 become inf-tsk-023-013)
2. Add #[must_use] attribute (pure function returning String)
3. Write comprehensive unit tests
