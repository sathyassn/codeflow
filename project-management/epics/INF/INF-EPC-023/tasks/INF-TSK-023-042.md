# INF-TSK-023-042: Fix worktree base directory default

## Description

The worktree manager currently defaults to `.claude/worktrees/` as the base directory for git worktrees, but `.gitignore` line 67 already excludes `.git-worktrees/`. This mismatch means worktree directories under `.claude/worktrees/` could be accidentally committed to git. Additionally, `.claude/` is Claude Code's configuration space (agents, settings, skills, memory) -- worktrees are ephemeral runtime artifacts that belong outside it.

Per Decision #15 from the parallel work analysis, the code default must be changed to `.git-worktrees/`. The `.gitignore` entry is already correct; the code is the mismatch.

## Approach

1. Locate the default base directory return value in the worktree manager (Rust equivalent of `worktree.go:102`)
2. Change from `project_dir.join(".claude").join("worktrees")` to `project_dir.join(".git-worktrees")`
3. Update all unit tests that reference the old default path
4. Remove empty `.claude/worktrees/` directory if it exists in the project
5. Verify `.gitignore` line 67 already contains `.git-worktrees/` (no change needed)
