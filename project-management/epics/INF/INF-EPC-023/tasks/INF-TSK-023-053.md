# INF-TSK-023-053: Scope team config by session

## Description

Claude Agent Teams stores config at `~/.claude/teams/{team-name}/config.json`. When two sessions use the same team name, their configs collide -- teammates from session A appear in session B's team list. This task implements session-scoped team naming per Decision #4.

For planned tasks (from an epic), the format is `{project}-{task-format-id}-{SID-short}` (e.g., `codeflow-INF-TSK-023-042-01kk0t08`). For adhoc tasks, the format is `{project}-{SID-short}` (e.g., `codeflow-01kk0t08`). SID-short is the first 8 characters of the session ULID.

## Approach

1. Add `generate_team_name(project: &str, task_format_id: Option<&str>, session_id: &str) -> String` function
2. If `task_format_id` is Some: `{project}-{task_format_id}-{sid[..8]}`
3. If `task_format_id` is None: `{project}-{sid[..8]}`
4. Store the generated team name in session context for `TeamCreate` to use
5. Write unit tests for both formats and uniqueness property
