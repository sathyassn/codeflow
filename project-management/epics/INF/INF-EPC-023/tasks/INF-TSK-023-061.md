# INF-TSK-023-061: PF6-TSK-08/09 ordering fix in pathflow-config.json

## Description

The PF6-TSK-08 (`record-pr-outcome`) and PF6-TSK-09 (`sync-local`) tasks must execute strictly in order — PF6-TSK-08 MUST run before PF6-TSK-09. This ordering is already enforced via the `blocked_by` field in pathflow-config.json, but the descriptions and notes do not make the reason explicit, risking parallel dispatch in autorun mode.

This task adds documentation clarity to pathflow-config.json so the ordering constraint is unmissable.

## Approach

1. Read `.codeflow/config/pathflow/pathflow-config.json` PF6-COMPLETE section
2. Update `PF6-TSK-09` description to mention it must follow `record-pr-outcome`
3. Add or update `enforcement_note` field on `PF6-TSK-09` making the dependency explicit
