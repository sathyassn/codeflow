## Description

The `ParallelWorkConfig` at `config.rs:17-28` currently has 4 sections: worktree, sync, merge, claims. Autorun-specific settings (worker timeout, blocked behavior, report directory) have no configuration home and use hardcoded defaults scattered across the codebase.

This task adds a 5th `autorun` section with proper defaults and validation.

## Approach

1. Define `AutorunConfig` struct with `#[derive(Debug, Clone, Deserialize, PartialEq, Eq)]` and `#[serde(default)]`
2. Add `pub autorun: AutorunConfig` field to `ParallelWorkConfig`
3. Implement `Default` for `AutorunConfig` with the specified defaults
4. Extend `validate_config()` to validate autorun fields
5. Add unit tests for parsing, defaults, and validation
