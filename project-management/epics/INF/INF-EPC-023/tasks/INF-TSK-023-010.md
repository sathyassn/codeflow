# INF-TSK-023-010: Scope codeflow-env.sh per worktree

## Description

`codeflow-env.sh` is one of three CRITICAL singletons blocking parallel execution. Currently, all sessions write to the same `.state/runtime/codeflow-env.sh`, causing later sessions to overwrite earlier ones' session IDs. This task scopes the file per worktree: each session writes to `{worktree}/.state/runtime/codeflow-env.sh`, and reads use `CODEFLOW_WORKTREE_PATH` to resolve the correct worktree-local path.

## Approach

1. Modify `session::current_session_id()` to check `CODEFLOW_WORKTREE_PATH` env var first:
   a. If set and worktree env file exists, read from `{CODEFLOW_WORKTREE_PATH}/.state/runtime/codeflow-env.sh`
   b. If not set or worktree env missing, fall back to `{project_dir}/.state/runtime/codeflow-env.sh`
   c. Use inner function pattern for testability (avoid `std::env::set_var`)
2. Add `session::current_env_file()` helper with same worktree-aware resolution:
   a. Returns full `EnvFile` struct (not just session_id)
   b. Needed by `SessionEnd` cleanup which checks env file ownership
3. Update `SessionEnd::clean_runtime_files()` for worktree-aware resolution:
   a. Clean worktree-local env file first (if `CODEFLOW_WORKTREE_PATH` set)
   b. Clean main project env file second
   c. Preserve race-safe SID matching for both locations
4. Verify all hook callers of `current_session_id()` -- fixing the function itself fixes all callers
5. Write concurrency test: two threads write env files to separate worktrees simultaneously
