# INF-TSK-023-012: Scope project temp dir per worktree

## Description

The project temp directory at `/tmp/claude/{project}/managed/protected-edits/` is the third CRITICAL singleton. When session A starts, `create_project_temp_dir()` cleans the entire `{project}/` directory -- destroying session B's temp files. This task scopes the temp dir per worktree by including the worktree name in the path, so each session only cleans its own subdirectory.

## Approach

1. Update WorktreePaths::temp_dir() (paths.rs) to include worktree name in path
2. Update create_project_temp_dir() (session_start.rs) to use worktree-scoped path via WorktreePaths
3. Update clean_project_temp() (session_end.rs) to scope cleanup per worktree using inner function pattern
4. Update ProtectionGuard (pre_tool_use.rs) to generate worktree-scoped staging paths
5. Write tests verifying two sessions have separate temp directories
