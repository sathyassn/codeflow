# INF-TSK-023-012: Scope project temp dir per worktree

## Description

The project temp directory at `/tmp/claude/{project}/managed/protected-edits/` is the third CRITICAL singleton. When session A starts, `create_project_temp_dir()` cleans the entire `{project}/` directory -- destroying session B's temp files. This task scopes the temp dir per worktree by including the worktree name in the path, so each session only cleans its own subdirectory.

## Approach

1. Modify `create_project_temp_dir()` to use worktree-scoped path:
   a. New path: `/tmp/claude/{project}/{worktree-name}/managed/protected-edits/`
   b. Accept worktree name from `CODEFLOW_WORKTREE_PATH` (extract last component)
2. Change cleanup logic to scope to `{worktree-name}/` subdirectory only:
   a. `remove_dir_all` targets `{project}/{worktree-name}/` not `{project}/`
   b. Project-level directory is never cleaned by any single session
3. Update all references to the temp dir path to use worktree-scoped resolution
4. Write tests verifying two sessions have separate temp directories
