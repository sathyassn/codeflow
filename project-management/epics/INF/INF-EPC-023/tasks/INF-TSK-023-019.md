# INF-TSK-023-019: SurrealDB parallel access tuning

## Description

SurrealDB with the `surrealkv://` embedded engine (replacing SQLite from Epic 0) needs validation for multi-session access. When 3 concurrent sessions perform CRUD operations on the shared database, write contention may cause latency spikes. This task tunes the connection strategy, measures contention, and implements retry/backoff for busy errors.

## Approach

1. Configure SurrealDB embedded connection for shared access:
   a. Use `surrealkv://{path}` pointing to the shared `.state/db/` directory
   b. Evaluate connection pooling vs per-session connections
   c. Document the chosen strategy with rationale
2. Implement retry/backoff for contention errors:
   a. On `Db::Error` indicating busy/lock contention: retry with exponential backoff
   b. Backoff: 10ms, 20ms, 40ms, ..., cap 1s, max 5 retries
   c. After max retries: return error with context
3. Write performance benchmark:
   a. Spawn 3 threads simulating concurrent sessions
   b. Each thread performs 100 CRUD operations (mix of insert, select, update, delete)
   c. Measure p50, p95, p99 latencies
   d. Assert p99 under 100ms
4. Write unit tests for concurrent access and retry behavior

## Acceptance Criteria

1. SurrealDB embedded connection configured for multi-session access via surrealkv:// shared path
2. Connection pool or per-session connection strategy documented and implemented
3. Write contention measured under 3 concurrent sessions: p99 latency under 100ms for CRUD operations
4. Graceful handling of SurrealDB busy/contention errors with retry and backoff (100ms initial, 2x multiplier, 1s max, 3 attempts). Retry on `surreal::Error::Db(DbError::TxTimeout)` and connection errors; fail on schema errors
5. Connection pool size: 3 (one per max concurrent session). Query timeout: 5s. Transaction retry: 3 attempts with 100ms exponential backoff
6. Performance benchmark test: 3 concurrent session simulations performing CRUD operations
7. Unit tests: concurrent read/write, retry on contention, graceful degradation
