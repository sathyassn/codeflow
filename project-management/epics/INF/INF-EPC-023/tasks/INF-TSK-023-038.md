# INF-TSK-023-038: Batch report generation

> **MANDATORY VALIDATION:** Files created from this template MUST be validated against the task validation script before committing:
> `bash .codeflow/scripts/validation/validate-task.sh project-management/epics/INF/INF-EPC-023/tasks/INF-TSK-023-038.md`

## Description

After a batch completes, there is no persistent human-readable record of the results. The `report_results()` function at `autorun.rs:69-96` prints to stdout only.

This task generates a markdown report saved to the project's tracking directory as a Tier 2 artifact.

## Approach

1. Add `generate_batch_report()` function that takes batch metadata and `Vec<WorkerResult>`
2. Read `report_dir` from `AutorunConfig` (defaults to `project-management/tracking/autorun`)
3. Create the directory if it does not exist
4. Generate markdown with batch header, per-task table, and summary statistics
5. Write the file with naming pattern `{batch_name}-{YYYY-MM-DD}.md`
6. Call `generate_batch_report()` from `run_with_dir()` after `orchestrator.execute()` completes
