## Description

Agent definitions and CLAUDE.md currently describe autorun at a high level but lack specific behavioral instructions for when agents operate inside an autorun worker. Agents need to:
- Detect autorun mode via environment variables
- Make autonomous decisions without user prompts
- Handle Tier 3 decisions by documenting rationale in PR description
- Follow auto-PR and auto-merge flows

This task adds concrete SOPs to each agent definition.

## Approach

1. Update CLAUDE.md Section 4.4 (Autorun Mode) with detailed env var detection and behavior rules
2. For each agent definition, add an "Autorun Behavior" subsection under Constraints that describes:
   - How to detect autorun (AUTORUN_SESSION_ID env var)
   - What changes in autorun mode (no prompts, autonomous decisions, auto-PR)
   - Decision tier handling (Tier 3 -> make best decision, document in PR)
3. Update cf-git-operations with auto-merge flow for non-protected branches
4. Update cf-review with autonomous rework handling
