# INF-TSK-043-001: Fix interactive session implementation gaps

> **MANDATORY VALIDATION:** Files created from this template MUST be validated against the task validation command before committing:
> `codeflow validate task <file-path>`
> Fix all errors (exit code 1) before requesting a commit. Warnings are advisory.

## Description

Fixes 13 gaps in the `codeflow interactive` command implementation introduced in PR #258 (feat/interactive-command). These are correctness and completeness gaps — no new features.

**Gap list:**
1. `.state/interactive` not gitignored
2. `interactive` missing from `LOCAL_STATE_DIRS` in `worktree/mod.rs`
3. Interactive heartbeat dead code — written by SessionStart but never read by status/cleanup
4. Interactive heartbeat not cleaned on session end
5. Interactive heartbeat not cleaned by stale sweep
6. `codeflow interactive status/cleanup` not using heartbeat as filesystem fallback
7. `codeflow interactive cleanup` only hits DB, misses filesystem artifacts (heartbeats, PID env files, session dirs, sentinel dirs, worktree map entries)
8. Dead-PID env file sweep missing
9. `session.lock` is a migration artifact that should be removed or documented
10. Worktree registry stale entries from interactive sessions not cleaned
11. Session log accumulation not bounded
12. Cleanup command fragmentation — multiple cleanup paths not unified
13. Main repo session dirs not swept during cleanup

**Expected Outcome:** `codeflow interactive cleanup` reliably removes all artifacts from completed/stale sessions. `codeflow interactive status` uses filesystem heartbeat as fallback when DB is unavailable. SessionEnd hook removes heartbeat on clean exit.
