# INF-TSK-013-002: Fix SessionEnd cleanup bugs and systemic UUID session ID misuse

## Description

A sweep of the hook infrastructure revealed that 10 hook scripts use Claude's per-agent UUID
(read from stdin `session_id` field) instead of the shared `CODEFLOW_SESSION_ID` environment
variable sourced from `codeflow-env.sh`. This causes log files, state directories, and sentinel
path lookups to be written under UUID-based paths rather than the canonical CodeFlow session ID,
producing orphan directories and broken cross-hook coordination.

Additionally, the PostToolUse hook for `cf-post-tool-use-pathflow-sentinel.sh` is missing
`TeamDelete` from its matcher, meaning the TEAMDELETE handler (which removes the
`pathflow-active` flag) is dead code and the flag is never cleaned up after `TeamDelete`.
A PID self-reference bug in `cf-session-end-cleanup.sh` may also cause incorrect
teammate-vs-lead detection. One test file is the sole failing test in the suite.

## Approach

Work is organized into 5 categories:

- **A (Critical):** PostToolUse matcher, PID guard, team-guard env sourcing
- **B (UUID→CODEFLOW_SESSION_ID):** 5 hooks sourcing env file and fixing path lookups
- **C (Low priority):** 1 hook with incorrect session ID in logs only
- **D (Tests):** 5 test files asserting correct env-file-priority behavior
- **E (Documentation):** 2 doc files updated with corrected flows

## Notes

- UUID bug is systemic: all hooks currently prefer `_STDIN_SESSION_ID` (Claude per-agent UUID) over `CODEFLOW_SESSION_ID`. The fix pattern is consistent: source `codeflow-env.sh` early, then prefer the env var.
- The `verify-work-retry` block in `cf-stop-logging.sh` is a V3 orphan — the writer hook was deleted in V4. Remove it entirely; do not refactor.
- The `test-cf-pathflow-enforcement.sh` failure is caused by the isolated test environment lacking the checkpoint config file that `checkpoint_init_all_phases()` requires. The fix is in the test setup, not in the hook itself.
- `codeflow-env.sh` sourcing pattern (reference from `cf-session-end-cleanup.sh`):

  ```bash
  _env_file="${REPO_ROOT:-$(git -C "$(dirname "$0")" rev-parse --show-toplevel 2>/dev/null)}/.state/runtime/codeflow-env.sh"
  [[ -f "$_env_file" ]] && source "$_env_file"
  ```
