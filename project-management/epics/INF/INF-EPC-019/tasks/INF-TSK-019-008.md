## Description

Restructure CLAUDE.md from 1,424 lines (~10K tokens) to ~400 lines (~3K tokens) by extracting procedural HOW content. The key principle: CLAUDE.md provides AWARENESS (WHAT/WHEN/WHERE), not PROCEDURES (HOW). All step-by-step procedures move to `cf-pathflow-protocol` skill (created in INF-TSK-019-001). The remaining content gives the team lead awareness of what exists, when to use it, and where to find detailed procedures.

**Execution order:** This task runs LAST among the referencing artifacts (bottom-up approach). Skills are created first, then agent defs are slimmed, then commands are slimmed, and finally CLAUDE.md is restructured. This ensures CLAUDE.md can correctly reference the restructured agents, commands, and skills.

1. Read current CLAUDE.md in full
2. Read cf-pathflow-protocol skill (INF-TSK-019-001 must be complete first) to verify content coverage
3. For each section, apply the restructuring plan above:
   - Keep awareness content (tables, lists, references)
