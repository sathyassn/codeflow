## Description

Restore the archived `cf-security-management` skill (344 lines at `.codeflow/docs/archived/skills/cf-security-management/`) and update it with improvements from the `cf-security` agent definition. During V4 Phase 4, the archived skill content was embedded into the agent def and improved. This task restores the archived skill as the base, then merges back the improvements. The resulting skill is renamed to `cf-security-operations` (domain-consistent naming) and becomes the single procedural reference for cf-security, allowing its agent definition to be slimmed from ~323 to ~140 lines.

## Approach

### Cross-Reference Requirement (Principle 0: No Blind Restore)

Before writing ANY operation, the implementer MUST:

1. Read the archived skill (structural base)
2. Read the CURRENT cf-security agent def (improvements since archival)
3. Read the CURRENT CLAUDE.md sections referencing security (enforcement, sandbox) to verify alignment
4. Read CURRENT command files that invoke security checks to verify conventions
5. Reconcile: the final skill must reflect the CURRENT state, not the archived state

### Restoration Steps

1. Start from the archived skill at `.codeflow/docs/archived/skills/cf-security-management/SKILL.md` (344 lines) as the base
2. Read cf-security agent def at `.claude/agents/cf-security.md` (323 lines), focusing on Execution Steps
3. Compare archived operations with agent def procedures -- identify improvements made when content was embedded in the agent def during V4 Phase 4 migration
4. Merge improvements from the agent def into the archived operations (updated procedures, new patterns, refined logic)
5. Validate the merge is lossless: no archived content dropped without equivalent in the update, no agent def improvement omitted

### Content Scope

Archived operations to restore + update:

- sandbox classification, protected resource staging, merge protection, permission diagnosis, settings sync

Agent def improvements to merge:

- Step-by-step procedures for each security check, autorun detection patterns

### Post-Restoration Steps

7. Remove V3 references, update to V4 patterns
8. Add YAML frontmatter with "Used by:" scope
