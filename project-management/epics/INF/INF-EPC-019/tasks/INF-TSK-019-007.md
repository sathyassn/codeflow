## Description

Restore the archived `cf-documentation-standards` skill (267 lines at `.codeflow/docs/archived/skills/cf-documentation-standards/`) and update it with improvements from the current `cf-documentation` agent definition. This is NOT a simple copy -- the archived skill content must be MERGED with documentation-related SOPs from the agent def to produce an updated skill that reflects the latest operational procedures.

The cf-documentation agent def contains documentation structure standards, style conventions, and quality checks that were developed or refined after this skill was archived. These improvements must be incorporated.

## Approach

### Cross-Reference Requirement (Principle 0: No Blind Restore)

Before writing ANY operation, the implementer MUST:

1. Read the archived skill (structural base)
2. Read the CURRENT cf-documentation agent def (improvements since archival)
3. Read the CURRENT CLAUDE.md sections referencing documentation -- verify alignment
4. Reconcile: the final skill must reflect the CURRENT state, not the archived state

### Restoration Steps

1. Read archived skill at `.codeflow/docs/archived/skills/cf-documentation-standards/SKILL.md` (267 lines)
2. Read cf-documentation agent def at `.claude/agents/cf-documentation.md`
3. Identify documentation-related SOPs in agent def (structure standards, style conventions, quality checks, formatting rules)
4. **MERGE** archived skill content with agent def improvements:
   - Use archived skill as the structural base
   - Update documentation standards with any enhanced conventions from agent def
   - Incorporate quality checks from agent def that aren't in archived skill
   - Add any new style conventions introduced in agent def since archival
   - Remove V3 references, update to V4 patterns
5. Add V4 YAML frontmatter with "Used by: cf-planning, cf-documentation"
6. Ensure all workflow diagrams use ASCII art (no Mermaid)

### Merge Strategy

| Archived Content | Agent Def Source | Merge Action |
|------------------|------------------|--------------|
| Doc structure standards | cf-documentation SOP: documentation procedures | Merge: keep archived standards, add agent def improvements |
| Style conventions | cf-documentation SOP: style and formatting rules | Merge: incorporate refined conventions |
| Quality checks | cf-documentation Quality Checklist | Merge: add any new checks from agent def |
| V3 sentinel references | N/A | Remove and replace with V4 equivalents |

### What "merge with agent def improvements" means

1. Start with the archived skill's operation structure and procedure steps
2. Compare each section with corresponding content in the cf-documentation agent def
3. If the agent def has additional quality checks or standards: ADD them to the skill
4. If the agent def has refined or clarified a convention: USE the clearer version
5. If the agent def references V4 concepts not in the archived skill: INCLUDE them
6. If the archived skill has content NOT in the agent def: KEEP it
