## Description

Restore the archived `cf-documentation-standards` skill (267 lines at `.codeflow/docs/archived/skills/cf-documentation-standards/`), MERGE the current `cf-markdown-standards` skill (~410 lines at `.claude/skills/cf-markdown-standards/SKILL.md`) into it, and update with improvements from the current `cf-documentation` agent definition. This is a THREE-WAY MERGE: archived cf-documentation-standards (structural base) + current cf-markdown-standards (markdown formatting, templates, lint rules) + agent def improvements.

"Markdown" is too narrow a name (it's a file format); "documentation standards" is the broader discipline covering templates, structure, style, and formatting. The merged cf-documentation-standards absorbs ALL content from cf-markdown-standards. After the merge, the current cf-markdown-standards skill directory is archived to `.codeflow/docs/archived/skills/`.

### Restoration Steps

   - Merge ALL content from cf-markdown-standards (markdown formatting, templates for epic/task/ADR, section structure, heading standards, lint rules)

### Merge Strategy

| Content Domain | Source 1 (Archived) | Source 2 (cf-markdown-standards) | Source 3 (Agent Def) | Merge Action |
|----------------|--------------------|---------------------------------|---------------------|--------------|
| Doc structure standards | cf-documentation-standards archive | -- | cf-documentation SOP | Merge: keep archived, add agent def improvements |
| Markdown formatting | -- | cf-markdown-standards (headings, lists, links) | -- | Absorb: all formatting rules from cf-markdown-standards |
| Templates (epic, task, ADR) | -- | cf-markdown-standards (template sections) | -- | Absorb: all templates from cf-markdown-standards |
| Style conventions | cf-documentation-standards archive | cf-markdown-standards (style rules) | cf-documentation SOP | Three-way merge: deduplicate, keep most comprehensive version |
| Quality checks | cf-documentation-standards archive | cf-markdown-standards (lint rules) | cf-documentation Quality Checklist | Three-way merge: combine all checks |
| V3 sentinel references | Archive only | -- | -- | Remove and replace with V4 equivalents |

### What "three-way merge" means

1. Start with the archived cf-documentation-standards skill as the structural base
2. Absorb ALL content from current cf-markdown-standards (templates, formatting rules, lint rules, heading standards)
3. Compare each section with corresponding content in the cf-documentation agent def
4. If the agent def has additional quality checks or standards: ADD them
5. If the agent def has refined or clarified a convention: USE the clearer version
6. If the agent def references V4 concepts not in the archived skill: INCLUDE them
7. If the archived skill has content NOT in the agent def or cf-markdown-standards: KEEP it
8. Deduplicate: where archived skill and cf-markdown-standards overlap, keep the more comprehensive version
9. Result: single cf-documentation-standards skill covering ALL documentation concerns (structure, style, templates, formatting, quality)
