## Description

Slim 4 role agent definitions by removing the duplicated Working Protocol section and trimming Communication sections. Unlike function agents (batch 1), role agents keep their SOPs inline because these contain role-specific logic that cannot be extracted to a shared skill. The reductions are smaller (4-9% per agent) but still eliminate duplication.
