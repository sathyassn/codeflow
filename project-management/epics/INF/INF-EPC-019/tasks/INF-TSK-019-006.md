## Description

Restore the archived `cf-code-exploration` skill (265 lines at `.codeflow/docs/archived/skills/cf-code-exploration/`) and update it with improvements from agent definitions that use codebase exploration (cf-development, cf-planning, cf-review). ## Approach

### Cross-Reference Requirement (Principle 0: No Blind Restore)

Before writing ANY operation, the implementer MUST:

1. Read the archived skill (structural base)
2. Read the CURRENT agent defs that consume this skill (cf-development, cf-planning, cf-review)
3. Read the CURRENT CLAUDE.md sections referencing codebase exploration -- verify alignment
4. Reconcile: the final skill must reflect the CURRENT state, not the archived state

### Restoration Steps

1. Read archived skill at `.codeflow/docs/archived/skills/cf-code-exploration/SKILL.md` (265 lines)
2. Read agent defs that use exploration patterns:
   - `.claude/agents/cf-development.md` -- code exploration during implementation
   - `.claude/agents/cf-planning.md` -- architecture analysis during planning
   - `.claude/agents/cf-review.md` -- code comprehension during review
3. Identify exploration-related content in each agent def (search patterns, Glob/Grep strategies, code comprehension procedures)
4. **MERGE** archived skill content with agent def improvements:
   - Use archived skill as the structural base
   - Add any enhanced Glob/Grep/Read strategies from agent defs
   - Incorporate architecture analysis patterns from cf-planning
   - Include review-specific exploration patterns from cf-review
   - Remove V3 references, update to V4 patterns
5. Add V4 YAML frontmatter with "Used by: cf-planning, cf-development, cf-review"
6. Ensure all workflow diagrams use ASCII art (no Mermaid)

| Archived Content | Agent Def Sources | Merge Action |

| Search patterns (Glob/Grep/Read) | cf-development SOP: codebase exploration step | Merge: keep archived patterns, add any new strategies from agent def |

| Architecture analysis | cf-planning SOP: explore codebase step | Merge: add architecture analysis patterns for planning |
| V3 sentinel references | N/A | Remove and replace with V4 equivalents |

### What "merge with agent def improvements" means

1. Start with the archived skill's operation structure and procedure steps
2. Read each agent def for exploration-related content
3. If an agent def has search strategies not in the archived skill: ADD them
4. If an agent def has improved Glob/Grep patterns: USE the improved version
5. If an agent def references V4 concepts not in the archived skill: INCLUDE them
6. If the archived skill has content NOT in the agent defs: KEEP it
