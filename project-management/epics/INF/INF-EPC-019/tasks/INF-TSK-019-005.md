## Description

Create a new shared skill `cf-team-communication` that extracts common communication patterns currently duplicated across all 8 agent definitions. The 8 agents have ~259 total Communication section lines, of which ~170 lines are common patterns eligible for extraction (per 06-skills-detail.md source extraction map). After extraction, each agent's Communication section retains only agent-specific peer information (~5-10 lines each), saving ~120-160 lines across all agents.

## Approach

### Cross-Reference Requirement (Principle 0: No Blind Restore)

Before writing ANY operation, the implementer MUST:

1. Read ALL 8 CURRENT agent definitions (not just their Communication sections -- understand the full context)
2. Read the CURRENT CLAUDE.md Section 5 (Communication Patterns) to verify alignment
3. Read CURRENT command files that reference communication patterns
4. Reconcile: the skill must reflect the CURRENT message formats and routing conventions

### Extraction Steps

1. Read Communication sections from all 8 agent definitions:
   - cf-knowledge-layer (55 lines), cf-git-operations (35 lines), cf-development (33 lines)
   - cf-security (30 lines), cf-planning (28 lines), cf-documentation (26 lines)
   - cf-quality-assurance (26 lines), cf-review (26 lines)
2. Identify common patterns shared across 3+ agents:
   - Commit request format: `"Please commit: {type}: {description}"`
   - Progress update format: `"{PREFIX}-UPDATE: task={id}, status={status}"`
   - Escalation format: `"BLOCKED: {reason}"`, `"ESCALATE: {issue}"`
   - Stage completion format: `"STAGE-COMPLETE: WS-{stage}"`
   - Peer routing: who sends to cf-git-operations, cf-knowledge-layer, cf-security, team-lead
3. Organize into 5 operations
4. Write SKILL.md with "Used by: all agents" scope
5. Document which lines can be removed from each agent's Communication section
