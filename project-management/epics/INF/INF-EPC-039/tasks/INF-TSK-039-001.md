# INF-TSK-039-001: Fix PID detection, centralized liveness, interactive cleanup UX

## Description

Three-layer fix for broken PID detection and cleanup UX:

**Layer 1 — PID Writers:** `get_claude_code_pid()` in `session/process.rs` currently walks up exactly 2 levels assuming `claude → sh -c → codeflow`, but the actual process tree is `claude → zsh → codeflow` (no `sh -c`). Fix uses name-based tree walk to find the claude process. Add `validate_claude_pid()` to verify before storage. Fix `worktrees.yaml` writer which uses `std::process::id()` (ephemeral hook PID, always dead).

**Layer 2 — Centralized Readers:** Create `session/liveness.rs` with `check_session_liveness()`. All 11 existing PID readers currently implement ad-hoc liveness checks. Centralize into one function: PID liveness check + heartbeat fallback (24h default threshold).

**Layer 3 — Interactive Cleanup UX:** Implement `codeflow worktree cleanup` interactive flow: analyze all worktrees → display status table → confirm → execute. Support `--force <id>` for targeted cleanup and `--force all` for nuclear cleanup.
