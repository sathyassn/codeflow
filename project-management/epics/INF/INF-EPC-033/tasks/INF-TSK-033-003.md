## Description

Fix three categories of autorun session management bugs:

1. **Stale session detection**: Three-layer liveness check (PID alive, tmux pane alive, heartbeat recency). Sessions detected as stale are automatically swept and cleaned up.
2. **Cleanup subcommand**: New `codeflow autorun cleanup` subcommand to list and remove stale sessions from the DB and worktree registry.
3. **Abort/resume fixes**: `codeflow autorun abort` correctly marks sessions as aborted in DB; `codeflow autorun resume` skips already-complete/aborted sessions.

20 individual changes across 8 files, with 58 acceptance criteria.
