### DEV Report

> Populated by cf-development before STAGE-COMPLETE: WS-DEV

**Verdict:** PASS

**Implementation Summary:**

Three related path resolution bugs fixed across 8 files:
1. `WorktreeManager::resolve_effective_root()` -- new public method that detects when running from inside a worktree (via `.git-worktrees/` ancestor walk or `.git` file parse) and returns the main repo root. `WorktreeManager::new()` uses this to set `base_dir` and `registry_path` relative to the main repo even when instantiated from a worktree path.
2. `CF_PROJECT_ROOT` now stores the absolute main repo path (via `resolve_effective_root`) instead of just the directory basename. All readers (`ProtectionGuard`, `TmpModule`) extract the basename when needed for tmp folder paths.
3. `scan_orphaned_directories` now receives `base_dir` from `WorktreeManager` instead of constructing it from `project_dir`. `worktree.rs::run()` uses `detect_project_root()` instead of `detect_project_dir()`.
4. `DEFAULT_BASE_DIR` made `pub` and used by `autorun/config.rs` and `autorun/worker.rs` instead of hardcoded strings.
