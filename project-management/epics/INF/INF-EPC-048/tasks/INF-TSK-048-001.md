## Description

Six P0 reliability fixes for the autorun subsystem. Each fix addresses a distinct bug or missing feature, but they are grouped into a single FIX task and PR to reduce merge overhead. The fixes span: hook enforcement, rescue subsystem refactor, report commit safety, status TUI correctness, CI-wait before merge, and configuration gate addition.

**Deployment:** PR merge to main. Binary rebuild required for TUI and CLI changes.

## Approach

1. **gh-pr-guard**: In `pre_tool_use.rs`, when `AUTORUN_SESSION_ID` env is set and command is `gh pr create`, verify `--base` arg is present and matches `AUTORUN_INTEGRATION_BRANCH` env (fallback: `active-task.json:target_branch`). Block with clear error if mismatch.
2. **Rescue refactor**: Replace branch-commit path in `rescue_uncommitted_work()` with `git format-patch` into `.state/rescue/{sid}-{ts}-{pid}/`. Gate rescue on `GateConfig(pr_pushed)` + `LedgerEvent(PrCreated)` — only run if PR already pushed. Add `codeflow rescue list|show|apply|drop` subcommands.
3. **Ephemeral report commit**: Rewrite `commit_report_to_branch()` to: `git worktree add --detach .git-worktrees/_orch-report-{ts}-{pid}/`, checkout target branch, write report, commit (hooks run normally), `git push --force-with-lease` with up-to-3 retries, capture stderr on failure, `git worktree remove` on exit. Write no-rescue marker in ephemeral worktree.
4. **pathflow-config gate**: Add `session_complete` entry to gates section with `on_phase_complete: PF7-END`.
5. **Status TUI bulk query**: Replace per-session query loop with `SELECT * FROM autorun_sessions WHERE session_id IN $ids`. Spawn background `tokio::task` with `tokio::sync::watch` channel; render thread reads snapshot. 2s fetch timeout with stale-snapshot fallback; `[STALE — Ns]` footer.
6. **AutorunSession schema**: Add `DEFINE FIELD current_task_id ON autorun_sessions TYPE option<string>; DEFINE FIELD updated_at ...; DEFINE FIELD last_heartbeat_at ...` to `schema.surql`. Update writers on task dispatch, task state change, and heartbeat (10s).
7. **TUI columns**: Add TASK column from `current_task_id`. Freeze ELAPSED for terminal statuses. Add IDLE column (Running only), RED when `> heartbeat_ttl` (120s default). Esc/r/? key bindings.
8. **CI-green wait**: After `gh pr create`, poll `gh pr checks` until all required checks pass or timeout (configurable via `.codeflow/config/autorun/ci-wait.json`, default 30min). On fail/timeout: leave PR open, mark task `blocked`, release merge-queue slot.
9. **Hardcoded phase-name removal**: Replace `resolve_pr_pushed_sentinel_name()` fallback at `autorun.rs:3922` with `return Err(...)`. Ensure all new code uses `GateConfig` or `LedgerEvent` enum variants — no string literals.
10. **Tests**: Add unit tests per fix area. Add guard test that greps modified files for `\bpf-[0-9]\b` and `\bws-(dev|plan|docs|rev|qa|test|sec)\b` outside sentinel/phase modules.
