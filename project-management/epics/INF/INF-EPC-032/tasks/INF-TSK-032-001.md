## Description

Fix two bugs preventing independent Claude Code windows from getting their own isolated git worktrees:

1. **Teammate false positive** in `handle_stale_cleanup()` (`session_start.rs`): The function reads `lead_pid` from a prior session's `pathflow-team.json` and detects it as alive, incorrectly treating the new lead session as a teammate and skipping worktree creation.

2. **Stale worktree reuse** in `detect_precreated_worktree_inner()` (`post_tool_use.rs` or `mod.rs`): The function finds a prior session's worktree in `worktrees.yaml` and returns it as "pre-created", causing the new session to inherit the stale worktree.

Additionally: create a design document for multi-session worktree isolation and renumber the missequenced INF-EPC-922 epic to INF-EPC-029.
