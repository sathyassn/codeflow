## Description

Write comprehensive user-facing documentation for the Generic Testing Framework introduced in INF-EPC-046. The framework is config-driven and stack-agnostic — it can orchestrate tests for any language given a test-config.json with runner commands, coverage paths, and threshold rules. This task produces the single authoritative user-facing guide covering architecture, configuration schema, per-stack quickstart guides, coverage model, CLI reference, PR body format, WS-QA integration, template library, and troubleshooting.

This task can execute in parallel with INF-TSK-046-006 (CHOR — flag removal + binary verification). There is no file overlap between the two tasks. Both depend only on INF-TSK-046-005 (PR #293 merging).
