# INF-TSK-041-001: Fix worktree cleanup orphan scan independence and force override

## Description

Fix three related bugs in the worktree cleanup flow:

1. **Orphan scan independence**: The orphan scan (`cleanup_orphan`) is blocked by early returns in the main cleanup flow when all registry entries are alive or the registry is empty. The orphan scan should always run regardless of the state of registry entries, since orphaned worktree directories may exist even when no stale registry entries are found.

2. **--force override**: The `--force` flag in `cleanup_stale` does not override alive entry protection. When `--force` is passed, it should remove entries unconditionally even if their associated processes are still alive (needed for manual cleanup of stuck sessions).

3. **dry_run propagation**: The `dry_run` parameter is not correctly propagated to the `cleanup_orphan` function, causing orphan cleanup to always execute in non-dry-run mode even when the user requested a dry run.
