# INF-TSK-016-001: Fix PathFlow cleanup logic: session-end, team-guard, sentinel hooks

## Description

Fix bugs in the PathFlow cleanup system that cause improper session lifecycle management. This task addresses three areas:

1. **Session-end hook**: The `is-pathflow-active` flag is not being removed correctly at session end, causing stale state in subsequent sessions
2. **Team-guard hook**: The `cf-pre-tool-use-team-guard.sh` hook is not correctly gating TeamDelete during active PathFlow sessions
3. **Sentinel creation hooks**: Phase/stage sentinels are not being created at the correct phase boundaries

## Approach

1. Identify the exact failure modes in each hook
2. Fix session-end cleanup logic
3. Fix team-guard gate enforcement
4. Fix sentinel creation hooks
5. Write/update tests for each fix
6. Verify full test suite passes
