## Approach

1. Run `cargo audit --file codeflow-cli/Cargo.lock` to confirm the 5 advisory IDs are present
2. Check upstream surrealdb releases (`cargo search surrealdb`, GitHub releases) for a version that pulls in patched quinn-proto and rustls-webpki
3. If a patched surrealdb version is available: bump `surrealdb` in `Cargo.toml`, run `cargo update`, verify audit clean
4. If no patched surrealdb exists yet: use `[patch.crates-io]` or `cargo update -p quinn-proto --precise <patched-version>` to pin transitive deps directly
5. Run `codeflow test --mode full` to confirm no regressions
6. Re-run `cargo audit` to confirm zero remaining advisories for the 5 IDs
