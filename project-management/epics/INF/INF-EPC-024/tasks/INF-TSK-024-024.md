## Description

Update the cf-knowledge-layer agent definition (`.claude/agents/cf-knowledge-layer.md`) to reference the canonical event schema and enforce standardized field usage. The cf-knowledge-layer teammate is the primary agent that writes JSONL events (via the Rust `codeflow` CLI), manages the three-tier data model, and performs DB operations. After schema standardization, the agent definition must reflect the new canonical conventions to prevent regression through incorrect field usage in prompts and operations.

In the post-Epic 0 Rust codebase, many schema violations are caught at compile time (EventType enum exhaustive match, SessionId/WorktreeId newtypes). The agent definition update documents these type-level guarantees and references the Rust types that enforce them.

This is an additive update -- existing valid instructions are preserved, and new references to schema standardization deliverables are added.
