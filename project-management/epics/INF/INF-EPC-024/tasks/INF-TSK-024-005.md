# INF-TSK-024-005: Log audit: pathflow-events.jsonl and pr-events schema documentation

## Description

Document the pathflow-events.jsonl and pr-events JSONL schemas. These log files have unique issues: pathflow-events has a dual-generation problem (both Go's TransitionWriter and shell's pathflow-state.sh write to it), and pr-events has a dead writer (shell hooks retired during Go migration) with partial compensation from work-graph.jsonl pr_created/pr_merged events.

Both schemas need to be mapped to Rust target types for the post-Epic 0 codebase.

## Approach

1. Read schema-standardization.md Section 2.1 (pathflow-events) and Section 2.2 (pr-events)
2. Read `.state/logs/pathflow-events.jsonl` to verify dual-generation patterns
3. Document pathflow-events schema: Go-written entries vs shell-written entries
4. Document the `e` field naming (non-canonical -- should be `event`)
5. Document pr-events: legacy shell format vs current work-graph.jsonl coverage
6. Assess whether pr-events JSONL should be revived in Rust or fully replaced by work-graph events
7. Map both to Rust types at `codeflow-core/src/ledger/` or `codeflow-core/src/logs/`
8. Write both audit documents
