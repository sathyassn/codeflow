## Description

Synthesize all audit outputs (tasks 001-006) into a single normative canonical event schema document. This document defines the universal required fields, per-event-type fields, deprecated field mappings, and Rust type structure for all JSONL events.

The canonical schema references existing types in `codeflow-cli/core/src/types/` and proposes new types only where gaps exist.

## Approach

1. Read all 6 audit documents (outputs of tasks 001-006)
2. Read `codeflow-cli/core/src/types/` to understand existing type definitions
3. Identify universal required fields across all event types
4. Define per-event-type required field tables
5. Create deprecated field mapping table
6. Propose Rust types for gaps (CanonicalEvent, SchemaError)
7. Reference existing types (SessionId, EventType, etc.)
8. Specify the details object pattern
9. Write the canonical schema document
