## Description

Enforce session_id as a required field on all JSONL event writers in the Rust codebase. The SessionId newtype (already defined in `codeflow-cli/core/src/types/ids.rs`) should be used to guarantee type-safe session identification on every event.

## Approach

1. Read canonical schema from task 007 for session_id requirements
2. Read `codeflow-cli/core/src/types/ids.rs` to verify SessionId exists and its current validation
3. Read `codeflow-cli/core/src/ledger/jsonl.rs` to understand LedgerWriter API
4. Audit all call sites of LedgerWriter to identify events missing session_id
5. Add session_id as a required parameter to LedgerWriter::append (or verify it already is)
6. Update hook writers to include session_id
7. Write unit tests
