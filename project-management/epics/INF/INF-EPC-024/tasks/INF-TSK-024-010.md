# INF-TSK-024-010: Add session_id to all JSONL writers (schema enforcement)

## Description

Enforce `session_id` as a required field on ALL JSONL event writers. Currently, some writers omit session_id (notably commits-*.jsonl has no session_id at all). In Rust, this is enforced at the type level: writer functions require `SessionId(Ulid)` as a parameter, making omission a compile-time error rather than a runtime surprise.

Uses shared types from INF-TSK-024-007: CanonicalEvent, SchemaError, SessionId, FieldName.

## Approach

1. Read canonical event schema (output of INF-TSK-024-007)
2. Audit all writer call sites in `codeflow-core/src/` that produce JSONL events
3. Update writer trait/function signatures to require `SessionId` parameter
4. Update `schema.rs` validation to reject events without session_id
5. Update git commit writer to include session_id
6. Update hook writers (logging, activity) to include session_id
7. Implement `SessionId::new()` with ULID format validation
8. Write unit tests and insta snapshot tests
9. Run `cargo test`, `cargo clippy`, `cargo fmt --check`
