# INF-TSK-024-004: Ledger audit: config.jsonl schema documentation and gap analysis

## Description

Document the config.jsonl schema -- the simplest of the four ledger files. Config events (`config_set`, `config_updated`) store key-value configuration changes. Schema-standardization.md notes that the required-field maps for config events in schema.go are currently empty `{}`, meaning no field validation is enforced.

This audit verifies the routing and validation infrastructure for config events and maps fields to the Rust target types at `codeflow-core/src/ledger/config.rs`.

## Approach

1. Read schema-standardization.md Section 1.4 (config.jsonl audit)
2. Read existing `.state/ledger/config.jsonl` to verify actual field usage
3. Document config_set and config_updated event schemas
4. Verify routing table entry in schema-standardization.md (maps to config.jsonl)
5. Document the empty validation map gap and what fields should be required (key, value)
6. Map to Rust types: `ConfigKey(String)`, `ConfigValue(serde_json::Value)`
7. Write the audit document
