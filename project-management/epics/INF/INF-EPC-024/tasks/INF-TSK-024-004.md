## Description

Document the config.jsonl schema -- the simplest of the four ledger files. Config events (`config_set`, `config_updated`) store key-value configuration changes. This audit verifies the routing infrastructure for config events in the Rust codebase and maps fields to target types.

## Approach

1. Read schema-standardization.md Section 1.4 (config.jsonl audit)
2. Read existing `.state/ledger/config/config.jsonl` (base) and session fragments to verify actual field usage (note: subdirectory layout per PR #221; run `codeflow ledger migrate` if still flat)
3. Read `codeflow-cli/core/src/ledger/routing.rs` to verify routing table entry for config events
4. Document config_set and config_updated event schemas
5. Document any validation that exists in the Rust codebase for config events
6. Map to Rust types: reference existing patterns in `codeflow-cli/core/src/types/`
7. Write the audit document
