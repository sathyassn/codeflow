## Description

Document the autorun-events.jsonl schema for all 9 autorun event types emitted by the autorun subsystem. These events are routed via `ledger/routing.rs` and represent batch lifecycle (start, complete, abort) and worker lifecycle (start, complete, fail, timeout, block, cancel). The events are defined as `AutorunEvent` enum variants in `codeflow-cli/core/src/coordination/types/events.rs`.

Autorun events are in `files::ALL` (7 types) but excluded from `files::CANONICAL` (4 types synced to DB). Three separate autorun DB tables exist in schema.surql: `autorun_session`, `autorun_worker`, `autorun_task_run`. This audit must clarify whether autorun-events.jsonl is redundant with, complementary to, or independent of these DB tables.

No autorun-events data may exist on disk yet. Schema derived from Rust types.

This audit feeds into INF-TSK-024-007 (canonical event schema synthesis).
