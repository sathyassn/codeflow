## Description

Three interrelated worktree mode issues:

1. **JSONL ledger is SHARED (symlinked)** -- writes from worktree land on main repo's working tree, not the feature branch. Parallel workers interleave events.
2. **Main repo codeflow-env.sh missing CODEFLOW_WORKTREE_PATH** -- hooks running from main repo CWD can't find the worktree, breaking the sentinel chain.
3. **Stale session dirs** -- main repo retains old `.state/session/{old-SID}/` dirs from previous sessions.

Fix: Session-scoped ledger with subdirectory layout, main repo env redirect, stale session cleanup, ledger CLI commands, auto-migration, and doctor health check.

## Approach

1. Restructure ledger from flat files to subdirectories per canonical type with session-scoped fragments
2. Update routing to return directory names instead of filenames
3. Add session_id to JsonlWriter for session-scoped path resolution
4. Create compact.rs, rebuild.rs, migrate.rs modules
5. Move ledger from SHARED_STATE_DIRS to LOCAL_STATE_DIRS
6. Add worktree env redirect in session_start.rs
7. Add stale session cleanup in worktree setup
8. Expand ledger CLI with status/compact/rebuild/migrate subcommands
9. Add auto-migration in SessionStart
10. Add doctor ledger health check
11. Update .gitignore for new layout

## Concurrency Considerations

- **Shared resource:** `.state/ledger/` -- currently symlinked (shared), will become local (copied)
- **Access pattern:** After this fix, each worktree has its own ledger copy. No cross-worktree writes to same files.
- **Safety mechanism:** File locking in `LedgerWriter` still applies for concurrent writes within a single worktree (multiple hooks writing simultaneously). Cross-worktree isolation is achieved by having separate file copies.
- **Merge strategy:** Ledger events from the worktree branch are committed to git and merged with the main branch at PR merge time. JSONL files are append-only, so merge conflicts are unlikely (both sides add lines). If conflicts occur, both sides' entries should be kept (union merge).
