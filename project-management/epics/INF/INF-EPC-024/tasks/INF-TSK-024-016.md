## Description

Create retention policy documentation for Tier 0 JSONL ledger files. The fundamental rule is: **NEVER delete** Tier 0 data -- ledger files are the rebuild authority for the three-tier data model. Loss means data loss. Instead, old data is archived (moved to archive directory) and compressed.

Currently, NO retention policies exist for any file category. Files grow unbounded. With parallel sessions (INF-EPC-023) increasing write volume proportionally, this becomes unsustainable.

The policy document specifies the Rust CLI interface (clap-based subcommand) that will implement these policies in INF-TSK-024-018. Decision #15 (Retention Policies) from the analysis phase governs this work.
