# INF-TSK-024-027: Resolve batch dependencies from DB tasks table

## Description

Change the autorun orchestrator to read task dependencies from the SurrealDB `tasks.dependencies` field when the batch `TaskSpec.depends_on` field is empty. Currently, task dependencies in autorun batches are specified explicitly in the batch file. This task adds DB-backed dependency resolution as a complement, so the orchestrator can automatically order tasks based on the dependency graph stored in the DB.

Dependencies from the DB are filtered to only include tasks present in the current batch -- cross-batch dependencies are not relevant for scheduling within a single batch execution. The batch `depends_on` field remains as an optional override: if specified, it takes precedence over DB dependencies.

## Approach

1. Read current `orchestrator.rs` dependency resolution logic
2. Read current `batch.rs` TaskSpec struct for depends_on field
3. Read `codeflow-cli/core/src/workgraph/query.rs` for dependency query patterns
4. Add `resolve_dependencies(db, batch_tasks) -> DependencyGraph` function to orchestrator
5. Query DB: `SELECT dependencies FROM tasks WHERE format_id IN $batch_task_ids`
6. Filter dependencies to batch-local tasks only
7. Build DAG from filtered dependencies
8. Detect cycles using topological sort (report error, mark tasks blocked)
9. Integrate into `dispatch_ready_tasks()` scheduling
10. Write unit tests with mock DB data
