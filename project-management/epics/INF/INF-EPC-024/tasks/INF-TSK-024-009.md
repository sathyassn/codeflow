## Description

Collapse three coexisting schema patterns in memory-events.jsonl to a single canonical format. This is the most complex schema standardization task in the epic due to the three distinct patterns: (1) nested data+event_type (~80%), (2) flat aliases (~10%), (3) non-canonical types (~10%).

## Approach

1. Read audit document from task 003 and canonical schema from task 007
2. Read `codeflow-cli/core/src/types/events.rs` for existing event type patterns
3. Read `codeflow-cli/core/src/ledger/jsonl.rs` for LedgerWriter
4. Define or extend memory event type enum in `types/events.rs`
5. Add write-time validation to reject non-canonical types
6. Add read-time normalization for legacy patterns
7. Add flattening for doubly-nested data.data
8. Write comprehensive unit tests
