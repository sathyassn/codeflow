# INF-TSK-024-009: Standardize memory-events.jsonl: consolidate 3 schema patterns to 1

## Description

This is the LARGEST SCHEMA CHANGE in the epic. Currently, memory-events.jsonl has three coexisting patterns: (1) nested data+event_type (~80%), (2) flat aliases (~10%), (3) non-canonical types (~10%). The Rust writer must produce only the 6 canonical event types and the normalizer must handle all legacy patterns.

Uses shared types from INF-TSK-024-007: CanonicalEvent, SchemaError, FieldName, EventType.

## Approach

1. Read memory-events audit (output of INF-TSK-024-003) for pattern details
2. Read canonical event schema (output of INF-TSK-024-007) for canonical types
3. Define `MemoryEventType` enum with serde rename_all for serialization
4. Define `MemorySchemaError` enum with thiserror
5. Update `memory_events.rs` writer to produce only canonical types
6. Update `normalize.rs` to map legacy types and flatten doubly-nested data
7. Implement backward-compatible reader via serde untagged enum for 3 patterns
8. Write unit tests for each canonical type and each legacy pattern
9. Write proptest for round-trip serialization (100+ cases)
10. Write insta snapshot tests for each canonical type's JSON output
11. Run `cargo test`, `cargo clippy`, `cargo fmt --check`
