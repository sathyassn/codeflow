# INF-TSK-024-006: Log audit: security, network, conversation log schema documentation

## Description

Document the security, network, and conversation log schemas. These are the most problematic log files: security and network logs have completely dead JSONL writers (shell hooks retired during Go migration, Go replacement uses slog to stderr), security logs are pretty-printed (violating JSONL spec), and several log directories are discontinued.

This audit determines which logs need new Rust writers in `codeflow-core/src/logs/` and which are obsolete artifacts.

## Approach

1. Read schema-standardization.md Sections 2.3-2.5 (security, network, conversation logs)
2. Read schema-standardization.md Section 3 (Discontinued Logs Assessment)
3. Examine `.state/logs/security/` directory structure for actual JSONL files
4. Document security log schema: audit, blocked, protection subdirectories
5. Document network log schema: fields, pretty-printing violation
6. Document conversation log format (if JSONL exists)
7. Catalog discontinued logs: sentinel, stop-events, git-operations, test-category
8. Assess Rust target: which logs get new writers vs deprecated
9. Write all three audit documents
