# INF-TSK-024-011: Add worktree field to all JSONL writers

## Description

Add the `worktree` field to all JSONL writers. This field is required for the parallel execution support in Epic A (INF-EPC-023) -- without worktree attribution, events from parallel sessions cannot be distinguished. The field uses `WorktreeId(String)` newtype and is `Option<WorktreeId>` in the writer, serializing as empty string for non-worktree sessions.

Uses shared types from INF-TSK-024-007: CanonicalEvent, SchemaError, WorktreeId.

## Approach

1. Read canonical event schema (output of INF-TSK-024-007)
2. Define `WorktreeId(String)` newtype in `codeflow-core/src/types/`
3. Update `CanonicalEvent` struct to include `worktree: Option<WorktreeId>`
4. Update all writer functions to accept `Option<WorktreeId>` parameter
5. Update schema validator: worktree required (empty string accepted)
6. Add special validation: begin_work/complete_work require non-empty WorktreeId
7. Add backward-compatible deserialization: missing field defaults to empty string
8. Write unit tests and insta snapshot tests
9. Run `cargo test`, `cargo clippy`, `cargo fmt --check`
