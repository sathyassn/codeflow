## Description

Add a worktree field to all JSONL event writers. This field identifies which worktree produced the event, enabling correct event attribution in parallel session scenarios. The field is nullable (None for non-worktree sessions) but required for worktree-scoped events like begin_work and complete_work.

## Approach

1. Read canonical schema from task 007 for worktree field requirements
2. Read `codeflow-cli/core/src/types/ids.rs` to check if WorktreeId exists
3. Read `codeflow-cli/core/src/worktree/` module for existing worktree types
4. Add WorktreeId to types if not present
5. Add worktree field to LedgerWriter event output
6. Add validation: worktree-scoped events require non-empty worktree in worktree mode
7. Add backward compatibility for reading events without worktree field
8. Write unit tests

## Concurrency Considerations

- **Shared resource:** `.state/ledger/*.jsonl` files -- written by LedgerWriter
- **Access pattern:** Append-only JSONL writes via file lock in `jsonl.rs`
- **Safety mechanism:** `LedgerWriter` uses file locking. Adding worktree field enables event attribution across concurrent worktree sessions.
- **Worktree impact:** This task directly supports worktree isolation by tagging events with their source worktree. Critical for parallel session debugging and event replay.
