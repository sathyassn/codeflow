## Description

Document the coordination-events.jsonl schema for all 6 coordination event types emitted by the CRDT coordination subsystem. These events are routed via `ledger/routing.rs` and represent claim lifecycle operations (acquire, conflict, release, scope expansion) and merge conflict operations (detect, rebase). The events are defined as `CoordinationEvent` enum variants in `codeflow-cli/core/src/coordination/types/events.rs`.

Coordination events are in `files::ALL` (7 types) but excluded from `files::CANONICAL` (4 types synced to DB). However, a `coordination_event` table already exists in `schema.surql` with 10 fields. This audit must clarify the relationship: are JSONL events synced to the DB table, or are they written independently?

No coordination-events data may exist on disk yet (no parallel sessions may have run). If no file exists, document the expected schema from Rust types only and note the absence of empirical data.

This audit feeds into INF-TSK-024-007 (canonical event schema synthesis).
