## Description

Update Claude Code configuration artifacts (CLAUDE.md, agent definitions, command definitions) to document the new DB-authoritative data flow for autorun task metadata. After tasks INF-TSK-024-026 and INF-TSK-024-027, the autorun orchestrator reads task metadata (file_scope, scope_policy, dependencies) from SurrealDB instead of parsing markdown frontmatter. These documentation artifacts must reflect the new data flow to prevent agents from assuming markdown is the authoritative source during autorun execution.

This is an additive update -- existing valid instructions are preserved.
