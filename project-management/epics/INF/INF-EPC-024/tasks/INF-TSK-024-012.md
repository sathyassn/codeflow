# INF-TSK-024-012: Migrate ad-hoc flat fields to details object in sessions.jsonl writer

> **MANDATORY VALIDATION:** Files created from this template MUST be validated before committing:
> `codeflow validate task <file-path>`
> Fix all errors (exit code 1) before requesting a commit. Warnings are advisory.

## Description

Move variable event-specific fields from top-level to a `details` object in sessions.jsonl events. Universal fields (timestamp, event, session_id, worktree) remain top-level. Variable fields (source, interaction_mode, work_completed, summary) go into a nested details object. This standardizes the sessions.jsonl format to match the canonical schema pattern.

| Unit tests | test | `codeflow-cli/core/src/ledger/`, `hooks/` | cargo test coverage enforcement |

**Expected Outcome:** New sessions.jsonl events nest variable fields (source, interaction_mode, work_completed, summary) under a details object. Universal fields (timestamp, event, session_id, worktree) remain top-level. Legacy entries are normalized on read.
**Deployment:** PR merge; backward-compatible read path handles both old and new formats.
