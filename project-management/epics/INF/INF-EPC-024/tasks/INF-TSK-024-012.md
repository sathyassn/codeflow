# INF-TSK-024-012: Migrate ad-hoc flat fields to details object in sessions.jsonl writer

## Description

Move variable event-specific fields from top-level positions into a `details` object in the sessions.jsonl Rust writer. The canonical schema (INF-TSK-024-007) specifies: universal fields (timestamp, event, session_id, worktree) stay top-level; everything else goes into `details`. Old entries remain immutable (append-only invariant) -- the reader handles both formats.

Uses shared types from INF-TSK-024-007: CanonicalEvent, details object pattern.

## Approach

1. Read sessions audit (output of INF-TSK-024-001) for current field layout
2. Read canonical event schema (output of INF-TSK-024-007) for details pattern
3. Update `sessions.rs` writer to produce `details: { source, interaction_mode, ... }` structure
4. Update `normalize.rs` to convert flat entries -> details format on read
5. Implement serde custom deserializer that handles both flat and nested formats
6. Write unit tests for both formats
7. Write insta snapshot tests for canonical output
8. Run `cargo test`, `cargo clippy`, `cargo fmt --check`
