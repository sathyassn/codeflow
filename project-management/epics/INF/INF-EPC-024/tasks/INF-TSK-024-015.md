## Description

Ensure the Rust schema validator (`schema.rs`) enforces canonical required fields for all event types. This task consolidates all required-field changes from tasks 008-011 into a comprehensive validation update. The Rust type system provides compile-time guarantees that Go's runtime checks cannot: every `EventType` variant MUST have validation rules via exhaustive match, and `SessionId`/`WorktreeId` newtypes enforce format constraints at construction time.

Uses shared types from INF-TSK-024-007: CanonicalEvent, SchemaError, FieldName, EventType, SessionId, WorktreeId.

## Approach

1. Read canonical event schema (output of INF-TSK-024-007) for complete required-field specifications
2. Review current `schema.rs` validation logic
3. Add universal required fields to `validate_event()`: session_id (SessionId), worktree (WorktreeId)
4. Update per-event-type validation using exhaustive match on EventType enum
5. Update `SchemaError` variants for clear error messages identifying field + event type
6. Verify exhaustive match covers all EventType variants (compiler enforces this)
7. Write unit tests for each event type's required fields
8. Write proptest for arbitrary valid events passing validation (100+ cases)
9. Write insta snapshot tests for error messages
10. Run `cargo test`, `cargo clippy`, `cargo fmt --check`
