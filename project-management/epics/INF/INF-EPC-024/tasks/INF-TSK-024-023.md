## Description

Create comprehensive Rust tests that verify the JSONL writer enforcement layer works correctly after all Phase D (Schema) and Phase E (Enforcement) tasks are complete. These tests serve as the regression safety net for schema standardization -- if any future change breaks canonical field naming, required field enforcement, event routing, or deprecated field handling, these tests will catch it.

The tests cover four key areas: schema validation (`schema.rs` tests), event normalization (`normalize.rs` tests), event routing (`routing.rs` tests), and writer output format (writer tests). In Rust, some categories of bugs that required runtime tests in Go are eliminated at compile time -- for example, non-canonical event types cannot exist because they are not `EventType` enum variants. The tests focus on runtime behavior that the type system cannot catch.

Uses shared types from INF-TSK-024-007: CanonicalEvent, SchemaError, EventType, FieldName, SessionId, WorktreeId.

## Approach

1. Read canonical event schema (output of INF-TSK-024-007) for the complete list of EventType variants and required fields
2. Read current `schema.rs`, `normalize.rs`, `routing.rs`, and writer module for existing test patterns
3. Add tests to schema module:
   - One `#[test]` per canonical EventType variant verifying required fields
   - Test for universal required fields (timestamp, event, session_id, worktree)
   - Test for SchemaError variants on missing fields
4. Add tests to normalize module:
   - Deprecated field name conversion (ts->timestamp, event_type->event, e->event)
   - Timestamp format normalization to ISO 8601 UTC with milliseconds (chrono)
   - Idempotency: normalizing an already-normalized event is a no-op
5. Add tests to routing module:
   - Each canonical EventType variant routes to the correct JSONL file
   - Exhaustive match verified (compiler ensures this, tests document behavior)
6. Add writer tests:
   - Output is compact single-line JSONL (serde_json::to_string, not to_string_pretty)
   - Write followed by read roundtrips correctly
7. Add proptest for arbitrary CanonicalEvent round-trip (100+ cases)
8. Add insta snapshot tests for canonical JSON and error messages
9. Run `cargo test`, `cargo clippy`, `cargo fmt --check`
