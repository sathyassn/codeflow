# INF-TSK-024-042: Regression-prevention enforcement of canonical session ID resolution

> **MANDATORY VALIDATION:** Files created from this template MUST be validated against the task validation command before committing:
> `codeflow validate task <file-path>`
> Fix all errors (exit code 1) before requesting a commit. Warnings are advisory.

## Description

Task INF-TSK-024-028 (PR #301) consolidated session ID resolution: all hook handlers in the current codebase use `session::current_session_id(project_dir)` which reads from the per-worktree env file (with `CODEFLOW_SESSION_ID` env-var fallback). The previously-suspected "Systemic UUID Session ID Bug" is resolved — the 2026-04-22 chain audit verified this (see `audits/2026-04-22-chain-audit.md` Verification Closure row).

This task prevents **regression** by (a) introducing a single point of truth helper `resolve_session_id_for_hook()` that encapsulates the fallback chain, (b) migrating any direct `input.session_id` reads still present to the helper, (c) adding a lint test that fails CI if a future edit reintroduces a direct read, and (d) documenting the invariant in `cf-rust-standards`. The MEMORY.md "UUID Session ID Bug (Systemic)" block is updated as part of memory hygiene. Closes gap G3 from the 2026-04-22 chain audit (downgraded to LOW severity after verification).

**Deployment:** Compiled into the `codeflow` binary; SKILL change is a documentation update loaded on-demand by agents; MEMORY update is an agent-side artifact.

## Approach

1. Grep the hooks directory for every `input.session_id` site and catalogue them (file, line, context, disposition = keep/migrate/exempt).
2. Add the helper to `codeflow-cli/core/src/hooks/mod.rs`:
   ```rust
   /// Resolve the canonical session ID for a hook handler.
   ///
   /// Prefers the env-file-backed `session::current_session_id(project_dir)`;
   /// falls back to `input.session_id` with a stderr WARN when the env file
   /// is unavailable. Callers MUST use this helper — direct reads of
   /// `input.session_id` are forbidden by the regression lint.
   pub fn resolve_session_id_for_hook(input: &HookInput, project_dir: &Path) -> SessionId { ... }
   ```
3. Implementation:
   - Call `session::current_session_id(project_dir)` — the real signature at `session/mod.rs:207` is `pub fn current_session_id(project_dir: &Path) -> Result<SessionId, SessionError>` (returns `Result<SessionId, _>`, NOT `Result<Option<SessionId>, _>`).
   - On `Ok(id)`: return `id`.
   - On `Err(_)` (any SessionError variant): emit `eprintln!("warn: hook session-id fallback: env-file unavailable at {project_dir}; falling back to input.session_id={} (consider running inside codeflow -i)", input.session_id)` and return `SessionId::try_from(input.session_id.as_str()).unwrap_or_else(|e| { eprintln!("warn: input.session_id malformed: {e}"); SessionId::generated() })` (or the equivalent safe sentinel the codebase uses).
4. Migrate each `input.session_id` read in the hooks directory to call the helper. For any site that legitimately requires the raw Claude-provided ID (there should be zero — audit to confirm), add `// EXEMPT: <reason>` on the same line.
5. Add the regression lint test in `hooks/mod.rs` `#[cfg(test)]`:
   - Uses `std::fs::read_to_string` on each `hooks/*.rs` file path (discovered via `env!("CARGO_MANIFEST_DIR")`).
   - Walks lines; ignores `#[cfg(test)]` module bodies (track brace depth after encountering `#[cfg(test)] mod tests`).
   - Fails if any line contains `input.session_id` and does NOT contain `// EXEMPT:`.
6. Update `.claude/skills/cf-rust-standards/SKILL.md` with a new subsection under a "Hooks" or "Session ID resolution" heading documenting the invariant and helper.
7. Stage and produce the MEMORY.md diff per Section 5 Protected Resource Staged Edits (flat basename in `/tmp/claude/codeflow/managed/protected-edits/MEMORY.md`, supply reverse cp command to the user).
8. Run `cargo test --workspace`, `cargo clippy --all-targets --all-features -- -D warnings`, `cargo fmt --check`, then `codeflow test --mode full` twice.
