## Description

Create retention policy documentation for log files (as distinct from ledger files). Unlike Tier 0 ledger files which must NEVER be deleted, log files are operational data that can be rotated and deleted after their retention period.

The policy document specifies the Rust CLI interface (clap-based subcommand) that will implement these policies in INF-TSK-024-018. Decision #15 (Retention Policies) from the analysis phase governs this work.

## Approach

3. Define per-category retention periods
4. Define compression and rotation policies
5. List discontinued files for immediate deletion
6. Specify Rust CLI interface (clap subcommand)
7. Clearly distinguish from ledger retention policy
8. Write the policy document
