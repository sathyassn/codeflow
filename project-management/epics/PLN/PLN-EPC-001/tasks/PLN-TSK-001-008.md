# PLN-TSK-001-008: Plan: Epic 0 — Rust CLI Idiomatic Redesign

## Description

Create a comprehensive epic document and task breakdown for Epic 0: the idiomatic Rust CLI redesign that replaces the Go CLI (`codeflow-cli/`) with a pure Rust implementation. The new CLI will use SurrealDB as the sole database backend (replacing SQLite), implement idiomatic Rust patterns (error handling, async, traits), and maintain full feature parity with the current Go CLI.

This planning task covers:
1. Defining the Epic 0 epic document (INF area, scope, goals, acceptance criteria)
2. Breaking down the implementation into numbered tasks with dependencies
3. Identifying migration strategy (parallel build vs. cut-over)
4. Documenting key architectural decisions (SurrealDB schema, Rust crate selection, CLI framework)

## Approach

1. Review current Go CLI structure and identify all commands, subcommands, and DB operations
2. Research idiomatic Rust CLI patterns (clap, tokio, surrealdb crate)
3. Draft Epic 0 epic markdown at `project-management/epics/INF/INF-EPC-{NNN}/`
4. Define task breakdown covering: project scaffold, DB layer, hook subcommands, pathflow subcommands, internal subcommands, validate subcommands, test suite migration
5. Specify dependency ordering between tasks
6. Write ADR for key decisions (SurrealDB over SQLite, Rust over Go, crate choices)
