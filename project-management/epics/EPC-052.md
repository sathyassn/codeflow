# EPC-052: Test results and acceptance evidence are honest by default

## Summary

A test target passes on its exit code, coverage is judged only after merge, and acceptance evidence need not name a test that exists or prove a fix failed before. This epic makes test results, coverage and acceptance evidence honest by default for adopters. It was split by outcome from EPC-024 by the stricter consolidation pass of 2026-11-04, and lands on EPC-024's line. Planned version: 4.0.0, with EPC-024 (operator decision of 2026-10-31 12:05).

## Outcome

After this merges, an adopter's gate passes a test target only on its own report, judges coverage in essential against a default floor held at the default branch, and accepts a criterion only with evidence that exists and, for a fix, a regression test that failed before.
