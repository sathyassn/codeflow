# EPC-018: autonomy with judgment and the current model roster

## Summary

The operator asked that CodeFlow get work done without being watched, and
stop only where a human really has to decide, clarify or supply an input.
Fable's audit found the doctrine already leans toward acting, but the
operator-owned list is written seven ways in seven places, no source says
that a task runs to its finish line, and three skill texts still stop where
they should continue. The same day the operator set a new model roster, and
the managed ensemble, tests and decision records still bind the old one.
This epic lands both: one owned autonomy reference with its decision record,
the skill corrections that point at it, the current roster with its decision
record, and blind cases that fail an agent in either direction.

| Gap | Where it shows today |
|---|---|
| Seven differing operator-owned lists, no single owner | `AGENTS.md` planning and blocker bullets, `workflow-lifecycle.md`, orchestrator preflight, `cf-plan` clarity gate, `quality-contract.md`, workspace `AGENTS.md` |
| No positive finish-line statement | only the pull request loop from EPC-017 covers one stage |
| Plan-then-stop is not forbidden | mode selection in the orchestrator and the lifecycle reference |
| Seat disagreement on a reversible choice stops for the human | orchestrator plan reconciliation |
| Green pull request into an integration branch waits for a human | `cf-ship` step and `pr-evidence.md` say human merge for every target |

| Ensemble binds Fable as Claude primary, Terra and 5.6 Sol as Codex routes, `grok-4.6` | `current-ensemble.json`, its test pins and the evaluation kit |

## Operator decisions

Settled here from evidence, with the reason:

- The design owner stays the `claude-judgment-primary` role, and its design
  authority is carried by the Fable route. The validator requires a Claude
  standing role, Opus design work is an unqualified pilot today, and Fable
  holds the design record; so Fable authors direction and real design and
  approves fidelity, and the Opus primary briefs, integrates and accepts
  everything else. ADR-0069 writes the rule.
- The recorded fallback for an unavailable Opus primary is Fable at high;
  for an unavailable Fable route it is the Opus primary with reduced
  assurance recorded, a Fable review taken when the seat returns and never
  claimed before.
- `grok-4.7-build-fast` is recorded as known and is not routed.
- The reviewer agents stay model-neutral; selectors live only in the
  ensemble.

Open for the operator:

- Promotion evidence for the new bindings. The ensemble rule says a changed
  concrete binding needs native-interactive qualification, and ADR-0041
  asks for a controlled evaluation beside the human decision. Recommended:
  treat the 2026-09-23 roster as the human promotion, run one native
  identity canary per binding in TSK-074, and record the full suite as a
  named gap. The alternative holds the rebinding until full suites run.
- The minimal contract at its 16 KiB cap. Recommended: a trade inside the
  file, replacing the minimal escalation sentence and the densest clause of
  the legitimate-intent bullet with the short statement, keeping every
  pinned clause. The alternative is a ratchet move of the minimal cap to
  17 KiB, which is the operator's call.
