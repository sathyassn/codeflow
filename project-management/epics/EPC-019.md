# EPC-019: delegate turn continuation and live transport proof

## Summary

CodeFlow 3.0.0 ships the typed directive after a pasted delegate prompt. Three
pieces of delegate work followed it. The first is the rule that lets a
backgrounded task's notice continue the turn that launched it (TSK-090). By
operator decision on 2026-09-26, after qualification run E failed only its
pipeline row on that defect, TSK-090 moved into 3.0.0. The other two stay for
the 3.0.1 patch release: the qualification harness fixes that stop it typing
into a pane it cannot identify (TSK-092), and a live run of the degraded tmux
transport, since only the Herdr path ran live for the directive (TSK-091).
Together they let a delegating host rely on the lifecycle on both transports,
with release evidence from a harness that cannot submit blind.

Target releases: TSK-090 in 3.0.0; TSK-091 and TSK-092 in 3.0.1. Done means
TSK-090 has landed on `chore/release-assembly` and passed the 3.0.0
qualification run, TSK-092 has landed on `integration/EPC-014-public-docs`,
and a qualification run on the final head of
`integration/EPC-019-delegate-turns` is green, with that body prepared for a
human to land on `main` after the 3.0.0 release.

Evidence at plan time: the TSK-090 implementation is on
`fix/delegate-task-notice-3.0.0`, branched from the 3.0.0 candidate
`chore/release-assembly` at `e49726807`. It ports the continuation rule of
`a56551dad` and `aa74edd83` and adds a Stop-time origin check (see TSK-090).
The harness fixes end at `0e6715828` on `fix/delegate-paste-bytes`, which
branches from `integration/EPC-014-public-docs` at `4896ec72b`. The conforming
pull request body fixture is `a0f859b48` on `fix/qualify-pr-body`, which has
the same base.

## Acceptance Criteria

- [ ] When a Workflow or background command launched inside a delegated
      Claude turn finishes after that turn's `Stop`, the delegate hook admits
      the resulting task notice as a continuation of that turn, rejects every
      near miss, and records a result only when the session transcript proves
      the notice native; this ships in 3.0.0; evidence: TSK-090 and the 3.0.0
      qualification run.
- [ ] When the qualification harness cannot read the pane, or can see only
      history, a dialog or an ambiguous screen instead of the current editor,
      it sends no text and no keys and the verdict names that state; the
      conforming pull request body fixture passes `codeflow ci` with no
      warning; evidence: TSK-092.
- [ ] A live delegated turn over the degraded tmux transport delivers the
      pasted prompt, types the directive, and is accepted and completed by
      the lifecycle, with the run recorded as verification evidence; evidence:
      TSK-091.
- [ ] The integrated EPC-019 body passes the full local gate and a
      qualification run on its final head, every task has cross-lineage
      review, and its pull request to `main` is prepared with release impact
      `patch` and a CHANGELOG entry; evidence: the TSK-091 closeout and the
      pull request.

## Out of scope

- New delegate transports, a change to the Herdr path beyond what the port
  needs, and Codex or Grok delegate seats.
- The model catalog and autonomy work of EPC-018, and the qualification CLI
  work of EPC-014 (TSK-044); this epic ports only the specific commits named
  above, plus the Stop-time origin check TSK-090 adds.
- Publishing 3.0.0 or 3.0.1. Tagging and publication stay with the operator
  under `docs/releasing.md`.

## Affected surfaces and interfaces

- CAP-014 transport-neutral delegate lifecycle: `codeflow hook delegate-turn`
  admission rules, the Stop-time read of the session transcript, and the
  on-disk run records (`turns/<turn>/continuations/<task-id>/`), in
  `crates/codeflow-core/src/delegate.rs` and `delegate/continuation.rs`.
- The delegate prompt boundary of ADR-0037: a task notice is admitted without
  an armed turn, so the boundary change is recorded as a dated note on that
  record.
- `cf-delegate` skill resources (`claude-turn-completion.md`) in
  `assets/base`, `.claude/skills` and `.codeflow/.baseline`, with manifest
  hashes.
- The release qualification harness under `tests/release-qualification/`.
- Consumers: every project that delegates Claude turns through `codeflow
  delegate`. A notice that was blocked is now admitted under narrow
  conditions; one the transcript cannot prove native poisons the run at its
  `Stop` instead of being blocked at submit.
