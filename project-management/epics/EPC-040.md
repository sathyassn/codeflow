# EPC-040: Criteria and status changes land with the work

## Summary

A task's own criteria change, a waiver, a deferred result or a status change is refused today unless it rides in a pull request opened only for it, and record-check refusals often name the wrong cause. This epic makes those changes land in the pull request that carries the work, judged at exact commits. It was split from EPC-031 by the stricter consolidation pass of 2026-11-04. Planned version: 4.0.0. Why that version: adopter workaround defects (2026-10-18 rule); operator 2026-11-01 14:22 (no PR only to mark done).

## Outcome

After this merges, a maintainer can change a task's own criteria, waive or defer a criterion, or cancel a task in the pull request that settles the work, and a refusal names the real cause and the remedy.
