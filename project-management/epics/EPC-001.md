# EPC-001 — v2 bootstrap

Retroactive record: this epic documents the v2 rebaseline executed per
`docs/plan/v2/00-charter.md` (§12), recorded after the fact as the first
entry of the fresh PM numbering (charter D14).

## Summary

Rebuild CodeFlow as one Rust binary plus embedded scaffold, replacing the
archived v1 framework. Executed as waves of parallel agent workstreams in
isolated worktrees:

- **Reset:** `v1-final` tag + `archive/v1` branch, v2-reset commit, skeleton.
- **Probe:** native workflow rework-loop — verdict Door A (native scripts).
- **Day 1 — A/B/C/D/E:** testing engine import (A), records import (B),
  guards import (C), scaffold engine new-build (D), corpus authoring (E).
- **Day 2 — F/G/H:** hooks plane — git-guard, git client hooks, orient,
  session-summary (F); work-landing flow — test gate, validate + docs lint,
  status, integrate (G); recall, registry, remote protect (H).
- **Integration:** workstreams merged serially into main, full suite green,
  clippy zero workspace-wide.
- **Dogfood:** `codeflow init` on this repo (consumer #1), doctor clean,
  all subsequent landings via `codeflow integrate`.
