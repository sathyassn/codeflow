# EPC-003 — role-based model selection and layered verification

## Summary

Separate stable orchestration responsibilities from changeable concrete model
choices without weakening the two independent plans, Claude-led design,
producer-relative review, or integrated Claude judgment. Done means a
consuming project can reference only a locally qualified model binding through
a fail-closed project-owned file, the current Fable binding remains unchanged,
and verification guidance combines selected deterministic analyzers with
contextual cross-model review and regression coverage for structural erosion.

## Acceptance Criteria

- [x] When `.codeflow/model-selection.json` is absent or empty, model-selection
      unit and doctor tests prove the shipped ensemble remains effective.
- [x] When a project selection is malformed, unknown, drifted, role-ineligible,
      provider/lineage-mismatched, or collapses the two primary lineages,
      `cargo test model_qualification` and doctor tests prove the whole
      selection fails closed without partially applying.
- [x] When the scaffold is initialized or updated, manifest and mirror tests
      prove that the user-owned selection seed and role-based managed doctrine
      are installed without making `current-ensemble.json` project-owned.
- [x] `eval_kit.py validate-suite` proves role-neutral primary duties, concrete
      requested/observed identity, seat-collapse rejection, layered
      verification, deterministic-finding precedence, and longitudinal
      craftsmanship remain traceable to hard requirements.
- [x] CodeFlow documentation records GitHub CodeQL default Rust setup as a
      post-public, server-side repository canary, while `cf-stack` and
      `cf-customize` select rather than prescribe analyzers for consumers.
- [x] All Rust gates, `codeflow test --mode full --strict`,
      `codeflow validate --docs`, coverage, corpus validation, cross-lineage
      review, and integrated Claude-judgment-primary review pass on the final
      diff.

## Out of scope

- Promoting Opus 5, changing the current Fable-high binding, or treating a
  diagnostic pack as production qualification.
- Adding automatic model discovery, routing, launch, vendor-internal worker
  tracking, or raw model selectors to project configuration.
- Shipping CodeQL, Semgrep, Sonar, or another analyzer universally; enabling
  GitHub CodeQL before the repository is public.
- Weakening existing quality, testing, security, review, or graceful
  degradation duties in the name of role abstraction.
