# EPC-057: Hosted CI runs once per epic, and the push to main can reuse that run

## Summary

Hosted CI now runs per task and again on line pushes, and the push to `main` repeats what the pull request into `main` already proved. Under the operator's ruling of 2026-11-11 (ADR-0102), no line push starts a hosted run, a pull request into a line runs only the short checks, the full set runs once on the pull request into `main`, and the push to `main` reuses that run only under strict equality. This epic ships that placement and the reuse capability as the default for adopters, and gives CodeFlow's own workflows the same placement and reuse job. CodeFlow's own proof that its `main` reuses a run comes after TSK-1452's restore of `main`'s relaxed checks (TSK-1452 AC-7), outside this epic.

## Outcome

After this epic merges, a project on CodeFlow's CI templates runs one full hosted run per landing into `main`, none on a line push, and reuses that run on the push to `main` only when nothing it proved has changed. CodeFlow itself carries the same placement and reuse job. Its full run on `main` and its reuse start with TSK-1452's restore of `main`'s relaxed checks, and the proof of that reuse is TSK-1452 AC-7, outside this epic.
