# EPC-057: Hosted CI runs once per epic, and main reuses that run

## Summary

Hosted CI now runs per task and again on line pushes, and the push to `main` repeats what the pull request into `main` already proved. Under the operator's ruling of 2026-11-11 (ADR-0102), no line push starts a hosted run, a pull request into a line runs only the short checks, the full set runs once on the pull request into `main`, and the push to `main` reuses that run only under strict equality. This epic makes that the shipped default for adopters and CodeFlow's own placement.

## Outcome

After this merges, a project on CodeFlow's CI templates, and CodeFlow itself, runs one full hosted run per landing into `main`, none on a line push, and reuses that run on the push to `main` only when nothing it proved has changed.
