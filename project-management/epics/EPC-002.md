# EPC-002 — transport-neutral delegate foundation

## Summary

Replace the Codex-to-Claude lane's terminal-only tmux signal with a durable,
transport-neutral turn lifecycle without making CodeFlow a harness or model
router. Done means the binary can prove startup, prompt acceptance, and terminal
correlation; the scaffold uses that protocol; and deterministic, PTY, and
available native-platform evidence support the claims.

## Acceptance Criteria

- [x] When a host drives schema-v2 startup, acceptance, and terminal events,
  `cargo test delegate::` and `cargo test --test delegate_cli` prove the
  write-once lifecycle, binding, poison, timeout, and exit-code contract.
- [x] When legacy `hook delegate-turn --result` callers run, the existing hook
  tests prove byte-compatible record and signalling behavior; schema-v2 tests
  prove that lifecycle makes no tmux call.
- [x] When the rebuilt binary runs `codeflow doctor --check
  delegate-roundtrip`, it completes a synthetic lifecycle through the real
  executable and reports the thirteenth check green.
- [x] The fresh full-workspace `cargo llvm-cov` run reports 92.68% whole-file
  line coverage for `delegate.rs` and 92.96% for `cmd/delegate.rs`. Against
  base `0be99f5b`, changed-line coverage is 94.49% for `delegate.rs`, 94.34%
  for `hook.rs`, 96.67% for `doctor/mod.rs`, and 94.67% across changed Rust.
  The Rust gates (fmt, clippy `-D`, rustdoc `-D`, workspace tests), `codeflow
  validate --docs`, and the real-binary doctor round trip pass; the
  implementation snapshot `307e03fd` carries cross-lineage review.
- [x] PR1 security evidence is dual-lens and green: the Claude defender lens

- [x] A fake-TUI/PTY suite proves delayed readiness and acceptance, duplicate

## Out of scope

- Adopting Herdr; its trigger remains demonstrated advantage over the durable
  lifecycle, not transport novelty alone.
- Changing the Claude-to-Codex official-plugin lane or the duo's role and
  quality contract.
- Supporting native Windows delegate state; native Windows fails closed and
  directs the operator to WSL2.
- Removing legacy `--result`; that is a later major-release change.
- Letting the binary launch a harness, deliver a prompt, or route models.
