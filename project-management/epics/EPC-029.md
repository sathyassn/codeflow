# EPC-029: Guards read command lines and inline programs as they run

## Summary

Known bypasses of the in-session guard plane remain: interpreters, runners, the shell reader, a hook binary stand-in and the unguarded Monitor tool. This epic closes each at the installed build. It is one of the feature epics the operator approved on 2026-11-03, when the 4.0.0 milestone epic (EPC-022) and the 4.1.0 epic (EPC-023) were regrouped by outcome. Planned version: 4.0.0. Why that version: Operator 2026-10-18: every security gap ships in this release.

## Outcome

After this merges, an adopter's in-session guards read each command line through a qualified shell parser and each inline program, runner and interpreter by its own grammar, so every known bypass through them is refused at the installed build and quoted prose is no longer refused.

- Amended 2026-11-04 by the stricter consolidation pass: protected files and paths moved to EPC-050, and the hook binary, the Monitor tool and outward command classes to EPC-051. Earlier title: "Guards close known bypasses"; earlier outcome: "an adopter's in-session guards refuse every known bypass (interpreters, runners, the shell reader, a hook binary stand-in, the Monitor tool) at the installed build."
