# EPC-041: Pushes and claims are judged by the live line they target

## Summary

Pushes, line syncs, topic pull requests and claims are judged against a stale local branch, the wrong line or the destination's default branch, and a failed claim leaves state that blocks its retry. This epic binds each of these judgments to the fetched tip of the line it targets. It was split from EPC-031 by the stricter consolidation pass of 2026-11-04. Planned version: 4.0.0. Why that version: adopter workaround defects (2026-10-18 rule).

## Outcome

After this merges, a builder can push, sync a line, split a line's pull request into topics and claim or stack a task from any checkout, and each is judged against the live line it targets, failing closed when that line cannot be read.
