# EPC-009 — adopt proportionate project organization

## Summary

Help new projects choose an earned structure and existing projects adopt
CodeFlow without moving credible source or work authorities. Correct accidental
durable-work activation by foreign task directories, clarify organization and
planning guidance, and prove the result without adding a PM engine.

## Acceptance Criteria

- [x] Hook/CI regressions distinguish full, historical, foreign and indeterminate
  tracking state without weakening planning anchors.
- [x] Native diagnostics show proportionate greenfield/brownfield reasoning,
  living-requirement versus SPC clarity and honest gate authority.
- [x] Canonical assets, mirrors and managed distribution pass consistency gates;
  built CLI init/update fixtures preserve project content.
- [x] Integrated local gates, targeted decision fault injections and independent
  cross-lineage review pass, with measured evidence and explicit limitations.

## Out of scope

No forced source layout, new PM IDs/schema/paths, tracker-sync service, database,
universal monorepo skeleton, model-policy change, public release or main merge.
Keep all engineering, design, review and safety responsibilities intact.

## Affected surfaces and interfaces

Workgraph activation and hook/CI consumers; method/customize/plan guidance,
relevant PM templates, evaluation fixtures and distribution. Agent OS separately
corrects conditional software-work handoff guidance, not its general task system.
