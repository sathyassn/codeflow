# EPC-006 — optional agentic delivery and estimation

## Summary

Give consuming projects a complete, optional agent-driven operating and
estimation method: evidence-anchored Easy/Medium/Hard/Very Hard grades,
project-specific estimates, feasible resource allocations, and learning from
delivery outcomes. Make it discoverable in ordinary planning, customization,
operating-model and estimation conversations, without replacing project
authority or claiming universal agent productivity.

## Acceptance Criteria

- [x] Ordinary-language native trials demonstrate offer, useful preview,
      adoption confirmation, adopted-profile reuse, and respect for a decline
      or existing tracker; no unrequested adoption or implementation.
- [x] The corrected rubric and cold-start procedure return populated,
      evidence-labelled scenarios without universal hour constants, weakened
      quality gates, or confusion between grade and model effort.
- [x] A read-only native checker rejects malformed/pin-drifted/over-capacity/
      dependency-invalid allocations and reports resource use separately from
      elapsed time; adversarial unit and CLI tests prove its boundaries.
- [x] Standard/full initialization and brownfield/repeated update distribute
      the method consistently, preserve project-owned records, and leave the
      minimal tier lean. Agent OS hands off to the installed CodeFlow method.
- [x] Native cross-family evaluation and task/integrated review record exact
      evidence, limitations, and a prospective observation protocol; fixture
      success never becomes a claim of predictive calibration.

## Out of scope

Automatic scheduling/optimization, a workflow runtime, tracker synchronization,
new model routing, universal duration tables, statistical prediction services,
forced adoption, and claims of field accuracy without prospective evidence.
The original agentic-development-model repository remains historical input.

## Affected surfaces

CLI/core forecast verification; standard/full skills and routing; manifest,
mirrors/baselines; method documentation; deterministic and behavioral evals.
Agent OS owns only the outer software handoff and general uncertainty guidance.
