# EPC-023: the 4.1.0 adopter features and follow-ups

## Summary

Since 2026-10-18 this is the 4.1.0 epic. The operator's release decision
of that day puts in 4.1.0 the feature generalizations whose manual route
works, and the test-integrity, qualification and evaluation work; every
security gap and every defect that forces an adopter workaround or blocks
work goes in 3.2.0 (EPC-022), whatever its severity. So TSK-322 to TSK-325
moved to EPC-022, the defect portions of issues 169, 171 and 172 became
EPC-022 repairs, fourteen EPC-022 tasks moved here, and two tooling
follow-ups were added (Release scope amendment below). The text that follows
describes the original 3.2.0 feature scope; where it names 3.2.0 for the
remaining features, read 4.1.0.

An adopter running many integration lines asked for nine capabilities
(issues 164, 166, 167 beyond its binding defect, 168, 169, 170, 171, 172
and 174). This epic delivers them in 3.2.0, as the operator directed on
2026-10-13: a generated program report over every fetched line, a
project-declared class and lane for tasks, record-hygiene reports, a
reworded planning rule with scope-drift reporting, a checked carry of a
landed change to another line and a proven cleanup of pushed branches, a
managed bootstrap that installs the pinned binary on a fresh clone,
project-declared outward commands, a person-applied route for enforcement
changes an agent proposes, and blocked names and protected paths at any
depth. Nothing a project or agent writes narrows the shipped floor.

It serves adopters and contributors who run several lines, onboard new
clones, or need project-specific enforcement. Done means each task below
has landed on `integration/EPC-022-the-3-2-0-milestone-fixes`, the line it
shares with EPC-022, with its cross-lineage review; this epic's criteria
and journey pass, beside EPC-022's, on the final combined candidate with
the full gate on the installed build; and the line's pull request to
`main` is ready for a human merge.

from independent discovery, reviewed in six rounds by Codex and Grok until
