# EPC-053: A repository holds only what it needs long term

## Summary

Adopter repositories collect caches, per-task evidence folders, run output and duplicate managed skills (issue 279). This epic ships the ignore entries that `ignored_files` blocks, reports the cheap warning classes in PR evidence, ships each managed skill once, and summarises this repository's own verification tree. It was split by outcome from EPC-024 by the stricter consolidation pass of 2026-11-04, and lands on EPC-024's line. Planned version: 4.0.0, with EPC-024.

## Outcome

After this merges, an adopter's path gate refuses caches and per-task evidence folders that a range adds, lists size and run-output warnings in the PR evidence, and their tree holds each managed skill once.
