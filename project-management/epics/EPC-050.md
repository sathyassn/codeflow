# EPC-050: Guards protect the files and paths that run code later

## Summary

Files that make code run in a later shell or login, workflow and scanner files, secret-bearing files, deletions and odd path spellings each leave a known way around the edit and deletion guards. It was split out of EPC-029 on 2026-11-04 by the stricter consolidation pass (the operator's rule, relayed by the Director at 21:5x: epics of "around 5 - 10" tasks that reach `main` "in very few days", with "medium to hard" tasks). Planned version: 4.0.0, the version of EPC-029, whose placement reasons carry over.

Value line: an adopter knows an agent cannot reach an enforcement, startup or secret-bearing file through another spelling, a deletion tool or a glob that never finishes.

## Outcome

After this merges, an adopter can rely on the guards protecting every file that runs code later, every enforcement and secret-bearing file and every path spelling the guards meet, on macOS, Linux and Windows.
