# DOC-TSK-001-003: Add structured stage reporting to task markdown files

## Description

Add structured stage reporting to task markdown files by introducing two new sections to the task template:

1. **Criteria Status matrix** — a pipeline-aware table tracking acceptance criterion status per stage (DEV/REV/QA columns with a status legend)
2. **Stage Reports section** — structured DEV Report, REV Report, and QA Report sub-sections written by the executing agent at stage completion

Also update supporting documentation: cf-markdown-standards (new section specs and validation rules), four agent definitions (cf-development, cf-review, cf-quality-assurance, cf-planning SOPs), and CLAUDE.md (Sections 4 and 5) to ensure all agents know when and how to write these sections.

## Approach

1. Design Criteria Status matrix format (pipeline-aware columns, status legend)
2. Design Stage Reports section format (DEV/REV/QA sub-sections)
3. Update `project-management/templates/task-template.md` with both new sections
4. Update `.claude/skills/cf-markdown-standards/SKILL.md` with section specs and validation rules
5. Update `cf-development.md` — add DEV Report writing step to SOP
6. Update `cf-review.md` — add REV Report with dimensional assessment to SOP
7. Update `cf-quality-assurance.md` — add QA Report writing step to SOP
8. Update `cf-planning.md` — add pipeline-specific column mapping generation
9. Update `.claude/CLAUDE.md` Sections 4 and 5 with stage reporting awareness
