# DOC-TSK-001-004: Fix PF7 sentinel creation gap

## Description

Clarify the PF7 task completion ordering around TeamDelete in the PathFlow documentation. The pf-7 sentinel is created by the checkpoint system when all PF7 tasks complete. TeamDelete must happen AFTER all PF7-TSK tasks are individually completed so the checkpoint fires and creates the pf-7 sentinel before the team is dissolved.

This requires updating:

1. `pathflow-config.json` — PF7-TSK-03 description and operation fields to make the TeamDelete ordering explicit
2. `CLAUDE.md` Section 4.2 Step 8 (PF7-END execution steps), Section 4.3 Phase Reference table, and Section 5 (Deferred Shutdown sequence) to clarify that TeamDelete is the final action only after all teammate shutdown tasks are individually completed in the task tracker

## Approach

1. Read pathflow-config.json PF7 task definitions
2. Update PF7-TSK-03 description/operation to clarify it is the last action after all other PF7 tasks complete
3. Update CLAUDE.md Section 4.2 Step 8, Section 4.3 PF7 row, and Section 5 Deferred Shutdown sequence accordingly
