# EPC-021: delivery system follow-on for 3.1

## Summary

Plan v4 (section 12) keeps six parts of the delivery system out of 3.0.0 and
plans them here: change fragments under a successor ADR feeding the same
release calculator (operator decision 4a), the lines view, pipeline wiring to
the status verbs, PR title lint for squash repositories, configurable
required record sections, and exclusive claim leases, to be built only when
two independent coordinators need to compete for work (decision 2a). This
record holds the scope so it is not lost; it has no tasks, criteria or
graph yet. It is planned after 3.0.0 is tagged, on top of EPC-020's shipped
verbs and registry.
