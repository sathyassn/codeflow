# TSK-076: skill corrections that let a task run to its finish line

## Description

Correct the skill texts that stop where the doctrine says to continue, each
by the smallest wording that points at `autonomy.md`.

| Correction | Where | Rule |
|---|---|---|
| Outcome mode | orchestrator `SKILL.md` mode selection | a brief that asks for a change selects implementation through the readiness report; planning-only, review-only or research-only mode needs a brief that asks for that output |
| Seat disagreement | orchestrator `SKILL.md` plan reconciliation (the stop after two rounds) | after two rounds, a disagreement on a reversible choice is settled by the Claude judgment primary with the dissent recorded, except design direction and fidelity, which the Fable design and review route settles (TSK-074's rule); only a disagreement on an operator-owned axis stops for the operator, and other units keep moving |
| Preflight list | orchestrator `SKILL.md` preflight step 1 | the operator-owned list becomes a pointer to the reference, which also frees bytes for the two lines above |
| Merge split by target | `cf-ship/SKILL.md` landing step and `references/pr-evidence.md` | a green, reviewed pull request into an integration branch is merged by the primary with a no fast forward merge and the gate rerun; a pull request into a protected branch is reported ready with its URL and evidence and left to a human; when hosted jobs never ran, the report says "ready for your merge on local evidence" and does not present a choice |
| Trust prompt | `cf-herdr/SKILL.md` launch section | answer a trust prompt for the task's own project folder or a disposable sample the harness created; any other folder goes to the operator; the full rule is in the reference |
| Seat loss | orchestrator `SKILL.md` readiness step, one clause | a seat, tool or credit missing after preflight moves the unit to the recorded fallback with reduced assurance and the work continues; spend (buying credits) is the operator's and is named in the report without waiting on it |

Byte plan, measured at this epic's base: the orchestrator skill has 14
bytes free under a pin equal to its class ceiling, so the preflight pointer
must reclaim at least what the other three clauses add, and any longer
sentence moves to `capability-routing.md` or the reference; `cf-ship` has 5
bytes free, so the landing line changes at equal length and the split lives
in `pr-evidence.md`; `cf-herdr` has 91 bytes free. A ratchet move is
recorded in EPC-018 with bytes and reason before landing, never silently.

The qualify harness comment "No agent may answer that question"
(`tests/release-qualification/qualify.sh`, commit `814cbebeb`) contradicts
the trust rule. If the file is present at this task's base, correct the
comment and point it at the reference; if not, file one tracked item against
the line that owns it and name it in the closeout.

Non-goal: new cases (TSK-077), the roster (TSK-074), the reference text
(TSK-075), Agent OS and the workspace contract.
