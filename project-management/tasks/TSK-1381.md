# TSK-1381: Guards judge commands run through other terminal launchers the same as bare commands

## Description

TSK-1344's sibling sweep found that commands carried by other terminal and job launchers still pass exec-guard and git-guard unread: terminal multiplexers (tmux, screen, zellij, dtach, abduco), terminal emulators' remote control (wezterm, kitty), remote shells (ssh), schedulers and service launchers (at, launchctl, systemd-run), container exec (docker exec), application openers (open -a) and scripted terminals (expect). No open task covers this; TSK-1073 covers how a command line is parsed, not what a launcher carries. This task extends TSK-1344's carrier reader to these launchers, so a carried command is judged as if typed bare and a form the reader cannot read refuses. Non-goals: judging text typed into a running session, which TSK-1344 leaves unjudged with its stated floor, and launchers TSK-1344 already reads.

## Outcome

After this merges, an agent that runs a command through tmux, screen, ssh, docker exec or another listed launcher meets the same guard refusals as when it types the command bare.

## Deliverables

- the launcher tables in TSK-1344's carrier reader: `crates/codeflow-core/src/security/`
- the CLI tests beside TSK-1344's: `crates/codeflow-cli/tests/hooks_cli/`
- the guard docs: `docs/policy-reference.md`
- release note: `changelog.d/TSK-1381.md`

## Acceptance Criteria

- AC-1 Before any change, the builder shall judge, on the line's built binary, each listed launcher crossed with the headless-peer, Git, destructive, privileged and outward classes, and record in `## Findings` which forms are weaker than bare, in class-only wording; evidence: the Findings table.
- AC-2 When a command is carried by a listed launcher in a form the reader knows, exec-guard and git-guard shall judge the carried command as they judge it typed bare, in the directory it runs in; evidence: one test per launcher and class.
- AC-3 When a launcher form carries a command the reader cannot read with certainty (an unknown option, a template, a word the guard cannot fill in, or a remote host whose repository is unknown), the guards shall refuse naming the form; evidence: one test per launcher.
- AC-4 Forms that carry no command (listing sessions, attaching, read-only queries) shall pass; evidence: a test per launcher.
- AC-5 The docs shall list each launcher the guards read and the floor that holds for typed text; evidence: `docs/policy-reference.md` and a test that the list matches the reader's table.
- AC-6 A changelog entry shall name the launchers; evidence: `changelog.d/TSK-1381.md`.
- AC-7 When a launcher form runs its command in a directory the guard cannot establish (a remote host, a container, an existing multiplexer pane or window, or a directory option the reader cannot resolve), exec-guard and git-guard shall refuse naming the form, whatever the carried command; a directory option the reader resolves (such as a new window's start directory) is judged as `cd` to it. Text typed into a running session stays out of scope, as in the Description; evidence: one test per launcher with a relative destructive command and a relative secret read.
