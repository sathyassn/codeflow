# TSK-323: Ignored and oversized files are judged by the base revision's rules

## Description

The second step of https://github.com/sathyassn/codeflow/issues/174, on
TSK-322's path gate: a file the project's own ignore rules exclude, or a
file over a size limit, can still be committed. This task adds two keys,
both off by default and both read at the base revision, never the working
tree:

- `git.ignored_files` (`{level: off, allow: [{path, reason}]}`): the base
  revision's `.gitignore` files through a gitignore matcher; a tracked file
  is still tested; a `.gitignore` edit in the range admits nothing.
- `git.max_file_bytes` (`{limit, except_under}`): the optional size limit
  outside `except_under`; the tighter limit wins when sources compose.

Both honour TSK-322's built-in exemption and its normalization. The matcher
needs the `ignore` crate or an equivalent, a new dependency, so a tier-3
decision is recorded before any code (`Cargo.toml:36` holds
`unicode-normalization`; `ignore` is not yet a dependency). Non-goal: a
type rule beyond the name patterns TSK-322 already gives.

## Deliverables

- the dependency decision: an ADR under `docs/decisions/` (number allocated with `codeflow adr new` in this task's PR)
- the two rules: TSK-322's path gate module, `crates/codeflow-core/src/hooks/policy_schema.rs`, `docs/policy-reference.md`, and the root `Cargo.toml` if the dependency is taken
- release note: `changelog.d/TSK-323.md`

## Acceptance Criteria

- AC-1 Before the first code commit, an ADR shall record the matcher
  dependency decision (the `ignore` crate or an alternative) with its
  audit and licence check; evidence: the ADR at a commit before the first
  code commit.
- AC-2 With `git.ignored_files` on, a file the base revision's ignore
  rules exclude shall be refused, a tracked ignored file shall still be
  tested, an `allow` entry from the target shall admit its path, and a
  `.gitignore` change in the range shall change nothing; evidence: tests.
  (serves EPC-023 AC-8)
- AC-3 With `git.max_file_bytes` set, a file over the limit outside
  `except_under` shall be refused, and the tighter limit shall win when
  sources compose; evidence: tests. (serves EPC-023 AC-8)
- AC-4 Both rules shall be off by default and shall never judge TSK-322's
  exempt inputs; evidence: tests with each exempt input over the limit and
  ignored.
- AC-5 When the installed hooks and `codeflow ci` judge a scratch project
  with both rules on, an ignored build artefact and an oversized file
  shall be refused, and an allowed path shall pass (journey); evidence:
  the journey output.
