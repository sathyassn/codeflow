## Diagnosis

The fixture helper disables host Git configuration while the real integrate
commands inherit it. A checkout converted to CRLF by product Git appears
modified to the helper when that helper has conversion disabled. A disposable
repository probe and all ten merge tests under this mismatch reproduced the
same three hosted failures. Product Git reported the converted file clean.
The fixture now pins `core.autocrlf=true` and `core.filemode=false` in local
repository configuration, shared by setup, product and assertions. The target
refresh test also checks the resulting CRLF bytes. Product code and the three
clean-checkout assertions are unchanged. Native Windows confirmation remains
for hosted CI after publication is authorized.
