# TSK-092: qualification harness that never submits blind

## Description

The release qualification harness drives live harness sessions in terminal
panes. Codex's review of the delegate directive found two defects in it
(DPD-1 and DPD-2): an unreadable pane still received Enter, and a screen
showing only a historical `[Pasted text ...]` line was taken as the current
editor, so the harness typed the directive and retried on history. Commit
`0e6715828` on `fix/delegate-paste-bytes` sends text and keys only into an
identified editor and adds history, dialog and ambiguous controls to
`self-check.sh`; Codex's recheck of it is pending. Separately, the harness's
conforming pull request body fixture lacks the Reviews and Release impact
sections that the 3.0.0 template requires; `a0f859b48` on
`fix/qualify-pr-body` adds them and a Not tested line. This task lands both
so the 3.0.1 qualification cannot pass or fail on a harness artifact.

The harness lives only on the EPC-014 line (`tests/release-qualification/`,
added by TSK-044, which is `blocked` on its live rows); it is not on `main` or
the 3.0.0 candidate, and each qualification runs it from its own checkout
against the candidate commit. That is why this task targets
`integration/EPC-014-public-docs` while its epic lands elsewhere. If the
reviewers prefer, the same change can be taken as a TSK-044 fix instead; that
choice needs no other change to this epic.

Target release: 3.0.1 qualification evidence (the harness itself ships with
the EPC-014 body in 3.1). Non-goal: any change to the CLI or the delegate
engine.

## Affected surfaces and interfaces

- `tests/release-qualification/lib.sh`, `self-check.sh` and `qualify.sh` on
  the EPC-014 line; TSK-044 owns the harness and its release record rows.
- No shipped asset, CLI surface or scaffold file changes.

## Acceptance Criteria

- [ ] When the pane read fails after a paste, the harness shall send no text
      and no keys and report the pane as unreadable; evidence: a
      `self-check.sh` control that requires zero Enter presses after the
      initial paste.
- [ ] When the screen shows history, a dialog or an ambiguous layout without
      a positively identified current editor, the harness shall treat the
      editor as unavailable and send nothing; evidence: `self-check.sh`
      history-only, dialog and ambiguous controls, each failing against the
      pre-fix `lib.sh`.
- [ ] Given the 3.0.0 pull request template, the harness's conforming body
      passes `codeflow ci` PR body checks with no warning; evidence: the
      qualification row and its observed output.
- [ ] Codex's recheck of the pane handling returns with no open finding, and
      a second family reviews the fixture change; evidence: the review
      records named in the closeout.
- [ ] `sh tests/release-qualification/self-check.sh` passes in full;
      evidence: its summary line in the closeout.
