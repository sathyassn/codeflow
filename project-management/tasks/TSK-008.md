# TSK-008 — research and prototype documentation portals

## Description

Independently research, design, render, and compare multiple documentation
portal directions before selecting a framework, information architecture,
theme system, or starter. Use CodeFlow's real documentation as evidence and
dogfood content; do not copy Linear or any single reference, and do not select
a direction from prose or one screenshot.

## Affected surfaces and interfaces

- Disposable prototype worktrees/artifacts, source mapping and content model,
  framework/maintenance investigation, rendered browser evidence, SPC-005.
- No production scaffold or public portal mutation before direction settlement.

- [x] Fable independently researches and proposes materially different portal
      directions; Codex performs an independent research/proposal pass before
      either sees the other's conclusion.
- [x] Research spans several strong modern documentation, editorial, knowledge,
      and product experiences plus relevant maintained frameworks; Linear is
      one input, not a template, and claims are sourced.
- [x] At least three materially different, sufficiently complete prototypes use
      representative CodeFlow content and expose concept, architecture, and
      technical drill-down rather than palette-only variations or attractive
      text-card grids.
- [x] Every viable prototype is rendered in light/dark modes and evaluated for
      hierarchy, navigation/search, source traceability, responsive behavior,
      accessibility, language, visual/prose balance, maintainability, build
      cost, product/utility isolation, and whether each claimed visual carries
      real explanatory information.
- [x] Claude leads the design recommendation; Codex reviews feasibility,
      durability, implementation size, and verification. The operator receives
      the real alternatives if the remaining choice changes the experience.
- [x] SPC-005 is updated from evidence and becomes approved only after all
      consequential questions are resolved and both primary seats approve the
      same direction.

disposable until an exact direction is approved; promising experiments are not
production authority.
