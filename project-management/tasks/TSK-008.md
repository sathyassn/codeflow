# TSK-008 — research and prototype documentation portals

## Description

Independently research, design, render, and compare multiple documentation
portal directions before selecting a framework, information architecture,
theme system, or starter. Use CodeFlow's real documentation as evidence and
dogfood content; do not copy Linear or any single reference, and do not select
a direction from prose or one screenshot.

## Affected surfaces and interfaces

- Disposable prototype worktrees/artifacts, source mapping and content model,
  framework/maintenance investigation, rendered browser evidence, SPC-005.
- No production scaffold or public portal mutation before direction settlement.
