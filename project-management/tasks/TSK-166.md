# TSK-166: the workspace root branch is not an epic line in ci

## Description

TSK-165 names `integration/workspace` as CodeFlow's convention for an
umbrella repository's root branch. `codeflow ci` treats every
`integration/*` branch without a `Task:` line as an epic line and refuses
one it cannot verify ("'<branch>' is not a verified epic line",
`cmd/ci/classification.rs:151-156`, with the same prefix test at `:255-257`,
`cmd/ci/acceptance.rs:75` and `workgraph/readiness.rs:961`). Classification
runs only with durable work tracking (`cmd/ci/classification.rs:186-217`),
so this affects an umbrella at the standard or full tier. This task makes
the repository's configured `git.root_branch` a workspace root branch in
those checks, and leaves `integration/EPC-NNN-*` lines judged as today. It
follows TSK-140, the last listed editor of the acceptance judge in SPC-013
R-118.

## Affected surfaces and interfaces

- `crates/codeflow-cli/src/cmd/ci/classification.rs`,
  `crates/codeflow-cli/src/cmd/ci/acceptance.rs` and
  `crates/codeflow-core/src/workgraph/readiness.rs`, reading the root
  branch from TSK-165's module.

## Acceptance Criteria

- AC-1 When the branch under check equals the repository's configured
      `git.root_branch`, `codeflow ci` shall not classify it as an epic line
      nor refuse it as "not a verified epic line", acceptance amendability
      shall not treat it as one, and readiness shall not report it as a live
      integration line; evidence: classification, acceptance and readiness
      tests with `git.root_branch: "integration/workspace"`.
- AC-2 `integration/EPC-NNN-*` branches, and an `integration/*` branch that
      is not the configured root branch, are judged exactly as before;
      evidence: the existing classification tests pass unchanged.
- AC-3 Each message this task adds names the rule, the branch, the
      configured root branch and the next step; evidence: a pinned message
      test.

## Execution contract

EPC-020, follow-up of TSK-165. Starts after TSK-165 and TSK-140 land.
Integration target `integration/EPC-020-delivery-system`. Workers run
targeted tests; the primary runs the full gate.
