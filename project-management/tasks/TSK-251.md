# TSK-251: The docs portal takes the fixed sharp release

## Description

Advisory GHSA-wq5f-xc86-pv6w (high, CVSS 8.9) affects `sharp` 0.35.4 and is
fixed in 0.35.5. TSK-246 pinned 0.35.4, so the dependency audit in the
security review job fails on `main` and on every pull request that merges
`main`. This task moves the `sharp` override to 0.35.5 in the docs portal and
in the shipped starter, regenerates both lockfiles so only `sharp` and its
`@img/*` packages change, and re-pins the portal state and the runtime script
list to the new lockfile. It adds no audit suppression, because a fixed
release exists. Effect on adopting projects: `codeflow update` installs the
starter's new `package.json` and lockfile, and the portal's recorded runtime
scripts are unchanged. Non-goal: other dependency upgrades.

## Deliverables

- the dependency fix: `docs-portal/package.json`, `docs-portal/package-lock.json`, `assets/docs-portal/starter/package.json`, `assets/docs-portal/starter/package-lock.json`
- the portal pins: `.codeflow/docs-portal.json`, `docs-portal/scripts/runtime-scripts.json`, `assets/docs-portal/starter/scripts/runtime-scripts.json`
- the release note: `CHANGELOG.md`

## Acceptance Criteria

- AC-1 When osv-scanner and `npm audit` run on the docs portal and the shipped starter lockfiles, they shall report no advisory, and the lockfile change shall be limited to `sharp`, its `@img/sharp-*` packages and `@img/sharp-libvips-*`. Evidence: osv-scanner 2.4.0 and `npm audit --package-lock-only` on both, a diff check of the changed lock entries, and the hosted security review job.
- AC-2 When the docs portal is built and checked from a committed tree, the portal state and runtime script list shall match the new lockfile. Evidence: `npm ci && npm run build` in `docs-portal`, `manifest_consistency`, the portal Rust tests that read the starter, and `codeflow test --mode quick`.
- AC-3 (journey) When an adopter sets up the docs portal with this build, the project's portal lockfile shall carry `sharp` 0.35.5 and its dependency audit shall report no advisory. Evidence: a fresh `codeflow init` and portal setup with the built binary in a temporary project, `npm ls sharp` there, and osv-scanner on the resulting lockfile.
