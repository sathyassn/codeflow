# TSK-427: Shipped instructions and reviews require full typing by default

## Description

Issue #275, items 1 and 6 and the comment of 2026-10-22 on the
instruction side. Three shipped texts steer agents away from strictness:
`cf-model-orchestrator/resources/quality/design-implementation.md:24-33`
(types "where they prevent material errors", no stricter-compiler
migrations "merely to satisfy this rule"), `cf-develop/SKILL.md:41-44`
("never force a stricter compiler") and `cf-stack/SKILL.md:32-35` ("Do
not mandate TypeScript, a validator library"). Under them, reviews
passed Python at 5 % annotated with hundreds of `dict[str, Any]` and
hand-written validators.

Outcome: **by default, new and changed code is fully typed; escape
types and every suppression carry an inline reason or the review is
`changes_requested`; structured external data is parsed into typed
models generated from its schema; adding the profile's type checker,
linter and typed-model library is in scope for `cf-develop`; and
CodeFlow's own vendored Python passes the same defaults.**

Rules: the three texts are rewritten so the default reads as above and
the proportionality wording applies only under a recorded relaxation
(TSK-424); `cf-reviewer` adds a typing check to its verdict (untyped
new code, unexplained escape types, a hand-written validator where a
schema-generated model fits); the vendored Python under `assets/` is
annotated and checked by pyright strict and Ruff in this repository's
gate.

Non-goals: the tooling (TSK-426); rewriting adopters' existing code.

## Deliverables

- the instruction texts: `cf-model-orchestrator/resources/quality/design-implementation.md`, `cf-develop/SKILL.md`, `cf-stack/SKILL.md` and the `cf-reviewer` agent in `assets/base/`, `.claude/skills` and `.agents/skills`, byte-identical
- the vendored Python: the scripts under `assets/` with their annotations, and the pyright and Ruff targets in `.codeflow/test-config.json`
- qualification: the instruction cases under `evals/qualification/` for `/cf-evaluate-model`
- release note: `changelog.d/TSK-427.md`
- managed wiring, mirrors and baseline: `assets/base/scaffold-manifest.toml`, installed managed files and `.codeflow/` baseline, synchronized when changed

(serves EPC-024 AC-4)
- AC-2 `cf-reviewer` shall return `changes_requested` for untyped new code, an unexplained escape type or a hand-written validator where a schema-generated model fits, each with file:line; evidence: the verdict format and a qualification case per finding kind. (serves EPC-024 AC-4)
- AC-3 CodeFlow's vendored Python shall pass pyright strict and Ruff with the TSK-426 selection in this repository's essential gate; evidence: the gate run. (serves EPC-024 AC-4)

- AC-5 (journey) A fresh `codeflow init --standard` project and a project updated from the previous release shall carry the new text, and every pointer shall resolve; evidence: the journey output.
