# TSK-1475: The EPC-022 line carries the rustix advisory fix

## Description

RUSTSEC-2026-0486 (`rustix` 1.1.4, fixed in 1.1.6) turns codeflow-ci's "security review" red on every pull request into the EPC-022 line, so nothing reviewed can land there. TSK-1432 fixed it on `main` (pull request 773) by moving `rustix` from 1.1.4 to 1.1.6 in `Cargo.lock`. The line would get that change through the TSK-1468 sync with `main`, but the sync waits for other line work. This task breaks that wait by making the same `rustix` bump on the line, as TSK-1430 did on the EPC-026 line.

The change equals `main`'s, so the later sync finds `Cargo.lock`'s `rustix` entries already equal and neither conflicts nor counts the bump twice.

Non-goals: any source change, any other dependency change, any audit suppression, and a changelog fragment of its own. Its record rides in its own pull request, because a records-only filing into the line fails the same audit and cannot land first.

Source: the Director's ruling of 2026-11-12, relayed by coord/ci; modelled on TSK-1430.

## Outcome

After this merges, pull requests into the EPC-022 line pass the security review without suppressing RUSTSEC-2026-0486, so the line's reviewed pull requests can land before the main sync.

## Deliverables

- the bump: `Cargo.lock` (the `rustix` package entries only)
- this task's record
- evidence in the pull request body: the `Cargo.lock` diff, the resolved `rustix` versions, the local security scan and the quick gate

## Estimate

- Grade: Easy; band: Easy (under 1 h); moved: none
- Split: not needed; one outcome, a mirror of reviewed work on `main`
- Basis: one lock-file bump equal to TSK-1432's on `main`; the work is the proof and the review. Graded by coord/records under issue 334's bands.

## Acceptance Criteria

- AC-1 `Cargo.lock` shall differ from the line base only in the `rustix` package entries, which move from 1.1.4 to 1.1.6 as on `main`, and the workspace shall resolve `rustix` 1.1.6 only. No other path shall change except this task's record. Evidence: the `Cargo.lock` diff, `git diff --stat` of the range, and `cargo metadata` output listing every resolved `rustix` version.
- AC-2 The security scan shall pass on the line's tree with this change, with no new ignore entry, filter or advisory exemption, and the audit's enforcement levels unchanged. Evidence: a local osv-scanner run over `Cargo.lock` as the workflow runs it, at the head.
- AC-3 (journey) The bump shall be proven on the line's own code: `codeflow test --mode quick` shall pass at the head, through `nice10.sh`. Evidence: its result line at the head SHA.
- AC-4 The lock diff shall have one review by a family that did not build it, with the `cf-security-reviewer` dependency checks, its seat checked live at dispatch. Evidence: the review row.
