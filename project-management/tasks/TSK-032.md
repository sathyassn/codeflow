# TSK-032 — Integrate responsible autonomy contract

## Description

Integrate the approved responsible-autonomy kernel into CodeFlow's existing
always-loaded contracts and extend the existing quality, security, delegation
and customization owners with missing operational detail. Preserve ordinary
authorized research, tests and recoverable project work; do not create a new
safety subsystem or silently change default policy and harness permissions.

## Affected surfaces and interfaces

Canonical `assets/base/AGENTS.md.tmpl` and `AGENTS.minimal.md.tmpl`;
orchestrator `quality-contract.md`; `cf-security-reviewer`; `cf-delegate`;
`cf-customize`; evaluator requirements/source markers; focused orchestration,
settings, security, mirror and byte-budget tests; affected managed copies and
release documentation. Authority/data boundaries include purpose, action,
resource, destination/recipient, data class and material side effects. The
production Codex profile's technical no-prompt/full-access posture must be
described honestly and never confused with task authorization.
