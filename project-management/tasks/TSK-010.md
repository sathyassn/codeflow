# TSK-010 — integrate and release the CodeFlow system

## Description

Review the combined CodeFlow system, reconcile every managed/documented surface,
prove clean consumer setup/update/use paths, and prepare the release that Agent
OS must consume. This task does not implement downstream Agent OS or portal
changes; those repositories create and own their linked work after this lands.

Resolve a reported release-integration conflict or finding within the release pull request,
under SPC-013 R-120's direct-change rules. Before the combined release is ready,
accept the disposition of the nine other-line byte-cut losses in TSK-150's audit
table, each restored or justified as superseded. The post-landing automation
reports findings to this task and never resolves them itself.

## Affected surfaces and interfaces

- Combined CodeFlow diff, capabilities/architecture/ADRs, manifests and
  baselines, AGENTS/CLAUDE routing, model eval kit, version/changelog/release
  checklist, install/update canaries and worktree/runtime cleanup.
