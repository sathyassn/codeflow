# TSK-1191: The update warning separates steps that can alter the secret scan from steps that cannot

## Description

Issue 516. The `codeflow update` warning says a workflow step "can hide a leak" for steps that cannot alter the secret scan, such as the reporter's exit-only guard step before checkout. Code: `crates/codeflow-core/src/scaffold/update.rs:557-562`, with the text at `:489-493`. This task narrows the warning, so the unproven case stays a warning (fail closed).

Security task: it narrows a security warning.

## Outcome

after this merges, a person updating a project gets the "can hide a leak" warning only for steps that can alter the secret scan, and the warning says which reason applied.

- release note: `changelog.d/TSK-1191.md`

## Acceptance Criteria

- AC-1 The reporter's exit-only guard step before checkout shall get no "can hide a leak" warning; evidence: a fixture that warns before the change.

- AC-3 Anything the check cannot prove harmless shall keep the warning; evidence: a fixture with an unparsed step.
