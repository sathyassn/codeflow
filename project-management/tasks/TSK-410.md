# TSK-410: The docs portal takes the fixed astro release

## Description

Advisories GHSA-98hj-9722-w3j8 (fixed in astro 7.3.2) and GHSA-mpr7-6m5w-76rw
(fixed in 7.3.3) affect `astro` 7.2.8, which the docs portal and the shipped
starter pin. The dependency audit in the security review job now fails on
every pull request on the EPC-022 line. This task moves `astro` to the latest
7.3.x release in both `package.json` and `package-lock.json` pairs, with the
smallest lockfile change npm produces, and re-pins the portal state and the
runtime script list if the lockfile hash changes. It adds no audit
suppression, because a fixed release exists. Effect on adopting projects:
`codeflow update` installs the starter's new `package.json` and lockfile.
astro 7.3.8 requires `vite` ^8.3.1, which the exact `vite` override of
8.2.4 (TSK-409) no longer satisfies, so this task removes that override: the
revisit TSK-409 recorded for an astro upgrade. The override's advisories are
fixed in vite 8.2.4 and the lockfiles now resolve 8.3.5 through astro's own
range. Non-goal: other dependency upgrades, and the 7.4 line.

## Deliverables

- the dependency fix, including the removed `vite` override: `docs-portal/package.json`, `docs-portal/package-lock.json`, `assets/docs-portal/starter/package.json`, `assets/docs-portal/starter/package-lock.json`
- the portal pins, where the lockfile hash changes: `.codeflow/docs-portal.json`, `docs-portal/scripts/runtime-scripts.json`, `assets/docs-portal/starter/scripts/runtime-scripts.json`
- the release note: `changelog.d/TSK-410.md`

## Acceptance Criteria

- AC-1 When the docs portal and the shipped starter lockfiles are read, both shall resolve `astro` at 7.3.3 or later, and osv-scanner shall report neither GHSA-98hj-9722-w3j8 nor GHSA-mpr7-6m5w-76rw. The resolved `vite` shall satisfy astro's range. Evidence: osv-scanner and `npm audit` on both lockfiles before and after, `npm ls vite`, and the hosted security review job.
- AC-2 When the docs portal is built and checked from a committed tree, it shall build and its checks shall pass. Evidence: `npm ci && npm run build` in `docs-portal`, `codeflow test --mode quick`, and the docs-portal gate targets.
- AC-3 (journey) When the shipped starter is installed and built, it shall build with the new `astro`. Evidence: `npm ci && npm run build` on the starter's files in a temporary project, and the portal Rust tests that read the starter.
