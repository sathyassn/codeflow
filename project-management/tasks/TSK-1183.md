# TSK-1183: Bump pulldown-cmark to 0.13.6 for RUSTSEC-2026-0433

## Description

Hosted "security review" fails every pull request on the EPC-022 line and on main because Cargo.lock pins pulldown-cmark 0.13.5, which RUSTSEC-2026-0433 (CVSS 7.5) lists as fixed in 0.13.6. The workspace pins the crate exactly (`=0.13.5`), so this task moves that one pin and the lockfile entry to 0.13.6 and changes nothing else. Non-goals: no code change, no advisory suppression, no other dependency update.

## Outcome

After this merges, the hosted security review passes on the EPC-022 line, and the markdown parser that reads repository and pull request files is the patched release.

## Deliverables

- Exact pin at 0.13.6: Cargo.toml
- Lockfile entry for pulldown-cmark at 0.13.6: Cargo.lock
- Task record: project-management/tasks/TSK-1183.md

## Acceptance Criteria

- AC-1 When the lockfile is updated, it resolves pulldown-cmark 0.13.6 and no other package version changes. Evidence: `git diff Cargo.lock` shows only the pulldown-cmark version and checksum, and `git diff Cargo.toml` shows only the workspace pin.
- AC-2 When the markdown paths in codeflow-core, codeflow-cli and codeflow-present run their tests, they pass. Evidence: the test targets that touch `pulldown_cmark` modules, plus clippy and rustdoc for those crates.
- AC-3 When osv-scanner v2.4.0 scans the repository at the head, it reports no RUSTSEC-2026-0433. Evidence: `osv-scanner scan -r --no-ignore .` output at the base and at the head.
