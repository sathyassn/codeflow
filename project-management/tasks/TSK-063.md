# TSK-063: agent-os guide rebuilt on the doctrine

## Description

Rebuild the Agent OS repository guide fully, inside this epic, on the starter
as it stands on `integration/EPC-016-visual-guide` and the figure grammar,
dogfooding the integration starter rather than a published release. The
guide exists on Agent OS's `docs/repository-guide` branch (34 commits ahead
of its `main`, starter 2.0.0, six layers over `system/` and `docs/`,
`guide/portal.config.json`, ADR-0041 declaring the guide a derived,
never-committed output); it renders the sources as text. Adopt the
integration starter through `portal setup` from a CodeFlow binary built at
the integration head on that branch, so the guide carries the kit's chrome,
the three skins, the Display panel, search and the panels. Compose a figure
per altitude on each explanatory page and a figure in each how-to section
under the grammar (the design primary authors the declarations), rewrite the
prose to the rules (short, plain, bullets where they help, no em or en dash),
settle and record the tier question (Agent OS is minimal tier and the portal
workflow ships at standard and full: either move to standard, or record a
minimal-tier exception in an Agent OS ADR), and run its own
`validate --portal` and browser verification. The design primary reviews
every route rendered. Non-goal: the public showcase in the sibling
`agent-os-portal` repository (ADR-0012 there), which is not a CodeFlow
portal. Landing the Agent OS PR on Agent OS `main` waits for the CodeFlow
release that publishes the starter the guide pins; the rebuild, verification
and review are complete inside this task.

## Affected surfaces and interfaces

The Agent OS repository only: `guide/**`, `.codeflow/docs-portal.json`,
`.codeflow/project.toml` if the tier changes, the `system/` and `docs/`
sources that gain figure declarations and rewritten prose, one new ADR for
the tier decision. The CodeFlow side ships nothing new for this task.

## Acceptance Criteria

- [ ] The Agent OS guide builds from the starter at the integration head,
      its `.codeflow/docs-portal.json` pins that starter's hashes, and
      `validate --portal guide` is clean with the binary built at that head;
      evidence: the Agent OS branch and the recorded output with both SHAs.
- [ ] Every explanatory page of the Agent OS guide carries a figure per
      altitude in a named family and every how-to section carries a figure,
      each passing the figure gate; the prose carries no em or en dash and no
      Technical altitude has over 1500 words outside its tables; evidence:
      `browser:verify` on the Agent OS branch, the dash sweep and the
      altitude word counts from the evidence manifest.
- [ ] The rebuilt guide carries the kit's chrome: the three skins, the
      Display panel, search, breadcrumbs, the collapsible and resizable
      panels and the altitude tabs, all working on the Agent OS routes;
      evidence: `browser:verify` chrome cases on the Agent OS branch.
- [ ] The tier decision is recorded in an Agent OS ADR and the scaffold state
      agrees with it; evidence: the ADR and `codeflow doctor`.
- [ ] The design primary reviews every Agent OS route rendered in three skins,
      two modes and two widths at every altitude; Grok adversarial review of
      the combined Agent OS diff; evidence: the review records.
- [ ] The Agent OS branch is pushed with a draft PR body that names Agent
      OS PR #54 and the CodeFlow release as its preconditions and states that
      re-pinning to the released starter is the one change left before
      landing; evidence: the branch and the draft body.
