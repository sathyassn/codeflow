# TSK-1084: The guard test fixtures ignore the host's Git configuration

## Description

Source: the hosted failure of PR 346 (TSK-1002) at `92e7b5029`, root
cause found 2026-10-30. A `hooks_cli` fixture sets `HOME` to a
temporary directory, yet the guard under test still read the host's
system Git configuration: on the macOS runner, Homebrew Git's
`credential.helper=osxkeychain` made the Git runner reader see a
configured program and refuse a caret revision the Linux and Windows
runners allowed. TSK-1002 pinned `core.pager` in that one fixture
(`c201cc0b3`, `crates/codeflow-cli/tests/hooks_cli/target_repository.rs`).

The suite's `codeflow()` helper already sets `GIT_CONFIG_GLOBAL` and
`GIT_CONFIG_SYSTEM` to `/dev/null`
(`crates/codeflow-cli/tests/hooks_cli.rs:57-68`), so the leak comes from
a path that helper does not cover: a test that overrides it, a `git`
call the guard makes with its own environment, or a configuration file
libgit2 finds by itself. A guard verdict that depends on the host makes
the suite pass on one runner and fail on another, and can hide a real
change in a verdict.

Non-goals: changing any guard verdict; the guard's own reading of a
user's real configuration, which is product behaviour.

## Outcome

After this merges, a maintainer gets the same `hooks_cli` verdicts on macOS, Linux and Windows whatever Git configuration the host has.

## Deliverables

- investigation findings: a `## Findings` section in this record
- the harness: `crates/codeflow-cli/tests/hooks_cli.rs` and `crates/codeflow-cli/tests/hooks_cli/` (the shared fixture helpers)
- a host-configuration canary test in the same suite

## Acceptance Criteria

- AC-1 Before any change, the builder shall find every path by which a `hooks_cli` run reads Git configuration outside its fixture (the hook's own `git` calls, libgit2's search paths, tests that build their own commands or override the helper's environment) and record each in the Findings section; evidence: the Findings section, committed before the first code change.
- AC-2 Every `hooks_cli` fixture shall run the guards with no system or global Git configuration from the host (`GIT_CONFIG_NOSYSTEM`, `GIT_CONFIG_GLOBAL` and whatever AC-1 finds), set once in the shared helpers rather than per test; evidence: the helper code and the suite passing on all three hosted runners. (serves EPC-022 AC-170)
- AC-3 A canary test shall plant a program-valued setting (for example `credential.helper`) in a system and a global configuration file the run could otherwise reach, and show the guard verdicts of a fixed set of lines unchanged; evidence: the canary, failing before the change on a host whose configuration leaks and passing after. (serves EPC-022 AC-170)
- AC-4 The single-fixture pin from TSK-1002 shall be removed, or kept with a comment naming why, once AC-2 covers it; evidence: the diff.
