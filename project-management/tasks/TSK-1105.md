# TSK-1105: A builder works under its harness sandbox and permission preset, bypass included, with every guard in force

## Description

Two harness sandboxes stop a builder before its first commit. Codex builder
seats (the `cf-builder` posture) cannot finish a build here: the Codex
sandbox denies the `.git/config` write `git worktree add` makes, denies
`ps`, which `coordination/scripts/gate-turn.sh` uses to prove a ticket
holder is alive, and denies the gate lock holder record under
`~/.codeflow/locks/` (`full-gate.lock: Operation not permitted`), so a Codex
builder cannot claim, run `codeflow reserve` or push (queue items 29 and
29b, 2026-10-31; TSK-1077, TSK-323 and TSK-330 were reassigned to Claude
builders for this reason). In a scaffolded project, Claude's sandbox
write-deny on `.claude/` (an enforcement path) makes the required
`git worktree add` fail on `.claude/agents/*.md`, so a subject cannot start a
task worktree without the auto-mode unsandboxed retry; in the TSK-1032
trials one subject stopped to ask the user and the other retried with the
sandbox off (queue item 30, 2026-10-31 01:15). Every Claude builder and
every adopter on the sandboxed preset meets this.

This task gives both a sanctioned route that works inside the sandbox
without weakening any deny: `codeflow work claim` (one step with the claim
commit and preflight, operator decision D4 of 2026-11-01) creates
the worktree through a route the presets allow, with the enforcement-path
denies judged on the worktree's own copies after checkout as TSK-399
requires; the Codex builder posture gets a lock home its profile allows and a
liveness proof that does not need `ps`. Non-goals: no deny is relaxed, no
preset gains a broad allow, and the coordination scripts are the workspace's
(`coordination/` is not in this repository); this task changes the shipped
posture and the `codeflow` commands they call.

## Outcome

After this merges, a Claude or Codex builder can create its task worktree, claim, reserve and push from inside its harness sandbox with no unsandboxed retry and every enforcement-path deny still in force.
