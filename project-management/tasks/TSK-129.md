# TSK-129: a tested reading budget and split skill references

## Description

An ordinary task's contract calls for about 265 KB of reads, about 205 KB of
it after the always-loaded layer, and nothing stops it growing. The quality
contract (39 KB) and the turn adapter (13.7 KB) are read whole for rules
that apply to one surface or one host, and cf-delegate (21 KB) is read whole
for one lane. This task splits them so only the needed part loads, and adds
a tested byte budget for the per-task mandatory chain. The root map is
budgeted by TSK-127, not here. Source: guidelines strand, "End-to-end
reading budget" and top five item 4.

## Affected surfaces and interfaces

- `cf-model-orchestrator/resources/quality-contract.md` (index plus
  sections), the turn adapter (Codex host only), `cf-delegate` (core plus
  one file per lane); skills that name them; all mirrors and the manifest.
- `capability-routing.md` (index plus sections) and
  `cf-model-orchestrator/SKILL.md` (index plus trigger sections, after
  TSK-127 lands), as amended in SPC-013 R-118 on 2026-09-27.
- Eval requirement marker paths in `cf-evaluate-model/resources/requirements.json`
  for the files this task splits (paths only).
- `crates/codeflow-core/tests/artifact_budget_contract.rs`.

## Acceptance Criteria

- [ ] AC-1 The budget test shall list the mandatory per-task reading chain
      as the skills name it (orient and route, before launch, every
      exchange, plan, build and ship) and fail when its total exceeds a
      recorded cap at least 50 KB below the baseline measured at this task's
      start; evidence: `artifact_budget_contract` with the baseline and cap
      in the test.
- [ ] AC-2 The quality contract shall load by section from an index, the
      turn adapter shall be read only on a Codex host, and cf-delegate shall
      load a common core plus the lane in use; evidence: the skill text and
      a test that no Claude-host path names the turn adapter as mandatory.
- [ ] AC-3 Every duty in the split files shall have a home in a duty map,
      and the pinned-duty tests shall pass with pins re-pointed, none
      deleted; evidence: the duty map in the pull request and
      `orchestration_contract`.
- [ ] AC-4 Skills shall be byte identical across mirrors with matching
      manifest hashes; evidence: `skill_mirrors` and `manifest_consistency`.
- [ ] AC-5 (serves EPC-020 AC-13) In a freshly scaffolded project at the
      standard and full tiers the split files shall be installed, and
      `codeflow update` shall replace the old whole files without leaving
      stale copies; evidence: `init_e2e` and an update test.
