# TSK-128: rules re-injected after compaction and on prompt triggers

## Description

After compaction or resume the skill listing and the always rules are gone,
and nothing reminds the agent of a rule at the moment it applies. This task
makes the session-start digest source-aware: on compact and resume it adds a
guidance block of at most 1.5 KB (the always rules, the moment table and the
skill names available at that tier), generated from TSK-127's kernel. A new
UserPromptSubmit hook adds the one relevant rule, at most 300 bytes, when a
prompt asks for a duration, a status or a complex explanation. It is
advisory (warn) first and never blocks. Source: research map Part 3, "What
to re-inject".

## Affected surfaces and interfaces

- `crates/codeflow-core/src/hooks/orient.rs`; a new prompt-reminder hook
  command; policy schema (one level key, default warn).
- Scaffolded settings: Claude presets in `assets/base/settings/`, Codex
  `assets/base/codex/hooks.json`, Grok `assets/base/grok/hooks.json`.
- Tests: `hooks_cli.rs`, `settings_presets.rs`, `codex_hooks.rs`.

## Acceptance Criteria

- [ ] AC-1 When the session-start hook runs with source compact or resume,
      it shall add a guidance block of at most 1,536 bytes holding the
      always rules, the moment table and the tier's skill names, generated
      from the kernel; on startup the digest stays as today; evidence:
      `hooks_cli` tests for each source and a byte-size assertion.
- [ ] AC-2 The SessionStart matcher shall list each host's documented
      sources explicitly: Claude `startup|resume|clear|compact|fork`, with
      `fork` treated as resume for guidance, and Codex
      `startup|resume|clear|compact`; evidence: a `settings_presets` test
      of the supported sources per host. (Amended 2026-09-27 as a planning
      amendment on the line, after the cross-lineage review found that a
      Claude fork runs SessionStart with source `fork`.)
- [ ] AC-3 When a prompt matches the duration, status or complex-explanation
      triggers, the prompt hook shall inject exactly one rule line of at
      most 300 bytes; other prompts get nothing; evidence: a fixture corpus
      of at least 10 matching and 10 non-matching prompts with expected
      results.
- [ ] AC-4 The prompt hook shall be advisory by default, switchable off by
      policy, and shall never block or fail the prompt, including when the
      kernel or policy file is missing; evidence: tests for the off level
      and the missing-file paths.
- [ ] AC-5 (serves EPC-020 AC-13) In a freshly scaffolded project at every
      tier (minimal, standard and full where it applies), the Claude, Codex
      and Grok hook files shall wire both events where the host supports them,
      the record naming any host that lacks an event; `codeflow update` shall
      add the wiring and keep the adopter's own hooks; evidence: `init_e2e`,
      `codex_hooks` and an update test.
