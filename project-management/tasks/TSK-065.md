# TSK-065: post-open pull request loop in the ship skill

## Description

Add the step the ship skill lacks between opening a pull request and a human
landing it. After `gh pr create` the agent polls the required checks under a
stated budget, classifies redness with the quality contract's existing
taxonomy (assertion-red returns to the owning stage and is repaired,
infrastructure-incomplete is missing evidence and is reported as such),
never merges, and, once every required check is green, tells the operator
the pull request is ready with its URL and the evidence, without being asked.
The mechanics (which command, the budget, how a hosted-check outage such as
unpaid Actions is recorded) live in the ship skill's evidence reference; the
skill itself gains one step. The pull request template gains the summary
shape TSK-066 decides. Non-goal: a second redness taxonomy; ADR-0038's
language in the quality contract is the classifier.

## Affected surfaces and interfaces

`.claude/skills/cf-ship/SKILL.md` (one step after the open step, inside the
byte ratchet or with the ratchet moved and recorded), `cf-ship/references/pr-evidence.md`,
`.github/pull_request_template.md` (or the project's template path), the
ship rows of `cf-model-orchestrator/resources/quality-contract.md` closeout
list, `.agents` and `assets/base` mirrors and manifest hashes. CAP-010.

## Acceptance Criteria

- [ ] When a pull request the agent opened has a required check that is assertion-red, the agent repairs it and pushes without waiting for the operator to name the job; evidence: the step text and the TSK-068 blind case.
- [ ] When a required check is infrastructure-incomplete (queued, cancelled, or hosted checks unavailable), the agent reports it as missing evidence with the reason, does not treat it as a product defect, and does not spin: the poll has a stated budget and ends with a report; evidence: the reference text and the paired case.
- [ ] When every required check is green, the operator-facing report carries the pull request URL from the tool output and the check summary, and the agent still does not merge; evidence: the step text and the case whose faulty control merges or omits the URL.
- [ ] The pull request template's summary guidance matches the TSK-066 decision (two to four sentences of plain prose, then bullets or a table where they carry facts); evidence: the template diff.
- [ ] All mirrors are byte identical, hashes match, and no ratchet is exceeded without a recorded change; evidence: `manifest_consistency` and `artifact_budget_contract`.
- [ ] Editorial review of the step and reference, Grok adversarial review; evidence: the review records.
