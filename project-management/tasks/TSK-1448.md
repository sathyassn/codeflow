# TSK-1448: The limits of the local hooks when a hook is skipped are stated and tested

## Description

CodeFlow's git floor has four planes: the git hooks, the in-session guards, CI, and the remote's branch protection. A user can skip a git hook, for example from a terminal outside an agent session. The adopter docs and ADR-0009's residuals do not say plainly what still stops a change to a protected branch when that happens:

- Push side: with the push hook skipped, no local layer stops a forced update or deletion of a protected branch on the remote. The local reference hook judges local references only. Only the remote's protection refuses it, so an adopter without remote protection has no layer there.
- Commit side: the local reference hook refuses a local move of a protected branch, and unit tests prove the rule, but no end-to-end test runs a commit that skips its hooks on a protected branch through the installed hooks.

`codeflow doctor` does not say what is left open when a protected branch has no remote protection it can verify.

Source: the Director, 2026-11-11 about 17:2x, from coord/catalog's read-only reading of `main` at f8aabc62c. Owner search (coord/records, 17:30, open task records on `main` and the EPC-022 and EPC-024 lines): no open record states what each layer stops when a hook is skipped. TSK-1349 (todo) makes the guard refuse the skip options; TSK-383 (todo) makes doctor accept live remote rules it did not create; TSK-1344 AC-7 runs one wrapped push case. None covers the residual text, doctor's warning for an unprotected branch, or an end-to-end test of the commit case.

## Outcome

After this merges, an adopter can read in ADR-0009 and the policy reference which layer stops what when a hook is skipped, `codeflow doctor` warns when a protected branch has no remote protection it can verify and says what that leaves open, and an end-to-end test proves the commit-side refusal through installed hooks.

## Acceptance Criteria

- AC-1 ADR-0009's residuals and `docs/policy-reference.md` shall state, for a skipped commit hook and a skipped push hook, which layer stops a move, forced update or deletion of a protected branch, locally and on the remote, and that only the remote's protection stops the push-side case. Evidence: the docs diff, checked by the reviewer against the hook code.
- AC-2 `codeflow doctor` shall report each protected branch with no remote protection it can verify, naming what that leaves open (a forced update or deletion on the remote when the push hook is skipped) and the step that clears it (`codeflow remote protect`, or the host's settings). It shall be quiet when the protection is verified. Evidence: doctor tests for verified, missing and unverifiable protection against a stubbed host.
- AC-3 One end-to-end test shall install the hooks in a scratch repository and run a commit that skips its hooks on a protected branch, and show the local reference hook refusing the move. If it does not refuse today, the test shows fail-before and the fix lands here. Evidence: the test and its result.
- AC-4 Any guard row added for these cases shall be a test that feeds a hook payload string and executes nothing. Evidence: the tests.
- AC-5 Behaviour for every other hook, guard and doctor check shall be unchanged. Evidence: the existing hook and doctor tests, `hooks_cli`, `codeflow test --mode quick`, clippy `-D warnings`, `cargo fmt --check`.
- AC-6 Public text shall name the gap by class only. Evidence: the pull request as opened, checked by the reviewer.
