# TSK-1379: The first release's CodeFlow runs are recorded as TSK-1026's hosted proof

## Description

Once a published release carries TSK-1026's shipped helper and template, this task records the three CodeFlow hosted run links that TSK-1026 AC-21 names: a landing push to `main` that reuses the pull request verdict, a push to an integration line that reuses a pull request run, and a run whose recorded provenance shows its merge tree and jobs run. It is TSK-1026's follow-up for AC-21 and sits outside EPC-028, so the epic does not wait for the release. Non-goal: no proof in any other project, no new proof work and no workflow, helper or template change; it only records runs that already exist. Added 2026-11-07 on the operator's ruling that AC-21 is proved on CodeFlow's own runs.


## Outcome

After this lands, a maintainer can open TSK-1026's hosted proof from three CodeFlow run links recorded after the first release that carries its helper and template.


## Deliverables

- The three run links and the release they ran on, with the reason a link is missing if one cannot be shown: this record's `## Findings`
