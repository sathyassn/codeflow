# TSK-247: An update is previewed read-only before anything is written

## Description

Fixes the preview portion of #74. An adopter who has tailored CodeFlow
needs the whole update in view before it lands: which files change and how,
which project rules and docs cite managed lines that move, which new
defaults the project overrides, which skill mirrors have drifted apart,
and which paths the agent's session cannot write so a person must. Today
the only preview is one file's `decide`
(`crates/codeflow-core/src/scaffold/update.rs:141`), `--diff` writes its
report after applying, and a sandboxed run that cannot write `.claude/`
stops part way with the manifest unwritten. An adopter on 3.1.1 reported
on 2026-10-13 that an agent now has no preview route at all: exporting the
tree to a scratch copy is refused by the guard, so the preview has to run
against the live repository without writing.

This task adds a read-only `codeflow update --plan [FILE]` produced by the
same steps as the apply (one write sink, so the plan cannot drift from the
apply), a cross-reference scan of project-owned text for citations of
managed lines that move, a write preflight shared by plan and apply, the
policy report for every changed default the project overrides, and a
mirror-pair comparison. The plan separates the files an agent may resolve
from the files only a person may change, so the agent prepares the first
set and hands the person a short list for the second. It reads bases as
`SPC-015` defines them (TSK-1087).

History: allocated as a standalone task on 2026-10-06 (its branch
`task/TSK-247-update-plan` never landed); joined this epic on 2026-10-30
when the operator's version decision brought the read-only update plan into
4.0.0. Two criteria moved out on 2026-10-30 and their ids are retired,
never reused: AC-5 (whole-file drift in doctor, which read the recorded
shipped hash that the baseline replacement removes) is TSK-1087 AC-7, and
AC-7 (the procedure file, `[scaffold] ignore` in the adoption guide and
the skew warning naming the procedure) is TSK-1088 AC-1, AC-3 and AC-5;
this task's skew warning names `--plan` only, under AC-9. Non-goals: generating
one skill tree from the other (an ADR-sized change, a recorded follow-up in
the epic), embedding changelog entries or ADRs (the plan links each
release), and a doctor cross-reference check.

## Outcome

After this merges, an agent in an adopting project can run `codeflow
update --plan` against the live repository, see every file's predicted
action, the citations and overrides the update makes stale and the paths
only a person can write, with nothing on disk changed.
