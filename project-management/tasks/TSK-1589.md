# TSK-1589: Every tier installs the pattern layer at its default, and CodeFlow's own repository runs it at block

## Description

Owner: to be assigned by the Director. Staged 2026-11-23 for coord/records.

SPC-018 R-2 and R-6. ADR-0019 makes enforcement the floor at every tier,
so the pattern layer installs from `--minimal` up. The shipped default
is `block`, by the operator's decision of 2026-11-23; this departs from
TSK-1372's off-for-adopters precedent for these layers only, and a
project can still set `warn` or `off`, reported as a relaxation.
By SPC-018 R-2b this task installs and advertises only the pattern
section (`privacy.patterns` and `privacy.pattern_kinds`): the identity
key and its `block` default are installed by TSK-1594 when the
identity detector lands, and the names and terms keys by TSK-1598 and
c5. The final defaults are unchanged.
`codeflow update` adds the pattern section to an existing project at
the shipped defaults and reports it, as it adds other missing keys, and
never changes a level a project set. CodeFlow's own repository turns the layer
on at `block`; its existing occurrences are admitted once through
TSK-424's baseline (AC-2 there) with a fix task each, or replaced by
placeholders in this task.

## Outcome

After this merges, a new project at every tier gets the pattern section
at its shipped default, an existing project gains it on update and keeps
any level it set, and CodeFlow's own repository runs the pattern layer
at `block` with any remaining occurrence admitted in the baseline.

## Acceptance Criteria

- AC-1 A fresh `codeflow init` at minimal, standard and full shall write the pattern section (`privacy.patterns: block`, `pattern_kinds` all) and no other privacy key (SPC-018 R-2b); `codeflow update` over a project without the section shall add it and report it, and over a project that set its own levels shall change none of them; a project level of `warn` or `off`, and a narrowed `pattern_kinds`, shall print the privacy relaxation line (SPC-018 R-2a) in every hook, `codeflow ci` and `codeflow doctor`, with TSK-424's activation key unset; evidence: scaffold tests per tier, two update tests, and relaxation output tests per placement with the key unset.
- AC-2 This repository's policy shall set `privacy.patterns` to `block`; each existing occurrence at the base shall be replaced with a placeholder or admitted with a fix task, and `codeflow ci` on this repository shall pass; evidence: the policy diff, the replacement diff or baseline, and the run.
- AC-3 (journey) With the installed build, on Linux and on macOS, a scratch minimal-tier project shall: refuse a commit adding one value of each pattern kind at `block`; warn at `warn`; pass placeholder forms; refuse the push of a commit made with the layer off locally while the authority holds `block`; fail a `codeflow ci` run, in the form the trusted verdict job runs it (the authority checked out, the range fetched as data), over a range holding a commit made with `--no-verify` that adds a pattern value; still scan a prose file a head `.gitattributes` marks `binary`; accept an authority-held exception and print it, with TSK-424's activation key unset, for every pattern rule of the SPC-018 R-31a list that the installed defaults put on; and never print a matched value (the content and path canary searches over the journey's output); evidence: the journey output per platform.
- AC-4 Final layer 2 speed run (SPC-018 R-9a): with the real hook wired and every detector of this epic present, the privacy pass of the installed pre-push hook on the typical-change fixture, measured as wall-clock from the authority read through the range's diff, path and message reads to the last finding, shall have a median of five runs under 500 ms on the hosted Linux runner and an Apple silicon macOS machine; evidence: both medians in the PR, with the measured span stated.
