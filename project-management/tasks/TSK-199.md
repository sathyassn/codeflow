# TSK-199: Make the full gate pass on hosted Linux

## Description

The first hosted Linux full gate on `main` (ubuntu-24.04, after the 3.0.0
merge) failed, and the v3.0.0 release dispatch needs that gate green. This
task fixes the causes, not the checks: tests that read the developer's git
identity, macOS paths or a fine-grained file clock; gate scripts that assume
the macOS Playwright cache; a read benchmark whose latency baseline holds
only on macOS; a hook that hashes its own binary with an unoptimized SHA-256
in debug and coverage builds; one profile file per instrumented process,
which would outgrow the runner's free disk; and one product defect, where an old Git's
refusal of `git check-attr --source` surfaced as a broken pipe on Linux. No
gate is relaxed and no check is removed. Non-goal: Linux aarch64 release
assets (`ci_pin_platforms` names no aarch64 Linux release).

- AC-1 When the Rust suite runs on Linux with no git identity configured, the tests that issue IDs or merge shall supply their own identity and pass; evidence: cli_flow, init_e2e, id_registry_journey and release_line tests pass in a Linux container whose user has an empty passwd name.
- AC-2 When the coverage target runs on Linux, it shall finish inside its 1800 s timeout and within the runner's free disk; evidence: a commit-msg hook on the Linux debug binary takes about 0.25 s instead of 2.85 s, and the instrumented suite completes in about 600 s with merged profiles under 100 MB instead of 27.5 GB.
- AC-3 When the present transport and conversation checks run on Linux, they shall find Playwright's browsers where Playwright installs them, honouring `PLAYWRIGHT_BROWSERS_PATH`; evidence: `npm run check:browser`, `check:figures`, `check:real-browser`, `check:real-browser-cleanup` and `check:conversation` pass in the Playwright Linux image and on macOS.
- AC-4 When `codeflow ci` meets a Git that refuses `check-attr --source`, it shall report Git's refusal and the upgrade remedy, never a broken pipe; evidence: ci_names_a_git_upgrade_when_check_attr_has_no_source passes on Linux and macOS. (journey)
- AC-5 When the read benchmark runs, it shall judge latency against the baseline recorded on the same operating system; evidence: the Linux run in a container is within the Linux budget, the_budget_check_flags_a_run_over_its_baseline passes on both systems.
- AC-6 When a top-level file, symlink or directory is replaced, or a top-level file changes size, even within one clock tick, the qualification snapshot shall flag the change, and its limitation text shall state that a same-size in-place rewrite within one tick is not observed; evidence: test_top_level_entry_changes_still_invalidate, with controls that keep the old mtime, passes on Linux and macOS.
- AC-7 When the guard tests run on Linux, they shall judge only paths that exist there; evidence: exec_guard_refuses_unresolved_temp_paths_through_both_aliases and every_round_three_probe_keeps_its_verdict pass on Linux and macOS.
