# TSK-199: Make the full gate pass on hosted Linux

## Description

The first hosted Linux full gate on `main` (ubuntu-24.04, after the 3.0.0
merge) failed, and the v3.0.0 release dispatch needs that gate green. This
task fixes the causes, not the checks: tests that read the developer's git
identity, macOS paths or a fine-grained file clock; gate scripts that assume
the macOS Playwright cache; a read benchmark whose latency baseline holds
only on macOS; a hook that hashes its own binary with an unoptimized SHA-256
in debug and coverage builds; one profile file per instrumented process,
which would outgrow the runner's free disk; and one product defect, where an old Git's
refusal of `git check-attr --source` surfaced as a broken pipe on Linux. No
gate is relaxed and no check is removed. Non-goal: Linux aarch64 release
assets (`ci_pin_platforms` names no aarch64 Linux release).

## Deliverables

- the Linux and macOS fixes to the tests and checks the full gate runs: crates/codeflow-cli/tests/ and crates/codeflow-present/web/scripts/
- the per-system read benchmark baselines: crates/codeflow-cli/tests/read_benchmark_baseline-linux.json and read_benchmark_baseline-macos.json
