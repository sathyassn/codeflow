# TSK-1406: Exec-guard decides a wide glob inside its deadline under load

## Description

The hooks test `tsk1002_review2_b10_flat_globs_use_search_budget` (`crates/codeflow-cli/tests/hooks_cli.rs:11097`, review case 30) fails now and then because exec-guard, judging `python3 tool.py many/*` over a wide flat directory, refuses with "the guard reached no decision within 20 seconds" (the TSK-1082 deadline). It was seen twice under parallel load: in the TSK-1375 completion at a load average near 280, and on the TSK-1400 merge head 62e2a3312 on 2026-11-09 at a load average of 24 to 31, in a debug build during the full `hooks_cli` run. Both times the test passed when run alone (28 s for the whole test). A refusal at the deadline fails closed, so this is not a bypass, but it makes the suite unreliable, and if a wide glob in a real project comes near the deadline in a release build, an adopter's ordinary command is refused. This task measures where the time goes and fixes the cause: the guard's glob search, the test's setup, or both. Non-goal: lengthening the shipped deadline or adding any switch that lets a run change it; the 20-second deadline and its fail-closed refusal stay as TSK-1082 set them.

## Outcome

After this merges, the hooks suite no longer fails this test under the parallel load the gates run at, and a wide flat glob is judged well inside the guard's deadline.

## Deliverables

- the fix: exec-guard's glob search in `crates/codeflow-core/src/security/` and the test or its fixture in `crates/codeflow-cli/tests/hooks_cli.rs` and `crates/codeflow-cli/tests/guard_cases*`, as the measurement decides
- evidence: the timing measurements in the pull request body

## Acceptance Criteria

- AC-1 Before any change, the builder shall measure exec-guard's decision time for each payload in review case 30, in a debug and a release build, alone and under a parallel load like the full `hooks_cli` run, and record where the time goes (glob expansion, the search budget, repository opens or process start); evidence: a Findings section in this record with the measurements, committed before the first code change and summarised in the pull request body.
- AC-2 Exec-guard shall decide each review case 30 payload in under half its deadline in a release build under that load, the bar TSK-1082 AC-2 sets for an ordinary call; evidence: a timed run recorded in the pull request body, and the existing deadline test still passing.
- AC-3 The test shall pass in repeated full `hooks_cli` runs at the parallel load where it failed before; evidence: the number of runs and their results, with for each set the build identity (profile and commit), the test thread count, the host hardware, the competing workload and the load average, and the failing run before the change if it reproduces.
- AC-4 The shipped deadline, its fail-closed refusal and the hook timeouts shall be unchanged, and no environment variable, flag or setting shall lengthen the deadline; evidence: the diff, and `a_guard_stalled_on_a_fifo_include_refuses_at_its_deadline` (the deadline still refuses) and `each_guard_decides_well_inside_its_deadline` (an ordinary call still decides in time) passing.
- AC-6 Every completed allow or refuse decision exec-guard makes on a glob payload shall be the same before and after the change; a search the guard cannot finish within its budget shall still refuse (fail closed); only a command refused solely because it hit the deadline may become allowed, and each such case shall be named; evidence: real-hook regression tests with protected matches placed among many ordinary matches (at least as wide as review case 30's 5,000), including just inside and just past the search budget, refused at the head, and a before-and-after table of completed decisions in the pull request body. The wide fixture keeps its width.
- AC-5 Every guard case in the same file whose payload expands a glob over the seeded matches shall be checked for the same exposure, and each one near the deadline under load shall be fixed in this task; evidence: the list with each case's measured time.
