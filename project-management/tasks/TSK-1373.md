# TSK-1373: A published release proves verdict reuse and run provenance on an adopter's hosted runs

## Description

Source: the Director's ruling D5 of 2026-11-06 on TSK-1026, via coord/ci. The operator withdrew scratch repositories on 2026-11-01 (`coordination/HANDOFF-2026-10-27.md:1643-1644`: "hosted adopter run at release"), and the managed helper and template reach an adopter only in a published binary, so these hosted runs cannot exist before TSK-1026 lands and a release publishes it. This task carries TSK-1026 AC-21, the adopter legs of its AC-2, AC-4, AC-7 and AC-19. TSK-1270 and TSK-1273 prove this repository's own runs; this task proves the managed template in an adopter repository. Non-goal: it changes no workflow, helper or template.

## Outcome

After this merges, a maintainer can see from run links in an adopter repository that the published managed workflow reuses a bound pull request verdict on a push, still runs the secret scan, and records its provenance.

## Deliverables

- the run links and the log lines that name each reused run: this record's `## Findings`
- the adopter repository used: this record's `## Findings` (provisional; settled at claim)
- when a run does not behave as TSK-1026 requires: a defect record with the run evidence

## Acceptance Criteria

- AC-1 (journey) With a published release that carries TSK-1026's helper and template installed in an adopter repository, a landing push to the protected branch shall reuse the pull request verdict, naming the run and its mode, and shall execute the secret scan; evidence: the pull request run and push run links and the push run's job list.
  - Added 2026-11-07 by the planning pull request for TSK-1026 and TSK-336: takes the hosted proof of TSK-1026 AC-2 and AC-4, through its AC-21, because that run cannot exist before a release publishes the helper (the Director's ruling D5).
- AC-2 In the same repository, a push to an integration line shall reuse a pull request run's verdict, naming the run; evidence: both run links.
  - Added 2026-11-07 by the planning pull request for TSK-1026 and TSK-336: takes the hosted proof of TSK-1026 AC-7, through its AC-21, for the same reason.
- AC-3 In the same repository, a hosted run's recorded provenance shall show its merge tree and jobs run; evidence: the run link and the recorded provenance.
  - Added 2026-11-07 by the planning pull request for TSK-1026 and TSK-336: takes the hosted proof of TSK-1026 AC-19, through its AC-21, for the same reason.
