# TSK-395: The user's Claude settings folder is protected for directories and globs

## Description

Source: PR 239 (TSK-373) confirm round, 2026-10-18. The user's `~/.claude` folder is unprotected for directories and globs on both routes: `python3 tool.py ~/.claude`, `~/.cla*`, `cp x ~/.claude`, `rm -rf ~/.claude` and `echo x > ~/.claude/settings.json` pass git-guard; the interpreter route refuses only `~/.claude/settings.json`. Claude's sandbox denies the settings write; other harnesses may not. Security, info, older than 3.2.0.

Outcome: **the guards protect the user's harness settings folders (`~/.claude`, and the Codex and Grok equivalents CodeFlow configures) as a directory, by glob and by file, on both routes.**

Added to EPC-023 (4.1.0) by the amendment of 2026-10-18: the operator's release decision of that day puts lower-severity review follow-ups in 4.1.0 (workspace `RELEASE-PLAN.md`, 2026-10-18 operator decision).

## Acceptance Criteria

- AC-2 Reads of those paths and writes elsewhere under the home directory shall pass; evidence: tests.
- AC-3 (journey) With the installed build in a harness without Claude's sandbox, each write form shall be refused; evidence: the journey output.
