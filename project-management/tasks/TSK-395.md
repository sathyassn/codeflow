# TSK-395: The user's Claude settings folder is protected for directories and globs

## Description

Source: PR 239 (TSK-373) confirm round, 2026-10-18. The user's `~/.claude` folder is unprotected for directories and globs on both routes: `python3 tool.py ~/.claude`, `~/.cla*`, `cp x ~/.claude`, `rm -rf ~/.claude` and `echo x > ~/.claude/settings.json` pass git-guard; the interpreter route refuses only `~/.claude/settings.json`. Claude's sandbox denies the settings write; other harnesses may not. Security, info, older than 4.0.0.

Outcome: **the guards protect the user's harness settings folders (`~/.claude`, and the Codex and Grok equivalents CodeFlow configures) as a directory, by glob and by file, on both routes.**

First added to EPC-023 (4.1.0) on 2026-10-18; moved to EPC-022 (3.2.0) the same day after the Codex review of PR 249, under the operator's rule that every security gap and every defect that forces an adopter workaround or blocks work belongs in 3.2.0.

## Deliverables

- tests: guard tests per form

## Acceptance Criteria

- AC-1 A write, copy, move or recursive delete whose target is `~/.claude`, a glob that can match it, or a file under it, through a shell command or an interpreter argument, shall be refused by both guards; evidence: guard tests per form, failing before the change. (serves EPC-022 AC-85)
- AC-2 For each of `~/.claude`, `~/.codex` (or `$CODEX_HOME`) and `~/.grok` (or `$GROK_HOME`), the folder, a file in it and a glob that can match either shall each be refused for a write, copy, move and recursive delete; evidence: a matrix test of harness by form by operation.
- AC-3 Existing refusals shall hold: reads of credential files such as `~/.claude/.credentials.json` (`crates/codeflow-core/src/security/actions.json:649`) and the Codex and Grok auth files stay refused, and writes to shell-startup files outside the harness folders stay refused; ordinary non-secret reads (`cat ~/.claude/CLAUDE.md`) and writes to unprotected home paths (`~/notes.txt`) still pass; evidence: negative and positive controls in the same test.
- AC-4 (journey) With the installed build in a harness without Claude's sandbox, each write form shall be refused for all three harness folders, and the positive controls shall pass; evidence: the journey output.
