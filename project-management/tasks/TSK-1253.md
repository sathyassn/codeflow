# TSK-1253: Tests that wait on a fake remote or child process tolerate a loaded runner

## Description

Source: hosted run 41523922494, attempt 1, partition 4, on PR 526.

On hosted Windows, `codeflow-cli::policy_authority_journey` test `asking_the_remote_sends_no_stored_http_credentials` (`crates/codeflow-cli/tests/policy_authority_journey.rs:369`) timed out at a 10 second fake-remote wait. It passed on rerun. The red shard also failed commit standards, which reuses the run, and it stalled a records-only pull request's landing chain. The cause class is a fixed wall-clock wait on a loaded runner. The test file has no 10 second constant: it calls `challenging_server()` (`:324`) and `Adopter::doctor()` (`:112`), so the wait sits either in the product's remote query timeout that `doctor` uses or in a shared helper. Find it first.

No open task owns this test. TSK-1077 introduced the journey (its AC-8) and is complete. TSK-1005's flaky-test register is related: a quarantine entry used meanwhile follows its register rules.

## Outcome

After this merges, the fake-remote tests wait on events, not on a fixed wall-clock bound, and a loaded runner no longer reddens them.

## Deliverables

- the event-based wait in the failing test or its helper: `crates/codeflow-cli/tests/`
- the sibling sweep of fixed short waits, each fixed or recorded with a reason

## Acceptance Criteria

- AC-1 The exact wait that expired shall be named (file:line) and classed as test code or a product timeout; if it is a product timeout that adopters hit on slow remotes the finding shall say so and keep the product limit unless there is evidence to change it; the test shall wait on the event (a request seen, or a child exit); evidence: a `## Findings` section.
- AC-2 The failing test shall no longer depend on a fixed wall-clock bound under load; evidence: a run under induced load that fails before and passes after, or a deterministic event-based wait whose generous bound is documented.
- AC-3 A sibling sweep of fixed short wall-clock waits in tests shall fix or record each with a reason, starting with `delegate_pty_stress.rs:591`, `:595`, `:599` and `:656`; `hooks_cli.rs:6454`; `present_cli.rs:181` and `:2565`; `test_gate_cli.rs:151`; `codeflow-core/tests/coord_store.rs:53`; deliberate timing assertions stay with the reason recorded; evidence: the sweep table.
- AC-4 `codeflow test --only <the journey target>` shall pass on Windows and on the local host under load; evidence: both runs. (journey)
