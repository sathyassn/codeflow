# TSK-060: portal themes, panels and tab strip

## Description

Replace the three skins with ones that separate cleanly. Graphite is the
neutral pair modern tools use: light on an off-white canvas with white
surfaces and near-black text, dark on a near-black grey canvas with surfaces
stepping lighter and no blue cast. Slate is the blue-tinted pair, its light canvas retuned so
it clears the distance from Graphite (the current editorial light canvas
does not). The third is named by the operator (the proposal is Plum, a violet-tinted pair); the
current warm pair is retired. Make both side panels collapsible from the
header with the state remembered, and the navigation panel resizable by drag
within declared bounds. Redesign the altitude tab strip: body typeface,
sentence case, body size, selected state carried by weight and an accent
underline, hover by text colour only. Keep the portal, the managed starter and
the embedded present distribution on one token contract, value identical per
token role. Runs after TSK-059 so the two never write the same files.
Non-goal: figure tokens beyond line, fill, hatch, accent, warn and stop,
which TSK-058 declares and this task carries in the sheet; the verifier and
the page classes, which TSK-059 owns.

`docs-portal/src/styles/utility-tokens.css` and the starter copy,

## Acceptance Criteria

- [ ] Each skin holds text and muted at or above 4.5:1 on canvas and surface
      in both modes, the neutral dark canvas has red, green and blue channels
      equal within 2, and every pair of skins is separated in the same mode
      by a CIEDE2000 distance of at least 3 between canvases and at least 1.5
      between surfaces; the design primary chooses the third skin's values to
      clear that against Graphite and Slate in both modes, and proposes a
      replacement identity before tokens land if no violet pair can; evidence: the token
      contract test with the computed table.
- [ ] The skin names in the Display control are Graphite, Slate and the
      operator's third name, and the retired warm pair is absent from every
      token sheet, test and skill example; evidence: grep and the control.
- [ ] Both side panels collapse and restore from a header control by mouse
      and keyboard, the state persists across pages in the browser, and the
      navigation panel resizes by drag between 220 and 400 px with the width
      remembered; content reflows without horizontal scroll at every width;
      evidence: `browser:verify` cases and the design primary's review.
- [ ] The altitude tabs render in the body typeface in sentence case with
      the selected tab in weight 600 and an accent underline, hover changes
      text colour only, and the tablist keeps its three connected panels;
      evidence: the existing tablist check extended with the style assertions.
- [ ] The live portal, the starter and the present distribution carry the
      same value for every token role in every skin and mode, checked by
      extracting the custom properties from each sheet, and the present check
      prints a reproducible tree; evidence: the per-role equality test and
      `npm run check` twice from clean.
- [ ] The design primary reviews the chrome (panels, tab strip, header,
      navigation) in three skins, two modes and two widths on three
      representative routes and records pass per skin; per-page figure review
      is TSK-064's; Grok adversarial review; evidence: the review records.
