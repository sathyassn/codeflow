# TSK-1585: IP and MAC addresses and private host names in added content are privacy findings

## Description

Owner: to be assigned by the Director. Staged 2026-11-23 for coord/records.

SPC-018 R-14: the network kinds of layer 2. An internal address, a device
MAC or a tailnet host name (`*.ts.net`) reveals a person's network and
devices. The detector is structural: IPv4 and IPv6 with the documentation
ranges, loopback, unspecified and broadcast accepted; private, shared and
link-local addresses are findings; MAC addresses outside the RFC 7042
documentation block; host names under the reserved private suffixes and
`.ts.net`, a fixed set in code.

Non-goals: resolving any name or address; a project-maintained host list.

## Outcome

After this merges, an added IP address, MAC address or private host name
outside the placeholder forms is a `privacy.patterns.ip`, `.mac` or
`.private_host` finding at the `privacy.patterns` level.

## Deliverables

- `crates/codeflow-core/src/privacy/patterns/network.rs` (new) with unit tests
- placeholder rows in the TSK-1583 table
- docs: the kinds and the reserved sets in `docs/policy-reference.md`
- release note: `changelog.d/TSK-1585.md`

## Acceptance Criteria

- AC-1 Fail before: at the base, a commit adding a private IPv4 address, a non-documentation MAC and a `<host>.<tailnet>.ts.net` name (assembled at run time) is accepted with no finding; evidence: the base output in the PR.
- AC-2 Pass after: each shall be a finding at the level, naming kind and place and not the value; IPv6 forms (full, compressed, with zone id) and an address embedded in a URL shall be found; evidence: detector and hook tests.
- AC-3 `192.0.2.10`, `198.51.100.7`, `203.0.113.9`, `2001:db8::1`, `127.0.0.1`, `::1`, `0.0.0.0`, `00:00:5e:00:53:01` and `host.example` shall pass; evidence: tests per form.
- AC-4 Version strings, OIDs, semantic versions with four parts and timestamps shall not match; evidence: a negative corpus test from this repository's sources at the base.
- AC-5 The reserved suffix set shall be the fixed set SPC-018 R-14 names and a test shall fail if a policy value can add to it; evidence: the test.
