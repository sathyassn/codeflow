# TSK-1292: The catalog ships the new default models and routes, and a harness choice still wins

## Description

The operator set new model and effort defaults on 2026-11-03 and ruled that every model usage rule becomes data a project can override. Today the defaults and rules are prose in `cf-model-orchestrator` `SKILL.md` (for example `:70-79` design authority, `:108-126` and `:270-286` effort), in the managed `AGENTS.md` seat table and in `current-ensemble.json` routes (`:355-740`).

New defaults:

| Family | Default | Effort | Subagent only |
|---|---|---|---|
| Claude | Opus 5.5 | high for the Director or a lone session; medium for Coordinators, Workers and everything else | Fable 5.1, for bounded review, analysis and design consults |
| Codex | GPT-6.1 Sol | high for a Codex Director; medium otherwise | GPT-6 Astra |
| Grok | the latest active Grok (4.7 now; never a Fast variant) | high for important work (security, release, the hard-review triggers); medium otherwise | none |

Design stays with Claude models (`design_owner: claude-primary`). Sonnet and Luna stay available as routes, not defaults, with one exception added on 2026-11-07: Sonnet 5.5 at medium is the default route of the read-only duty (AC-11).

This task ships the defaults and turns the prose rules into catalog fields: `launch` per line (`subagent-only`, `seat` or `either`), `design_owner`, the effort triggers, fallbacks, retired lines and the seat roles. Effort per coordination role is TSK-1288's (folded there). TSK-1131 (PR 480) would have given Grok high with no trigger (its AC-1); it was cancelled on 2026-11-07 and PR 480 closed, so this task sets medium with the triggers above without waiting on it. Non-goals: project overrides (TSK-1293, TSK-1294), the harness rule (TSK-1295), the docs page (TSK-1296).

## Outcome

After this merges, a session that asks `codeflow models resolve` gets the operator's 2026-11-03 defaults, and the skill reads each usage rule from the catalog instead of stating it as a fixed fact.
