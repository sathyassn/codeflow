# TSK-036 — preserve committed directory links in portals

## Description

Agent OS's clean guide build rejects an existing committed directory link in
ADR-0029 because the adapter inventories only files. Preserve valid relative
directory links through commit-pinned repository tree URLs without rewriting
accepted source documents or using the mutable working tree as authority.

## Affected surfaces and interfaces

CAP-015; shared docs-portal starter URL resolution, regression fixtures, managed
CodeFlow adoption and ownership hashes, source-link contract and its managed
mirrors, appropriate existing runtime version metadata, changelog, and the rebuilt candidate
used for Agent OS's ordinary managed update. No schema, theme, or runtime fork.

## Acceptance Criteria

- [x] Existing committed directories resolve with and without trailing slash;
      encoded spaces and Unicode survive correctly in commit-pinned URLs.
- [x] Supported providers use directory/tree routes rather than file/blob
      routes; unknown providers retain visible source references.
- [x] Missing directories, similarly prefixed siblings, traversal and unsafe
      schemes stay rejected; links never consult the live filesystem or treat
      a symlink/submodule as an ordinary committed directory.
- [x] Directory resolution is link-only, follows exact-file resolution, and
      precedes the missing-document failure; file/blob and media behavior stays
      intact. Images targeting directories fail; exact case and root boundaries
      remain checked. Provider-owned suffixes follow the existing link policy.
- [x] The actual Agent OS ADR-0029 link builds and remains a faithful source
      link; the historical ADR is unchanged.
- [x] Starter/adoption bytes and hashes agree after supported managed setup;
      regression, build, evidence validation and affected browser checks pass.
- [x] Independent Codex/Fable review and Grok challenge cover the exact repair;
      final combined verification follows the guide work.

## Execution contract

EPC-013 Plan v3: narrow prerequisite discovered by the real clean-consumer
rehearsal. Codex owns implementation through a bounded Sol worker; native
interactive Fable reviews and retains guide-design ownership. Root integrates
on the non-protected epic branch before TSK-035 acceptance. Agent OS then uses
the patched candidate's ordinary managed update. Recover with ordinary Git
reversal; no publication, historical ADR rewrite, or weakening clean-input and
source-boundary guards.
