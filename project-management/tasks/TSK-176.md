# TSK-176: a reloaded form shows and corrects its sent answer

## Description

TSK-120's live qualification found that after a reload a form with a sent
answer shows only its state words, such as "Acknowledged by agent", and not
the values that were sent, and Amend opens the controls empty. A correction
then fails validation ("Answer this question.") until the reviewer retypes
every required value, without seeing what they sent. That breaks the
correction journey TSK-120 ships. SPC-014 keeps answers out of browser
storage, but the service holds the sent answer and the page already renders
its state on load. This task has the page show the last sent values on load
beside the state words and start Amend from them, so a correction after a
reload changes only what the reviewer edits. Keeping answers out of browser
storage is unchanged. It follows TSK-120, whose criteria it does not change,
and must land before the 3.0.0 release.

## Affected surfaces and interfaces

- The page's form rendering and Amend path in
  `crates/codeflow-present/web/src/forms.ts`, the answer data the service
  hands the page on load (`crates/codeflow-present/src/service.rs`,
  `delivery.rs`), the rebuilt assets, the browser checks, and SPC-014's page
  states.

## Acceptance Criteria

- AC-1 When a page loads a form with a sent answer, it shows the last sent
      values, the latest answer or correction, next to the state words, for
      every field kind; evidence: a check:forms case that sends, reloads and
      reads each value.
- AC-2 When the reviewer chooses Amend after a reload, the controls start
      from the last sent values, and a correction that changes one field
      sends the others unchanged; evidence: a check:delivery regression that
      reloads between send and Amend, changes one field and reads the stored
      amendment, failing before the fix.
- AC-3 No answer value is written to `localStorage`, `sessionStorage`,
      IndexedDB or cookies; evidence: the existing storage assertion run on
      the reload case.
- AC-4 SPC-014 states what a reloaded form shows and where Amend starts,
      landed through a planning PR before completion; evidence: the PR.
- AC-5 `npm run check`, the browser checks and `cargo test -p
      codeflow-present` are green and the assets match a clean rebuild;
      evidence: recorded output with the head SHA.

## Execution contract
