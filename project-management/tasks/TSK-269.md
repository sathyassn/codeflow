# TSK-269: CodeQL findings are triaged and the design kit escapes review data

## Description

Every alert from the first CodeQL default-setup scan (run 38158838901 on main
c941877ba, 103 open alerts, all high) has a recorded, evidence-backed
disposition. The triage read each data flow from source to sink in the
scan's SARIF and judged it against CodeFlow's threat model: a local CLI,
plus `codeflow-present`, a loopback service that renders untrusted
repository content (ADR-0049). It found no exploitable alert. The one
hardening it calls for is in the design-system kit `chrome.js` that the
cf-present and cf-docs-portal skills ship: the earlier-feedback rail wrote a
note's `kind` from the page's `#cf-data` JSON into HTML without escaping
(alerts 1 and 2), and two sibling sinks in the same file did the same with a
local note's `kind` and a heading `id` in the table of contents. All three
now go through the kit's `esc`. The rest are false positives or test-only
code; the operator dismisses them with the prepared script, since dismissal
changes the repository's security state. With no real alert, 3.1.0 carries
no change from this triage, and this hardening lands after the release.

Non-goals: no alert is dismissed by this task; no change to the present
service, the CLI output, the portal runtime, or the frozen evidence under
`docs/verification/`.

## Deliverables

- the escaped kit sinks: `assets/base/agents/skills/cf-present/resources/design-system/chrome.js` and `assets/base/agents/skills/cf-docs-portal/resources/design-system/chrome.js`, with their `.claude/skills`, `.agents/skills` and `.codeflow/.baseline` mirrors and their `.codeflow/manifest.json` hashes
- the injection probe and its test: `scripts/design-kit-check.mjs`, `scripts/design-kit-check.test.mjs`
- the release note: `changelog.d/TSK-269.md`
- this record: `project-management/tasks/TSK-269.md`

## Acceptance Criteria

- AC-1 When the design kit renders a page whose `#cf-data` holds markup in an earlier note's `kind`, or whose content holds a heading `id` with a double quote, the rendered rail and table of contents shall show that value as text and create no element or attribute from it: the kit injection test fails at main c941877ba and passes at the head (journey)
- AC-2 Every copy of the kit `chrome.js` stays byte-identical across `assets/base`, `.claude/skills`, `.agents/skills` and `.codeflow/.baseline`, and `.codeflow/manifest.json` records its hash: the `manifest_consistency` test passes
- AC-3 Every alert of the scan has a disposition with evidence (real, defense in depth or false positive), the PR body names it by rule and site, and no alert is dismissed by this task
- AC-4 The Rust gates pass at the head: `cargo fmt --all -- --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `RUSTDOCFLAGS="-D warnings" cargo doc --workspace --no-deps`, `codeflow validate --docs` and `codeflow test --mode quick`
