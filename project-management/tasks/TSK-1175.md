## Description

The five shipped checkout steps lack `persist-credentials: false`: `codeflow-ci.yml:49`, `:197`, `:333`, `:795` and `codeflow-policy.yml:69`. This task is separable from verdict identity and has no edge to the other pieces; TSK-336's Findings (its AC-13) are read when present.

Outcome: **no shipped checkout persists a token for later repository code, and private-repository fetches still work through an explicitly scoped authentication that code under test cannot read.**

Non-goals: who may produce a verdict (TSK-336 and TSK-1177); the secret scan (TSK-1176).
