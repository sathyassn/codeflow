# TSK-197: close the release criteria waived at 3.0.0

## Description

The operator decided to release 3.0.0 on 2026-10-01 with six of
TSK-010's criteria waived to after the release (decision of 2026-10-01
12:47 in the workspace `RELEASE-PLAN.md`). This task owns them: each criterion below
carries the TSK-010 criterion it replaces, now proved on the first patch
release candidate after 3.0.0 instead of the 3.0.0 candidate. The native
Linux x86-64, native Windows and WSL2 runs of AC-5 are required before
that patch release is published. Revisit when the first 3.0.x patch
release candidate is cut. Non-goal: publication itself (public sync, tag,
release notes), which stays with the operator under the release policy.

By a further operator decision on 2026-10-01, 3.0.0 ships without native
Windows (TSK-200), and native Windows support moves to 3.0.1 under this
task. Its scope therefore also covers fixing the defects the hosted
Windows job found, such as the git guard that strips backslashes from
Windows paths; restoring the `x86_64-pc-windows-msvc` target and the
PowerShell installer in `dist-workspace.toml`; making the `windows` CI job
a gate again and returning it to `required_publication_checks` in
`.release/config.json`; and restoring the Windows rows of the release
checklist and the install docs. AC-7 to AC-11 name that work; AC-1 to
AC-6 predate the decision and keep their TSK-010 scope.

The release after 3.0.0 became 3.1.0, not 3.0.1, once TSK-203 added the
`codeflow test --only` feature, so "the first patch release candidate"
here means the 3.1.0 candidate. TSK-203 also split the Windows job into
checks, six test partitions and a journey job; the gate is now one
`windows` verdict over them, and that name is the publication check.

Amended 2026-10-02 by the operator's decision of that day (the workspace
`RELEASE-PLAN.md`): native Windows support lands in this task's pull
request, and AC-1 to AC-6 move unchanged to TSK-205, which proves them on
the 3.1.0 candidate on `main` before 3.1.0 is published. Reason: they bind
the exact release candidate, which this pull request is not; they need
Fable reviews, unavailable until 2026-10-08, native Linux, Windows and
WSL2 runs, and the operator's public-history steps. The waivers in this
task's acceptance block name the commit that records them here. AC-7 to
AC-12 stay here.

The live `main` rules require `codeflow gates`, `commit standards`,
`release impact`, `secret scan` and `security review`, but not `windows`.
Once this task lands, the operator adds `windows` to those required
checks; until then a red Windows verdict blocks publication through
`required_publication_checks` but not a merge. Checked 2026-10-03 with
`gh api repos/sathyassn/codeflow/rules/branches/main`.
