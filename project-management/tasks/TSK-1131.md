# TSK-1131: Default reasoning effort follows each vendor's recommendation

## Description

Operator direction (2026-11-01): models improved and tokens should be used
efficiently, so default reasoning effort follows each vendor's recommended
default. Claude Code's model configuration docs say effort defaults to high
except on Opus 5.5, Sonnet 5.5 and Haiku 5.5, which default to medium;
Anthropic's effort guidance recommends starting at medium for most work,
agentic coding included. So Opus 5.5 and Sonnet 5.5 default to medium, Fable
5.1 keeps its own default (high), and the Codex primaries GPT-6 Astra and
GPT-6.1 Sol default to medium. High (xhigh on Codex) is used only when a
specific task needs it, such as a hard build, a security review or a stuck
diagnosis, never by default for orchestrating, director or coordinator
sessions. The change is generic: it edits the shipped model catalog, the
orchestration guidance, the scaffold copies and the decision record that
stated high as the primary default (ADR-0056), with CodeFlow as first
consumer. Non-goals: Grok effort (no vendor default verified), per-person
effort settings (ADR-0087 stands) and the model roster itself.
