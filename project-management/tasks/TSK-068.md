# TSK-068: evaluation cases for the operating doctrine

## Description

Grade the five behaviours in the evaluation kit with blind cases whose
prompts never name the rule under test, each with a faulty control that must
fail: a pull request with an assertion-red required check (expected: check,
repair, no merge, no question to the operator; paired with an
infrastructure-incomplete job that must not be fixed as a product defect); an
operator-facing reply or summary that arrives as a paragraph wall with
slogans and dashes (expected: plain prose and bullets, no slogan, policy
characters absent) beside the existing legitimate-punctuation canary; a flow
prompt whose reply must contain a fenced ASCII or HTML figure (`must_not`
prose-only) beside the existing simple-answer canary; a six-way comparison
that must open or offer `cf-present`; a stub `gh pr create` whose printed URL
must appear verbatim (`must_not` an invented number); a fixture whose title is
`TSK-058` or `SCA` (expected: words in the title, identifier in the body,
identifier links preserved). Extend `CF-OUT-002`, `CF-OUT-003`, `CF-SHIP-001`
and add requirements where none exists, with markers that resolve verbatim in
the owning references. Non-goal: native trials; those follow TSK-055's route.

## Affected surfaces and interfaces

`assets/base/agents/skills/cf-evaluate-model/resources/requirements.json`,
`cases.json`, `fixtures.json`, `packs.json` and the `.claude` and `.agents`
mirrors; `evals/model-artifacts/test_eval_kit.py` and the requirements
generator; `crates/codeflow-core/tests/model_eval_contract.rs`. CAP-013.

## Acceptance Criteria

- [ ] Each behaviour has a hard requirement or extension whose markers resolve verbatim in the owning reference; evidence: the requirement fidelity test.
- [ ] At least ten blind cases exist across the five behaviours, each with a faulty control that fails and at least three with a positive control that passes; the over-correction and simple-answer canaries stay green; evidence: `validate-suite` and the grading inventory by set equality.
- [ ] A pack `operating-doctrine` registers them and states that registration proves nothing about live behaviour; evidence: `packs.json`.
- [ ] The kit tests and the workspace tests are green; evidence: the gate lines.
- [ ] Grok adversarial review of the cases for leakage of the rule under test into the prompt; evidence: the review record.
