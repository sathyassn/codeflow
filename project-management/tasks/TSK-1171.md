# TSK-1171: Estimate outcomes compare each task with its frozen band, time a deleted line's landing and report open-task age

## Description

Consolidated 2026-11-04 (second consolidation amendment, coord/catalog, under the operator's sizing direction of 2026-11-04 21:5x): this task absorbs TSK-1012 (a deleted line's landing, `--ref`, and open-task age with idle claims). Both read the blocked spans in `history.rs`, both put every task in exactly one category, and this task's AC-7 was already TSK-1012's old AC-7. TSK-1012's live criteria AC-1, AC-2, AC-4, AC-9 and AC-8 are now this task's AC-9 to AC-13, word for word with `Moved` notes; its deliverables are listed with `(from TSK-1012)`, its rules stay in its cancelled record, and its edge to TSK-1173 (the recorded claim) is carried here. Moved from EPC-035 to EPC-044 (Estimation method and outcomes) by the same amendment.

Issue #334 item A, plus the Estimate block warnings of item G and the
history rules of the method. A project with the profile on needs each
finished task compared with the band it was given at breakdown. This task
is the reader and the warnings. The templates, profile file and ADR are
TSK-1013's; the end of the clock is TSK-1172's; open tasks and deleted lines, TSK-1012's until 2026-11-04, are this task's too.

Outcome: **after this merges, a project with the profile on sees every
completed, cancelled, reopened, superseded or unknown-start task compared
with the band and profile revision frozen at its breakdown, as hit, miss,
breach or no band, apart from forecasts, with each task's clocked time
(blocked spans removed) and elapsed time (blocked included) printed; a
project without the profile sees no change.**

Rules:

- No profile means no change. A task planned before the profile's effective
  date is "no band", never back-filled.
- A malformed block warns, never fails. A breach never blocks.
- A re-planned or split task keeps the parent's band and breach; cancelled
  stays in the denominator and is shown; unknown start is its own category.
- A band moved after breakdown carries its reason. A band set by an approved
  planning amendment before the task's start is read as frozen (decision
  P2.6).

Non-goals: the clock's end rule (TSK-1172); the claim record (TSK-1173);
class grouping (TSK-313); any default band set.

## Outcome

after this merges, a project with the profile on sees every completed, cancelled, reopened, superseded or unknown-start task compared with the band and profile revision frozen at its breakdown, as hit, miss, breach or no band, apart from forecasts, with each task's clocked time (blocked spans removed) and elapsed time (blocked included) printed; a project without the profile sees no change. It also times a task whose integration ref was deleted after its line merged, measures a line before deletion with `--ref`, and lists each open task's start, blocked spans, current age less blocked time and idle claims (from TSK-1012).
