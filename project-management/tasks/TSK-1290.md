# TSK-1290: The hosted run measured the coverage split, which settled that line pull requests keep coverage

## Description

TSK-1241 (PR 560) proposed splitting coverage measurement from Linux test execution on integration pull requests, and asked for a measurement first: the replacement job against the instrumented shards on the same commit, with the minutes of each and run links. Dispatch run 41741936765 supplied it, and the operator then decided to keep coverage on line pull requests, which withdrew the split. This task holds that measurement as the decision's evidence. TSK-1242 AC-7 removes the job unless vetting keeps it, so a later run may not be able to repeat it; the recorded run is the only one this task needs.

## Outcome

After this merges, a maintainer can see from a real hosted run, with a link for each job, why line pull requests keep the coverage shards, by the operator's decision.

## Deliverables

- the hosted measurement (run and job links and the minutes of each job): this record's `## Findings` section
