# TSK-1290: The hosted run measures the split coverage, then the integration tier switches to it

## Description

TSK-1241 (PR 560) splits coverage measurement from Linux test execution on integration pull requests. Its AC-1 asks for a measurement before the switch: the replacement job against the instrumented shards on the same commit, with the minutes of each and run links. That measurement needs a hosted run. It comes from a `workflow_dispatch` run of `codeflow-ci` on the line, because that job runs only on dispatch (`.github/workflows/codeflow-ci.yml:565`). This task holds the hosted measurement and the integration tier switch that follows it (AC-2 to AC-5, moved from TSK-1241).

## Outcome

After this merges, a maintainer can see on a real hosted run how many minutes the split coverage takes against the instrumented shards, with a link for each job, and an integration pull request then runs the full Linux suite without instrumentation, with the coverage measurement on pull requests into main and on a schedule.

## Deliverables

- the hosted measurement (run and job links and the minutes of each job): this record's `## Findings` section
- the integration tier switch: `.github/workflows/codeflow-ci.yml` and the contract text that lists what "codeflow gates" contains per tier
