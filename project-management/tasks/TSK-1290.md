# TSK-1290: The hosted run measured the coverage split, which settled that line pull requests keep coverage

## Description

TSK-1241 (PR 560) splits coverage measurement from Linux test execution on integration pull requests. Its AC-1 asks for a measurement before the switch: the replacement job against the instrumented shards on the same commit, with the minutes of each and run links. That measurement needs a hosted run. It comes from a `workflow_dispatch` run of `codeflow-ci` on the line, because that job runs only on dispatch (`.github/workflows/codeflow-ci.yml:565`). This task holds that measurement, which is the evidence for the operator's decision to keep coverage on line pull requests.

## Outcome

After this merges, a maintainer can see from a real hosted run, with a link for each job, why line pull requests keep the coverage shards, by the operator's decision.

## Deliverables

- the hosted measurement (run and job links and the minutes of each job): this record's `## Findings` section
- the doc removals that follow the decision: the docs this task's pull request names

## Acceptance Criteria

- AC-1 The measurement shall be recorded from `workflow_dispatch` run 41741936765 of `codeflow-ci` on the line, with its uninstrumented job recorded as failed, with that cause and its 0.18 s effect: the minutes of both instrumented shards, of the coverage report job and of the new uninstrumented job, each with its job link, all from the same commit; evidence: the links and minutes in the Findings. (journey)
  - Amended 2026-11-03 by the first planning pull request after PR 562; earlier text named run 41659586627 or the first line push; reason: that dispatch had two failed tests, and a line push skips the measurement job (run 41709815373, job 126174627158; coord/ci). Run 41741936765 is accepted as timing evidence by coord/ci's ruling: the uninstrumented job failed one of 6827 tests because it does not install `cargo-llvm-cov`, a 0.18 s setup failure that passed in shard 1; it is recorded as a failed job with that cause.
