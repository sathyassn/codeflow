# TSK-1425: The unrecorded-task canary in the ci tests never matches a commit SHA

## Description

TSK-1040's tests prove that `codeflow ci` never repeats a `Task:` value no record vouches for. They select `TSK-987654` or `EPC-987654` and assert that the output does not contain the digits `987654` (`crates/codeflow-cli/tests/classification_cli.rs:236-238`, `:255`, `:280`, `:288`, at 0318b9c03). The same output prints commit SHAs, and a 40-character hex SHA can contain `987654`. On 2026-11-10 PR 749's run at fdf14c69c went red on `exemption_routes_never_repeat_an_unrecorded_task` (`:280`) because the fixture's head SHA was 34a7a9c332e0e2b62d500987654ef3a4dd45c9c7. The change under test was not at fault. The chance per run is small, but each false red costs a rerun and reads as a regression in a security test.

Source: Requested by coord/ci on 2026-11-10 at 17:5x (Director's routing). Searched by coord/ci on origin/main, the line at ee4b33625 and open plan branches for the test name and "987654": no record covers it. Verified by coord/records at ee4b33625.

## Outcome

The canary tests fail only when `codeflow ci` repeats the unvouched task value, never because a SHA happens to contain its digits.

## Acceptance Criteria

- AC-1 Each assertion that an unvouched task or epic value is not repeated shall still catch a repeat in any form (bare digits included). It shall exempt only spans the test identifies as commit SHAs: the full and abbreviated forms of the commits the fixture's own repository holds, read from that repository and removed from the output before the check. No pattern-based exclusion, such as every hex run of some length, is allowed, because it can hide a real repeat (`value987654` holds the hex run `e987654`). Evidence: the diff of `classification_cli.rs` and every sibling AC-3 finds.
- AC-2 A fixture whose printed head SHA contains the old canary digits shall pass. A deliberate repeat of the unvouched value in the output shall still fail, including where the repeated digits adjoin hex characters (`value987654`, `e987654f`) and where a repeat sits next to a fixture SHA. Evidence: the SHA-collision test failing before the change and passing after, and each negative fixture failing before and after.
- AC-3 A sweep of the test suites shall list every assertion that a digit-only or hex-only string is absent from output that can contain a SHA or other hex, with each fixed under AC-1 or recorded with a reason; evidence: the sweep in `## Findings`.

## Estimate

Grade Small (under 2 h). Basis: test-only edits in one file and its siblings, with a sweep by grep. Planner judgment.
