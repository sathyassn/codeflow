# TSK-1134: The portal reads the capability folder and the legacy file

## Description

Design unit U5a. The docs portal adapter and the Rust fidelity check read capability records from the folder, from the legacy file and from a mixed tree, and the field limit is raised for the new record shape. Basis: `adapter.mjs:195`, `figures.rs:1358` and the `lib.mjs` limits, about 2 to 3 hours in the design. Visual and docs lane. This is reader compatibility only; the new views are TSK-1141. It is not blocked, because TSK-1138 depends on it.

Design: `coordination/coordinators/capabilities/design-note.md` revision 5 (workspace repository) and its acceptance tests.

## Outcome

After this merges, the docs portal builds from a folder catalog, the legacy file or a mixed tree with the same row count the Rust check computes.

## Deliverables

- adapter and limits: the docs portal `adapter.mjs` and `lib.mjs` (under `assets/docs-portal/`)
- fidelity check: `crates/codeflow-core/src/validate/portal/figures.rs`
- fixtures: the three catalog layouts
