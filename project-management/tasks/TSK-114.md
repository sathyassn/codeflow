# TSK-114: retire the present diagram input on the 3.0.0 source

## Description

Under decision 3a, EPC-014 and EPC-016 ship in 3.1, so TSK-087's retirement
of Mermaid and the present `diagram` block, complete on
`integration/EPC-016-visual-guide`, is not on the 3.0.0 source. Present has
never shipped, so 3.0.0 must not publish a schema that accepts an input the
plan already removes. This task ports TSK-087's retirement onto the release
source, confirms which of its figure-runtime dependencies (TSK-059 on the
EPC-016 line) the release source has, rebuilds the built artefacts, and
keeps stored revisions readable.

## Affected surfaces and interfaces

- `crates/codeflow-present` (document, render, limits, state, export), the
  three `document-v1.schema.json` copies, the web bundle and its
  dependencies, `assets/supply-chain/` (CAP-016).
- cf-present skill text and examples; a pending 3.0.0 entry in
  `CHANGELOG.md`; ADR-0049.
- Shared files this task edits: `CHANGELOG.md`. Ownership follows
  SPC-013 R-118: the edit lands after TSK-106, and the cf-present skill
  edit after TSK-115 has landed on `main` and been synced into the line.

## Acceptance Criteria

- [ ] AC-1 On the 3.0.0 source, `codeflow present` shall refuse a new
      document that holds a `diagram` block with a refusal naming the
      conversion, and no shipped document schema shall define `diagram`;
      evidence: present tests and the three schema copies.
- [ ] AC-2 A stored revision holding a `diagram` block shall stay readable
      and export shall render the conversion notice, never a diagram hook;
      evidence: stored-revision and export tests.
- [ ] AC-3 Every dependency the port has on the figure runtime shall be
      listed with its presence on the release source, and each conversion the
      refusal names shall exist on that source; evidence: a dependency list
      in the pull request and a test per named conversion.
- [ ] AC-4 The embedded web distribution, the licence list and the SBOM shall
      be rebuilt without Mermaid and match the manifest; evidence: the build
      checks and the supply-chain files.
- [ ] AC-5 A pending changelog entry shall describe present without the
      `diagram` block, since the 3.0.0 legacy group is frozen; evidence: the
      entry and `release.py check-pr`. Amended 2026-09-28 by the primary:
      TSK-106 pins the legacy group's bytes by digest
      (`legacy_pending_group` in `.release/config.json`;
      `docs/verification/tsk-106-release-integrity.md`), and
      `release.py check-pr` refuses any change to them, so the 3.0.0 Added
      entry inside the group cannot change.
- [ ] AC-6 (journey) With the installed 3.0.0 candidate, a document with a
      `diagram` block is refused and a pre-release session that holds one
      opens read-only; evidence: journey test.
