# TSK-1383: Line runs record the post-landing evidence for TSK-1157 and TSK-369

## Description

TSK-1157 (local coverage as parallel shards) and TSK-369 (each landing candidate's full gate records its own coverage) each leave criteria that only runs on the EPC-022 line can prove after they land: TSK-1157 AC-14 needs the coverage shards' disk figures from a line run, and TSK-369 AC-1, AC-3 and AC-4 need full gates on landing candidates. This task records those run ids and figures against the deferred criteria once the runs exist. Window: the EPC-022 line's first push run, and its next landing candidates, after PRs 664 and 665 land. Scope: recording run ids and figures in this record's Findings and pointing the parents' criteria at them. Non-goal: any product, test, workflow or config change; a run that fails one of these criteria is reported to the parent's owner as a defect, never fixed here.

Epic: this follow-up inherits TSK-369's epic, EPC-038. The two parents do not share an epic (TSK-1157 is in EPC-047, TSK-369 in EPC-038), so TSK-369's was used.

## Outcome

After this merges, a reviewer can read the line-run evidence for TSK-1157 AC-14 and TSK-369 AC-1, AC-3 and AC-4 in one place, named by run, job and run record.

## Deliverables

- run ids, job ids, run records and figures for each criterion: `## Findings` in this record
- a pointer from each parent's deferred criterion to those Findings: `project-management/tasks/TSK-1157.md`, `project-management/tasks/TSK-369.md` (dated amendment or Closeout lines only)

## Acceptance Criteria

- AC-1 For TSK-1157 AC-14, the record shall name a push run or a dispatched run of the EPC-022 line, by run id and job id, with the coverage shards' disk figures; evidence: the run and job ids with the figures in `## Findings`.
- AC-2 For TSK-369 AC-1, the record shall name three consecutive full gates for `release-automation` on landing candidates of the line, each by run record; evidence: the three run records with their figures in `## Findings`.
- AC-3 For TSK-369 AC-3 and AC-4, the record shall name one passed full gate on a landing candidate whose run record carries the coverage block; evidence: that run record and its coverage figures in `## Findings`.

## Execution contract

- Source: coord/catalog, 2026-11-07, for the criteria TSK-1157 and TSK-369 defer to runs after landing.
- Owner: coord/catalog. Builder: coord/catalog's Worker.
- Window: the EPC-022 line's first push run and its next landing candidates after PRs 664 and 665 land.
- Affected surface: records only. Not adopter-facing.
