# TSK-1086: The binary carries the shipped bases of every published release

## Description

Source: the operator's retention decision of 2026-10-17 (every published
release's bases in the binary, about 0.6 MB then, advisory 2 MB budget) and
`SPC-015`.

A three-way merge in `codeflow update` needs the pristine shipped copy of
the file at the version the project installed it from. Today that copy is
the project's own `.codeflow/.baseline/<dest>`. This task makes the binary
the source instead: it embeds the shipped scaffold of every published
release (v2.0.0 and v2.1.0 with 44 asset files each, v3.0.0 with 194,
v3.1.0 and v3.1.1 with 199, at their tags) as one compressed, read-only
pack, with an index that names each retained release, and gives the engine
a reader that returns a shipped file's bytes at a named version. The
release tooling adds the release being prepared to the pack and refuses a
release whose bases are missing. Nothing reads the pack in `update`,
`init` or `doctor` until TSK-1087; this task is its own unit because the
pack's layout and the release step are a contract TSK-1087 consumes and
the two together are too large for one thorough review.

Non-goals: rendered copies (templates filled with project values), which
`SPC-015` places in the sparse pack; any change to how a project is
updated.

## Outcome

After this merges, a maintainer can ask the line's binary for the exact
shipped bytes of any managed file at any published release, and a release
cannot be prepared without adding its own bases to that pack.

## Deliverables

- the retained bases and their index: under `assets/`, at the home `SPC-015` names (provisional: `assets/releases/`)
- the reader: a new module under `crates/codeflow-core/src/scaffold/`, read through `AssetSource` or beside it (`crates/codeflow-core/src/scaffold/assets.rs`)
- the embedding: `crates/codeflow-cli/src/embedded.rs` and the build script that registers the inputs
- the release step and the budget check: `scripts/release.py`, `scripts/test_release.py`
- tests: `crates/codeflow-core/tests/` (a retained-bases test with fixtures captured from the tags), `scripts/test_release.py`
- docs: `docs/releasing.md` (the release step), `docs/architecture.md` (where bases live), `changelog.d/TSK-1086.md`

## Acceptance Criteria

- AC-1 When the binary is built, it shall carry the shipped bases of every release the index names, and the reader shall return, for every file of each retained release, bytes equal to the file at that release's tag; evidence: a test that compares every retained file of v2.0.0, v2.1.0, v3.0.0, v3.1.0 and v3.1.1 against fixtures captured from the tags with `git show <tag>:assets/base/<path>`, with those five tags as its list and no sampling, and the index listing the same five. (serves EPC-022 AC-171)
- AC-2 When a version is asked for that the index does not name, or a path that release did not ship, the reader shall return "not retained" as a distinct outcome, never an error that reads as a corrupt pack and never a file from another version; evidence: unit tests for both cases.
- AC-3 The reader shall take its bytes from the embedded pack only: no filesystem read, no link followed, no path outside the pack; evidence: unit tests and the reviewer's read of the reader.
- AC-4 When `scripts/release.py` prepares a release, it shall add that release's bases and index entry, and `check-state` shall refuse a release version whose bases are absent from the pack or differ from `assets/base` at the release commit, naming the version; evidence: `scripts/test_release.py` cases, fail-before at the parent commit.
- AC-5 The build or the release check shall report the pack's compressed size and warn, never fail, when it passes the advisory 2 MB budget; evidence: a test with a budget fixture, and the measured size in the pull request body against `SPC-015` AC-3's numbers.
- AC-6 `codeflow update`, `codeflow init` and `codeflow doctor` shall behave exactly as before this task; evidence: the existing `scaffold_test`, `init_e2e`, `permission_presets_update`, `installed_cli_journey` and doctor drift tests pass unchanged.
