# TSK-396: The guards' reach over other repositories by absolute path is decided and enforced

## Description

Source: PR 239 (TSK-373) confirm round, 2026-10-18. From inside one repository, another repository's enforcement files are not guarded by absolute path (`cp x $OTHER/.claude/settings.json` and `rm -rf $OTHER/.worktrees/w` pass; after `cd $OTHER` they refuse). The review asked to decide whether the guards protect every repository on the machine or only the current one. Security, info, older scope limit.

TSK-379 (EPC-022, 3.2.0) judges each target against every repository that encloses it and the session's project. That may already cover this case; the edge is real because this task starts from TSK-379's judgement model.

Outcome: **the guards' reach over a repository that is neither the session's project nor an enclosing one is a recorded decision, and the shipped behaviour matches it.**

The decision of reach is the operator's (it is a public behaviour and security boundary). This task prepares the options with their costs, records the decision, and then implements it or states it as a residual.

Added to EPC-023 (4.1.0) by the amendment of 2026-10-18: the operator's release decision of that day puts lower-severity review follow-ups in 4.1.0 (workspace `RELEASE-PLAN.md`, 2026-10-18 operator decision).

## Deliverables
