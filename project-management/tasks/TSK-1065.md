# TSK-1065: A program-valued Git setting cannot read a protected path through the program it runs

## Description

Source: Fable review 10 of TSK-1002 (PR 346), a nit tracked once. It is
the residual that the option D scope leaves for later: what a program
does once it runs.

Several Git settings name a program that Git runs, and the words of
that program are a command of their own:
`git -c core.pager='cat copies/id_r*' log`, `git -c core.editor=...`,
`git -c diff.external=...`, `git submodule foreach 'cat ...'`. TSK-1002
judges the alias-free `!` helpers. The other program-valued settings
can read a protected checkout or secret path through the program Git
starts, so the guard's verdict on the `git` line says nothing about
what that program reads.

Some program values are plain text the guard can read as a command.
Others are a script file, or a value Git takes from the environment or
a configuration file; their effect cannot be read from the line, and
option D's containment rule (TSK-397, `sandbox_state`) decides them.

Non-goals: changing what TSK-1002 already refuses; credential helpers
are not run or queried by any test (agents never run `git credential`).

## Outcome

After this merges, an agent cannot read a protected checkout or secret path by giving Git a program to run through a setting such as `core.pager`, `core.editor`, `diff.external` or `submodule foreach`.

## Acceptance Criteria

- AC-1 Before any change, the builder shall list every Git setting and command form that runs a program the requester names (at least `core.pager`, `pager.<command>`, `core.editor`, `sequence.editor`, `diff.external`, `diff.<driver>.textconv`, `diff.<driver>.command`, `merge.<driver>.driver`, `filter.<name>.clean`, `smudge` and `process`, `core.sshCommand`, `core.fsmonitor`, `gpg.program`, `submodule foreach` and `-c alias.<name>=!...`), each spelled with `-c`, `--config-env`, the `GIT_CONFIG_COUNT` environment and a configuration file, and shall record which of them TSK-1002 already refuses at its landed head and which reach a program unread; evidence: the Findings section, committed before the first code change.
- AC-2 Where the program value is text the guard can read, the guard shall judge it as the same command run directly: `git -c core.pager='cat copies/id_r*' log`, `git -c core.editor='cat copies/id_rsa' commit`, `git -c diff.external='cat copies/id_rsa' diff` and `git submodule foreach 'cat copies/id_rsa'` shall refuse; evidence: guard tests for each form, each allowed at TSK-1002's landed head (failing before) and refused after.
- AC-3 Where the program's words cannot be read from the line (a script path, a value from the environment or a configuration file, a quoting form the guard does not model), the verdict shall follow TSK-397's containment rule: refused where containment is not established, judged by the established containment otherwise; evidence: guard tests for each such form under each `sandbox_state` case.
- AC-4 Ordinary program values that name no protected path shall keep their verdict: `git -c core.pager=less log`, `git -c core.editor=vim commit` and `git -c diff.external=difft diff` in a public tree allow; evidence: control tests passing before and after.
- AC-5 `docs/policy-reference.md` shall list the program-valued settings the guard reads and the rule for those it cannot read; evidence: the text diff and `codeflow validate --docs`.
