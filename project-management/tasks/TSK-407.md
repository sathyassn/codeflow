# TSK-407: A link created earlier on a command line is refused like an existing link

## Description

Source: the security review of PR 239 (TSK-373) on 2026-10-18, severity medium, shipped in both guards. A link that already exists is followed and refuses, but a link created earlier on the same command line is not seen, because the guards judge the line before it runs and the link is not on disk yet. Reproduced on the line at `236e9d08b` with that tree's built hooks, the commands judged and never run: git-guard and exec-guard both allow `ln -s .claude/settings.json s2 && python3 tool.py s2`, `ln -s .claude/settings.json s2 && cp x s2` and `ln -s .claude/settings.json s2 && printf x > s2`, while exec-guard refuses `python3 tool.py .claude/settings.json`.

Decision: the residual is refused, not accepted. A link created earlier on the same line is part of the shell grammar the guards model (operator decision of 2026-10-15 on TSK-302's scope), so it is judged like an existing link. Decided by the primary on 2026-10-18 under the operator's direction of that day to decide from evidence (workspace `RELEASE-PLAN.md`, "Settled under it the same day", item 2).

Outcome: **a writer or interpreter that names a link created earlier on the same command line gets the verdict it would get if the link already existed, and a link whose target the guard cannot resolve is refused.**

Rule: when a link-creating command (`ln`, symbolic or hard, with `-s`, `-f`, `-n`, `-T` or `-t <dir>`; `link`; `cp -s`, `cp -l`, `cp --symbolic-link`, `cp --link`) runs before a writer or interpreter on the same line, any later word that names the link, or a path under it, is judged as the link's target. A target that reaches an enforcement path or a checkout root refuses with the same rule the target itself would get. A target the guard cannot resolve (an expansion, a glob, a path under a link it cannot read) refuses as cannot-verify. A literal target that resolves to an ordinary path keeps the ordinary verdict. "Later" covers every list and pipeline separator (`&&`, `||`, `;`, `|`, `&`, newline), subshells, brace groups and command substitutions. The writers are the ones the guards already judge (redirects, `tee`, copy and move destinations, in-place editors, `rm`), plus interpreter arguments and code.

The startup-file judgment already reads `ln` and `cp -s` or `cp -l` as link-creating commands (`crates/codeflow-core/src/security/startup.rs:2848-2867`, `copy_judgment`); this task reads the same commands for enforcement paths and checkout roots and carries the link to the later words on the line.

Non-goals: a link created by interpreter code (`os.symlink`, `fs.symlinkSync`) is runtime-built and stays the stated residual of the 2026-10-15 decision; the OS sandbox and the permission preset are the backstop. A link name hidden by a shell expansion is TSK-406's class.

Added by the second EPC-022 amendment of 2026-10-18.

## Acceptance Criteria

- AC-1 When a line runs `ln -s <enforcement path> <link>` before a writer or interpreter that names `<link>`, the guards shall refuse it as they refuse the enforcement path itself: `ln -s .claude/settings.json s2 && python3 tool.py s2`, `... && cp x s2`, `... && printf x > s2`, `... && tee s2`, `... && sed -i s/a/b/ s2`; evidence: one guard test per writer and per interpreter route, each failing before the change. (serves EPC-022 AC-97)
- AC-2 The same refusal shall hold for a hard link (`ln .claude/settings.json h`), `cp -s`, `cp -l`, `link`, `ln -sfn`, `ln -t <dir>`, a link to a directory followed by a write under it (`ln -s .claude d && printf x > d/settings.json`), a link to a checkout root followed by `rm -rf` through it (`ln -s .worktrees/w l && rm -rf l/`), and each separator: `;`, `||`, `|`, `&`, a newline, a subshell and a brace group; evidence: guard tests per form. (serves EPC-022 AC-97)
- AC-3 A same-line link whose target the guard cannot resolve (`ln -s "$X" l && printf x > l`, a glob target) shall be refused as cannot-verify with a message naming the link; evidence: guard tests. (serves EPC-022 AC-97)
- AC-4 Ordinary uses shall keep passing: `ln -s src/app.py app.py && python3 app.py`, `ln -sf build/out latest && cat latest/log.txt`, `ln -s ../shared lib && printf x > lib/a.txt` where `../shared` holds no enforcement path or checkout, and a link created with no later writer or interpreter; an existing link to an enforcement path shall keep refusing; evidence: guard tests.
- AC-5 `docs/policy-reference.md` shall state the same-line link rule, the link-creating commands it reads, and the runtime-built link residual with its sandbox backstop; evidence: the doc text.
- AC-6 (journey) With the installed build, an agent session in a scratch adopter project shall be refused each planted line of AC-1 to AC-3 and shall run the ordinary forms of AC-4; evidence: the journey output.
