# TSK-113: same-family models run inside the host harness

## Description

Operator request of 2026-09-26: a host calls models of its own family inside
its own harness. A Claude host calls Fable or Opus workers as native
subagents of that session, in the desktop app and the CLI alike, never as a
separate Claude CLI session or a Herdr tab. The same rule holds for Codex
and Grok hosts, with a recorded fallback where a harness has no native route
for that model. The rule is stated in cf-model-orchestrator and
capability-routing, with an eval case. Cross-family seats are unchanged.

## Affected surfaces and interfaces

- `cf-model-orchestrator` SKILL and `resources/capability-routing.md` in
  `assets/base`, `.claude/skills`, `.agents/skills` and the baseline, with
  manifest hashes (CAP-010).
- The model evaluation cases (CAP-013).
