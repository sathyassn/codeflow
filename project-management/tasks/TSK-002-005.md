# TSK-002-005: cross-platform live canaries

## Description

Run and interpret the available native interactive canaries after the stress
suite is frozen. Fable owns the evidence judgment, may use Opus workers for
bounded operation, and records unavailable environments as evidence gaps;
Codex independently audits the record.

## Acceptance Criteria

- AC-1 The dated record names model, harness, version, effort, host, settings,
  commands, hashes, and observed outcomes for each executed canary.
- AC-2 Available environments exercise sequential reused-pane turns,
  interrupt-after-acceptance, terminal loss, canonical UTF-8/internal-LF
  exact-byte prompt delivery, early CRLF/terminal-LF and other noncanonical
  input rejection, and read-only review behavior.
- AC-3 macOS arm64, macOS x64, Linux x64, and WSL2 are claimed only where native
  evidence exists; deterministic-only or unavailable platforms are explicit.
- AC-4 Codex independently audits the evidence, and Fable judges the integrated
  PR2 snapshot before it is offered for human merge.
