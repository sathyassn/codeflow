# TSK-1112: Html stages recompose through scoped container and media queries

## Description

the design audit of 2026-10-31 (Fable 5.1, design seat; the artifact "Present and Portal Redesign" and its scratch notes `present-redesign/` and `portal-audit/`) found that stage CSS rejects every at-rule: `AtRuleParser` uses the
default implementation and `consume_tokens` refuses `AtKeyword`
(`scoped_css.rs:24-28`, `:85-87`), so an html stage cannot recompose at 400
px while the figure block itself uses `@container` (`figure.css:16-20`).
The status report's lane board lost two of nine rows at narrow width. This
task lets a stage sheet use `@media` and `@container` only, with every inner
selector prefixed by the stage scope as flat rules are today, makes the
stage host a size container, and keeps every other at-rule refused
(`@import`, `@font-face`, `@keyframes`, `@supports`, nesting). The parser
change is a sanitiser change, so it carries the security checklist and
adversarial fixtures. Non-goal: the export frame height (TSK-1101, PR 438)
and the frame chrome (TSK-1111).

## Outcome

After this merges, an author can write a stage that recomposes at phone width with a container or media query, and no other at-rule reaches the page.

## Deliverables

- the parser: `crates/codeflow-present/src/scoped_css.rs` (at-rule acceptance for `@media` and `@container`, prefixed inner rules, everything else refused)
- the stage host as a size container: `crates/codeflow-present/web/src/styles.css`
- guidance: `assets/base/skills/cf-present/references/document-authoring.md` and a stage starter sheet `resources/stage-starter.css` with a 400 px reflow pattern, both mirrors byte-identical
- tests: parser unit tests (accepted, prefixed, refused), adversarial fixtures, a 400 px reflow browser fixture, the `present check` warning on a stage wider than 600 units without a container query

## Acceptance Criteria

- AC-1 Before any change, the builder shall research scoped CSS at-rules broadly: how CSS sanitisers and scoped-style systems admit conditional at-rules safely (prefixing inside conditional groups, refusing nested at-rules, `url()` and escapes), the cssparser crate's `AtRuleParser` and `consume_tokens` as this code uses them (`scoped_css.rs`), the figure block's own `@container` use, and adjacent concerns (export frames, the comment overlay positions after reflow, `@media print`, a selector list with a stage-escaping comma); and shall record the findings with sources and the chosen scope before anything else changes; evidence: the Findings section, committed before the first code change in the PR. Listed first because it runs first (the operator's rule of 2026-10-27).
- AC-2 A stage sheet shall accept `@media` and `@container` blocks whose every inner selector is prefixed by the stage scope, and shall refuse every other at-rule and any nesting, with the refusal naming the rule; evidence: parser tests for each accepted and refused form, failing before the change. (serves EPC-022 AC-187)
- AC-3 Adversarial fixtures shall be refused: an escaped at-keyword, a nested at-rule inside `@media`, `@import` or `url()` inside a conditional block, a selector that escapes the scope through a comma or a comment, and a condition longer than the limit; evidence: one test per fixture and the `cf-security-reviewer` checklist in the review. (serves EPC-022 AC-187)
- AC-4 The stage host shall be a size container and a 400 px reflow fixture (a nine-row lane board) shall keep every row visible; evidence: the browser fixture.
- AC-5 `present check` shall warn on a stage wider than 600 units with no container or media query, and the starter sheet shall ship with the rem rule and the reflow pattern; evidence: the check test and the starter file.
- AC-6 (journey) With the installed build, the 4.0.0 status report's lane board shall render all rows at 400 px in cf-present and in the export; evidence: the screenshots.
