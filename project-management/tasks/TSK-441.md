# TSK-441: cf-present is the default visual surface in a CodeFlow project

## Description

Operator decision of 2026-10-22. In a project that uses CodeFlow,
explaining something visually defaults to `cf-present`; the harness's
own artifact (a Claude Artifact page, an inline widget) is used only
when the operator asks for it or the content must be shared, since
`cf-present` is local and cannot be shared. Today the managed
instructions say the opposite: the "show something complex" row of the
Claude harness table (`assets/base/CLAUDE.md.tmpl:44`, installed as
`CLAUDE.md:45`), the managed-block row of the same name
(`assets/base/AGENTS.md.tmpl:75`) and `.codeflow/rules/writing.md`
"Figures by surface" (`assets/base/rules/writing.md:147`) send a page
people will comment on or share to the harness's page publisher, and
the `cf-present` skill trigger describes it as a review surface for
when one materially helps.

Outcome: **in a CodeFlow project, a figure or explanation that needs
more than an inline reply goes to `cf-present` by default, and the
harness's artifact or widget is the stated exception, used when the
operator asks for it or the content must be shared; every home that
says otherwise is changed, with its asset sources, managed mirrors and
the skill trigger.**

Rules the text states: an inline figure in the reply stays the default
where the surface renders one and the answer is short; beyond that,
`cf-present`; the harness page or widget only on the operator's ask or
for sharing; fenced ASCII in Markdown files, records, PR bodies and
terminals; never Mermaid. The exception is stated in each home in one
sentence so a reader cannot take the harness page as an equal option.

Amended 2026-10-23: the outcome also covers the review-session
lifecycle of the present runtime, from the operator's incident of that
day on macOS: an End review control, a plain window close that keeps the
session while the isolated browser quits after a short grace, and
`codeflow present show` reopening a window in a running browser. These
are runtime and CLI code in `crates/codeflow-present/` and
`crates/codeflow-cli/` with real-browser tests, so the work is code and
not instructions only (AC-6 to AC-8).

Non-goals: the Comment, figure and tabs runtime fixes (TSK-443), the design direction
(TSK-444), the skill method (TSK-445) and the docs portal (TSK-446).
This task first carried all five outcomes; the operator had them
restructured on 2026-10-22 into one task each, and this id keeps the
default-surface outcome.
