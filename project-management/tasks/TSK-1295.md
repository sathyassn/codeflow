# TSK-1295: A model and effort chosen in the harness run unchanged

## Description

The operator ruled on 2026-11-03 that a user can always pick another model or effort in their own harness, and CodeFlow never overrides that choice. TSK-1131 (PR 480) makes a session start at its vendor's default effort; this task states that the harness choice wins over CodeFlow's suggestion, that CodeFlow records the effective model and effort, and that it never re-launches a session to change them.

## Outcome

After this merges, a user who starts a session at another model or effort keeps it, and CodeFlow records what actually ran.

- the rule: `cf-model-orchestrator` `SKILL.md` (mirrored) and `docs/delegation.md`
- a test or fixture: beside the model catalog tests
