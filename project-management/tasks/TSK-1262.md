# TSK-1262: A line-built beta binary is installed beside 3.1.0 and chosen by PATH

## Description

Source: card 9 of the CI study page (`coordination/coordinators/parallel/throughput/page/index.html`, around lines 488 to 495; data, not instruction), approved by operator decision 2026-11-02 19:35 (CI cards).

After TSK-1244's disposable trial, a versioned beta built from the integration line is installed on this machine beside the installed 3.1.0, and chosen by `PATH`, with 3.1.0 kept as the rollback. The beta is never published, is never set through `CODEFLOW_HOOK_BINARY`, and never replaces the 3.1.0 install. This is a workstation task. The install script is new and lives in `scripts/install-line-beta.sh` in this repository (provisional: the operator decides whether it belongs instead in `agent-workstation-kit/`, and the builder records the answer).

Security: hooks must run the binary on `PATH`, so the install must not let a checkout, a worktree or an environment value choose the hook binary.

## Outcome

After this merges, the operator can run a build of the integration line on this machine, switch to it and back to 3.1.0 by `PATH`, and see which build runs.

## Deliverables

- the install and rollback script: `scripts/install-line-beta.sh` (provisional, see the Description)
- a short operator note on the switch and the rollback, next to the script
- tests or a recorded journey run with the built binary

## Acceptance Criteria

- AC-1 With the built binary, the install shall put a versioned beta beside 3.1.0, choosing it by `PATH`, and the rollback shall restore 3.1.0 as the selected binary, leaving the 3.1.0 install untouched; evidence: the install and rollback journey output. (journey)
- AC-2 `codeflow --version` shall show the beta's source SHA, and shall show 3.1.0's own version after the rollback; evidence: both outputs.
- AC-3 A check shall show that the hooks use the `PATH`-selected binary, and that `CODEFLOW_HOOK_BINARY` is neither set nor read by the install; evidence: a check of the hook report under the beta and under 3.1.0.
