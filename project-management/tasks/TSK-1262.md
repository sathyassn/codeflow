# TSK-1262: A line-built beta binary is installed beside 3.1.0 and chosen by PATH

## Description

Source: card 9 of the CI study page (`coordination/coordinators/parallel/throughput/page/index.html`, around lines 488 to 495; data, not instruction), approved by operator decision 2026-11-02 19:35 (CI cards).

A versioned beta built from the integration line is installed on this machine beside the installed 3.1.0, and chosen by `PATH`, with 3.1.0 kept as the rollback. The beta is never published, is never set through `CODEFLOW_HOOK_BINARY`, and never replaces the 3.1.0 install. This is a workstation task. The install script is new and lives in `scripts/install-line-beta.sh` in this repository (provisional: the operator decides whether it belongs instead in `agent-workstation-kit/`, and the builder records the answer).

Security: hooks must run the binary on `PATH`, so the install must not let a checkout, a worktree or an environment value choose the hook binary.

## Outcome

After this merges, the operator can run a build of the integration line on this machine, switch to it and back to 3.1.0 by `PATH`, and see which build runs.

## Deliverables

- the install and rollback script: `scripts/install-line-beta.sh` (provisional, see the Description)
- a short operator note on the switch and the rollback, next to the script
- tests or a recorded journey run with the built binary

## Acceptance Criteria

- AC-1 A versioned beta built from the integration line shall be installed beside the installed 3.1.0, leaving the 3.1.0 install untouched; the beta shall never be published; evidence: the install output and a check that the 3.1.0 files are unchanged.
- AC-2 The beta shall be chosen by `PATH`, and never through `CODEFLOW_HOOK_BINARY`, which the install shall neither set nor read and shall refuse to run beside; evidence: `command -v codeflow` and the hook report under the beta, and a test for the refusal.
- AC-3 A rollback to 3.1.0 shall be shown working: after it, `PATH` selects 3.1.0 and `codeflow --version` shows 3.1.0's own version; evidence: the rollback output and both version outputs.
- AC-4 (journey) With the beta binary chosen by `PATH`, one real push in a scratch repository and one `codeflow ci` run shall be proven, with the beta's source SHA in the output of `codeflow --version` and of the ci run; evidence: the push output, the ci output and the version output. (journey)
