# TSK-086: main merged forward into the autonomy integration branch

## Description

Bring `main` onto `integration/EPC-018-autonomy-roster` once EPC-017 has
landed there, so the EPC-018 pull request diff shows only this epic, and
observe the harness guard. It is a task, not a prose step, so that
`codeflow work start` can see it: TSK-083 and TSK-078 both list it, and it is
never cancelled.

On a task branch cut from the integration head, merge `origin/main` with a
no fast forward merge at a commit that contains the EPC-017 landing. If
EPC-016 has landed on `main` first, run the cross-epic pass (reconcile the
paragraphs named in the EPC-018 cross-epic table, rerun the pins, the budget
test and `validate-suite`). Then record the guard evidence for
`harness:present-at-merge-forward`: whether
`tests/release-qualification/qualify.sh` is present on the merged head. That
record selects TSK-083 or resolves it `not_selected`.

The merge-forward commit lands on the integration branch through a reviewed
pull request with a no fast forward merge, like every task; a rebasing
`codeflow integrate` would not preserve that merge commit and is not used
here.

The merge also reconciles the summary rule (TSK-088, ADR-0071): the
`main` wording from the ADR-0067 note of 2026-09-24 (context only, no file
name or number) yields to the anchoring judgment in every surface TSK-088
names, and the PR Summary code span and path warnings in
`crates/codeflow-cli/src/cmd/ci/pr_body.rs` are dropped or reworded so a
key file name in a summary is not flagged; the sentence-count warning may
stay as soft guidance.

Non-goal: authoring; a conflict outside the named paragraphs returns to its
owning task.

## Affected surfaces and interfaces

The merge commit on the integration branch; the files named in the EPC-018
cross-epic table; the ledger entry for the guard.
