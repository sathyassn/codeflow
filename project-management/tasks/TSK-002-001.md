# TSK-002-001 — durable delegate lifecycle engine

## Description

Implement the schema-v2 lifecycle core, `delegate init|arm|wait`, multi-event
hook mode, legacy compatibility, deterministic doctor round trip, and their
unit and CLI tests. Codex produces and first-verifies the Rust unit; Fable
independently reviews the exact diff and reruns the gates.

## Acceptance Criteria

- [x] `cargo test delegate::` covers startup, acceptance, terminal binding,
  poison precedence, exact retries, unsafe state, lock contention, and the
  pre-2.1.196 single-turn compatibility path.
- [x] `cargo test --test delegate_cli` covers the public CLI, exits, timeout,
  SIGINT poison, and zero tmux use in schema-v2.
- [x] Existing legacy hook tests remain byte-compatible and green.
- [x] `codeflow doctor --check delegate-roundtrip`, run with the HEAD-built
  binary first in `PATH`, completes the real synthetic lifecycle.
- [x] A fresh full-workspace `cargo llvm-cov` run reports 92.68% whole-file
  line coverage for `delegate.rs` and 92.96% for `cmd/delegate.rs`. Against
  base `0be99f5b`, changed-line coverage is 94.49% for `delegate.rs`, 94.34%
  for `hook.rs`, 96.67% for `doctor/mod.rs`, and 94.67% across changed Rust.
  The LCOV input comes from `cargo llvm-cov --no-clean --workspace
  --all-targets --lcov`; changed lines are executable additions from the
  zero-context base-to-HEAD diff. Workspace tests, formatting, clippy, rustdoc,
  docs validation, and the dependency audit pass.
- [x] Security findings SF-1 and SF-2 are remediated: schema-v2 hook input
  is capped at 32 MiB pre-parse — sufficient for the worst-case JSON escaping
  of every allowed decoded field — and fails closed (exit 2) on unreadable or
  oversized input without advancing state; `SessionStart.source` is bounded;
  the doctor round-trip root is `0700`; and legacy hook behavior is
  byte-unchanged. Codex produced the remediation; Fable independently
  reviewed it and reran the focused gates.
- [x] Fable independently approved the implementation snapshot `307e03fd`
  with no blocker or major finding; the integrated judgment on PR1's final
  SHA is tracked in TSK-002-002.
