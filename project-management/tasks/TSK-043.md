# TSK-043: integrate and verify the public docs body

## Description

The preceding tasks change doctrine, styling, sources, root documents,
contracts, the verification gate and the CLI qualification matrix in separate
worktrees, and none of them proves the combined result. This task integrates all of them on
`integration/EPC-014-public-docs`, runs the full verification matrix against
that head, that is the locked portal build, both validators, the browser suite, the full
Rust gate, managed-drift doctor and a rebuilt, integrity-checked present
distribution, then obtains editorial, Codex and Grok review of the combined diff,
and prepares the PR to main. Non-goal: this task authors no content and lands
nothing protected. It prepares the PR, and a human lands it only when the
required checks are actually green, after EPC-013's PR.

## Affected surfaces and interfaces

The whole EPC-014 combined diff on `integration/EPC-014-public-docs`; the
rebuilt embedded present distribution; the EPC-014 pull request to `main`.
CAP-015 and CAP-016. No file is authored here that another task owns.
