# TSK-037 — reconcile the utility presentation doctrine

## Description

The cf-docs-portal and cf-present skills each carry their own drifted account
of the utility presentation system, and both promise carriers the adapter does
not render, so authors cannot tell what a compliant page is. This task settles
one shared `utility-presentation-system.md` text for both skills with only the
profile-specific parts isolated in each skill's references, states the
composition rule and the page-class rule, truncates the carrier list to what
the adapter actually supports, and gives the doctrine a durable home in
`docs/architecture/utility-presentation.md` with a short ADR-0063 clarifying
precedence over ADR-0053. Non-goal: no new theme, no adapter feature is added
to make an unsupported carrier true — unsupported carriers are dropped or
marked, not implemented.

## Affected surfaces and interfaces

`.claude/skills/cf-docs-portal/**` and `.claude/skills/cf-present/**` with
their `.agents` and `assets/base` mirrors and the scaffold-manifest hashes;
new `docs/architecture/utility-presentation.md`; new `docs/decisions/ADR-0063`.
ADR-0053 is append-only and is not edited. CAP-015 and CAP-016 authoring
contract.

## Acceptance Criteria

- [ ] Both skills carry byte-identical shared doctrine text, with only the
      profile-specific portions living in each skill's own references;
      evidence: a diff of the shared file across both skill trees is empty.
- [ ] The doctrine states explicitly that the portal composes the sources
      visually with supporting text and that a page of re-rendered Markdown
      fails; evidence: the rule is quoted in the doctrine and cited by the
      TSK-042 coverage gate.
- [ ] The page-class rule is recorded — orient: governing claim plus one
      carrier; architecture: trio plus stage; technical and records: tables and
      evidence; historical ADRs exempt; evidence: rendered review of one page
      per class in TSK-043.
- [ ] The carrier list names only carriers the adapter supports: tree, diagram
      and mermaid promises are removed or explicitly marked unsupported;
      evidence: each listed carrier maps to a handler in the portal adapter.
- [ ] The Display panel and the type floors are recorded as numbers, not prose;
      evidence: the recorded floors match the shipped token values checked in
      TSK-038.
- [ ] `docs/architecture/utility-presentation.md` exists as the durable home
      (trio plus cf-stage) and ADR-0063 records its precedence over ADR-0053
      without editing ADR-0053; evidence: ADR-0053 is unchanged in the diff.
- [ ] `assets/base` and `.agents` mirrors and the scaffold-manifest hashes are
      regenerated; evidence: `codeflow doctor --check managed-drift` and the
      scaffold parity tests pass.
