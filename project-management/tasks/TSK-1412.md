# TSK-1412: Main carries the SQLite advisory fix

## Description

TSK-1407 fixed RUSTSEC-2026-0459 on the EPC-022 line (PR 752, merged at 4dc4dbf4c) by upgrading `rusqlite` from 0.37 to 0.41.1, which brings `libsqlite3-sys` 0.39.1. `main` still carries `libsqlite3-sys` 0.35.0, so the hosted dependency audit (the "security review" check) fails on every pull request into `main` until the same upgrade lands there. This task mirrors TSK-1407's dependency change onto `main` unchanged: the same `rusqlite` line in `Cargo.toml`, the same `Cargo.lock`, and TSK-1407's changelog fragment `changelog.d/TSK-1407.md`, byte for byte, so that the line's later checkpoint merge into `main` finds these files already equal and one release note covers the fix. TSK-1407's record keeps its one home on the line and reaches `main` with the checkpoint; this task does not copy it. Non-goals: any source change, a second changelog fragment, and any audit suppression. It is standalone because a records-only filing into `main` fails the same audit and cannot land first.

## Outcome

After this merges, pull requests into `main` pass the dependency audit without suppressing RUSTSEC-2026-0459.

- evidence: file digests against the line's landed tree and the audit run, in the pull request body
