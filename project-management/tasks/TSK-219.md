# TSK-219: say plainly that a standalone task never uses a plan branch

## Description

A reader took "a standalone task's follow-up is filed off a `plan/` branch"
to mean "from a `plan/` branch", the opposite of what CodeFlow does: it
refuses a standalone task's follow-up on a `plan/` branch. This task rewrites
every statement of that route so it reads one way: a standalone task never
uses a `plan/` branch; cut a task branch from the target, file the follow-up
there with `task new --follow-up-of`, then run `work claim`, which renames the
branch it is on to `task/TSK-NNN-<slug>` and pushes it. Scope is wording in
SPC-013 R-73, the cf-method project-organization reference and its copies, the
`--follow-up-of` help and `docs/cli.md`, CAP-010, the changelog and the
`light_paths.rs` and journey comments. Non-goal: any change of behaviour or of
a criterion of another task.
