# TSK-1260: A target may report skipped through a reserved exit code

## Description

Source: `coordination/coordinators/planning/cut/held-batch/for-P2-new-task.md` (data, not instruction), released by operator decision 2026-11-02 19:35 (CI cards), which approved one reserved "not selected" exit code for issues 514 and 521.

A target that receives the base, the head and the changed paths (TSK-1190) can decide that nothing it owns changed. Today it can only exit 0, which counts as a pass, so a skipped suite looks the same as a green one. The ask (#514) is one reserved exit code that means "skipped, not selected".

Security: the target is project code from the pull request head and can claim a skip. A skip therefore grants nothing: no reuse, no evidence, no pass count. Non-goals: selection by the runner (P1) and the target-side inputs (TSK-1190).

## Outcome

After this merges, a target can say it was skipped, and the run never treats that skip as a pass or as evidence.

## Deliverables

- the exit-code contract in `crates/codeflow-core` test running, with output and `run.json` states
- docs of the reserved code where target commands are described
- tests per case below

## Acceptance Criteria

- AC-1 Exit 0 shall be a pass, one documented reserved code shall be "skipped, not selected", and any other code shall fail; evidence: a test per exit code.
- AC-2 A skip shall be reported as not selected in the output and in `run.json`, and the run shall be incomplete and not evidence; evidence: a test over both. (serves EPC-022 AC-238)
- AC-3 In a complete-gate mode (full, strict or a protected target) a skip shall fail the run or leave the gate incomplete; evidence: a test per mode.
- AC-4 A skip shall grant no reuse, no evidence and no pass count, including for a reporting job that aggregates shards; evidence: tests for reuse and the aggregate with a skipped target offered.
- AC-5 (journey) In a scratch repository with a target that exits the reserved code, a quick run shall report it skipped and incomplete, and a strict run shall not pass; evidence: the journey output.
