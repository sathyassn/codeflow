# TSK-440: The ledger surfaces run on every harness through one implementation

## Description

ADR-0086, the enforcement part, as the Codex review corrected it (F13,
F14, F20). Surfacing the ledger never depends on a session timer, which
is session-scoped and vendor-specific: one implementation in the binary
serves every harness through adapters. Today Claude wires SessionStart,
Stop and UserPromptSubmit in `.claude/settings.json`, Codex wires
SessionStart and UserPromptSubmit in `.codex/hooks.json`, and Grok has
PreToolUse only in `.grok/hooks/codeflow.json`; wiring is not runtime
evidence, so each route is proven by a native canary.

Outcome: **at every session start, `codeflow hook session-orient`
reports, read-only, the session's own stream in detail (who leads and
whether it is stale, the follow-ups owed, overdue or awaiting the
operator, the lanes with stale seats) plus one summary line per other
stream and the intake list, bounded to counts, the urgent subset and a
pointer, never guessing a stream; `codeflow coord status` shows every
stream, its coordinator's liveness, lanes, owed follow-ups and operator
items, and flags, as an advisory, more than one distinct epic with
active build attempts in a stream unless the earlier epic records an
outside wait (issue 280's rule with its allowance); at
every turn end, a check reports follow-ups past their next check,
follow-ups with no effective schedule and a turn that answered an
operator ask without an item, advisory, never blocking inside a tracked
delegate session, and blocking elsewhere only as a verified project
opt-in; any `codeflow` command can print the overdue count; status and
`orient` are built from `follow list`; and a truthful capability matrix
says what each harness runs.**

Rules:

- The surfaces are one module the hooks and the CLI's shared output
  call; a harness adapter only wires an event. Claiming a role is a
  separate explicit step (TSK-439); the start digest never writes.
- Capability matrix, published in the docs and checked by a scaffold
  test: Claude (start, stop, prompt), Codex (start, prompt; the turn-end
  check runs at the next prompt or an explicit command until a stop
  route exists), Grok (PreToolUse only: a session hook is added where
  Grok supports one, else the orchestrator's launch prompt runs
  `codeflow orient` explicitly and the matrix says so). A no-hook
  harness uses explicit orientation with reduced coverage.
- Observations of pull requests and tasks (for due derivation and
  fulfilment) run with a bounded network budget and cached freshness,
  report offline as unknown, and promise discovery at the next check,
  never unattended execution (no daemon scheduling, `docs/product.md`).
- The turn-end check never blocks inside a tracked delegate session;
  a blocking mode elsewhere validates its effective policy and
  compatibility at launch, avoids recursive Stop loops, never reads
  "still waiting" as a demand for another answer, and ships its own
  targeted tests against the delegate Stop lifecycle. Semantic
  "ask without item" detection stays advisory.
- Orient stays within its line budget: counts, the urgent subset and a
  pointer to `follow list`; each stream folds once per invocation;
  backlog checking is resumable without marking unchecked items fresh.
  Whether coordination events enter `recall` is decided explicitly,
  with the privacy exclusions named.

Non-goals: the store (TSK-422), lanes (TSK-439), the rules (TSK-423).

Amended 2026-10-31 by the hierarchy amendment (ADR-0094): the surfaces
show the Director, Coordinator and Lane tree that TSK-439 and TSK-1126
record. `codeflow coord status --tree` groups child streams under their
parent, lists unharvested reports with their age, labels the role that
recorded each line and marks a lane whose recorded worktree or branch is
gone while its record is open as "worktree missing", from the inventory,
never removing anything. The start digest shows the session's own stream,
its children one line each and one line per other stream, and stays
read-only. The traversal is bounded: a cyclic, missing-parent,
closed-parent or deeper-than-two shape terminates and is shown as marked
rows, never refused, because depth is guidance (ADR-0094). A Claude hook
that appends a lane report at Stop or Notification is deferred: `lane
report` from the shell is the uniform path, and the question is revisited
once this task and TSK-439 show whether hook payloads carry the session
id. A cf-present view of the tree has no owning task; it is revisited
after the TSK-1122 prototype walk-through (EPC-022).

## Acceptance Criteria

- AC-1 `codeflow hook session-orient` shall report, read-only and without claiming, locking or guessing a stream, the session's own stream in detail (who leads and whether the lease is stale, the follow-ups owed, overdue or awaiting the operator for the bound role, the lanes with stale seats, its child streams one line each with their unharvested reports counted) plus one summary line per other stream and the intake list, within the orient line budget as counts, the urgent subset and a pointer, from any worktree, printing empty for no ledger, unavailable for a denied read and busy for a held lock, with each line labelled by the role that recorded it; evidence: hook tests from two worktrees, a read-only filesystem, a held lock and a parent stream with two children. (serves EPC-025 AC-3, AC-6)
- AC-2 The turn-end check shall report follow-ups past their next check, follow-ups with no effective schedule and a turn that answered an operator ask without an item, as warnings by default; it shall never block inside a tracked delegate session whatever the policy says; the opt-in blocking mode shall validate its policy and compatibility at launch, never loop and never read "still waiting" as a demand for another answer; and the existing delegate Stop-lifecycle tests shall pass with the check wired; evidence: hook tests at both levels, a delegate-session fixture and the lifecycle tests. (serves EPC-025 AC-3)
- AC-3 The Claude, Codex and Grok adapters shall match the published capability matrix (start, stop, prompt per harness), the matrix shall be checked by a scaffold test against the rendered files, and each wired route shall be proven by a native canary, with Grok's route either added where supported or stated as the explicit `orient` with reduced coverage; evidence: the scaffold test and the canary records. (serves EPC-025 AC-3)
- AC-4 Pull request and task observations shall run with a bounded network budget and cached freshness, report offline as unknown, never run unattended, and each stream shall fold once per invocation with backlog checks resumable; any `codeflow` command shall be able to print the overdue count, and `orient` and the status digest shall be built from `follow list`; evidence: tests with the network unreachable, a budget test and the fold count. (serves EPC-025 AC-3)
- AC-7 `codeflow coord status` shall show every stream with its coordinator's liveness, its lanes, its owed follow-ups and its operator items, and shall flag, as an advisory, a stream in which more than one distinct epic has active build attempts (counted by epic across lanes, whatever their scope), unless the earlier epic's active lane records an outside-wait reason (a review, the operator, another stream's epic), showing that reason instead; closed lanes and completed history shall not count; `coord status --tree` shall group child streams under their parent with each stream's coordinator session (name, harness, whether its lease is stale), shall list every reported event with no later harvest or accepted mark with its age and the role that recorded it, shall show harvest state for the rest, shall mark a lane whose recorded worktree or branch is gone while its record is open as "worktree missing" from `codeflow status` inventory without removing anything, and shall terminate and show every open stream as marked rows for a cyclic parent chain, a missing parent, a closed parent and a chain deeper than two levels, refusing none; evidence: CLI tests for two lanes building one epic (not flagged), one `tasks` lane with active attempts from two epics (flagged), the allowed wait (not flagged, reason shown), an unexplained second epic (flagged), completed history (not flagged), a Director with two Coordinator streams and three lanes, two unharvested reports with ages, a missing worktree, and one fixture per malformed shape. (serves EPC-025 AC-3, AC-6)
- AC-8 The session-start and turn-end hooks and the overdue count shall obtain every outside observation and heartbeat only through TSK-422's bounded interface (`coord/observe.rs`), never calling `gh`, `git ls-remote` or any unbounded observer directly, and shall finish within their own bound when an observer hangs, printing `unknown` for what could not be observed; evidence: a code search for direct observer calls in the hook paths with no hits, and a hook test with a hung observer completing within the bound. (serves EPC-025 AC-3)
- AC-9 `coord status --tree` shall flag, as an advisory from `codeflow status` inventory, a root checkout with uncommitted changes and a branch of the task-branch class (`task/*`; `integration/*` and `plan/*` stay unflagged) with commits that no open lane records, each naming the worktree or branch, so work done outside a lane is visible to the Director; the flag shall refuse no command and shall not block the Director's root checkout; evidence: CLI tests with a dirty root checkout, a task branch with commits and no lane, an `integration/*` branch with no lane (not flagged), and a clean fixture with no flag. (serves EPC-025 AC-6)
- AC-5 Whether coordination events enter `recall` shall be decided and documented with the privacy exclusions, and the per-harness notes shall say which hooks fire in each harness and give the optional timer recipe as an aid; evidence: the doc text and a recall test for the decided behaviour.
- AC-6 (journey) With the installed build, a Claude session, a Codex seat and a Grok seat in a scratch adopter project shall each see the same overdue follow-up at start by their matrix route, the Claude session's turn end shall warn on an unlogged operator ask, and a tracked Claude delegate seat with the blocking policy set shall still complete its turn; evidence: the journey output per harness. (journey)

## Execution contract
