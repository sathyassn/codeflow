# TSK-1441: The work next listing shows a cross-epic task waiting for that work on the default branch

## Description

Under ADR-0102 a dependency on another epic gates only the task that uses it, and that task waits for the predecessor's work on the default branch; the rest of its epic goes ahead. `work next` already shows a task waiting on another line (`crates/codeflow-core/src/workgraph/work_start.rs:3317-3367` on `main` at `f8aabc62c`, from draft 1), but not this case. This task adds the wait reason, using TSK-1440's derived edges. Non-goal: any change to same-epic dependencies.

Landing on its target (`main`, alone, early):

- Reachable: the new wait reason in `work next`.
- Inert: same-epic dependencies are unchanged.
- Other lines: their `work next` output changes after the release; no action.

Waits for TSK-1340's work on `main`: its record is on `main`, its work (a `kind: code` pin met on the line) is on the EPC-022 line.

## Outcome

After this merges, an agent running `work next` sees a task that waits for another epic's work named with that predecessor and its epic, and sees the epic's independent tasks as ready.
