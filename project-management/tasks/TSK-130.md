# TSK-130: guidance retention evals across compaction

## Description

Nothing measures whether the agent still follows the rules deep into a
session or after compaction, and cf-evaluate-model treats a reused session
as contamination. This task adds a declared scripted multi-turn case kind to
the protocol (the fixture supplies a turn script, only the probe turn is
graded) and a guidance-retention pack for the three hard cases: estimate
volunteered in a plan, outcome-first status, and spontaneous cf-present,
each with a paired negative. It runs against a freshly scaffolded fixture
project, since that is what adopters get, in a fresh arm and an after-
compaction arm. The full five-arm matrix is out of scope. Source: research
map "Evaluation that proves it"; Fable challenge F3.

## Affected surfaces and interfaces

- `cf-evaluate-model` protocol text, `resources/packs.json` and
  `resources/fixtures.json` (append-only), all mirrors and the manifest.
- Fixture settings for cheap auto-compaction
  (`CLAUDE_CODE_AUTO_COMPACT_WINDOW`), inside disposable fixtures only.

## Acceptance Criteria

- [ ] AC-1 The protocol shall declare the scripted multi-turn case kind:
      turn script from the fixture, one native interactive session, only the
      probe turn graded, deterministic grading first; evidence: the protocol
      text and a pack-schema test that accepts the kind.
- [ ] AC-2 The pack shall hold the three hard cases and their paired
      negatives (for example a simple question that must stay in chat), none
      naming the rule in the probe; evidence: `packs.json` entries and the
      schema test.
- [ ] AC-3 Each case shall run in a fresh arm and an after-compaction arm,
      the compaction happening inside a disposable fixture and never in the
      operator's session; evidence: the fixture settings and the case
      definitions.
- [ ] AC-4 The fixture project shall be created by `codeflow init` at the
      standard tier from the candidate under test, carrying TSK-127's map
      and TSK-128's hooks; evidence: the fixture recipe and the run log.
- [ ] AC-5 (serves EPC-020 AC-13) On the combined candidate, the hard cases
      shall pass 3 of 3 trials in both arms (18 sessions on the Claude host),
      adherence after compaction shall be no lower than fresh, and the paired
      negatives (one trial per arm) shall show no over-triggering; a human
      reviews every hard failure; evidence: the run report with session ids
      and grades.
