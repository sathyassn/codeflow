# TSK-097: move CI off Node 20 actions and pin the runner image

## Description

Two platform changes affect CodeFlow's CI and the workflow it scaffolds for
adopters, as reported in the 2026-09-26 release follow-up list (workspace
`RELEASE-PLAN.md`). First, `actions/checkout@v4` and `actions/setup-node@v4`
run on the deprecated Node 20 action runtime. Second, the `ubuntu-latest`
label moves to Ubuntu 26 from 2026-10-19, which changes the toolchain under
every job that uses it without a change in this repository. This task moves
both workflows to action versions on a supported runtime and decides, per
job, whether to pin the Ubuntu image or accept the move after a proven run.

At `e49726807`: `.github/workflows/codeflow-ci.yml` uses `checkout@v4` at
lines 55, 102, 126, 152, 173, 227 and 263, `setup-node@v4` at 67 and 137,
and a commit-pinned checkout at 22 and 43; eight jobs use `ubuntu-latest`
and one `windows-latest`. The scaffolded `assets/base/ci/codeflow-ci.yml`
uses `checkout@v4` at 35, 68, 88 and 152 and `ubuntu-latest` in four jobs.
`release.yml` already pins `ubuntu-22.04` and a checkout commit, which
`crates/codeflow-cli/tests/release_contract.rs` asserts;
`release-main-recheck.yml` and `release-post-announce.yml` use
`ubuntu-latest`.

Target release: 3.0.0 for both CodeFlow's own CI and the scaffold
workflow (delivery plan of 2026-09-26 evening), ahead of the 2026-10-19
runner move. Non-goal: changing what any job checks.

## Affected surfaces and interfaces

- `.github/workflows/codeflow-ci.yml`, `release*.yml` where the same actions
  appear, and `release_contract.rs` if a pinned commit changes.
- `assets/base/ci/codeflow-ci.yml` and its baseline copy; adopters receive it
  through `codeflow update` (3-way merge for edited copies).
