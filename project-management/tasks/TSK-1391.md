# TSK-1391: The docs-portal gate intermittently reads an empty Pagefind index entry under load

## Description

The `docs-portal` gate target sometimes fails with "Pagefind search index entry is empty: dist/pagefind/pagefind-entry.json" when nothing in the content explains it. The message comes from `verify_pagefind_entry` (`crates/codeflow-core/src/validate/portal.rs:2796-2799`), which TSK-048 added. In full mode the target runs `node scripts/workflow.mjs verify` (astro `check`, then astro `build`, whose Starlight integration runs Pagefind 1.5.2, then `scripts/evidence.mjs`) and then `codeflow validate --portal docs-portal`, with a 300 s timeout (`.codeflow/test-config.json:497-500`). Observed by coord/catalog on 2026-11-08: PR 698 at `5bc7f49c7` failed once and passed on an immediate rerun with no change, after a two-word docs edit; PR 716 read an empty entry at host load 57 to 100, then hit the 300 s timeout on its second run, after an edit to `docs/releasing.md`. Both point to a race or timing fault under load. Leads, none confirmed: the build exits before Pagefind has flushed the entry file; a later step or another target rewrites `dist/` while the validator reads it; or the validator reads a file that is still being written.

This task finds the cause and fixes it at its source. Non-goals: a retry, a longer wait or a relaxed check that would pass a real empty index; the 300 s timeout as a separate tuning question, unless the diagnosis shows it shares the cause.

## Outcome

After this merges, a Worker who runs `codeflow test --only docs-portal` on a loaded host gets a pass or a failure that names a real defect, and a rerun with no change gives the same result.

## Deliverables
