# TSK-091: live trial of the tmux delegate transport

## Description

The typed directive after a pasted delegate prompt (`d1236ad5c`) shipped in
3.0.0 with a live run only on the Herdr path. `cf-delegate` names tmux as the
degraded TTY host when Herdr is unavailable, and its launch recipe
(`load-buffer`, `paste-buffer -p`, then `send-keys -l` of the directive and
Enter) has not been exercised against a live Claude Code session since the
directive landed. This task runs that recipe live, on the integrated EPC-019
body, and runs the release qualification on the same head, so the 3.0.1
pull request carries evidence for both transports and for the task notice
continuation rule that TSK-090 ships in 3.0.0. It is the epic's verification
node: if the trial fails, the fix goes to TSK-092 for the harness or to a new
task (TSK-090 will have shipped in 3.0.0), never into this record.

The code under test must contain the reviewed TSK-090 implementation, which
lands on `chore/release-assembly`, not on this task's target. A completed
TSK-090 record on this branch does not prove that. The harness is not part of
this body either: it runs from a separate checkout of the EPC-014 line, pinned
by commit.

Target release: 3.0.1.

## Affected surfaces and interfaces

- `cf-delegate` SKILL.md tmux recipe and
  `resources/claude-turn-completion.md`; changed only if the trial shows the
  documented recipe is wrong.
- A new verification record under `docs/verification/` and the 3.0.1
  release record rows the qualification writes.
- A disposable sample repository and state directory under `$TMPDIR`; one
  owned tmux session, never the operator's sessions.
