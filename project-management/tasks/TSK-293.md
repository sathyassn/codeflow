# TSK-293: codeflow integrate can land a reviewed head with a merge commit

## Description

`codeflow integrate` lands a unit by rebasing it onto the line and
fast-forwarding (`crates/codeflow-core/src/integrate.rs:1-7` and `:241-266`
at v3.1.0). A project that lands each reviewed head with a no-fast-forward
merge, to keep the reviewed commit and the acceptance binding that names it
unchanged on the line, can use `integrate` only when the unit already sits
on the line tip; every other landing is a hand merge, gate and push
(https://github.com/sathyassn/codeflow/issues/150). This task adds a merge mode. Rebase stays the default.

## Deliverables

- the mode: `crates/codeflow-core/src/integrate.rs`, the flag in `crates/codeflow-cli/src/main.rs` and its command module
- tests: the integrate tests under `crates/codeflow-cli/tests/` and `crates/codeflow-core/tests/`
- docs: `docs/cli.md`, cf-method's "Land in batches" in `assets/base/claude/skills/cf-method/SKILL.md` (mirrors and baseline) if it names the landing modes
- release note: `changelog.d/TSK-293.md`

## Acceptance Criteria

- AC-1 When `codeflow integrate <head> --into <line> --merge` runs, it
  shall merge the head into the line with `--no-ff` without rewriting the
  head, run the gate on the merge result, and push under the checks
  `integrate` already applies; evidence: an integrate test asserting the
  merge commit's parents are the old line tip and the unchanged head.
  (serves EPC-022 AC-11)
- AC-2 When the gate fails or the merge conflicts, the line shall be left
  unchanged and the command shall say why; evidence: a red-gate test and a
  conflict test.
- AC-3 Without `--merge`, `integrate` shall rebase and fast-forward as at
  v3.1.0; evidence: the existing integrate tests unchanged.
- AC-4 A task landed with `--merge` shall keep its acceptance binding valid
  on the line, so `codeflow ci` over the landing is clean; evidence: a test
  that completes a task, lands it with `--merge` and runs `codeflow ci`.
- AC-5 When an operator lands a reviewed task head that is not on the line
  tip with the installed build's `codeflow integrate --merge`, the line
  shall gain one merge commit whose second parent is the reviewed head
  (journey); evidence: a CLI journey on a scratch repository.
