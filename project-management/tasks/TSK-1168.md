# TSK-1168: One shared top bar with the panel toggle, title and crumb, and the display gear

## Description

Consolidated 2026-11-04 into TSK-1160 by the second consolidation amendment (the operator's planning direction of 2026-11-04 21:5x; the Director ruled this merge on 2026-11-04). Every criterion below moved there word for word, with a `Moved` note naming its old id: AC-1 is TSK-1160 AC-9, AC-2 is TSK-1160 AC-10, AC-3 is TSK-1160 AC-11, AC-4 is TSK-1160 AC-12, AC-5 is TSK-1160 AC-13. This record stays as history; build work happens under TSK-1160.

Added 2026-11-01 (the Director, 20:50, after the operator rejected a page
whose top bar showed a sun icon instead of the agreed display gear). Every
page of `cf-present` and `cf-docs-portal` has a top bar with the same
controls: the panel-left toggle, the title and crumb, and one gear that opens
Mode, Themes and Text size. This task makes that bar one shared component, so no page
draws its own bar controls, and holds it with a test that fails any page
with other icons or buttons, or a gear that does not open Mode, Themes and Text size.

It was first written as TSK-1160 criteria. With them TSK-1160 (the navigation
component) would have graded Very Hard, so the bar is its own task. Split
of ownership, with no criterion in two places: this task owns the shared bar
component and its test. TSK-1162 keeps the tokens and the Mode, Theme, Accent
and Size choices behind the gear (its AC-2). TSK-1160 keeps the sidebar
navigation; the panel-left toggle controls that component, so its behaviour
is the operator's pick recorded under TSK-1160 AC-3. TSK-1120 (the
`cf-present` shell), TSK-446 (the portal pages) and TSK-1127 (the shipped
samples) use the bar and depend on this task.

Non-goals: the sidebar component and its behaviour (TSK-1160); the tokens and
choices (TSK-1162); the rest of the shell (TSK-1120).

## Outcome

After this merges, every `cf-present` and `cf-docs-portal` page shows the same
top bar, and a page with a different control, such as a sun icon, fails the
build.

## Deliverables

- the component: one top bar in the shared kit script and stylesheet both surfaces load, with the panel-left toggle, the title and crumb, and one gear that opens Mode, Themes and Text size, with no second copy in the present web sources, the starter or this repository's portal
- the spec: the bar's contents and the gear's behaviour, written in the design system
- the Comment text button outside the bar, with C as its shortcut, and its browser test (AC-4)
- the test: the page test that fails other bar icons or buttons or a gear that does not open Mode, Themes and Text size, with its planted fixtures
- release note: `changelog.d/TSK-1168.md`
- managed wiring, mirrors and baseline: `assets/base/scaffold-manifest.toml`, installed managed files and `.codeflow/` baseline, synchronized when changed

## Acceptance Criteria

- AC-1 (added 2026-11-01, the Director, 20:50, after the operator's rejection of a page with a sun icon in the top bar in place of the agreed display gear) The top bar of every `cf-present` and `cf-docs-portal` page shall be one shared component with exactly these controls: the panel-left toggle, the title and crumb, and one gear, plus optional docs text links that a page supplies through a data slot of the bar (text links only, never an icon or a button); no page shall draw its own bar controls, and no second copy of the bar shall exist in either surface's sources; evidence: the component, and a source test that finds one bar component and no copy. (serves EPC-022 AC-192)
- AC-2 (added 2026-11-01, the Director, 20:50; amended for Text size, the Director, 21:04) The gear shall be one icon-only button with an accessible name that opens a display popover listing Mode, Themes and Text size (the Theme, Accent and Size choices TSK-1162 AC-2 defines; the Director confirmed at 21:04 that Text size stays), keyboard and pointer operable, closing on Escape and outside click with focus returned to the gear; the choices, their tokens and their floors are TSK-1162's, and this criterion owns only the control that opens them; evidence: a browser test that opens the popover by pointer and keyboard, finds Mode, Themes and Text size in it, and selects an accent option through the gear and finds the accent role changed (the end-to-end proof that TSK-1162's choices work through this control). (serves EPC-022 AC-192)
- AC-3 (added 2026-11-01, the Director, 20:50) A test over every page build on both surfaces shall fail any page whose bar has an icon or a button other than the toggle and the gear, and any page whose gear does not open Mode, Themes and Text size (docs text links in the data slot are allowed); evidence: the test run over this repository's portal, the starter and a present document, and three planted fixtures that fail, a page with a sun icon in place of the gear, a page with a gear that opens nothing and a page with an extra icon button in the bar, with a clean control that has docs text links in the data slot; the test ports the top bar, toggle, gear, other-controls and Comment checks of the prototype `coordination/coordinators/visual-docs/design/_src/nav.test.cjs` (workspace commit 143654e), which TSK-1160 leaves to this task. (serves EPC-022 AC-192)
- AC-4 (added 2026-11-01, the Director, 21:04) On every page that has comments, the Comment control shall be a visible text button outside the top bar, never an icon in the bar, with C as its keyboard shortcut; pages without comments shall show no Comment control; evidence: a browser test that finds the text button outside the bar on a page with comments, that C activates it (and does not while typing in a field), and that a page without comments has none; and the AC-3 test still passes, since the control is not in the bar. (serves EPC-022 AC-192)
- AC-5 (added 2026-11-02, journey amendment: the task had no journey criterion; this one drives its own change with the built binary) When every page of the built `cf-present` and `cf-docs-portal` surfaces is opened, each shall show the shared top bar with the panel toggle, title and crumb, and the display gear, and no other icon or button; evidence: the page-build test over both surfaces. (journey)
