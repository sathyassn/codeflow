# TSK-185: Pre-push checks a landing against the line it lands on

## Description

The pre-push push set picks a single `--base` for `codeflow ci` from the
first boundary of `rev-list --boundary` against every tip the destination
advertises. When a push brings in history that several remote branches
hold, as a batch landing on the line does, that boundary is an arbitrary
task-branch tip (`89f6c41` on 2026-09-29), and the range then re-checks
old line history and refuses it. Batch 1 of EPC-020 cannot land for this
reason alone: the same range checked from the line's own tip is clean. The
change makes the push set check a push against the branch it updates, as
its own documentation says, and never checks fewer commits than the
destination lacks.

Non-goal: changing which checks run on the range, or any level.

## Affected surfaces and interfaces

- `crates/codeflow-cli/src/cmd/push_set.rs` (range base selection) and its
  tests; the pre-push hook behaviour adopters see.

## Acceptance Criteria

- AC-1 When a push updates an existing destination branch and extends it,
  the push set shall run `codeflow ci` from that branch's advertised tip,
  even when other destination branches hold part of the pushed history;
  evidence: a push-set test with a merge of several remote task branches
  onto the line, red before the change and green after.
- AC-2 When a new branch's pushed history has more than one boundary
  against the destination's tips, the push set shall choose a base whose
  range contains every commit the destination lacks and does not start at
  an arbitrary branch tip, and shall say which base it chose; evidence: a
  push-set test with several boundaries.
- AC-3 When a push rewrites or does not extend its destination, or the
  destination cannot be asked, the push set shall behave as it does today;
  evidence: the existing push-set tests unchanged and green.
- AC-4 When batch 1 is pushed to the EPC-020 line with the fixed binary,
  the pre-push range shall start at the line's old tip and pass; evidence:
  the push output. (journey)
