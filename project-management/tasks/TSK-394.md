# TSK-394: Task-line and document-index classification failures get separate remedies

## Description

Source: PR 237 (TSK-276) reviews, 2026-10-17. The shared `work.classification` remedy hint (`crates/codeflow-core/src/remedy.rs:314-316`, `crates/codeflow-cli/src/cmd/ci/classification.rs:826`) now shows document-index advice for `Task:` line failures too, so a reader with a malformed `Task:` line is told about document indexes.

Outcome: **a `Task:` line failure and a document-index failure each show only the remedy that fixes it.**

Added to EPC-023 (4.1.0) by the amendment of 2026-10-18: the operator's release decision of that day puts lower-severity review follow-ups in 4.1.0 (workspace `RELEASE-PLAN.md`, 2026-10-18 operator decision).
