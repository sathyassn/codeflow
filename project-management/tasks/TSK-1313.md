# TSK-1313: A newer line push cancels the older push run on that line

## Description

The operator asked on 2026-11-03: "A newer line push cancels the older push run - wasn't this already considered? anyways make sure its considered and tasked". `codeflow-ci.yml:30-32` cancels only `pull_request` runs and groups by ref, so a superseded line push runs to the end, and a dispatch on a line shares a group with that line's pushes. A superseded line commit's verdict is required nowhere (hosted CI savings analysis of 2026-11-03). This is a root task so it can land early; TSK-1026 keeps its pull request design and points here. Non-goal: anything on `main`.

## Outcome

After this merges, a newer push to an integration line cancels the older push run on that line, so a maintainer pays for the newest tip's run only.

## Deliverables

- the concurrency settings: `.github/workflows/codeflow-ci.yml`, by operator script if the guard lists the file
- the test: the workflow's scaffold or gate-parity test; AC-3 names it
