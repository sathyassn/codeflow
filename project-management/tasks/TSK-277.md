# TSK-277: A secret-scan exemption into the base can be classified

## Description

Since PR 26 the secret scan reads exemptions from the trusted base commit,
so an integration line that carries a reviewed false positive needs a small
exemption pull request into `main` first. That pull request has no class
`codeflow ci` accepts (https://github.com/sathyassn/codeflow/issues/139): with `Task: TSK-NNN` it fails
`work.stable_planning_anchor` on a dependency that is complete only on the
line, and with `Task: EPC-NNN` `amendment_path`
(`crates/codeflow-core/src/workgraph/classify.rs:257` at v3.1.0) refuses the
hidden `.gitleaksignore`. The operator then merges over a red required
check. This task adds one narrow class for a range whose only changed path
is the secret-scan ignore file the managed CI reads (`.gitleaksignore`).
Non-goal: admitting the ignore file into the planning class, which would
let any planning PR carry an exemption.

## Deliverables

- the class: `crates/codeflow-core/src/workgraph/classify.rs`, `crates/codeflow-cli/src/cmd/ci/`
- tests: `crates/codeflow-cli/tests/ci_cli/`
- docs: `docs/policy-reference.md`, `assets/base/ci/README.md` and its installed copy
- release note: `changelog.d/TSK-277.md`

## Acceptance Criteria

- AC-1 When a range's only changed path is `.gitleaksignore` and its body
  names `Task: EPC-NNN` or `Task: TSK-NNN`, `codeflow ci` shall give it a
  named exemption class that skips the stable-anchor dependency check;
  evidence: ci fixtures for both forms, replaying issue 139. (serves
  EPC-022 AC-1)
- AC-2 When the range changes any other path as well, it shall not get the
  class; evidence: one fixture per neighbour (a record, a doc, another
  hidden file).
- AC-3 The secret scan, the security review and code-owner approval shall
  still apply to a range in the class; evidence: tests of the class's
  checks and the managed workflow wiring.
- AC-4 `docs/policy-reference.md` and `assets/base/ci/README.md` shall
  document the class and the flow that needs it; evidence: the doc diff.
- AC-5 When a fresh full-tier project uses the installed build, an
  exemption-only pull request into `main` naming the epic shall pass
  `commit standards` while its task's dependency is complete only on the
  integration line (journey); evidence: a CLI journey on a scratch
  repository.
