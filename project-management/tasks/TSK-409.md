# TSK-409: The docs portal takes the fixed vite release

## Description

Advisory GHSA-698v-4r3x-3vcv (CVSS 6.3) affects `vite` 8.2.0 through 8.2.3 and
is fixed in 8.2.4. The docs portal and the shipped starter resolve `vite` 8.2.0
through `astro`, so the dependency audit in the security review job fails on
every pull request that carries those lockfiles. This task pins `vite` to 8.2.4
with an override in the docs portal and in the shipped starter, regenerates both
lockfiles so only `vite` and anything npm must move for it changes, and re-pins
the portal state and the runtime script list to the new files. It adds no audit
suppression, because a fixed release exists. Effect on adopting projects:
`codeflow update` installs the starter's new `package.json` and lockfile.
Non-goal: other dependency upgrades.

## Deliverables

- the dependency fix: `docs-portal/package.json`, `docs-portal/package-lock.json`, `assets/docs-portal/starter/package.json`, `assets/docs-portal/starter/package-lock.json`
- the portal pins: `.codeflow/docs-portal.json`, `docs-portal/scripts/runtime-scripts.json`, `assets/docs-portal/starter/scripts/runtime-scripts.json`
- the release note: `changelog.d/TSK-409.md`

## Acceptance Criteria

- AC-1 When the docs portal and the shipped starter lockfiles are read, both shall resolve `vite` at 8.2.4, the fixed release the advisory names, and the lockfile change shall be limited to `vite` and the packages npm must move for it. Evidence: `jq` on both lockfiles, the advisory text from osv.dev, and a diff check of the changed lock entries.
- AC-2 When osv-scanner runs on the docs portal and the shipped starter lockfiles, it shall report no `vite` advisory. Evidence: osv-scanner on both lockfiles, and the hosted security review job.
- AC-3 When the docs portal and the starter are built and tested from a committed tree, the builds and tests shall pass and the portal state and runtime script list shall match the new lockfile. Evidence: `codeflow test --only docs-portal` and `codeflow test --only docs-portal-deps`, `manifest_consistency`, and `codeflow test --mode quick`.
- AC-4 When an adopter sets up the docs portal with this build, the project's portal lockfile shall carry `vite` 8.2.4 and its dependency audit shall report no advisory. Evidence: a fresh `codeflow init --standard` and `codeflow portal setup --path docs-portal` with the built binary in a temporary project, `npm ls vite` there after `npm ci`, and osv-scanner on the resulting lockfile. (journey)
