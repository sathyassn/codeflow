# TSK-287: Every judging history read refuses an overlaid history

## Description

Local history checks trust commit parents that a graft file, a replace ref,
a forged commit-graph or a shallow boundary can rewrite (https://github.com/sathyassn/codeflow/issues/122). PR 107 guarded
`review_covers_pin` by calling `release_line::history_overlay` and
`shallow_boundary` first, but parent and ancestry reads are not
centralized: at v3.1.0 the guard is called from a few sites
(`acceptance.rs:946-955`, `landing.rs:192-196`, `work_start.rs:1328-1333`
and `:1933`, `release_line.rs`), and about 30 judging sites in the issue's
sweep read parents directly. Hosted CI on a fresh clone is unaffected; the
local floor (pre-push, work start, task status, a local `codeflow ci`) is
not. This task adds one guarded reader and moves every judging site onto
it.

## Deliverables

- the reader: `crates/codeflow-core/src/workgraph/release_line.rs` or a sibling module (provisional)
- the sites in the issue's sweep: `acceptance.rs`, `status_verb.rs`, `ci/classification.rs`, `lifecycle.rs`, `landing.rs`, `readiness.rs`, `status.rs`, `integrate.rs`, `work_start.rs`, `line_adoption.rs`, `push_set.rs`, `ci/change_class.rs`, `amendment.rs`
- tests: one planted-overlay test per class
- release note: `changelog.d/TSK-287.md`

## Acceptance Criteria

- AC-1 One guarded way to read parents and ancestry shall report "cannot
  verify" when the clone has a graft file, a replace ref, a commit-graph
  that disagrees with commit objects, or a shallow boundary in the history
  it judges; ordinary commit-graphs shall remain allowed. Judging Git
  subprocesses shall disable commit-graph reads and shall not inherit
  repository or object-store redirects; evidence: unit tests per overlay
  and CLI tests for redirects and linked worktrees.
  (serves EPC-022 AC-4)
- AC-2 Every judging site in the issue's sweep (acceptance binding, journey
  scope, reopen detection, landing, pin containment and stacking, epic-line
  review coverage, range bases) shall use it, and each display-only site
  left unguarded shall carry a stated reason; evidence: a sweep table with
  file:line per site, and a test that fails on a new direct parent read
  outside the reader without a reason.
- AC-3 For each class, a test with a planted graft and one with a planted
  replace ref shall reach "cannot verify" where v3.1.0 accepted the
  history; evidence: tests per class. (serves EPC-022 AC-4)
- AC-4 (journey) When a clone's `.git/info/grafts` turns a source change and its
  revert into one span, the installed build's pre-push, `work start` and
  local `codeflow ci` shall report "cannot verify", and a clean clone of
  the same history shall still pass; evidence: a CLI journey.
