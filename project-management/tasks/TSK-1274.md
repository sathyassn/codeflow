# TSK-1274: Main's markdown parser is free of the RUSTSEC-2026-0433 advisory

## Description

Hosted "security review" fails every pull request into main, because main's Cargo.lock pins pulldown-cmark 0.13.5, which RUSTSEC-2026-0433 (CVSS 7.5) lists as fixed in 0.13.6 (PR 544, job 125726284929). TSK-1183 (PR 511) and TSK-1254 (PR 534) made this fix on the EPC-022 and EPC-024 lines; this task makes it on main. The workspace pins the crate exactly (`=0.13.5`), so the pin and the one lockfile entry both move to 0.13.6. Non-goals: no code change, no advisory suppression or lock override, no other dependency update.

## Outcome

After this merges, the hosted security review passes on pull requests into main, and the markdown parser that reads repository and pull request files is the patched release.

## Deliverables

- Exact pin at 0.13.6: Cargo.toml
- Lockfile entry for pulldown-cmark at 0.13.6: Cargo.lock
- Release note fragment: changelog.d/TSK-1274.md
- Task record: project-management/tasks/TSK-1274.md

## Acceptance Criteria

- AC-1 When osv-scanner scans the repository, it reports RUSTSEC-2026-0433 at the base and not at the head. Evidence: `osv-scanner scan source --lockfile Cargo.lock` output at the base and at the head. (journey)
- AC-2 When the lockfile is updated, only pulldown-cmark (and pulldown-cmark-escape if it moves with it) changes. Evidence: `git diff Cargo.lock`, `git diff Cargo.toml` and `cargo tree -i pulldown-cmark` at the head.
- AC-3 When clippy and rustdoc run on the workspace, both exit 0. Evidence: `cargo clippy --workspace --all-targets -- -D warnings` and `RUSTDOCFLAGS="-D warnings" cargo doc --workspace --no-deps` results.
- AC-4 When the tests of the crates that use pulldown-cmark run, they pass. Evidence: the named targeted test results for codeflow-core, codeflow-cli and codeflow-present.
- AC-5 When the release notes are read, the changelog entry names RUSTSEC-2026-0433. Evidence: changelog.d/TSK-1274.md.
