# TSK-1397: Test helpers clear every agent session marker before they commit

## Description

The root-checkout pre-commit rule treats a process as an agent when any of
`AGENT_MARKERS` is set (`crates/codeflow-core/src/root_checkout.rs:54`
at the line's b85d30681: `CLAUDECODE`, `CODEX_SESSION_ID`, `CODEX_THREAD_ID`,
`CODEX_CI`, `GROK_SESSION_ID`). The `git` helper in
`crates/codeflow-cli/tests/adopter_fit.rs:78-89`, the `codeflow` helper at
`:25-38` and `land_policy` at `:668-678` clear none of them, so a scratch
repository commit made under an agent session is refused and the test
fails. The sibling `acceptance_cli.rs:32-36` and `:49-53` already clear all
five. `cargo test` hides the gap, because `.cargo/config.toml:23-27` forces
the five markers empty (TSK-1084), but a test binary run directly, or any
runner that does not apply that file, inherits them. The PR 649 Worker saw
six `adopter_fit.rs` tests fail this way.

The task makes those helpers clear the same list as the sibling, and sweeps
the test suites for other helpers that spawn `git` or `codeflow` and can
commit without clearing it.

Not in scope:
- Two gate-runner tests that fail on `main` when `CARGO_TARGET_DIR` is set
  (`testing::gate::evidence_root_link_tests::a_link_at_the_build_output_folder_is_refused_before_any_write`
  and `testing::runner::tests::timeout_cause_survives_dependent_skips_and_saved_report`).
  Completed TSK-1369 fixed both on the line (`delivery.rs:171-174`), and the
  fix reaches `main` with the line's checkpoint.
- Network hermeticity, which is TSK-1280.

## Outcome

After this merges, the test suites give the same results whether or not an
agent session marker is set, however the tests are started.

## Deliverables

- the helper fixes: `crates/codeflow-cli/tests/adopter_fit.rs` and any file the sweep finds
- the sweep result: the pull request body

## Acceptance Criteria

- AC-1 Every helper in `crates/codeflow-cli/tests/adopter_fit.rs` that spawns `git` or `codeflow` and can commit (the `git` helper, the `codeflow` helper and `land_policy`, and any other caller the builder finds) shall clear every name in `AGENT_MARKERS`, as `acceptance_cli.rs` does; evidence: the affected tests run as a direct test-binary run with each marker set, failing before and passing after, named in the pull request body, and the same tests passing under `cargo test`.
- AC-2 The builder shall sweep the test suites for helpers that spawn `git` or `codeflow` and can commit without clearing every name in `AGENT_MARKERS`; each hit is fixed in this task or listed with why it is safe; evidence: the sweep commands and their output in the pull request body.
