# TSK-1397: Tests pass the same inside an agent session and with a custom build folder

## Description

Two groups of tests fail for reasons of the environment that runs them, not
the code they test, so local suites report failures that are not real.

- Agent session variables leak into test repositories. The `git` helper in
  `crates/codeflow-cli/tests/adopter_fit.rs:79-91` (main 27932282f and the
  line b85d30681) does not remove `CLAUDECODE`. Under an agent session the
  root-checkout pre-commit rule then refuses the scratch repository's
  commit, and six tests fail. Sibling files already remove it
  (`acceptance_cli.rs`). Found by the PR 649 Worker.
- A build folder outside the project breaks two gate-runner tests. They
  assume build output under `<project>/target` and fail when
  `CARGO_TARGET_DIR` is set, passing with it unset on the same binary. One
  is `timeout_cause_survives_dependent_skips_and_saved_report`
  (`crates/codeflow-core/src/testing/runner/mod.rs:1814` on the line); the
  other is `testing::gate::evidence_root_link_tests::a_link_at_the_build_output_folder_is_refused_before_any_write`
  (`crates/codeflow-core/src/testing/gate.rs:1745`). Found by the TSK-1390 Worker.

The task makes each test independent of those two settings and sweeps the
test suites for the same two patterns. Non-goal: network hermeticity, which
is TSK-1280.

## Outcome

After this merges, a developer or agent running the suites inside an agent
session, or with `CARGO_TARGET_DIR` set, gets the same results as a plain
shell with the default build folder.

## Deliverables

- the test fixes: `crates/codeflow-cli/tests/adopter_fit.rs`, `crates/codeflow-core/src/testing/runner/mod.rs` and any file the sweep finds
- the sweep result: the pull request body

## Acceptance Criteria

- AC-1 The six `adopter_fit.rs` tests shall pass when run with `CLAUDECODE` set, the way sibling test files do; evidence: the six tests run with `CLAUDECODE=1`, failing before and passing after.
- AC-2 The two gate-runner tests shall pass with `CARGO_TARGET_DIR` set to a folder outside the project and with it unset; evidence: both runs of both tests, failing before with it set and passing after in both.
- AC-3 The builder shall sweep the test suites for test helpers that spawn `git` or `codeflow` without clearing agent session variables, and for tests that assume `<project>/target`; each hit is fixed in this task or listed with why it is safe; evidence: the sweep commands and their output in the pull request body.
