# TSK-1353: A declared base check reaches every CI template and survives update

## Description

Split 2026-11-05 from TSK-1103 by the CI records planning pull request, before claim, by outcome (Director ruling, 15:5x). TSK-1103 builds the trusted-base check in GitHub's `pull_request_target` verdict job. This task carries the same declaration to the GitLab, Bitbucket and generic templates, keeps it through `codeflow update`, reports it in `codeflow doctor --check ci-perimeter`, and makes `codeflow ci` note an edit to a declared script, its inputs or the declaration.
