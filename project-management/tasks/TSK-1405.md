# TSK-1405: Test files have names the agent sandbox can read

## Description

Three test files in this repository have names that the agent sandbox's
secret-path deny globs match, so an agent in the sandbox cannot stat, read or
delete them. A sandboxed `stat` of every tracked file fails on exactly these
three and on no other file (checked 2026-11-09 at the EPC-022 line tip
5538541c5):

- `crates/codeflow-cli/tests/ci_cli/secret_scan_exemption.rs`
- `crates/codeflow-cli/tests/refusal_journey/secret_paths.rs`
- `crates/codeflow-core/tests/managed_secret_scan.rs`

The effects: agents cannot remove a landed worktree, so every removal goes to
the operator; a reviewer in the sandbox cannot read these tests; and a
sandboxed `git grep` errors on them. This task renames the three files and
updates every reference, with no other change to the tests. Non-goal: the
shipped presets' deny rules, which TSK-1106 owns.

## Outcome

After this merges, an agent in the sandbox can stat, read and remove every
tracked file in a worktree, so worktree cleanup and test review need no
operator step.

## Deliverables

- the renames and their references: `crates/codeflow-cli/tests/`, `crates/codeflow-core/tests/`, and the test config, scripts, docs, product source and open records that name the files or the `managed_secret_scan` test target

## Estimate

- Grade: Medium; band: Medium (2 to 4 h); moved: none
- Split: not needed; one outcome
- Basis: three renames with their module and `#[path]` lines, references in about a dozen files (source, scripts, test-time data, docs, open records), and the test-count and sandboxed-stat proof; graded by coord/records under issue 334's bands. The builder re-scores at claim.

## Acceptance Criteria

- AC-1 The three files shall be renamed to `crates/codeflow-cli/tests/ci_cli/scan_exemption.rs`, `crates/codeflow-cli/tests/refusal_journey/protected_read_paths.rs` and `crates/codeflow-core/tests/managed_leak_scan.rs`, with their module and `#[path]` lines (`crates/codeflow-cli/tests/ci_cli.rs` and `crates/codeflow-cli/tests/refusal_journey.rs`) and the test target name updated to match; the tests' contents shall be otherwise unchanged; evidence: the diff (renames plus reference lines only) and the same number of tests passing in each renamed target before and after, by name.
- AC-2 Every reference to the old file names or the `managed_secret_scan` test target in product source, test config, scripts (including the recorded test-time data), docs and open task records shall name the new ones; completed records keep their history; evidence: a search at the head that finds the old names only in completed records and in this task's own record.
- AC-3 In the agent sandbox, a `stat` of every tracked file in a worktree at the head shall succeed; evidence: the sandboxed run of `git ls-files -z` piped to `xargs -0 stat` with exit 0, in the pull request body.
- AC-4 If a workflow file names a renamed file or the test target, that change shall be delivered as an operator script with its exact diff, since workflow files are not agent-editable; evidence: the script, or a search at the head showing no workflow names them.
