## Outcome

After this merges, an author of a `cf-present` document or a portal page gets
the same sidebar navigation and top bar from one shared component with a
written spec, and a browser test fails any page build that regresses them.
Amended 2026-11-04 when TSK-1168 and TSK-1169 joined this task; earlier text
named only the sidebar and left the test to TSK-1169.
