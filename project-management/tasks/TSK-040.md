# TSK-040 — correct the public-facing documentation

## Description

The root-level documents a public reader meets first contain outright errors
and dead structure: README misstates the estimate row and leads with install
one-liners for a repository that is not yet public, CHANGELOG carries an orphan
`[Unreleased]` heading and compare links to a version that does not exist, and
`releasing.md` and `release-checklist.md` restate each other. This task corrects
those files in place and defines Agent OS once. Non-goal: the pending 3.0.0
CHANGELOG prose is consolidated only through the existing release tooling —
published sections stay untouched, impact annotations are retained, and the
legacy pending-group hash is never hand-edited; if the tooling cannot reconcile
it, the consolidation is deferred and the reason recorded.

## Affected surfaces and interfaces

`README.md`, `CONTRIBUTING.md`, `SECURITY.md`, `CHANGELOG.md`,
`docs/releasing.md`, `docs/release-checklist.md`, comments only in
`.github/workflows/codeflow-ci.yml`, and the docs comment in
`assets/base/codex/config.toml` if one exists. The release tooling contract
owns CHANGELOG structure; this task does not change that tooling.

## Acceptance Criteria

- [ ] README's estimate row and documentation list match the shipped CLI and
      the `docs/` tree; evidence: each listed item resolves and the estimate row
      matches `codeflow estimate --help`.
- [ ] README's install one-liners are demoted below the checkout-and-build path
      until the repository is public; evidence: rendered review of the README
      ordering.
- [ ] The README enforcement-planes section is cut to a summary that points at
      its owning source rather than restating it; evidence: rendered review and
      no duplicated plane description.
- [ ] CONTRIBUTING carries the release paragraph required by ADR-0062 and
      SECURITY's version reference reads v1; evidence: the two statements are
      checked against ADR-0062 and the supported-version table.
- [ ] CHANGELOG has no orphan `[Unreleased]` heading and no compare link to a
      nonexistent v3.0.0; evidence: every compare link resolves.
- [ ] The pending 3.0.0 prose is consolidated by user-visible outcome using only
      the existing release scripts and tests, with published sections unchanged,
      impact annotations retained and the legacy pending-group hash reconciled
      by tooling; evidence: the release scripts and their tests pass on the
      result. If the tooling cannot reconcile it, the consolidation is deferred
      and the reason is recorded in this task rather than worked around.
- [ ] `releasing.md` reads as runbook prose and `release-checklist.md` as a pure
      checklist with no overlap, and Agent OS is defined in exactly one clause
      across the two; evidence: rendered review of both.
- [ ] The CI workflow comments name the owner of each Node pin — portal 24.18.0
      and present 26.4.0 — without changing either pin; evidence: the workflow
      diff contains comment lines only.
- [ ] `codeflow validate --docs` passes on the task head.
