# TSK-320: A project declares its own outward commands beside the infrastructure preset

## Description

exec-guard knows a fixed set of outward program families
(`crates/codeflow-core/src/security/outward.rs:66-70`, closed at
`:471-481`); a project cannot add its own, such as an infrastructure tool
that changes live systems (https://github.com/sathyassn/codeflow/issues/171).
This task adds the declaration and its grammar:

- Key: `security.project_actions`:
  `{id, why, program: [..], commands?: [[..], ..], verbs?: [..], value_options?: [..]}`,
  always deny, at the level of `security.outward_actions`.
- Tokens: after the program word, `--` ends options; a word starting with
  `-` is an option; attached forms are one word; a `value_options` option
  consumes the next word; other words are command words.
- Ambiguity: an option not in `value_options` followed by a command word
  before the declared path is matched makes the match unproven; refuse at
  the `outward_actions` level with "list the option in value_options if it
  takes a value, run without it, or declare the whole program". Arity is
  never invented.
- Matching: `program` alone refuses the whole program; `commands` sequences
  match as prefixes of the command path; `verbs` match any command word,
  after the matched sequence when `commands` is given.
- Parse: the shipped unwrapping and basename handling; opaque scripts and
  aliases stay the residual of ADR-0075 decision 2.
- Ids and composition: a shipped family id is a validation error; entries
  union by id; the same id with different content fails closed. The typed
  composition API (deny lists union by id, exception lists intersect) is
  added by TSK-322 beside `landed_policy::stricter`
  (`crates/codeflow-core/src/hooks/landed_policy.rs:339-364`); this task
  extends it to `project_actions`. Changed on 2026-10-18, when TSK-322
  moved to 3.2.0 and this task stayed in 4.1.0.
- Preset (shipped by TSK-400 in EPC-022 for 3.2.0 since 2026-10-18, because
  issue 171's adopter keeps its own deny rules until it ships; this task
  composes `project_actions` with it): `security.project_action_presets:
  ["infrastructure"]`, off by default (decision 5): `tofu` and `terraform` `apply`, `destroy`,
  `import`, `state rm`, `state mv`, `force-unlock`, `taint`, `untaint`;
  `gcloud` verbs `create`, `delete`, `update`, `deploy`, `set-iam-policy`,
  `add-iam-policy-binding`, `remove-iam-policy-binding`, `enable`,
  `disable`; `kubectl` `apply`, `create`, `delete`, `patch`, `replace`,
  `scale`, `edit`, `rollout`, `drain`, `cordon`, `taint`; `flux` as a whole
  program; `helm` `install`, `upgrade`, `uninstall`, `rollback`; `pulumi`
  `up`, `destroy`, `import`, `refresh`. `update` reports a changed preset.
- Both keys are schema and defaults only (TSK-280).

Native rendering of these entries into the Claude and Codex rule files, and
its `full` or `partial` coverage report, is TSK-321.

## Acceptance Criteria

- AC-1 Policy validation shall accept a well-formed `project_actions`
  entry and refuse a shipped family id and two entries with one id and
  different content; evidence: tests. (serves EPC-023 AC-6)
- AC-2 A token corpus shall pass: options before, between and after
  command words, attached values, unknown boolean options, `--`, each
  wrapper exec-guard unwraps, allowed read controls and refused mutations;
  evidence: the corpus test. (serves EPC-023 AC-6)
- AC-3 An undeclared option before a command word shall refuse as unproven
  with the stated remedy, at the `outward_actions` level; evidence: tests
  at `block` and `warn`.
- AC-4 `program`, `commands` and `verbs` shall match as stated, with the
  basename and the shipped unwrapping kept; evidence: tests per form.
- AC-5 The typed composition API, as extended to `project_actions`, shall
  union deny lists by id and intersect exception lists, the guards shall read landed policy and `ci`
  the target's; evidence: unit tests of the API and a test where a branch
  removes an entry the target holds.
- AC-6 Project-declared entries shall compose with TSK-400's
  `infrastructure` preset by union, under AC-1's id rule, and the
  `project_actions` key shall be schema and defaults only; evidence:
  tests. (The preset's own criteria moved to TSK-400 on 2026-10-18.)
  (serves EPC-023 AC-11)
- AC-7 When the installed guards run in a scratch project that declares
  `terraform apply`, `terraform -chdir=infra apply -auto-approve` shall be
  refused and `terraform plan` allowed (journey); evidence: the journey
  output.
