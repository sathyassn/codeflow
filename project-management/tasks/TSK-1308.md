# TSK-1308: A landed candidate branch is removed by tree-equality proof

## Description

A landing candidate branch whose tree landed on its line stays behind when the line got the same tree through another commit, so its commits are not reachable from the line and the ordinary merge proof fails. Local branches candidate/epc-022-c3b, c3b-full, c3b2, c3b3 and c3b4 are in that state on 2026-11-03. This task adds a sanctioned removal: a candidate branch can be removed when its tree equals a tree on the line's first-parent history, proved from the commit objects. Non-goal: any task branch, which keeps today's merge proof.

## Outcome

After this merges, whoever landed a candidate can remove its leftover branch with a recorded proof, without arguing from its name or age.

## Deliverables

- The proof and the removal route: provisional home in the worktree and branch cleanup code the `codeflow` CLI already has; AC-1 decides.
- Guidance: `.codeflow/rules/worktrees.md` "Cleanup".

## Acceptance Criteria

- AC-1 Before any change, the builder shall name the existing cleanup route and the guard rule that refuses this removal today, reproduced on a fixture; evidence: the refusal output and file:line.
- AC-2 A branch of the project's candidate naming shall be removable when its tip's tree equals the tree of a commit on the target line's first-parent history, checked from the commit objects at a freshly fetched tip; evidence: a positive fixture for a line that got the same tree through a different commit.
- AC-3 The removal shall be refused, naming the cause, when the trees differ, the tree is on a side branch only, the line or the branch cannot be read, the branch has an open pull request, a worktree uses it, or the branch is not of the candidate naming; evidence: one negative fixture per case.
- AC-4 The removal shall record the branch, its tip, the matching line commit and the tree in the ledger; evidence: an output and ledger test.
- AC-5 The candidate naming and the depth of history searched shall be project settings with defaults, not hardcoded; evidence: tests for the default and an override.
- AC-6 The cleanup guidance shall name this route as the merge proof for a candidate branch; evidence: the text diff.
- AC-7 (journey) The branches named in the Description that still exist when this lands shall be removed through this route; evidence: the command output. Cross-lineage security review, as this changes what a guard allows.
