# TSK-041 — repair contract and scaffold defects

## Description

The documentation pass surfaced nine places where the scaffolded artifacts,
settings presets and CLI help strings disagree with the code they claim to
describe — a CI PATH that assumes a default `CARGO_HOME`, presets with no
ask-tier entry for graphical privilege escalation, inventories that miscount
the guard planes, and help text that omits real events, checks and paths. This
task repairs all nine with the expected behaviour recorded in this record
before any edit, each carrying its own positive and negative regression test.
Non-goal: no new policy surface, no new plane and no relaxation of an existing
prohibition — the privilege-escalation entries are ask-tier only, never allow,
and the non-relaxable prohibitions and the fail-closed sandbox stay exactly as
they are and are re-tested to prove it.

## Affected surfaces and interfaces

`assets/base/ci/*`, `assets/base/settings/*.json`, `.claude/settings.json`,
the managed text in `assets/base/AGENTS*.tmpl` and `CLAUDE*.tmpl` and the
corresponding managed blocks in `AGENTS.md` and `CLAUDE.md`, help strings in
`crates/codeflow-cli/src/main.rs` and `crates/codeflow-cli/src/cmd/hook.rs`,
the `.claude/workflows/pipeline.workflow.js` example, and
`docs/decisions/ADR-0018` by clarifying-note append only if the append-only
contract permits it — otherwise the clause lands in `AGENTS.md` instead.

## Acceptance Criteria

- [x] Defect 1, CI template PATH: when `CARGO_HOME` is set to a non-default
      location, the four scaffolded CI templates shall resolve cargo binaries
      via `${CARGO_HOME:-$HOME/.cargo}/bin`; evidence: the ci-perimeter template
      canary asserts the expanded form in all four files and fails on the bare
      `$HOME/.cargo/bin` form.
- [x] Defect 2, privilege escalation: the three settings presets shall match
      `pkexec`, `gsudo`, `runas` and `Start-Process -Verb RunAs` at the ask
      tier and never at allow; evidence: the settings preset parse test asserts
      ask for each pattern, fails if any is promoted to allow, and a companion
      assertion shows the non-relaxable prohibitions and the fail-closed sandbox
      defaults unchanged.
- [x] Defect 3, guard planes: the minimal-tier inventories and the AGENTS
      four-plane paragraph shall name `.grok/hooks/` as part of the existing
      in-session guard plane, not as a fifth plane; evidence: the scaffold test
      asserts the plane count stays four and that `.grok/hooks/` appears inside
      the in-session plane's inventory.
- [x] Defect 4, `hook --help`: `codeflow hook --help` shall name all four
      delegate events; evidence: `hooks_cli` asserts each of the four event
      names is present and fails when one is removed.
- [x] Defect 5, `doctor --help`: the `doctor` help text shall be derived from
      the check registry rather than a hand-maintained list; evidence:
      `hooks_cli` (or the doctor CLI test) asserts help output equals the
      registry's check names, and adding a fixture check changes the help.
- [x] Defect 6, pipeline example: `.claude/workflows/pipeline.workflow.js` shall
      name `opus` where it currently names `sonnet`; evidence: the scaffold test
      asserts the example model id and fails on `sonnet`.
- [x] Defect 7, AGENTS mechanics row: the mechanics row shall include
      `estimate`, `policy` and `ci`; evidence: the scaffold test asserts the row
      contents against the registered subcommands.
- [x] Defect 8, ADR-0018 clause: the instruction-only nature of ADR-0018 shall
      be stated once, as an appended clarifying note to ADR-0018 if append-only
      permits, otherwise as a clause in `AGENTS.md`; evidence: the managed-block
      parity test shows exactly one home for the clause and ADR-0018's existing
      text is unmodified.
- [x] Defect 9, `git-hook` help path: the `git-hook` help shall print the path
      the command actually installs to; evidence: `hooks_cli` compares the help
      string against the path constant used by the install code.
- [x] The whole task head passes full `codeflow test`, `codeflow validate
      --docs` and `codeflow doctor --check managed-drift`.
