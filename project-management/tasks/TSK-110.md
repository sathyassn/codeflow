# TSK-110: aggregate journey gate and benchmark

## Description

Each task ships its own deterministic journeys. This task adds the final
gate target that aggregates them (design v4 section 10) and the benchmark and
budgets of section 11. The gate runs every journey with a passing control
and a fault that fails for the stated reason, including the ones that span
tasks: repeated `codeflow update`, a no-remote project end to end, the
standard tier without records, and read commands making no network calls.
The benchmark covers 10,000 records across ten lines and thousands of stale
branches; its first run sets the latency and memory budgets, which are then
guarded against regression. No figure is claimed before it is measured.

## Affected surfaces and interfaces

- Test targets under `crates/`, the CI workflow (gate job, Windows job).
- Read commands: `status`, `work next`, `validate`, `orient` (CAP-010).
- Shared files this task edits: the CI workflow (gate job). Ownership follows SPC-013 R-118.
