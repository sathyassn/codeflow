# TSK-1609: The release impact check judges a merged head against its event base

## Description

Source: Director ruling 2026-11-25 (`msg_bfd07dbccb44`), from Chief's finding on pull request 940's run 45613795761; diagnosis in `coordination/coordinators/planning/notes/pr940-release-impact-red.md`. Priority: P3, no work now.

The `trusted: release impact` step fetches `origin/main` when it runs and judges the pull request against that live target (`current_base`, `scripts/release.py:1259`). When the pull request merges before the step runs, the target already holds its changes, the computed impact is "none", and the step fails a correct declaration. So the current choice of base causes a false failure after a fast merge, which can hide a real one. The change proposed here prevents that false failure.

Non-goals: any change for a head the target does not contain.

## Outcome

After this merges, a pull request that merged before its check ran is judged against its event base, so the check reports on what the pull request changed. A head the target does not contain is judged against the current target as before.

## Deliverables

- `scripts/release.py`, `check-pr`: when the target contains the head, the event base is the base of the judgement; otherwise unchanged
- tests in the release script's suite for both cases
- release note: `changelog.d/TSK-1609.md`

## Estimate

- Grade: Small; band: Small; moved: none
- Split: not needed.
- Basis: one base choice and its tests. Graded by `coord/planning`; builder re-scores at claim.

## Acceptance Criteria

- AC-1 When the target ref contains the pull request's head and the declaration matches its fragments, `check-pr` shall pass and shall name the event base as the base; evidence: test output, fail-before and pass-after.
- AC-2 When the target ref contains the head and the declaration does not match its fragments, `check-pr` shall fail with the same message as before; evidence: test output.
- AC-3 When the target does not contain the head, the base and the verdict shall be the same as before this change, including a target that moved after the event base; evidence: the existing tests pass unchanged and one new test for a moved target.
- AC-4 A head the target does not contain shall never be judged against any base but the current target; evidence: a test and a cross-lineage review of the exact head.
