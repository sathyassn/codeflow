# TSK-1528: Cargo takes the libz-sys release past the second zlib advisory

## Description

Source: coord/ci's report of advisory RUSTSEC-2026-0544 against `libz-sys`, relayed to coord/records on 2026-11-17. Filed by coord/records. TSK-1069 made the same move for RUSTSEC-2026-0418, to `libz-sys` 1.1.31.

Checked here, at origin/main `ec8d5c1ab3`:

- `Cargo.lock:965-966` resolves `libz-sys` 1.1.31.
- The only dependent in the lock is `libgit2-sys` 0.18.7 (`Cargo.lock:942-950`), reached through `git2` 0.21.0.
- The security review job pins osv-scanner 2.4.0 (`.github/workflows/codeflow-ci.yml:1959`).

As coord/ci reported, not checked here (this session has no network):

- RUSTSEC-2026-0544 affects the resolved 1.1.31, so the dependency audit fails on it.
- 1.1.33 is the fixed version.
- The exact affected range, the flaw itself and whether a CodeFlow build is exposed are coord/ci's report; the builder confirms each from the advisory and records it in the pull request body.

This task moves `Cargo.lock` to `libz-sys` 1.1.33 with no other dependency change and no audit suppression. Non-goals: other dependency upgrades, and changes to the audit step or its policy.
