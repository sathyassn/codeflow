# TSK-1465: The decision-map figure stays true as the decision count grows

## Description

`codeflow test --only docs-portal` fails on `main` 63061d210 and on 4cc6de60a: "docs-portal/figures/decision-map/technical.json: rule 6 (fidelity): fact "70 decisions, 3 superseded" draws true but docs/decision-map.md#technical gives false". PR 772 brought `docs/decision-map.md`'s count sentence to its table's 75 rows; the figure's fact still checks for the text "70 decisions, 3 with `status: superseded`." (`kind: contains`, `technical.json:29-38` at 4cc6de60a). The check is `crates/codeflow-core/src/validate/portal/figures.rs:844`.

The defect has a cause beyond this one number. Every pull request that adds a decision updates the map's count sentence, and the figure repeats that sentence as fixed text, so each new ADR breaks the portal build until someone edits the figure by hand. A planning pull request cannot carry the figure edit, because a planning amendment admits only records and `docs/` paths (`work.classification`), and records-only evidence does not run the portal check, so the break reaches `main` unseen. That is what happened with PR 772.

Non-goal: no other figure's design changes beyond what AC-3 finds.

## Outcome

After this merges, `main`'s docs portal check passes, and a decision added to `docs/decision-map.md` no longer breaks a decision-map figure by changing the number of decisions the map lists. A decision that changes the map's supersession chains, by starting a chain or extending one, changes what the architecture figure draws, so it needs a figure edit and a figure review by design. The figure's chain facts (`docs-portal/figures/decision-map/architecture.json:41-67`) check substrings and the number of chains, so some chain changes, such as one more decision at the end of a chain, pass them while the drawing goes stale. Catching such a change automatically, and telling its author in the same pull request, is not built here.

## Deliverables

- the figure: `docs-portal/figures/decision-map/technical.json`
- the durable fix: the figure's fact checks a map row that a new decision cannot change, in `docs-portal/figures/decision-map/technical.json` (the builder's pick, with its reason in AC-2's amendment)
