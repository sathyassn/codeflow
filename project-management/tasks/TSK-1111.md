# TSK-1111: Figure frames, stat tiles, titled callouts, labelled code and disclosure chips are catalog blocks drawn once for both surfaces

## Description

The design audit of 2026-10-31 (Source, below) found that the figure chrome
is a review fixture fixed in the renderer: a mono "Figure N" label and uppercase mono kicker
(`render.rs:654-660`, `styles.css:810-816`, `figure.css:9-10`), a legend as
"label: means" text with no mark (`render.rs:676-696`), and Details as one
escaped paragraph (`render.rs:702-705`; `document-authoring.md:204-208`
caps it at 2000 characters). Every figure opens with code-looking chrome,
legends cannot show what a mark looks like, and Details cannot hold a list,
a table or a figure.

This task makes the frame read as part of the page: the number and kicker
leave mono (the kicker becomes a subtitle line in the body face), legend
entries gain a `mark` and the key is drawn, Details renders Markdown or
nested blocks with chips on its summary, `figure.css` stays shared byte for
byte with the portal and a parity test proves it. The sanitiser boundary is
unchanged: Details content is inert Markdown or catalog blocks, never raw
HTML. Non-goal: stage at-rules (TSK-1112). The stat tile, titled callout, labelled code and chip blocks, once TSK-1113's non-goal here, are this task's since the 2026-11-04 consolidation (AC-8 to AC-13).

Consolidated 2026-11-04 (operator ruling of 2026-11-04, consolidation planning amendment): this task absorbs TSK-1113, because both are catalog blocks drawn once in the grammar module for present and the portal, through the narrative sanitiser, proven by the same parity test and specimen renders (EPC-022 AC-187). TSK-1113's criteria follow this task's own, word for word, each with a `Moved` note naming its old id; its deliverables are listed under Deliverables with `(from TSK-1113)`, and its Description stays in its cancelled record.

Text fixes 2026-11-04 (second consolidation amendment, from the criteria check of PR 596 at cf2f806da): the title, the Outcome, the Non-goal, the chips deliverable and the Edges line now name the TSK-1113 blocks this task absorbed. Earlier title: "Figure frames read as part of the page with sans labels, keyed legends and rich Details". Earlier Outcome ended at "a list, a table or a nested figure"; the earlier Non-goal excluded "new block kinds (TSK-1113)"; the chips deliverable said TSK-1113 draws them; the Edges line said "TSK-1113 and TSK-1114 depend on it".

## Outcome

After this merges, a figure in cf-present or the portal opens with a readable label and subtitle, its legend shows each mark, and its Details can hold a list, a table or a nested figure; and an author can write a stat tile, a titled callout, labelled code with a copy button and disclosure chips, each drawn once for both surfaces.
