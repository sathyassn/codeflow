# TSK-137: unwired security code and inert policy key removed

## Description

Six security modules (`git`, `path`, `fileops`, `branch`, `tmp`, `network`)
and `SecurityChecker`, about 2,400 lines, are marked unwired with no
production caller; the `human_authorization` policy key accepts only `none`;
every sandboxed command prints a registry-touch warning; and exec-guard
blocks removal inside the agent's own temp root. This task removes the dead
code and the inert key without breaking adopters who have the key, amends
ADR-0008 and ADR-0009, silences the warning, and exempts the temp root.
Source: guardrails strand rows 16, 18, 19 and 33.

## Affected surfaces and interfaces

- `crates/codeflow-core/src/security/`; `hooks/policy_schema.rs`;
  `assets/base/policy.json`, `.codeflow/policy.json`; `codeflow update`.
- `docs/decisions/ADR-0008-harness-parity-and-exec-guard.md`,
  `ADR-0009-human-authorization-out-of-band.md`.
- `crates/codeflow-cli/src/cmd/mod.rs` and `main.rs` (registry touch);
  `hooks/exec_guard.rs`, `security/dangerous.rs`.

## Acceptance Criteria

- [x] AC-1 Modules under `security/` with no production caller shall be
      removed, those exec-guard uses stay, and the workspace shall build and
      pass clippy; evidence: a caller search in the pull request, `cargo
      build` and clippy.
- [x] AC-2 `human_authorization` shall be gone from the schema and the
      scaffold policy; a policy that still has it shall load with one
      deprecation warning, and `codeflow update` shall remove it; evidence:
      policy loader and update tests.
- [x] AC-3 ADR-0008 and ADR-0009 shall carry dated amendments saying what
      was removed and why; evidence: the ADR diffs.
- [x] AC-4 The registry touch shall be skipped for hook, ci and read-only
      commands and stay silent on a permission error; evidence: a CLI test
      under a read-only registry directory.
- [x] AC-5 exec-guard shall allow removal under `$TMPDIR` and the per-user
      temp root, and still block the same command on system directories;
      evidence: `hooks_cli` tests for both.
- [x] AC-6 In a freshly scaffolded project at every tier (minimal, standard,
      full) the policy shall validate without the key; evidence: `init_e2e`
      and `tier_floor_e2e`.
