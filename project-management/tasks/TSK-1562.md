# TSK-1562: The git guard's hook integrity checks judge the command behind every launcher

## Description

Source: the Director's request of 2026-11-20 (about 02:xx), from a finding of coord/catalog's TSK-1536 round 20 Worker. Filed by coord/records. coord/records did not read the finding itself; the claim below is the Director's relay and must be reproduced by the premise before any change.

Claim: the hook-integrity checks of the git guard (the rule `git.hook_integrity`) do not see the command behind a launcher, so a hook-integrity operation placed behind a launcher is judged as the launcher and not as the operation it runs. The concrete forms are kept in a coordination note that does not reach GitHub, and go to the builder with the brief. The exec guard models launchers (`launcher_commands`, `strip_launchers`, `launcher_effects`, `launcher_name` in `crates/codeflow-core/src/hooks/git_guard.rs` at the line tip 7a9692b9a5), so the table exists; these checks do not read it.

Premise: before any change, read the hook-integrity checks and the launcher functions, say which launchers the exec guard models today, and run each hook-integrity form, bare and behind each launcher the table lists, as an inert string through the guard to see each verdict. The forms and the launcher list are in the coordination note named above. Do not run a payload.

Non-goals: adding launchers the table does not model (a launcher the table does not model fails closed instead, below); changing the launcher table's membership except where a launcher the exec guard already models is missing from it; any other guard rule.

## Outcome

After this merges, every hook-integrity check judges the command behind each launcher the exec guard models, from one shared launcher table, and refuses (fails closed) behind a launcher it cannot model.

## Deliverables

- the premise answers: the launchers modelled today and, for each hook-integrity form, today's verdict bare and behind each launcher
- the hook-integrity checks reading the command behind a launcher from the shared launcher table (no second copy of the table)
- guarded tests: each form behind each modelled launcher refused as the bare form is, and an unmodelled launcher in front of a hook-integrity form refused, fail-before at a tests-only commit
- the changelog fragment `changelog.d/TSK-1562.md`
