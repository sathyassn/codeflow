# TSK-127: a moment-keyed root map from one kernel source

## Description

The managed AGENTS.md is 28.7 KB (standard template) and 16.4 KB (minimal),
written as doctrine, and the rules that failed in practice (human-calendar
estimates, ID-first status, no cf-present) sat one voluntary hop away with
nothing firing. This task replaces it, at every tier, with an 8 to 10 KB
moment-keyed map rendered from one kernel source: at most 12 one-line hard
rules with pointers, a "when you are about to" table, and the six-layer
table. Doctrine moves to references one hop away. The map leaves room under
Codex's 32 KiB instruction limit for the adopter's own project section.
Source: research map Part 3; guidelines strand top five item 2.

## Affected surfaces and interfaces

- Kernel source (new, one file) and the rendered `assets/base/AGENTS.md.tmpl`,
  `AGENTS.minimal.md.tmpl`, CLAUDE templates; this repo's `AGENTS.md`
  regenerated by `codeflow update`.
- New references one hop away: workflow discipline, worktrees, git rules,
  writing (one reference for chat replies, status, IDs and figures by
  harness); owning SKILL.md files for doctrine now in entry-point cells.
- `codeflow doctor` (instruction size check); `.codeflow/manifest.json`;
  `artifact_budget_contract.rs`, `orchestration_contract.rs`, `init_e2e.rs`.
- Workspace `CLAUDE.md` in the agentic-systems repository (route line).

## Acceptance Criteria

- [ ] AC-1 When any tier renders AGENTS.md, it shall come from the one
      kernel source, and its managed block shall be at most 10,240 bytes
      with at most 12 one-line always rules, each with a pointer, and a
      "when you are about to" table keyed on moments (estimate, status,
      explanation, plan, design, build, branch, ship, consult, instruction
      change, resume); evidence: a generator test that fails when a template
      drifts from the kernel, and `artifact_budget_contract`.
- [ ] AC-2 The always rules shall include: agent-delivered durations come
      from cf-estimate, never human weeks, sprints or person-days; replies
      lead with outcomes in words with IDs after; a multi-part explanation
      goes through cf-present where the harness can show it; orchestration
      entry is decided by touched paths; evidence: the rendered map text and
      a pinned-sentence test.
- [ ] AC-3 Every duty removed from the inline text shall have a home in a
      duty map (kept, moved with pointer, or enforced by a named check), and
      the existing pinned-duty tests shall pass with pins re-pointed, none
      deleted; evidence: the duty map in the pull request, reviewed before
      landing, and `orchestration_contract`.
- [ ] AC-4 Every pointer in the map shall resolve to an existing file or
      skill at the tier that renders it; evidence: a pointer-integrity test
      over each tier's rendered map.
- [ ] AC-5 When a project is scaffolded at each tier with a realistic 16 KiB
      project section, the whole AGENTS.md shall be at most 32 KiB so Codex
      reads the project section in full, and `codeflow doctor` shall warn
      when an AGENTS.md exceeds 32 KiB; evidence: a scaffold test per tier
      and a doctor test.
- [ ] AC-6 In a freshly scaffolded project at every tier (minimal, standard
      and full where it applies) the map, its references and the CLAUDE file
      shall be installed, and `codeflow update` on a project scaffolded from
      the previous templates shall replace the managed block and keep the
      project section and explicit values; evidence: `init_e2e` and an
      update test per tier.
- [ ] AC-7 The workspace CLAUDE.md shall carry one route line: for codeflow
      work, run the session from `codeflow/` or use `/add-dir codeflow`;
      evidence: the workspace commit on `docs/workspace`.
