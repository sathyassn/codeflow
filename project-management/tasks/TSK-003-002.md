# TSK-003-002 — implement fail-closed model selection

## Description

Add a bounded, reference-only project selection file and deterministic resolver.
The resolver must accept only local full-suite-qualified records for the exact
stable role and lineage, remain inert when absent, and make every invalid active
selection a hard doctor failure.
