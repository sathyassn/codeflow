# TSK-1398: Agent sessions refuse the git and merge actions ADR-0075 records

## Description

ADR-0075 records refusals for agent sessions that no task built. An audit
of every refusal the ADR states, against the code and tests at the line's
96a01e17e, found most of them built and five missing or partly built:

| Refusal (ADR-0075 line) | At 96a01e17e | Why it was never built |
|---|---|---|
| `git pull` refused in agent sessions; integrate by fetch, then a merge or rebase (72, 332-334) | missing: no git-guard rule refuses pull itself | TSK-172 AC-10 and AC-26 carried it; TSK-172 was cancelled and TSK-188 and TSK-189 took its scope without it |
| a push that would bring a workflow change to its destination, judged from the destination's own refs (D9 at 267, 72) | missing: no push-side check | TSK-172, cancelled |
| server-side landing: deferred merge modes, the administrator override and pull requests that change enforcement entries refused (205-211, 317-320) | partly built: `check_gh_pr_merge` (`crates/codeflow-core/src/hooks/git_guard.rs:12229`) refuses only branch deletion and a protected base | TSK-172, cancelled |
| a merge or rebase whose changed paths select a custom merge driver, a defined filter or renormalization (196-202, 334-335) | partly built: a config write that sets such a driver or filter is judged (`crates/codeflow-core/src/security/git_config_writes.rs`), a merge that uses an existing one is not | TSK-172, cancelled; TSK-242 built the config side |
| delegated seats deny the unsandboxed retry natively (decision 6 amendment, 418) | missing: the delegate lane text still permits it (`.agents/skills/cf-delegate/resources/lane-lifecycle.md:56-59`) | TSK-174, cancelled |

An agent session is one where any name in `AGENT_MARKERS` is set
(`crates/codeflow-core/src/root_checkout.rs:54`); a human terminal is
unaffected by every refusal here.

The server-side landing and merge driver rules sit in decision 5, which the
2026-10-03 amendment drops as a whole (line 434), while the consequences at
317-320 and 334-335 still state both rules. This task keeps them, failing
closed, and its ADR records that reading (AC-7). The two remedy texts that
recommend a rebasing pull (`crates/codeflow-core/src/remedy.rs:459`, `:651`) are fixed in TSK-1393,
not here.

The audit table lands in this record; the per-command detail for each
refusal lands in this task's own pull request with the fix.

Not in scope:
- TSK-1393's refusal of rebasing and merging pulls on a protected branch; this task widens the pull refusal to every branch in agent sessions and builds on it.
- The token and GitHub App half of D9, which is operator setup.
- The dropped mechanisms the amendment names (baseline, binding registry, readiness receipts, operator queue, fixture root).

## Outcome

named, every git and merge action ADR-0075 says agents do not take, while a
human terminal behaves as before.

## Acceptance Criteria

- AC-1 In an agent session, git-guard shall refuse `git pull` in every form on any branch, naming fetch followed by a fast-forward-only merge or a rebase; plain fetch shall pass; evidence: unit tests failing before and passing after, per form, with fetch as the control.
- AC-2 In an agent session, a push that would bring a workflow change to its destination shall be refused before anything transfers, judged against the destination's own advertised refs read once, never a local tracking ref; when that evidence cannot be read, the push shall be refused naming the fetch or retry; evidence: tests against a local bare remote with and without a workflow change, and with the destination unreadable.
- AC-3 In an agent session, git-guard shall refuse a server-side merge in a deferred mode, with the administrator override, or of a pull request whose commits change enforcement entries or whose head's entries differ from the base's, and shall pass an immediate merge with the head pinned when the entries are unchanged; a case the guard cannot judge shall be refused; evidence: tests with a stub `gh`.
- AC-4 In an agent session, a merge or rebase whose changed paths select a custom merge driver (by its effective definition), a non-built-in default driver, a defined filter or renormalization shall be refused before git runs it, naming the operator's route; evidence: tests with the attribute and the config present, and a plain merge as the control.
- AC-5 Delegated seat presets shall deny the unsandboxed retry through each harness's native configuration, and the delegate lane text shall match; evidence: a preset test and the text diff in both mirrors.
- AC-6 Each refusal in AC-1 to AC-4 shall pass unchanged when no agent marker is set; evidence: a human-terminal control per refusal in the same tests.
- AC-7 An ADR-0075 amendment shall state that the server-side landing and merge driver refusals hold after the decision 5 drop, and the policy reference shall list each refusal with its route; evidence: the ADR and `docs/policy-reference.md` diffs.
- AC-8 (journey) In a scratch adopter made by `codeflow init --standard` with the installed build, an agent session's pull, workflow push, deferred server-side merge and driver-selecting merge shall each be refused through the installed hooks and guards, and the same commands shall pass from a human terminal; evidence: the journey output in the pull request body.
