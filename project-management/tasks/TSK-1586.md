# TSK-1586: Home paths with a user name in added content and paths are privacy findings

## Description

Owner: to be assigned by the Director. Staged 2026-11-23 for coord/records.

SPC-018 R-15. Logs, transcripts and configs pasted into a repository
carry `/Users/<name>/...` or `/home/<name>/...`. CodeFlow's own records
already use the placeholder form (`TSK-141.md:65` at `origin/main`: "a
home path such as `/Users/<name>` or `/home/<name>`"). The detector flags
a home path whose user segment is not a placeholder form; layer 3 adds
the exact local user name (EPC-060).

Non-goals: Windows enforcement beyond the `C:\Users\<segment>` text form.

## Outcome

After this merges, `/Users/<segment>`, `/home/<segment>` or
`C:\Users\<segment>` with a non-placeholder segment, in added content or
in an added path, is a `privacy.patterns.home_path` finding.

## Deliverables

- `crates/codeflow-core/src/privacy/patterns/home_path.rs` (new) with unit tests
- placeholder rows in the TSK-1583 table; docs; `changelog.d/TSK-1586.md`

## Acceptance Criteria

- AC-1 Fail before: at the base, a commit adding a log line with `/home/` followed by a non-placeholder segment (assembled at run time) is accepted; evidence: the base output in the PR.
- AC-2 Pass after: it shall be a finding at the level, in content and in an added file path, in POSIX and Windows spellings, quoted and unquoted, and inside a `file://` URL; evidence: detector and hook tests.
- AC-3 `/home/<user>`, `/Users/$USER`, `/home/${USER}`, `%USERPROFILE%`, `~/notes.txt` and the table's placeholder words shall pass; evidence: tests per form.
- AC-4 `/home` and `/Users` with no segment, and system accounts the table lists, shall pass; evidence: tests.
- AC-5 A finding on an added path whose folder or file name holds the user segment shall print that path with the segment replaced by `<home>` (SPC-018 R-7a) in every hook, the CI annotation and doctor, and the path canary of TSK-1583 AC-6, run with a non-placeholder home segment only in an added folder name, shall find it nowhere; evidence: output tests per surface and the path canary.
