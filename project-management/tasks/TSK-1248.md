# TSK-1248: Prove on hosted runs that main reuses exact-tree evidence and caches only its own builds

## Description

Source: the CI throughput study of 2026-11-02 and the Director's decision on PR 528 (TSK-1240, the commit standards build cache), re-scoped by the Director's ruling at 07:16 on 2026-11-03 that main's run never saves a cache from integration output. TSK-1240 is now (a) exact-tree evidence reuse by the main-ref check and (b) main-only caches (its AC-2 to AC-8). Those criteria need hosted runs on `main`, which cannot exist before the change reaches `main`. This task owns that hosted proof, and TSK-1240's follow-ups cite it.

Non-goals: any change to the cache design or the workflow (TSK-1240), and admission (TSK-1239). A mismatch kind that cannot be provoked on a hosted run is named in the Findings with its reason and stays covered by TSK-1240's tests.

## Outcome

After this merges, the hosted behavior of main's cache and of the exact-tree evidence reuse (hit, miss, moved SHA, refused integration save, accepted and refused evidence) is recorded with run links and durations.

## Deliverables

- the evidence record: run links, hit or miss, durations, in this task's `## Findings`
- the mismatch kinds that cannot be proven on hosted runs, each with its reason and the TSK-1240 test that covers it: this task's `## Findings`
- when a run does not behave as TSK-1240 requires: a defect record with the run evidence

## Acceptance Criteria

- AC-1 On two consecutive pushes to main, the second shall restore main's cache with a shorter job time, and a moved main SHA shall miss and rebuild; evidence: run links and durations in the Findings. (serves TSK-1240 AC-2 and AC-6)
- AC-2 A hosted run in which an integration push tries to save a main-scope cache shall be refused or shall not save; evidence: the run link and the cache listing showing no main-scope entry from integration output. (serves TSK-1240 AC-3)
- AC-3 One accepted exact-tree evidence reuse on the main-ref check, and at least one hosted refusal on a mismatch, shall be recorded; any mismatch kind not provable on hosted runs shall be named with its reason and the TSK-1240 test that covers it; evidence: run links and the named list in the Findings. (serves TSK-1240 AC-7 and AC-8) (journey)

## Criteria changes

Reasons for every removed or changed criterion line (Director ruling, 07:16 on 2026-11-03: main's run never saves a cache from integration output):

- Criterion AC-1 changed: it proved a hit and a miss on two consecutive policy events; it now proves them on two consecutive pushes to main, matching TSK-1240 AC-2 and AC-6.
- Criterion AC-2 changed: it proved a moved target rebuilds; the moved main SHA now sits in AC-1, and AC-2 proves the refused integration save of TSK-1240 AC-3.
- Criterion AC-3 changed: it proved the integration push's job-token dispatch saving under main's cache scope, which the ruling forbids; it now proves the evidence reuse and its refusals of TSK-1240 AC-7 and AC-8.
- Criterion AC-4 removed: a pull request into the line reusing main's saved cache depended on the integration-built save the ruling withdrew; evidence reuse (AC-3) replaces it.
