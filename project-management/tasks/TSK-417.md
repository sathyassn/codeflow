# TSK-417: The shell reader keeps a quoted argument whole across newlines and braces

## Description

Issue #273 and its comment, on CodeFlow 3.1.1 (`48104f48b`) with the
Claude Code Bash tool. git-guard refuses
`L=/private/tmp/scratch; echo x | tee $L/probe5.log; python3 -I -c "\nprint(1)\n"`
under `git.hook_integrity`, naming the later quoted Python text as part
of the `tee` target ("targets the integrity path `the registered
worktree <worktree>/ (through `print(1)`)`"). The same line with a
literal tee path, `tee $L/x.log` alone, or a quoted string with no
newline each pass. With braces in the quoted text the refusal shows the
text brace-expanded, or says "a brace expansion too large to read"
(`crates/codeflow-core/src/hooks/git_guard.rs:2091`). The reader appears
to split the command into lines, or brace-expand it, before it accounts
for quoting, so a later quoted argument attaches to the unresolved
variable path. The comment adds a message defect: a list that combines a
`sed -i` on a variable path with `grep -c -E '^[0-9a-f]{64}  l1' $R` is
refused (expected, for the `sed -i`), but the message names the quoted
regex quantifier `{64}` as an enforcement path and claims a directory
read of more than 4096 entries.

Outcome: **inside quotes, a newline and a brace are part of one
argument: they never end a command, change another command's target or
expand; a `tee` to a path assigned earlier on the line resolves as it
does when no multi-line string follows; and a refusal names the operand
that caused it, never a quoted pattern from another command.**

Rules:

- The segmenter reads quoting before it splits on newlines or expands
  braces: a newline or `{...}` inside single or double quotes is text.
  An unquoted newline ends a command as today.
- Brace expansion applies to unquoted words only, and a quoted word
  whose text contains a brace is never read as a path glob or counted
  against the directory-entry limit.
- A refusal under `git.hook_integrity` names the writing command and the
  operand the judgment rests on (here `sed -i $R`), with the
  unresolved-word reason TSK-406 states; other commands' quoted
  arguments on the line do not appear in it.

Non-goals: the `sed` delimiter and address cases (TSK-415); making an
unresolved `sed -i` target pass (it stays refused where an enforcement
file is reachable).

Added by the EPC-022 amendment of 2026-10-22 under the operator's release
rule of 2026-10-18 (a defect that blocks work belongs in 3.2.0).

- AC-1 The issue's refused line (`L=/private/tmp/scratch; echo x | tee $L/probe5.log; python3 -I -c "<newline>print(1)<newline>"`) shall pass both guards, and so shall it with `print({k:1 for k in ('a','b','c')})` in the quoted text; evidence: guard tests, failing before the change. (serves EPC-022 AC-106)
- AC-2 A quoted newline or brace shall never end a command, attach text to another command's operand, expand, or count against the directory-entry limit, while an unquoted newline shall still end a command and an unquoted brace shall still expand; evidence: one test per position (single quotes, double quotes, a heredoc body, unquoted) on each guard. (serves EPC-022 AC-106)
- AC-3 `tee $L/x.log` to a path assigned earlier on the line, with and without a following multi-line quoted argument, shall get the verdict TSK-406 gives the assigned path, and `tee $L/x.log` where `$L` is assigned to a checkout's `.claude` shall stay refused; evidence: tests for both. (serves EPC-022 AC-106)
- AC-4 The comment's list (`sed -i ''` on `$R`, appends to `$R`, `grep -c -E '^[0-9a-f]{64}  l1' $R`) shall still be refused for the `sed -i`, and the message shall name `sed -i` and `$R` and shall not name `{64}` or a directory-entry count; evidence: a test on the message text.
- AC-5 Every refusal the segmenter gives today for unquoted multi-command lines, heredocs and brace expansions that reach an enforcement file (the TSK-373 and TSK-406 cases) shall stay refused; evidence: the existing tests passing.
- AC-6 (journey) With the installed build, an agent session shall run the issue's line and the brace variant and shall be refused `tee .claude/settings.json` on a line that also carries a multi-line quoted argument; evidence: the journey output.
