# TSK-078: integrate and verify the autonomy and catalog body

## Description

Verify the combined body on `integration/EPC-018-autonomy-roster` after
TSK-086 has merged `main` forward and recorded the harness guard.

1. If TSK-086's guard record selected TSK-083, wait for TSK-083 to land
   before step 4; if it resolved `not_selected`, confirm TSK-083 is
   `cancelled` and its tracked item exists.
2. Run the full gate, both validators, `codeflow ci`, the managed-drift
   doctor and `codeflow doctor --check model-bindings` on the head, and run
   `codeflow update` on a scaffolded sample to prove the catalog,
   `autonomy.md`, the amended contracts, skills and evaluation resources
   travel.
3. Run the native identity canary: launch each seat version and fallback the
   catalog holds by its pinned id and record requested versus observed id
   and effort; launch each line's alias once to discover whether the vendor
   now serves a newer version, and record any as "newer version observed,
   not designated". Record every result under `docs/verification/`; a seat
   that cannot be reached is recorded as unavailable, and a mismatch on a
   pinned launch is drift under the ADR-0069 rule, never a pass.
4. File the qualification follow-up: one tracked item that runs the native
   suite per designated seat version and adds qualification evidence to the
   catalog as each passes, with its event trigger (the first release
   candidate after EPC-018 lands on `main`, and each later designation).
5. Obtain the `body-review` duty: seat `codex-primary` review and seat
   `claude-primary` integrated judgment, seat `grok-primary` per the Q4
   policy, and the `design-and-editorial-review` duty as a second opinion.
   Then prepare the EPC-018 pull request to `main`, naming TSK-082 (Agent
   OS), the workspace seats and trust bullets, `RELEASE-PLAN.md`, EPC-015
   D21, the answers to Q1, Q2 and Q4, the qualification follow-up, and, if
   TSK-083 was not selected, the tracked harness item. The readiness report
   follows TSK-076's rule. A human lands it.

Non-goal: authoring; every defect returns to its owning task.
