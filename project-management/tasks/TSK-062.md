# TSK-062: evaluation cases for the visual doctrine

## Description

Grade the visual explanation doctrine in the evaluation kit so that an agent
that re-houses prose in boxes, picks a family that does not match the
relationship, carries a state by hue alone, answers a narrow width by
reflowing the wide marks, prints text over text, draws a mark under the
floor inside a state group, or declares a value its source does not hold is
caught by a blind case rather than by the operator. Add one hard requirement
per rule group (family choice, the no-box rule, the rendered two-channel
rule, narrow recomposition, overprint, the inner mark floor, fidelity, the
altitude contract) with source markers in the grammar resource, and blind cases whose prompts never name the
rule under test, each with a faulty control that must fail, graded from a
rendered fixture (the figure declaration and its rendered SVG) rather than
from what the subject says. Non-goal: native trials; those follow TSK-055's
phase B route.

## Affected surfaces and interfaces

`assets/base/agents/skills/cf-evaluate-model/resources/requirements.json`,
`cases.json`, `fixtures.json`, `packs.json` and the `.claude` and `.agents`
mirrors; `evals/model-artifacts/test_eval_kit.py` and the requirements
generator; `crates/codeflow-core/tests/model_eval_contract.rs` grading
inventory. CAP-013.

## Acceptance Criteria

- [ ] Eight hard requirements exist with markers that resolve verbatim in
      `figure-grammar.md`; evidence: the requirement fidelity test.
- [ ] At least twelve blind cases exist across the eight requirements, each
      with a faulty control that fails and at least two with a positive
      control that passes, graded on the fixture's declaration and rendered
      output; evidence: `validate-suite` and the grading inventory by set
      equality.
- [ ] A pack `visual-doctrine` registers them and states that registration
      proves nothing about live behaviour; evidence: `packs.json`.
- [ ] The kit tests and the workspace tests are green; evidence: the gate
      lines.
- [ ] Grok adversarial review of the cases for leakage of the rule under
      test into the prompt; evidence: the review record.
