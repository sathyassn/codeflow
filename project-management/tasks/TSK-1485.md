# TSK-1485: The EPC-024 line carries two advisory fixes

## Description

Two advisories turn codeflow-ci's "security review" red on every pull request into the EPC-024 line, so nothing reviewed can land there:

- RUSTSEC-2026-0486: `rustix` 1.1.4, fixed in 1.1.6. TSK-1432 fixed it on `main` (53cef268a) with a `Cargo.lock` change.
- RUSTSEC-2026-0459: the SQLite bundled by `libsqlite3-sys` 0.35.0. TSK-1407 fixed it on `main` (464103b94) by moving `rusqlite` from 0.37 to 0.41.1 in `Cargo.toml`, which brings `libsqlite3-sys` 0.39.1.

The line would get both through its next sync with `main`, but that sync waits for other line work. This task makes the same two changes on the line, as TSK-1475 did for `rustix` on the EPC-022 line. The changes equal `main`'s, so the later sync finds the entries already equal and neither conflicts nor counts the bumps twice.

Non-goals: any other dependency change, any audit suppression, and source changes beyond what the `rusqlite` 0.41 interface needs on the line's code. A changelog fragment is included only if the release impact check requires one, as it did for TSK-1475.

Source: coord/ci's request of 2026-11-12 15:03; modelled on TSK-1475.

## Outcome

After this merges, pull requests into the EPC-024 line pass the security review without suppressing either advisory, so the line's reviewed pull requests can land before its sync with `main`.

- this task's record
