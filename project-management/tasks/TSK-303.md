# TSK-303: A sample adopter's gates job runs the scaffolded workflow on GitHub

## Description

TSK-097 pinned the CI runner image and the actions in the scaffolded
workflow (pull request 177, merged as 4226a9408). Its fourth criterion, a
sample adopter's gates job running the new workflow on GitHub, was deferred
by the operator on 2026-10-13: owner the primary session, window before the
CodeFlow 3.2.0 qualification, follow-up TSK-303 (`project-management/tasks/TSK-097.md`,
its fourth criterion and Closeout). No sample adopter's gates job has run
the scaffolded workflow on GitHub, and the 3.1.0 qualification (TSK-205)
did not produce one.

This task runs it once, on the scaffold of the 3.2.0 candidate, so the run
also covers the workflow changes of TSK-292 and TSK-294. The sample is a
disposable repository on GitHub that the operator provides or approves; its
project is created with `codeflow init --standard` from the candidate
binary, and its gates job runs on a pull request. It pairs with the adopter
feature epic's install-on-clone task (issue 170), whose fresh-clone journey
needs a sample adopter too: one sample repository serves both, and either
task may create it. Non-goal: a standing adopter test fleet.
