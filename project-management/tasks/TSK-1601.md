# TSK-1601: The review lens, name warnings and keyed terms are proven together and documented

## Description

Owner: to be assigned by the Director. Staged 2026-11-23 for coord/records.

The epic's journey and its adopter page. One page in the docs explains
the five layers, which ones a project turns on, and how exemptions work,
pointing to the policy reference rather than repeating it.

## Outcome

After this merges, an adopter can read one page on the privacy check and
the installed build is proven for layers 1, 4 and 5.

## Deliverables

- `docs/privacy.md` (new) linked from `docs/policy-reference.md` and the docs portal navigation
- a journey script; `changelog.d/TSK-1601.md`

## Acceptance Criteria

- AC-1 (journey) With the installed build in a scratch standard-tier project: a `cf-reviewer` run on a change holding a non-placeholder example shall name it under the privacy question; with the engine installed, `privacy.names: warn` shall warn at pre-push on a placeholder person name in a changed Markdown line and at a local `codeflow ci --pr-body-file` run on a body file holding one, without it shall warn that the layer could not run, and with a slow stand-in shall skip over budget with its note while the push completes; evidence: the journey output, run on macOS and on Linux for layer 4.
- AC-2 The page shall state what each layer reads, what it never stores, its levels and the exemption route, and `codeflow validate --docs` shall pass; evidence: the diff and the run.
- AC-3 (journey, keyed terms) With the installed build, a key and a digest at the authority, and `privacy.terms: block`: a commit holding the term shall be refused, and a push of a range holding it shall be refused, without printing it; a commit made with `--no-verify` that holds the term shall be caught by the trusted terms job run in the form the managed workflow runs it (authority checked out, head fetched as data); that job with the CI secret missing shall fail closed naming the secret symbolically; and the content canary search over the journey shall find the term nowhere; evidence: the journey output, run on macOS and on Linux, and the workflow run or its local equivalent named under not_verified if a hosted run is not available.
