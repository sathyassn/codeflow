# TSK-1194: The docs portal builds a product site with a features home, feature captures and developer docs

## Description

Operator decision d8 (2026-11-02, confirmed by the Director at 12:14): the docs portal gains a product site mode. It has a features home, a screenshot or short clip per feature, and developer docs, built from the `cf-docs-portal` skill on the shared token source, at 390 and 1440 px, in light and dark. `TSK-1097:205` puts product design out of scope, which is why this is its own task.

It builds on the token source of TSK-1162 and the one navigation component of TSK-1160, so it depends on both. Product screenshots inside the developer docs pages, and the Markdown twins and `llms` files, are TSK-1195; a project's own brand tokens are TSK-1196. This task owns the features home, the feature pages with their capture, and the developer docs section of the site.

Non-goals: the Markdown twins and `llms` files (TSK-1195), brand tokens (TSK-1196), and CodeFlow's own marketing site.

## Outcome

after this merges, a project can turn on the product site mode of its docs portal and get a features home, a page per feature with a capture, and developer docs, readable at phone and desktop width in both modes.

## Deliverables

- the mode and its pages: `assets/docs-portal/starter/` and the `cf-docs-portal` skill (`assets/base/` and the `.claude/skills`, `.agents/skills` mirrors)
- a sample project and its product captures: `assets/docs-portal/starter/samples/` (provisional; the builder confirms the home with TSK-1127)
- tests: the site build, the capture check and the browser fit check
- docs: the skill's mode description
- release note: `changelog.d/TSK-1194.md`
