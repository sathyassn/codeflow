# TSK-1338: An away session claims, dispatches and lands work only under recorded checks

## Description

Split from TSK-1045 on 2026-11-04 by the stricter consolidation pass, by outcome. The design is TSK-1045's Description (the session system design, revision 12.3), which stays the one source: this task does not restate it. TSK-1045 builds the activation store, its owed items and notes, the digest line and `codeflow report away`. This task builds every unattended effect on that store: `work claim --away`, tick admission by watcher nonce, seat admission, dispatch, acknowledgement and replacement, owner-only commands, the time and scheduled-job rules, `away admit landing` and the admitted merge, `away start --from`, the `security_paths` policy key, the fault tests of the design's section 11 and the user's contract in the docs.

Non-goal: the store, the report and the digest (TSK-1045); the skill that drives the commands (TSK-1046).

## Outcome

After this merges, a session left to run without its user claims, dispatches seats, replaces a lost seat, renews its jobs and lands work into an integration line only when the activation admits each step first, and the user's contract for an activation is documented.

## Deliverables

- the effect commands in `crates/codeflow-cli/src/cmd/away.rs` (`away tick`, `away admit seat [--replaces <key>]`, `away seat ...`, `away admit landing`, `away landing --unblock`, `away watcher arm|renew ...`, `away start --from`), on the store TSK-1045 adds in `crates/codeflow-core/src/coord/away.rs`
- the claim: `work claim --away` in `crates/codeflow-cli/src/cmd/work.rs` and `crates/codeflow-core/src/workgraph/readiness.rs`
- the landing reads: the ruleset and bypass-actor read through the reader `codeflow doctor` uses (`crates/codeflow-core/src/doctor/remote_perimeter.rs`)
- the policy key: `security_paths` in the policy schema and loader, its default list in the shipped and this repository's policy files, and `docs/policy-reference.md`
- tests: CLI tests in `crates/codeflow-cli/tests/`, the reader fixture of AC-5 and the fault tests of AC-13
- docs: the two contracts and four preconditions (AC-14)
- release note: `changelog.d/TSK-1338.md`
- These lines were TSK-1045's Deliverables for the criteria that moved here; TSK-1045's own list is unchanged and names the shared homes.
