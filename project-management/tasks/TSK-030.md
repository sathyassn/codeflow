## Description

consumers without assuming entitlement or overwriting deliberate choices.

## Affected surfaces and interfaces

tests and corresponding managed distribution.
Codex owns this unit; root serializes shared manifests and release stamps.

## Acceptance Criteria

- [ ] Supported 1M-window/50-percent settings use the appropriate scope with
      explicit smaller-window consequences.
- [ ] Consumer customization preserves choice rather than silently imposing
      roughly 100K compaction on a 200K session.
- [ ] Merge/precedence, absent/malformed values and repeated updates are tested;
      native effective-context and bounded continuity evidence is recorded.
- [ ] Manual compaction is not automatic-threshold proof; no full-window burn,
      savings claim, global setting change or binding promotion occurs.
- [ ] Focused distribution tests and native review pass before integration.
