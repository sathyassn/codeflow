# TSK-1322: A claim whose push fails exits non-zero and leaves no claim behind

## Description

coord/ci reported on 2026-11-04 (11:4x) that `codeflow work claim TSK-1318`, run in a sandbox that blocks git credentials, created the local branch `task/TSK-1318-windows-fence-test-reads-process-handles-and-rep` at cecf1a03d, failed its push to origin ("could not read Username for 'https://github.com'"), and exited 0. A rerun with credentials then refused with "already claimed by a visible branch" (`crates/codeflow-core/src/workgraph/readiness.rs:1984`), naming the claim's own unpushed local branch. A failed claim reported success and then blocked its own retry.

In the source at the line tip, `claim_on` creates the local branch before the push (`readiness.rs:2016`) and maps a push failure to an error (`:2031`), which `work claim` turns into exit 1 (`crates/codeflow-cli/src/cmd/work.rs:318-324`). The reported exit 0 is therefore not explained by that path; this task first reproduces it with the binary that ran and finds its cause. Either way the local branch stays behind after the failure, and the retry counts it as another session's claim.

Non-goals: TSK-1308 (removing a landed candidate's leftover branch by tree-equality proof), and claims refused for a real remote branch, which stay refused.

## Outcome

After this merges, a builder whose claim fails to reach origin sees a non-zero exit with the reason, and running the same claim again completes it instead of refusing it.

## Deliverables

- the claim change and its tests: `crates/codeflow-core/src/workgraph/readiness.rs`, `crates/codeflow-cli/src/cmd/work.rs` and their tests
- the changelog entry: `changelog.d/TSK-1322.md`

## Acceptance Criteria

- AC-1 The reported exit 0 shall be reproduced or ruled out with the binary that ran (its path, version and source revision named), and its cause stated with file and line; evidence: the commands, their exit codes and the cause in this record.
- AC-2 When a claim's push to origin fails, `work claim` shall exit non-zero, print the push error, and leave no local branch it created; evidence: a test with an origin that refuses the push, checking the exit code, the message and that the branch is absent.
- AC-3 A claim shall never count its own branch as another claim: a local branch at the claimed name that has no remote counterpart, points at a commit the claim would start from, and holds no commits of its own shall be completed by a retry (pushed, with exit 0); a local branch that holds its own commits, or a remote branch of that name, still refuses; evidence: a test per case.
- AC-4 (journey) With the change built, a claim run where the push cannot authenticate exits non-zero and leaves no branch, and the same claim run again with access succeeds; evidence: both commands and their exit codes.
