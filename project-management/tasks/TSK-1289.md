# TSK-1289: The local gate reports a host browser fault as not runnable here, not as a failure

## Description

The local full gate's `present-browser` target fails on this host only on Firefox, while Chromium passes in the same run, and the gate reports that as a test failure. On 2026-11-03 (macOS 27.0.1, uptime 26 days) it failed this way on candidate c3b at 25d490c47 (gate run ca46792e and the browser-only run d6570862) and on candidate 536 at 2218c83b2 (gate 9ada4280).

- Firefox 153 (Playwright 1.62.1, revision 1538): "browserType.launch: Timeout 180000ms exceeded", with "sandbox_extension_issue_file_to_process failed ... plugin-container.app: 1 (Operation not permitted)" and "RenderCompositorSWGL failed mapping default framebuffer". A direct `firefox -headless --screenshot about:blank` hangs the same way, and a forced reinstall of the same pin did not help.
- Firefox 157 (Playwright 1.64.1, revision 1555, in a scratch cache): `firefox.launch` fails in 218 ms with "Could not find profile folder" for a folder Playwright had just created.
- Hosted Linux "codeflow gates (present)" is green at the EPC-022 tip 59c9ae965 (run 41637539351).

This task makes the gate tell a host fault at browser launch apart from a failing test. Scope: the `present-browser` target and its launch stage. Non-goal: fixing Firefox on this host, or skipping any test assertion.

## Outcome

After this merges, a maintainer whose local browser target cannot launch because of a host fault sees the gate report it as not runnable on this host, naming the browser and the host error, never as a pass, with the verdict naming the evidence that stands in for it: the hosted present job on the exact SHA.

## Deliverables

- launch-stage fault classification and the not-runnable result: the `present-browser` runner under `crates/codeflow-present/web/` scripts and the gate's result handling under `crates/codeflow-core/src/testing/` (provisional; the builder confirms the homes in a Findings section)
- the verdict's substitute-evidence line: the gate report code that prints the full-gate verdict
- tests: unit tests per classification case and a CLI test of the verdict
- release note: `changelog.d/TSK-1289.md`

## Acceptance Criteria

- AC-1 When a browser fails to launch with a known launch-stage signature (the launch timeout, a sandbox `Operation not permitted` on the browser's helper process, a missing profile folder Playwright created), the gate shall report that browser as not runnable on this host, naming the browser, its version and the host error, and shall not count it as a pass; evidence: unit tests per signature, failing before the change.
- AC-2 The fault shall be classified only from launch-stage signatures: a test assertion failure, a page error or a timeout after launch shall stay a failure; evidence: tests with each of those cases, failing before the change.
- AC-3 A not-runnable result shall fail closed for any candidate whose change touches the present, browser or package paths (`crates/codeflow-present/`, the browser scripts and their lockfiles, `package.json` files): the gate verdict is red; evidence: a test per path class, failing before the change.
- AC-4 For a candidate that touches none of those paths, the verdict shall name the substitute evidence, the hosted "codeflow gates (present)" job, and shall stay unproved until that job is green under the binding of TSK-1188 AC-4: CodeFlow finds the run itself through the API and never trusts a cited run id; the run is bound to the exact candidate SHA, the pull request number and base, the merge tree, a workflow blob equal to both the base line's and the default branch's, and the same verdict-deciding inputs, and was produced by trusted authority; and its browser coverage is complete, every browser the local target names (Chromium, Firefox and WebKit) having run to a result in that job. Anything else fails closed; evidence: tests with a matching bound run, a different SHA and a missing run, failing before the change.
- AC-5 When another browser in the same run launches and passes, the report shall keep that browser's pass separate from the not-runnable one; evidence: a test.
- AC-6 (journey) On this host, a full gate run on a candidate that touches no present path shall show Firefox as not runnable with its host error, Chromium as passed and the hosted present job named as the substitute for the exact SHA; evidence: the gate output, saved in the PR.
- AC-7 The substitute shall be refused, and the not-runnable browser shall count as unproved, for a forged workflow (a candidate that edits `.github/workflows/codeflow-ci.yml` so the present job passes without running the browsers), an altered verdict-deciding input, a run produced outside trusted authority, and a present job whose browser coverage is incomplete (Firefox skipped or missing from its results); evidence: one negative fixture per case, failing before the change.
