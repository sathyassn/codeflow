# TSK-386: Shipped CI scripts and the test harness remove their temporary directories

## Description

Source: found while landing PR 235 (TSK-371) on 2026-10-17 (workspace `RELEASE-PLAN.md`, 2026-10-17 late). The shipped CI scripts create temporary directories and never remove them: `assets/base/ci/ci-generic.sh:139`, `:178`, `:186`, `:196`; the GitLab template `.gitlab-ci.yml:182`; the Bitbucket template `bitbucket-pipelines.yml:177`, `:216`, `:224`, `:234`; and `assets/base/ci/codeflow-ci.yml:128`, `:291` and `codeflow-policy.yml:149`. The existing traps remove only the judge worktree. Hosted runners are discarded, but self-hosted runners fill up. This repository's own `ci_pin_platforms` tests run these scripts and left 61,216 `tmp.*` folders (about 4,800 a day) in the macOS user temp directory, which made the macOS guard case lookup slow enough to stretch guard suites past 30 minutes.

Outcome: **every shipped CI script removes every temporary directory it creates on success, failure and interruption, and this repository's tests run them under a private temporary directory they remove.**

Added by the EPC-022 amendment of 2026-10-18 under the operator's release decision of that day (workspace `RELEASE-PLAN.md`, 2026-10-18 operator decision).

## Acceptance Criteria

- AC-1 Each shipped script and workflow step that calls `mktemp` shall remove what it created on exit, including after a failing command and an interrupt, while keeping the existing exit status and the "ended before codeflow test ran" check; evidence: script tests that count temporary directories before and after a passing, a failing and an interrupted run. (serves EPC-022 AC-82)
- AC-2 A step that already uses `RUNNER_TEMP` shall keep doing so, and no cleanup shall remove a directory the script did not create; evidence: tests with a pre-existing directory beside the script's.
- AC-3 This repository's tests that run the CI scripts shall give each run a private temporary directory and remove it, so a full gate leaves no new `tmp.*` entries in the user temp directory; evidence: a count before and after a gate run of those tests.
- AC-4 (journey) A fresh and an updated adopter's generic, GitLab and Bitbucket scripts, run locally through the installed build's templates, shall leave the temporary directory as they found it; evidence: the journey output.
