# TSK-375: Bind standalone tasks to trusted epic lines

## Description

Restore standalone task pushes into trusted epic integration lines after the
TSK-275 regression at 790bbfac4. A standalone task may declare that line
without acquiring epic membership. The existing remote or protected-record
proof must still bind the line; another epic's task must still be refused.
This bounded repair serves EPC-022 and follows the operator's 2026-10-16
AC-6 decision. Fallback range behavior is outside this repair.

Builder: Codex GPT-6 Astra. Reviewers: Claude Fable 5.1 and cf-security-reviewer.
Execution: delegated peer implementation under the supplied approved brief.
Design intent: N/A, shared CI trust and range selection repair.
Verification: bounded membership mutations must fail the regression tests;
the original rejection and a cross-epic admission mutation cover both sides
of the changed CI trust decision.

## Deliverables

- Shared line binding: `crates/codeflow-core/src/workgraph/work_start.rs`.
- CI and pre-push agreement: `crates/codeflow-cli/src/cmd/ci/context.rs` and `crates/codeflow-cli/src/cmd/push_set.rs`.
- Regression and refusal tests: `crates/codeflow-cli/tests/ci_cli/range_context.rs`, `crates/codeflow-cli/tests/hooks_cli.rs` and workgraph tests.
- CLI help and generated reference: `crates/codeflow-cli/src/cmd/ci.rs` and `docs/cli.md`.
- Patch release note: `changelog.d/TSK-375.md`.
- Diagnosis, fail-before/pass-after, checks, task, head and draft PR: `target/build-standalone-target.md`.

## Acceptance Criteria

- AC-1 A standalone task declaring a trusted epic integration line shall bind to that line in work start, bare CI and pre-push, under the existing remote or protected-record rule. Evidence: shared binding tests and real CLI tests. (serves EPC-022 AC-1)
- AC-2 A local-only line, a line without trusted binding records, a forged or missing epic record, and a task belonging to a different epic shall remain refused. Evidence: regression tests for those cases.
- AC-3 A standalone task targeting a remote-bound epic line shall use that line as its range base in bare CI and a real push through the installed pre-push hook. Both regression tests shall fail before the fix and pass after it. (journey)
- AC-4 The requested complete CLI, hook, remedy, push-set, workgraph and contract suites, formatting, clippy, rustdoc, documentation validation and queued quick gate shall pass. Essential and full gates are excluded by the assignment.
- AC-5 The committed change and changelog fragment shall be pushed using the rebuilt worktree hook binary, with a draft PR into the EPC-022 line and evidence recorded in `target/build-standalone-target.md`.
