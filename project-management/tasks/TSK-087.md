# TSK-087: retire Mermaid and the present diagram block

## Description

Remove Mermaid from cf-present and remove the `diagram` block that is its
only consumer. The operator decided on 2026-09-24 that replies and documents
use HTML figures (the figure block drawn from the figure grammar, or a
justified `html` stage), ASCII on plain-text surfaces, and never Mermaid,
provided the removal causes no issue. The impact assessment of the same day,
on `integration/EPC-016-visual-guide` at `c5a86cf5d` and
`task/TSK-059-figure-runtime` at `11cd61e51`, found no issue that argues
against it. The portal never supported Mermaid (a fence renders as plain
code), so the change is confined to present, its skills, its records and
its supply chain. CodeFlow 3.0.0 is unreleased (the last tag is v2.1.0), so
the removal rides in its major version.

Security effect. Mermaid is the reason the review page allows inline style
elements and attributes. Without it the page can drop
`style-src-attr 'unsafe-inline'` and replace `style-src-elem 'unsafe-inline'`
with a hash of the one inline style element the service writes (the project
utility tokens, `src/render.rs:59-64`), or serve those tokens as a
stylesheet. The chrome sets its dynamic styles through the CSS object model,
which a style CSP does not govern, and the figure runtime's guard already
refuses a `style` attribute. The removal also retires the Mermaid SVG
sanitizer (`hardenSvg`), about a hundred third-party packages, and the
accepted residual in `present.md` that Mermaid renders synchronously within
one diagram. The `html` block keeps its own sandbox CSP, and the export keeps
its self-contained style allowance.

Conversion, stated once in `document-authoring.md` and named by the refusal:
`flowchart` becomes a flow figure, or a justified `html` flow stage while the
flow family is the interim form; `sequence` a sequence figure; `state` a
state figure; `class` and `entity_relationship` a structure figure, or a
table where no relationship must be seen; `mindmap` a `tree` block;
`timeline` a table, or a sequence figure when participants exchange
messages.

Order inside the task: the refusal and the stored-revision path land first,
so no intermediate head accepts a block the runtime can no longer draw.
Non-goals: the figure runtime (TSK-059), the chrome and the token values
(TSK-060), the annotation matrix (TSK-071), the Agent OS repository, and
Mermaid in the portal, which has none to remove.
