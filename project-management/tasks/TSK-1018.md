# TSK-1018: Worktree include tests resolve the fixture root on macOS

## Description

Two `hooks_cli` tests, `worktree_add_reads_includes_of_every_admin_name` and
`worktree_add_reads_linked_includes_by_their_logical_path`, fail on a macOS
machine with the default temporary directory and pass on hosted CI. `Fixture::new`
builds the repository under a temporary directory spelled through the `/tmp`
symlink, and the tests write `includeIf.gitdir:` conditions with that spelling.
Git did not apply those includes here, and a resolved path makes the tests pass.
The fix resolves the fixture root once in `Fixture::new`, and the linked-include
test adds a second, aliased spelling of its include. Non-goal: any change to the guard, which decided correctly.

## Deliverables

- the fixture fix: crates/codeflow-cli/tests/hooks_cli/target_repository.rs

## Acceptance Criteria

- AC-1 When `Fixture::new` builds a repository on macOS under the default `TMPDIR`, the fixture root shall be its resolved path, and the two named tests and the whole `hooks_cli` suite shall pass. Evidence: `cargo test -p codeflow-cli --test hooks_cli` before (two failures) and after (green) on macOS. (journey)
