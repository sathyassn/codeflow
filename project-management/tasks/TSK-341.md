# TSK-341: Reviewed predecessor chains have consistent claim and push decisions

## Description

Issue: #216. `workgraph/work_start.rs:1592` resolves stacked pins by iterating only `task.depends_on` (`:1622`), and returns those pins at `:1666`. It does not recursively preserve the verified predecessor's own stacked authority.
