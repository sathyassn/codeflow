# TSK-1180: The verb completes a reopened task by an append-only waiver and the route is documented

## Description

Split from TSK-1179 on 2026-11-02 (issue 502). TSK-1179 makes `codeflow ci` admit an append-only waiver annotation on a reopened task's criterion. This task makes `codeflow task status <id> complete` reach the same verdict and print the same refusal, so a person can complete the task in its own PR without the planning-amendment route, and it states the route and its limits in the docs. It changes no rule of TSK-1179: the verb calls the same check.

Until this lands, the verb still refuses the waiver, which fails closed. Security task: the verb is on the enforcement path, so it carries the same cross-lineage Codex review as TSK-1179 with the `cf-security-reviewer` checklist as its attacker lens, and the PR states the threat table of TSK-1179 AC-8 for the verb.

Non-goals: any change to the freeze rule, the annotation form or the planning-amendment route.

## Outcome

after this merges, a person can complete a reopened task whose completion landed with `codeflow task status <id> complete` and `AC-n: waived | <40-hex sha>` in the task's own pull request, with the same verdict and refusal as `codeflow ci`, and the docs state the route and its limits.
