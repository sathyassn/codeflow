# TSK-1077: The default branch is the only local policy authority

## Description

Source: CodeFlow's response to issue #279, the content policy design,
revision 5 (Claude Fable 5.1, finalized 2026-10-29 22:30Z), unit U2,
with all eleven of its decisions taken by the operator on 2026-10-29.
Code was read at `53749287c` and the citations hold at the line tip
`2e6f654a4`.

The local hooks take their policy from more than one place, and some of
those places are guesses:

- A line declared by a landed task record supplies path exceptions:
  `over_target` for the first declared target and `stricter` for the rest
  (`crates/codeflow-core/src/hooks/landed_policy.rs:113-127`), found by
  `declared_target` (`:305-394`) with a `root_branch` short-circuit at
  `:312`; documented at `docs/policy-reference.md:107-114`. Anyone who
  lands a record on a line controls the exception source for that line's
  task branches (design D-7, medium).
- With remote HEAD unset, a sole `origin/main` or `origin/master` is
  accepted as the authority (`landed_policy.rs:162-179`), so a repository
  whose default is `develop` with a stale or planted `origin/main` is
  judged by it (D-8).
- An empty `refs/remotes/<remote>/*` namespace falls back to `HEAD` or the
  working copy (`landed_policy.rs:67-81`); the condition also follows
  deleting the tracking refs or removing the remote (D-9, medium).
- Pre-push falls back to the range base's policy when no authority
  resolves (`crates/codeflow-cli/src/cmd/push_set.rs:280-291`) (D-10).
- `codeflow ci` judges with the working copy when the authority holds no
  `policy.json` (`crates/codeflow-cli/src/cmd/ci.rs:1986`) (D-14).

After this task the default branch, resolved to one SHA, is the only
local policy authority, no line supplies a policy, exception, denial or
level, and nothing is guessed. `git.root_branch` keeps its root-checkout
role and loses its policy-source role.

Public behaviour change for 4.0.0 (decision 5): a project that keeps real
exceptions only on a line loses them; the 4.0.0 release notes say so
under that label. None exist in this repository.

Non-goals: the baseline copy of the landed policy and its refresh rules
(TSK-1057, which depends on this task); the hosted jobs (TSK-336).

## Outcome

After this merges, an operator can rely on every local hook and `codeflow ci` judging with the default branch's policy at one named SHA, with no line able to add an exception and no fallback that guesses the authority.
