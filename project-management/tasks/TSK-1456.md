# TSK-1456: The guards find the program a command line runs behind its leading assignments

## Description

Before the guards judge a command, they skip the variable assignments that lead it to find the program the line runs. That skip, shared by the git guard and the headless reader, does not find the program the way the shell does in two cases: it accepts only some assignment forms, and it does not always read an assignment's value as the single word the shell reads. In both cases the guards judge a different program from the one that runs, so a launcher behind the assignments is never unwrapped. coord/catalog showed, by hook payloads to the installed guard, that git operations the guards refuse (on protected branches and remotes, and with hooks skipped) were allowed this way, on `main` and in v3.1.1.

Recording what those assignments set, for later readers on the line, is TSK-1457, which depends on this task. Matching variable names as Windows matches them stays with TSK-1455.

Overlap: TSK-1053 AC-17 (todo, EPC-029, into the EPC-022 line) judges Git program variables set on a line; it does not cover finding the program behind leading assignments. TSK-1344 (todo, EPC-029) and TSK-1346's fix forward read launchers on the line; their builders reuse this skip after the main sync (TSK-1459). A search of open task criteria on 2026-11-11 found no other owner.

Source: the Director's rulings of 2026-11-11 10:06, which split the earlier draft of this task by outcome (Very Hard as one unit), and 11:01, which cut it again: this task keeps the program position, and arguments on guarded lines go to TSK-1458. Two High findings by coord/catalog on `main` and in v3.1.1: the shared leading-assignment skip (step one, 09:31, workspace `coordination/coordinators/capabilities/TRACKER.md`, 9cafa58a) and a defect in how the same path reads an assignment's value (confirmed before 10:06; evidence in workspace `coordination/coordinators/capabilities/notes/key18-evidence/`). Hook payloads were given as strings to the installed guard 678d3fa48, an ancestor of `main`; nothing was executed. Sites located by coord/records on `main` f8aabc62c.

## Outcome

After this merges, on every OS, the guards find the program a command line runs behind any leading assignments, as the shell finds it, and read every word in the program position exactly or refuse it, so every command they refuse without assignments is refused behind them, and an assignment or program word the guard cannot place is refused.
