ordinary interpreter arguments the same verdict for plain and verbatim
repository roots while retaining enforcement-file refusals. Diagnose the
remaining red jobs and the check hidden after the parity failure in hosted

## Closeout

The script scanner discarded drive prefixes and backslash-separated parents.
It now retains literal Windows operands and quoted paths with spaces. The
guard read the question mark in a verbatim drive namespace as wildcard
syntax, sending an ordinary repository root into the registered-worktree
containment check. That marker is now literal on Windows; wildcard syntax
after it still takes the existing checks. Glob expansion also keeps structural
path prefixes in its literal starting directory.

The portable path classifier and script regressions failed before the fixes.
The native guard, interpreter, exec-guard, startup and argument suites passed;
Windows cross-target clippy compiled the new Windows-only regressions. The
hidden portal command passed locally, including its real Bash launcher branch.
