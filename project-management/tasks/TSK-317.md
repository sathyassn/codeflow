# TSK-317: Pull requests cite the authority paths they touch

## Description

A change to a file that carries product meaning, such as a spec or a
decision record, reaches review without a statement of why it changed
(https://github.com/sathyassn/codeflow/issues/168, part C). The operator
decided on 2026-10-13 to ship this off by default (decision 2). This task
adds `git.authority_paths`, opt-in (empty and `off` by default): for each
touched declared path, `ci` prints the disposition the PR body's Links
section gives, `Authority: <path>: <reference | editorial | carry>`, or
`uncited`. Any non-empty token is a reference, presented and never
authenticated; one word elsewhere in the body discharges nothing. Opting in
creates a diagnostic the reviewer reads, never a blocking duty. The key is
schema and defaults only (TSK-280). Non-goal: verifying that a cited
reference exists.

## Deliverables

- the diagnostic: `crates/codeflow-cli/src/cmd/ci.rs` and the PR body reader in `crates/codeflow-cli/src/cmd/ci/pr_body.rs`
- the key: `crates/codeflow-core/src/hooks/policy_schema.rs` (schema and defaults only), `docs/policy-reference.md`
- the PR body format: the Links row of `assets/base/agents/skills/cf-ship/references/pr-evidence.md`, mirrored
- release note: `changelog.d/TSK-317.md`

## Acceptance Criteria

- AC-1 With `git.authority_paths` empty or `off`, `ci` shall print
  nothing new; evidence: a CLI test on a range touching a spec.
  (serves EPC-023 AC-4)
- AC-2 With paths declared, `ci` shall print one line per touched declared
  path with the Links disposition or `uncited`, and a non-empty token shall
  read as a reference; evidence: CLI tests per disposition.
  (serves EPC-023 AC-4)
- AC-3 The diagnostic shall never change the verdict at any setting, and a
  disposition word outside the Links section shall discharge nothing;
  evidence: paired tests with and without citations.
- AC-4 The key shall be schema and defaults only (`policy show` marks
  `default (binary)`, `update` inserts none), and `pr-evidence.md` shall
  document the `Authority:` line; evidence: tests and the doc text.
- AC-5 When the installed build judges a scratch project's PR that touches
  a declared authority path with and without an `Authority:` line, the
  output shall show the citation and `uncited` respectively and pass both
  (journey); evidence: the journey output.
