# TSK-002-004 — delegate PTY stress suite

## Description

Build the fake-TUI/PTY stress harness for host-side prompt delivery and durable
event observation. The suite proves transport behavior under delayed,
duplicated, interrupted, malformed, and concurrent conditions rather than
inferring correctness from a stable-looking pane.

## Acceptance Criteria

- [x] Tests cover delayed ready and accepted events, duplicate Enter, Unicode,
  CRLF, multiline and large inputs, spinner and silent-pane timeouts, dual
  sessions, and kill-at-each-stage.
- [x] Every run ends with the expected valid record or an explicit timeout or
  poison; no test permits false completion, lost input, duplicate delivery, or
  cross-session misdirection.
- [x] The UI-answer interaction and a synthetic blocking sibling Stop hook are
  exercised explicitly.
- [x] Fable independently reviews the suite and reruns its gates.
