# TSK-011 — build the interactive presentation utility

## Description

Build the v1 `cf-present` skill and deterministic local runtime from approved
SPC-004 and TSK-006's exact settled design intent, including the declarative
block renderer, utility themes/modes, authenticated feedback/history lifecycle,
export, retention, cleanup, and sandbox boundary. Do not turn the escape hatch
into a component platform or a product dependency.

## Affected surfaces and interfaces

- Rust CLI/service modules and macOS/Linux/native-Windows/WSL state/process/
  browser handling; document/theme schemas and renderer assets;
  `cf-present` skill/references/assets.
- Scaffold/update/customize manifests and mirrors; capabilities/architecture/
  ADR/changelog/release surfaces; SPC-004 and the TSK-006 design intent.
