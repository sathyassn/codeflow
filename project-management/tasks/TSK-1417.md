## Description

No release since 3.0.0 has qualified the installed CLI against sample projects. The 3.0.0 matrix (`docs/verification/releases/v3.0.0-cli-qualification.md`, candidate `3f0013d66`) passed 679 rows with 0 failed and 10 unavailable. Its open rows were the live delegate canary, the scaffolded pipeline run and the positive `present resolve`.
