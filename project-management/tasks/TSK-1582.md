# TSK-1582: Make the remedy_clearing test independent of the caller's agent session

## Description

Owner: coord/catalog. Staged by coord/records on 2026-11-23 at the Director's ruling, relayed by coord/catalog.

The `remedy_clearing` test binary of codeflow-cli is not hermetic. Its
fixture commits run the real git hooks, and the hooks judge the caller's
session: when the test runs inside an agent session, `CLAUDECODE` is set,
and `git.root_checkout_commits` refuses the fixture commits. At TSK-1434's
head `379cf24843`, 65 of 179 tests fail this way: 49 directly and 16 more as
a result (workspace
`coordination/coordinators/capabilities/notes/tsk1434-round10/g4-remedy-clearing.log`,
"test result: FAILED. 114 passed; 65 failed" at :1146; the refusal at :195).

Main has the same gap. At `d2307063f2`, the test's `command` helper
(`crates/codeflow-cli/tests/remedy_clearing/main.rs:337-361`) removes the
git, CI and other agents' home variables but no session marker. The
acceptance tests already do this in reviewed test code:
`crates/codeflow-cli/tests/acceptance_cli.rs:31` ("A caller's agent session
must not judge fixture commits.") removes `CLAUDECODE` and the Codex and Grok
session variables from their fixture children.

Non-goals: clearing any marker from outside the test (a gate, a script or a
letter); changing the hooks or the policy.

## Outcome

After this lands, `cargo test -p codeflow-cli --test remedy_clearing` gives
the same result inside an agent session as outside one, because its fixture
child processes no longer carry the caller's session markers.

## Deliverables

- the `command` helper in `crates/codeflow-cli/tests/remedy_clearing/main.rs`, and any other fixture process the binary starts

## Acceptance Criteria

- AC-1 Every child process the `remedy_clearing` binary starts for a fixture shall run without `CLAUDECODE`, `CLAUDE_CODE_ENTRYPOINT` and the Codex and Grok session variables that `acceptance_cli.rs` removes, set in the test code itself; evidence: the diff, and a list of every `Command::new` in the binary with the helper it uses.
- AC-2 The binary shall pass in full when run with the markers set in the caller's environment; evidence: a whole-binary run inside an agent session with the markers left set, showing 179 passed (or the binary's count at the head) and 0 failed.
- AC-3 No gate, script, letter or CI step shall clear a session marker to make this test pass; evidence: the diff touches only test code.
