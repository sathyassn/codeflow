# TSK-082: Agent OS mirror of the catalog and autonomy rules

## Description

Bring Agent OS to the same rules once ADR-0069 and ADR-0070 are accepted on
the EPC-018 integration branch. The work lands in the agent-os repository
through its own reviewed pull request; this record tracks it, following the
EPC-015 TSK-056 precedent.

- Autonomy: `system/skills/operating-rules/SKILL.md` section 2 opens with
  the same short statement and keeps its tiers; the SOUL condensed block
  gains one line; the `qualify-model-binding` cases gain the over-asking set
  in their own schema (`tier`, `action`, `needs_approval`), and
  `test_doctrine_contract.py` asserts the clauses. Where Agent OS already
  states a rule, cite it instead of adding a copy.
- Routing: any Agent OS text that names a model or a CodeFlow binding points
  at the CodeFlow catalog by seat and duty instead, and resolves through
  `codeflow models resolve`. Hermes stays a
  delegate-only host; no Agent OS catalog copy is made.

Non-goal: CodeFlow files, the workspace contract.

## Affected surfaces and interfaces

agent-os `system/skills/operating-rules/SKILL.md`, the SOUL condensed block,
its `qualify-model-binding` cases and `test_doctrine_contract.py`, and any
agent-os text a search finds naming a model. No CodeFlow source.
