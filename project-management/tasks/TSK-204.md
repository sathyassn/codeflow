# TSK-204: model roster refreshed to the October lineup

## Description

On 2026-10-02 the operator set the model roster for the 3.0.x line. Claude:
Opus 5.5 stays the preferred primary seat, Sonnet 5.5 is added for execution
and routine work where Opus is not needed, and Fable 5.1 is for design,
architecture, technical planning and consultation. Codex: GPT-6 Astra stays,
GPT-6.1 Sol is the Sol version to use, and GPT-6 Luna serves low-level tasks.
Grok 4.7 is unchanged. The model ids are confirmed: `claude-sonnet-5-5` in
the Claude Code selector and `gpt-6.1-sol` in `codex debug models`.

This task applies that direction to the managed schema 5 catalog
(`current-ensemble.json` and its four mirrors) as a data change:

- A new `sonnet` worker line (`claude-sonnet-5-5`, medium and high, manual
  adoption, no designation, empty qualification) becomes the first Claude
  alternative for `bounded-execution`, `evidence-collection` and the Claude
  fallback of `engineering-implementation`, ahead of Opus. It gets no seat,
  design, review or orchestration duty.
- The `sol` line adds and adopts `gpt-6.1-sol`, designated for
  `codex-primary` on 2026-10-02; `gpt-6-sol` becomes fallback-only.
- A dated Note on ADR-0069 records the direction.
- `release.py sync`, which this version bump exposed, compares only the
  program and version on the first line of `codeflow --version` (which now
  adds provenance) and still fails on any other program, version or line.

The Fable part of the direction (design, architecture and technical
planning) is not applied: `design`, `independent-plan` design-primary and
`body-review` design-primary still resolve to the `claude-primary` seat,
Opus first. Only `consultation` and `reasoning-support` route to Fable
first, as before. No catalog-only route exists; the engine rules are cited
in the ADR-0069 Note of 2026-10-02 (`validate.rs:154`, `:171-176`,
`:333-335`; `resolve.rs:168-181`, `:228-238`, `:291-295`, `:395-401`).
Moving these duties to Fable is an engine and ADR change, offered to the
operator on 2026-10-02 as their decision. The Fable designation record
stays as it is because it still describes the routing. Non-goals: schema,
engine or CLI changes, and qualification (TSK-194 runs the suite).

Recovery: git reversal of the PR; `codeflow update` restores the previous
managed catalog in a consuming project.

## Acceptance Criteria

- AC-1 When `codeflow models resolve --duty bounded-execution` runs on
  `claude-code` with the Codex bucket excluded, the system shall return the
  `sonnet` line at medium with pinned id `claude-sonnet-5-5`, Opus next;
  evidence: the pasted `--json` output.
- AC-2 When `codeflow models resolve --duty evidence-collection` runs on
  `claude-code`, the system shall return `claude-sonnet-5-5` first and Opus
  as the next alternative, and `engineering-implementation` shall list Sonnet
  before Opus among its Claude alternatives; evidence: the pasted output.
- AC-3 When any duty resolves the `sol` line, the system shall launch
  `gpt-6.1-sol`; `gpt-6-sol` appears only as a seat fallback; evidence: the
  pasted `bounded-execution` and `engineering-implementation` output.
- AC-4 `design` shall still resolve to the `claude-primary` seat's first
  line (Opus) on every host, and `orchestrate` shall on the `claude-code`
  host; evidence: the pasted `design` output and the `design owner`
  structural check.
- AC-5 The catalog and its four mirrors shall be byte identical with matching
  manifest hashes; evidence: `manifest_consistency` and the mirror hashes.
- AC-6 Every designation shall carry its own decision's date (2026-10-02
  for `gpt-6.1-sol`, 2026-09-23 for the others) and every qualification
  field stays empty; evidence: the `designations` structural check, which
  fails before the test learns the new date and fails on a fixture with an
  unrecorded date or a real date on a version that decision did not cover.
- AC-7 `codeflow validate`, `codeflow validate --docs` and `codeflow doctor`
  shall report no new finding, except the expected `model-bindings`
  qualification warnings for the newly designated `gpt-6.1-sol`; evidence:
  their output.
- AC-8 (journey) When a project runs `codeflow update` with this binary and
  then `codeflow models resolve`, the system shall rewrite only the catalog
  mirrors and their manifest hashes and return the new routing of AC-1 to
  AC-3; evidence: the update report and the resolve output on this
  repository as its own first consumer.
