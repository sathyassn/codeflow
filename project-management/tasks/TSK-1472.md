# TSK-1472: Guard calls stay bounded when a sibling worktree's admin file is not a regular file

## Description

A guard can wait out its full deadline while reading one of a sibling worktree's administrative files, and then refuse. The refusal is correct; the wait slows every tool call in that repository. The reproduction stays in private review evidence until the fix is on `main`; any public update to this record about it comes after that. TSK-1082 built the bounded read this task reuses.

TSK-1275's builder found it; it holds at TSK-1275's base and head, so TSK-1275 is not a predecessor. A search of open task records on 2026-11-12 found no other owner.

## Outcome

After this merges, every guard call stays within its latency budget whatever file type a sibling worktree's administrative files hold, and still refuses what it cannot read.

## Deliverables

- the bounded regular-file read applied to the guards' sibling-worktree reads: `crates/codeflow-core`
- a fixture with fail-before evidence
- the list of other repository-settable reads with their disposition, in the pull request

## Estimate

- Grade: Medium; band: Medium (2 to 4 h); moved: none
- Split: not needed; one outcome (guard reads of repository-settable files stay bounded)
- Basis: reuse of TSK-1082's bounded read at one site, a sweep of sibling sites, and a cross-family security review; graded by coord/records under issue 334's bands.

## Acceptance Criteria

- AC-1 When a guard reads a sibling worktree's administrative files, it shall read each only after confirming it is a regular file, using TSK-1082's bounded regular-file read where it fits, and refuse any other file type at once with a reason naming the path. Evidence: a fixture reproducing the held case, refused within the guard's latency budget, failing before the change and passing after.
- AC-2 Every other place the guards read a file whose path a worktree or repository can set shall be listed with its disposition (already bounded, moved to the bounded read, or kept with a reason). Evidence: the list with file:line in the pull request.
- AC-3 The change shall get a cross-family review with the `cf-security-reviewer` checklist. Evidence: the review row.
