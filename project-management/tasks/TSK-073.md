# TSK-073: positive copy guide

## Description

Say how to write each string, not only what to avoid. The system today has a
smell list (`cf-editorial-review/references/editorial-smells.md`, from
EPC-017) and six writing bullets restated in about seven files with drifting
wording; voice is stated three ways. Write
`cf-editorial-review/references/copy-guide.md`, one section per string type,
each with its rules and one good example that exists verbatim in a named
source (the kit reference pages, the figure specimens, an accepted ADR, the
PR template or a skill), with the source named beside it:

| Section | What it settles |
|---|---|
| Voice | one statement: plain and calm; third person in documentation, second person in how-to steps and replies |
| Sentences | one idea, active, present tense, a named subject, about 25 words or fewer; colon and semicolon use |
| Words | exact identifiers and commands, acronyms expanded once, one term per thing, digits with units |
| Titles and headings | a noun phrase in words; a how-to heading names the outcome; sentence case; identifiers in the body |
| Leads | what the reader is looking at; never the caption again |
| Captions | one sentence, the takeaway |
| Legend keys and descriptions | a key is a noun phrase naming the state; the description names every state and drawn fact |
| Summaries | two to four plain sentences before any list or table |
| Bullets and tables | one fact per bullet, parallel form; a table when three or more items share fields; noun headers |
| Microcopy | verb-first labels, adjective states, empty states that say what to do, errors with cause and fix, digits, one-clause tooltips, no exclamation marks |
| Replies | the summary rule, a fenced figure when a relationship carries the point, a table for tabular facts, the exact link a tool printed |
| Skill prose | the same sentence and word rules in the imperative register; no slogans |
| ADR and PR shapes | ADR context in two to five sentences, one decision paragraph stated as fact, consequences with a cost; PR summary two to four sentences, then bullets or a table, with test evidence |

The guide cites ADR-0067 in one sentence as the policy and points at the
editorial smells for diagnosis; it does not copy the mannered prose table.
The kit README keeps its six writing bullets, because a product reads the kit
on its own, names the guide as the full text, and the guide carries the six
bullets verbatim. Every other restatement becomes a pointer: the writing
sentences in `explanation-method.md` stage 4, `utility-presentation-system.md`
section 3, `figure-grammar.md` section 3 (keeping its ADR-0067 citation), the
language lines of both presentation `SKILL.md` files and the language section
of `document-authoring.md`. Pointers also go into
`workflow-lifecycle.md` "Shape deliverables" (one sentence naming the method
and the guide, and the reply rule's figure wording aligned to the figure
block), `cf-editorial-review/SKILL.md` (load the guide when writing, the
smells when reviewing), `cf-ship/SKILL.md` step 5 and the PR template's
Summary comment in all three copies. The evaluation cases for the guide are
TSK-062's.

Precondition, recorded before work starts: step M of the EPC-016 plan has
run. The EPC-017 body (ADR-0067, `editorial-smells.md` with its mannered
prose table and identifier smell, the lifecycle reply and link rules, the
policy character check) is merged into `integration/EPC-016-visual-guide`,
and the `Shape deliverables` paragraph, which this branch and EPC-017 edit
differently, is reconciled to carry the nine family sentence, the reply rule
and the link rule. This task starts from that merged text and never
re-resolves the conflict.

Byte ratchets bind four skill files on the merged head. At the EPC-017 tip,
`cf-ship/SKILL.md` is 6651 of 6656 bytes and `cf-editorial-review/SKILL.md`
5823 of 6144; `cf-present/SKILL.md` and `cf-docs-portal/SKILL.md` carry what
TSK-072 left. A pointer replaces text of at least equal length; no ratchet is
raised. The three skills ship together at the standard and full tiers, so a
pointer into `cf-editorial-review` never dangles in a consumer. Non-goals: the
policy itself and its mechanical check (EPC-017), a copy of the smells, and
Agent OS product doctrine.
