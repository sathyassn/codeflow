# TSK-070: design system reference kit in both skills

## Description

Ship the approved round 2 design as a working reference kit under
`resources/design-system/` in cf-docs-portal and cf-present, byte identical
between the two skills, so any project that runs `codeflow init` or
`codeflow update` receives the design system as files that run, not only as
prose. The kit is a split of the approved `design-r2` build along the seams
the brief declared: `tokens.json` (the value source, the round 2 six pairs),
`tokens.css` (custom properties only: the six `[data-cf-skin][data-cf-theme]`
blocks plus typeface and scale attributes), `chrome.css` (the `cf-` primitives,
tokens only, no literal colour), `figure.css` (frame, legend, caption, table
twin and the mark classes of the grammar), `chrome.js` (prepaint, Display
panel, search dialog, panels with collapse, peek and resize, tabs, table of
contents, preview card, footer cards, and the Comment state machine; plain
ES2020, no framework, no build), `portal.reference.html` and
`present.reference.html` (each stands alone when opened from the folder with
the three sheets and the script), and a short README that states what each
file is, how the products consume it (token roles equal per role, `figure.css`
carried byte for byte, `chrome.css` and `chrome.js` as the behaviour
reference), the naming and persistence contract, the writing rules and where
the doctrine lives. Apply the design primary's round 2 findings 1 to 13
before the split and drop every `data-mock` block. Guard the kit against
drift with a contract test (tokens.css agrees with tokens.json per role;
no literal colour in chrome.css or figure.css; the two skill copies and the
mirrors are byte identical; the reference pages reference no file outside the
kit) and a browser check that opens both reference pages in all six skin and
mode pairs and runs the brief's section 9 checklist. Non-goal: the product
token sheets, the product chrome and the product figure copies; TSK-060 and
TSK-059 own those and add their equality tests after this kit has landed.
Non-goal: font binaries; the kit uses `local()` face names with system
fallbacks.
