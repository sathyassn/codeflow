# TSK-1273: The daily exact-SHA Windows run is green on main and its coverage switch can turn on

## Description

Scheduled workflows run only from main, so the green daily run that TSK-1242 AC-3 requires cannot exist before the 4.0.0 pull request to main merges (Director ruling, 23:5x on 2026-11-02, relayed by coord/planning). The daily runner ships in 4.0.0 with full pull request Windows coverage kept, and the coverage switch stays off until daily evidence exists. This task carries TSK-1242's AC-3 and the evidence that turns the switch on. Owner: coord/planning. Trigger and window: the first scheduled run on main after the EPC-022 pull request to main merges. Non-goal: it does not change the runner TSK-1242 ships.

## Outcome

After this merges, the maintainer can see a green daily exact-SHA Windows run on main, and pull request Windows coverage narrows only after that run.

## Deliverables

- the run id and SHA of the first green scheduled run on main, and the change that turns the coverage switch on citing it: this record's Closeout and the workflow diff
