# TSK-288: The autonomy diagnostic runs on the 3.1.0 uncertainty guidance

## Description

TSK-235 (PR 72) changed managed instructions with the uncertainty
guidance. Its review held that a material instruction change needs the
`cf-evaluate-model` focused diagnostic, the `autonomy-with-judgment` pack
(17 cases), or an operator exception. The operator granted the exception on
2026-10-09 so the guidance shipped in 3.1.0, with the diagnostic run as
evaluation after the release (https://github.com/sathyassn/codeflow/issues/133; the `not_verified` line of
`project-management/tasks/TSK-235.md`). This task runs that diagnostic and
records the results. It is an evaluation record and changes no product
file, so it has no journey criterion. Related but not a dependency: TSK-273
qualifies the meaning-taken pack on native seats, and TSK-194 (EPC-018)
runs the full suite per seat but is not bound to this run.

## Deliverables

- the evaluation record: `docs/verification/tsk-288-autonomy-with-judgment-3-1-0.md`
- the raw trial records, kept where the `cf-evaluate-model` protocol puts them and linked from the record
- one GitHub issue per behaviour regression, linked from the record

## Acceptance Criteria

- AC-1 The `autonomy-with-judgment` pack shall run as native interactive
  trials on the 3.1.0 guidance with the 3.1.0 scaffold installed,
  alternating Claude and Codex subjects, each graded by the other vendor,
  as `cf-evaluate-model` and its protocol state; evidence: each trial's
  native provenance (a Codex thread ID, Claude lifecycle records) in the
  record. (serves EPC-023 AC-14)
- AC-2 The record under `docs/verification/` shall give, per case, the
  subject, the grader, the verdict and the evidence it rests on, with the
  pass bar used and what was not run; evidence: the record.
- AC-3 Each behaviour regression shall be filed as its own GitHub issue
  linked from the record, and a clean result shall say so; evidence: the
  links or the stated clean result.
- AC-4 The record shall say whether the operator exception of 2026-10-09 is
  closed and on what result; evidence: the record's conclusion, checked by
  the reviewer. (serves EPC-023 AC-14)
