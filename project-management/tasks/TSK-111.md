# TSK-111: grader and case fixtures for the live evals

## Description

The eval kit grades transcript signals today
(`cf-evaluate-model/scripts/eval_kit.py:491`), which rewards explanations
over behaviour. This task adds a grader that checks fixture file state and
tool effects, which the subject cannot see, and builds the fixtures for the
six cases of the live pack (SPC-013 R-105, R-106). It starts early; the 36
live sessions that use them are TSK-116, split out by SPC-013 planning
resolution 15 because they need the guidance of TSK-108.

Dependency: TSK-105. Cases 1 and 4 grade the acceptance block a subject
writes or refuses (R-54, R-60), so the grader calls the shipped block
checker from TSK-105 rather than a second parser, and TSK-105 brings the
TSK-102 record formats (criterion ids, Blocker, acceptance block) the
fixtures are written in. The other fixtures are record data graded against
expected answers from the SPC-013 rules and need no other task's code.
Plan v4 section 12 gave the unsplit task "grader: SPC-013".

## Affected surfaces and interfaces

- `cf-evaluate-model` eval kit (`expected.files`, tool-effect assertions)
  and its case files (CAP-013).

      Spec: R-105.

      dropped; evidence: kit test with a timed-out fixture.
      Spec: R-105.
