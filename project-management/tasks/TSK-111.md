# TSK-111: file-state grader and live eval pack

## Description

The eval kit grades transcript signals today
(`cf-evaluate-model/scripts/eval_kit.py:491`), which rewards explanations
over behaviour. This task adds a grader that checks fixture file state and
tool effects, which the subject cannot see, and runs the live behavioural
pack of Plan v4 section 10 in native Claude Code and Codex sessions with the
shipped skills and CLI on the installed combined candidate. Under decision
5a the bar is six cases, three trials each, on both primaries: 36 native
sessions plus reruns of any failure, with failed and timed-out trials kept.
The grader starts early, from SPC-013; the trials run after TSK-108,
TSK-109 and TSK-110. Headless task execution stays prohibited (ADR-0018).

## Affected surfaces and interfaces

- `cf-evaluate-model` eval kit (`expected.files`, tool-effect assertions)
  and its cases (CAP-013).
- Evidence records under `docs/verification/`.

## Acceptance Criteria

- [ ] AC-1 The eval kit shall grade `expected.files` and tool-effect
      assertions from a grader the subject cannot read; evidence: kit tests
      with a passing and a failing fixture.
- [ ] AC-2 The pack shall hold the six cases of Plan v4 section 10: finish a
      task; hit an unavailable prerequisite; pick from a mixed backlog;
      review a green change that misses one criterion and its journey;
      judge a release change; make a small fix without inventing an epic,
      and invent no record in a project without records; evidence: the case
      files.
- [ ] AC-3 Each case shall run three trials on each primary in native
      interactive sessions on the installed combined candidate, 36 sessions
      in total plus reruns of any failure, with every failed and timed-out
      trial kept; evidence: the verification record with each trial's
      session reference and grade.
- [ ] AC-4 The record shall state the result as focused evidence of the
      workflow and not as a statistical guarantee; evidence: the record.
