# TSK-1305: A hosted gate run publishes each target's result where the API can read it

## Description

Issue 546: `codeflow test` gives no machine-readable target evidence in hosted CI, so a passing hosted gate cannot be checked target by target without reading logs. This task makes a passing hosted gate publish each target's result and timing where the GitHub API can read them. It sits beside TSK-1265 (hosted-run provenance) and feeds TSK-1188 (a hosted run standing in for the landing's full gate).

## Outcome

After this merges, a maintainer or a tool can read each target's result and timing for a hosted gate run through the GitHub API.

## Deliverables

- the publication: `.github/workflows/codeflow-ci.yml` and `assets/base/ci/codeflow-ci.yml` (with its baseline), and the `codeflow test` output it publishes
- tests: gate contract tests in `scripts/`
- release note: `changelog.d/TSK-1305.md`

## Acceptance Criteria

- AC-1 A hosted gate run shall publish each target's name, result and duration as a machine-readable file or check output that the GitHub API returns for the run; evidence: a contract test and the run record the gate writes. The API response for one hosted run is under TSK-1273 AC-6.
  - Amended 2026-11-05: earlier evidence "a contract test and the API response for one hosted run"; reason: that response needs the first hosted run on this task's pushed head, which cannot exist before the task completes, so it moved to TSK-1273 AC-6, which owns the hosted proof for this batch (as TSK-1313 did).
- AC-2 A run that fails or skips a target shall publish that target's state too, never only the passing ones; evidence: a contract test.
- AC-3 (journey) One gate run's record shall be read back with every target the run was given listed, passed, failed, not run and skipped; evidence: the CLI test that runs `codeflow test` and reads its `run.json`. The hosted run read through the API is under TSK-1273 AC-6.
  - Amended 2026-11-05: earlier text "One hosted run on the line shall be read through the API with every target listed; evidence: the run link and the API output"; reason: the hosted run is the first one on this task's pushed head, which cannot exist before the task completes, so it moved to TSK-1273 AC-6 (as TSK-1313 did); the local journey stays here.
- AC-4 A changelog entry shall describe the output; evidence: `changelog.d/TSK-1305.md`.
- AC-5 When a hosted gate run ends, pass or fail, the shipped `codeflow-ci.yml` shall upload each `target/codeflow-gate/*/run.json` with each target's captured output, under a name unique per job and attempt and with a short retention, without changing the gate's result; evidence: a template contract test (issue 546). The artifact list of one hosted run is under TSK-1273 AC-6.
  - Amended 2026-11-05: earlier evidence "a template contract test and the artifact list of one hosted run (issue 546)"; reason: that list needs the first hosted run on this task's pushed head, which cannot exist before the task completes, so it moved to TSK-1273 AC-6 (as TSK-1313 did).
