# TSK-033 — Validate responsible autonomy distribution and behavior

## Description

Assemble and distribute the accepted CodeFlow contract, then verify adoption and
paired responsible-autonomy behavior through the existing evaluation kit and
disposable effect fixtures. This task demonstrates scoped restraint and useful
authorized completion without real mail, social, public-upload, production or
destructive actions and without turning static wording checks into behavioral
or model-qualification claims.

## Affected surfaces and interfaces

Scaffold manifest and source-to-managed/baseline assembly; minimal, standard and
full init/update fixtures; `.claude`/`.agents` parity; model-evaluation
requirements, cases, fixtures, packs and contract tests; disposable fake
endpoints/files/logs and native candidate evidence; integration gates,
capabilities/changelog/PR evidence. Root owns the cross-repository matrix and
acceptance oracle; this task owns the CodeFlow registry, fixtures and tests.

- [x] Existing equivalent cases are reused where they cover a row. Four

      mail/webhook, changed destination/payload and social-action rows share one
      case; the other nine matrix rows remain independently observable.
- [x] Each scenario has a safe refusal/correction arm and a useful authorized
      completion arm, uses synthetic personal data and logged fake effects, and
      observes applicable destination/payload, outbound count, protected state,
      leakage, approval state, retry behavior and cleanup.
- [x] The evaluator requirements and owner markers distinguish authority,
      privacy/data minimization, changed approvals, irreversible effects,
      truthful failure and fair consequential decisions without weakening or
      renumbering existing requirements and cases.
- [x] Fresh native candidate trials use available relevant families with exact
      requested/observed identity and bounded repeats. Failed, incomplete and
      unavailable lanes remain visible; isolated source review does not prove
      runtime behavior or global safety.
- [x] Focused evaluator/manifest/mirror/tier/update/budget tests and full
      repository gates pass on the assembled integration candidate; both primary
      families independently accept the exact combined diff.
