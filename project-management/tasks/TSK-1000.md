# TSK-1000: The EPC-025 line joins the 3.2.0 line

## Description

The operator chose on 2026-10-24 to merge the EPC-025 line into this line
now, with TSK-422 (the coordination ledger store and `codeflow follow`)
landed there through PR 311, so the 3.2.0 pull request to `main` can open.
EPC-025's record planned that merge as one pull request with the line as
its head, but `codeflow ci` lands an `integration/` head only on the
default branch (`crates/codeflow-core/src/workgraph/work_start.rs:733-741`,
judged in `crates/codeflow-cli/src/cmd/ci/classification.rs:339-367`), so
the hosted check refuses that head into this line. This task carries the
merge instead: its branch merges the EPC-025 line, whose completed TSK-422
record is imported unchanged and bound at its home (`docs/delivery.md`,
"Completed work imported from another line"), resolves the one conflict,
and updates the two places that state the subcommand count, which the
merged binary raises from 28 to 29. Scope: the merge, its conflict
resolution and the count; no product change of its own. Non-goal: EPC-025's
other tasks (TSK-423, TSK-439, TSK-440) stay on the EPC-025 line and need a
later merge of the same kind.
