# TSK-243: Document the multi-epic Task line in the git rules

## Description

CodeFlow 3.1.0 lets one planning amendment name several epics on its `Task:`
line, `Task: EPC-001, EPC-002` (TSK-229, ADR-0078), but the git rules every
agent reads still list only `Task: TSK-NNN` and `Task: EPC-NNN` and call any
other form malformed, so an agent following the rule would not use the form.
This task states the multi-epic form in the "PR bodies" rule of
`git-rules.md`, in the shipped template and in this repository's live and
baseline copies, with the manifest hash updated. The per-task reading chain
has 31 bytes of room (`codeflow doctor` on main 685713fe0), so the paragraph
is rewritten to fit rather than extended.

Non-goals: no change to what `codeflow ci` accepts; no other rule text.

## Deliverables

- The rule paragraph: `assets/base/rules/git-rules.md`, `.codeflow/rules/git-rules.md`, `.codeflow/.baseline/.codeflow/rules/git-rules.md`
- The managed hash: `.codeflow/manifest.json`
- The other statements of the forms: `assets/base/agents/skills/cf-ship/references/pr-evidence.md` and its mirrors, `assets/base/ci/pull_request_template.md` and the repository's `.github/pull_request_template.md`, `assets/base/rule-map.toml` with the generated `AGENTS.full.md.tmpl` and `AGENTS.md`, `docs/delivery.md`, `docs/adoption.md`, and the CLI fixtures that fill the placeholder

## Acceptance Criteria

- AC-1 When an agent reads the "PR bodies" rule, it shall name the multi-epic planning form `Task: EPC-001, EPC-002` beside the task and epic forms, with the existing refusal sentence kept; evidence: the diff of the three copies and review.
- AC-2 When the change lands, the three copies shall be byte-identical, the manifest shall carry their hash, and `codeflow doctor` shall report the per-task reading chain within its 131072-byte guideline; evidence: `shasum`, the managed manifest test and `codeflow doctor` output on the head.
- AC-3 When an agent reads any other managed source that lists the `Task:` line forms (the PR evidence reference, the PR template, the delivery and adoption guides, the AGENTS.md row), it shall find the multi-epic planning form or a MUST OPEN pointer to the reference that names it; evidence: the search hit list with dispositions and review.
