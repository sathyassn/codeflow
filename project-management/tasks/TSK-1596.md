# TSK-1596: The reviewers ask on every review whether a change adds personal or identifying data

## Description

Owner: to be assigned by the Director. Staged 2026-11-23 for coord/records.

SPC-018 R-10 and R-12, layer 1. ADR-0016 gives the model reviewers the PII
reasoning scanners cannot do (`ADR-0016...md:97`, both revisions). Today:

- `cf-security-reviewer` axis 2, "Confidential data / PII flow"
  (`assets/base/claude/agents/cf-security-reviewer.md` main `:79`, tip
  `:78`), covers data reaching a provider, prompt, log or Git record at
  run time, not values a change writes into the repository or the
  contributor's own names.
- `cf-reviewer` has no privacy question
  (`assets/base/claude/agents/cf-reviewer.md`, Procedure `:24`).
- The editorial smells already say a placeholder must not name a real
  person (`editorial-smells.md:89`, `copy-guide.md:322`, both revisions).

This task adds one privacy question to `cf-reviewer`'s procedure, widens
axis 2 to repository content and contributor identity, points both at
the placeholder table TSK-1583 writes (never copying it), and adds one
line to the minimal-tier contract.

## Outcome

After this merges, every `cf-reviewer` and `cf-security-reviewer` verdict
answers whether the change adds a personal or identifying value or a
non-placeholder example, and a minimal-tier project's contract says
examples, fixtures and records use placeholders only.
