# TSK-1606: Cache first-parent walks and record lookups across the range in workgraph import authority

## Description

Source: Director ruling 2026-11-24 (`msg_6c68fc420eee`) and `coord/ci` report (`msg_556b7ef1b47b`).

During `proof n` (`scratch-ci-import-authority-2026-11-20-n-result.txt`, 14:59Z to 16:25Z on 2026-11-24), the full `proof n` run took about 85 minutes elapsed on the `TSK-1513` m3 range `960eb7dbf4..cd7649a358`. Code inspection shows `crates/codeflow-core/src/workgraph/acceptance/imports.rs` and `imports/home.rs` (`held_at`, `moves_of`) repeatedly walk `main`'s first-parent history and reload commit trees and task blobs per record without caching across records in the same range check. Before optimizing, measure the `work.import_authority` phase directly on a representative multi-record sync range to establish the phase baseline.

Non-goals: weakening any `work.import_authority` verdict or skipping records; caching across separate `codeflow` process invocations.

## Outcome

After this merges, `work.import_authority` caches first-parent history walks and commit/record lookups within a single range evaluation so the `work.import_authority` phase on a representative multi-record sync range runs at least 5x faster and finishes within 10 seconds with identical verdicts.

## Deliverables

- per-run cache for first-parent walks, commit trees, and parsed record blobs in `crates/codeflow-core/src/workgraph/acceptance/imports`
- benchmark / timing comparison (before and after) on a multi-record sync range showing the speedup
- regression tests proving cached verdicts match uncached verdicts
- release note: `changelog.d/TSK-1606.md`

## Estimate

- Grade: Medium; band: Medium; moved: none
- Split: not needed.
- Basis: in-memory per-evaluation memoization inside `workgraph/acceptance/imports` and timing verification. Graded by `coord/planning`; builder re-scores at claim.

## Acceptance Criteria

- AC-1 First-parent walks and record/tree lookups in `workgraph/acceptance/imports` (and `imports/home.rs`) shall be cached across records within one range check rather than recomputed from scratch per record; evidence: diff and unit tests verifying cache reuse.
- AC-2 Cached evaluation shall produce identical `work.import_authority` verdicts and diagnostics to uncached evaluation on existing import-authority test suites; evidence: passing test logs.
- AC-3 Measured wall-clock runtime of the `work.import_authority` phase directly on a representative multi-record `main`->line sync range (such as `960eb7dbf4..cd7649a358` or an equivalent synthetic multi-record history) shall drop by at least 5x compared to the measured uncached phase baseline and finish in at most 10 seconds; evidence: before/after phase timing measurements on the same range and host.
