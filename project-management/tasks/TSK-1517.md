## Outcome

On a line's main sync, the id-registry check and `codeflow ids check` list and read the code refs' records with a fixed number of git children, so the number of git children started to list and read them is the same however many distinct tips there are, and no record blob is read twice in one run; the findings, order and exit code stay the same. With TSK-1499's bounded walks and the split task's shared walk, a line's main sync of a few thousand commits gets its verdict within the bound the split task's AC-1 states.
