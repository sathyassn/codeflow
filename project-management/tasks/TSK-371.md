## Closeout

The product repair avoids filesystem inspection of structural path prefixes
and root separators. Existing entries still use the same metadata and case
normalization, and failures still propagate. The new reasoning-path regression
failed before this change and passed afterward. On 2026-10-18, when this was
written, native Windows execution was still owed by the hosted run. The
Windows cross-target test build passed.

The differential now requires every named shell and reports missing shells as
a failed prerequisite. Linux lacked zsh; the Windows test process could not
find a working bash. The proposed hosted installation is saved in
`target/hosted-red-2/workflow-shells.patch`, together with its gate-parity
contract update. On 2026-10-18 the edit guard refused the workflow mutation
under `git.hook_integrity`, and the host arranged the human edit, which the
operator later applied in `d4d08c637`. The adopter workflow template needs no
change because this differential belongs to CodeFlow's own test suite.

The Windows patch exports `CODEFLOW_DIFFERENTIAL_SHELL_DIR` through
`GITHUB_ENV`. The differential resolves every required shell from that
directory without fallback and prepends it to PATH only for its own shell
children, including nested shell commands. The job's PATH stays unchanged
for all other tests. Follow-up evidence is in
`target/build-hosted-red-2-patch.md`.
