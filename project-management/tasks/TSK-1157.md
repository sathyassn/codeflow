# TSK-1157: The local full gate runs coverage as parallel shards

## Description

<!-- One paragraph: the outcome/change, why it is needed, and its bounded scope.
     Name a non-goal when omission would otherwise be ambiguous.
     Review-relevant scope, interfaces and recovery notes go here: the
     public contracts or boundaries this task changes, and how to recover
     from an irreversible step, when a reviewer needs them. -->
The local full gate runs `rust-coverage` as one `cargo llvm-cov nextest`
process, 22.6 minutes and the longest target (about 25 to 35 minutes for the
whole gate). Hosted CI already splits the same suite into shards with
`scripts/coverage-shards.py`. This task runs the local target as N shards from
the same planner, in parallel within host capacity, merges their coverage into
one report, and keeps the total line floor from `.codeflow/test-config.json`.
It runs every test, relaxes no floor and reuses the planner's exactly-once
check. Non-goals: changing the planner, the CI workflow, or the floor.
