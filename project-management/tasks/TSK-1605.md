# TSK-1605: Allow settled main history and main-filed epic tasks to sync cleanly under work.import_authority

## Description

Source: Director ruling 2026-11-24 (`msg_6c68fc420eee`, relayed via `coord/ci` `msg_a1fae898a0ac`) after `scratch-ci-import-authority-2026-11-20-n-result.txt` (`proof n`, binary `8e1a7b27f8` on `TSK-1513` m3 range `960eb7dbf4..cd7649a358`) exited 1 with 16 `work.import_authority` blocks covering 15 affected task records across 11 settled historical `main`/line PRs (PRs 487, 528, 641, 649, 655, 666, 680, 772, 782, 831, 925).

Owner: `coord/planning` (critical path for installing the `main` binary).

All 15 blocked tasks in `proof n` are settled, merged history on `main` (or `EPC-022`), not new mutations introduced by the sync:
- **6 criteria-resolution blocks (`TSK-1240`, `TSK-1252`, `TSK-1305`, `TSK-1357`, `TSK-1361`, `TSK-416`):** `crates/codeflow-core/src/workgraph/acceptance/imports.rs:1107-1133` calls `RecordStore::judge(&[base, landed], ...)` where `base` is the receiving integration line (`960eb7dbf4`) and `landed` is a settled historical merge on `main`. On a long-diverged line sync, neither commit is an ancestor of the other and the line still holds an older (or absent) record while `main` holds the settled version, so `judge` returns `Authority::Unknown`.
  - Amended 2026-11-24 by the Director's decision: `TSK-1361` leaves the tasks this fix clears, so the criteria-resolution claim covers the other five. A task branch added the record (`f47854fc23`) and moved it to its `main` pull request (`bef8441920`). The commit graph alone cannot tell that from a record the line landed and a foxtrot merge later hid from its first-parent history, so the check stays fail closed and still refuses `TSK-1361`. Its unblock is a records route tracked in this same unit. Earlier text, kept above: the six tasks.
- **4 home/no-source blocks (`TSK-1317` `f248cf2845`, `TSK-1352`/`TSK-341` `63061d2109`, `TSK-1570` `5565469053`):** `imports/home.rs` blocks historical home moves predating the rule and blocks `TSK-1570` (filed on `main` via PR #925 with `integration_target: integration/EPC-022-the-3-2-0-milestone-fixes`) from syncing onto its own declared home line.
- **4 post-merge file blocks (`TSK-1177` `2070fabb82`, `TSK-1312`/`TSK-1318`/`TSK-1365` `841c367452`) and 1 archive-order block (`TSK-355` `82d46ec228`):** settled historical `main` merges from weeks earlier re-judged retroactively during a `main`->line sync.

Non-goals: weakening `work.import_authority` for unreviewed local commits, forged imports, or non-`main` branches; relaxing acceptance checks on new task completions after the sync.

## Outcome

After this merges, `codeflow ci` on a `main`->integration-line sync accepts records whose exact blob arrived cleanly from `main`'s published first-parent history (including tasks filed on `main` targeting that epic line) without false-positive `work.import_authority` blocks on diverged-branch criteria or settled historical `main` merges, while still blocking forged, unmerged, or locally altered imports.

Amended 2026-11-24 by the Director's decision: the Outcome excludes a record whose criteria the receiving line's own history decided, including one it planned and withdrew, as with `TSK-1361`. Such a record stays refused by the check.

Amended 2026-11-24 by `coord/planning` after a review finding: a historical completion whose proof the check cannot repeat syncs only after the operator sets `git.import_authority_settled_before` in the trusted default branch's policy. The merge of this task alone does not sync it, since the key is unset by default.

## Acceptance Criteria

- AC-1 On a `main`->integration-line sync where a task record at `head` matches `main`'s published blob and arrived via a merge of `main`'s first-parent history, `work.import_authority` shall not fail with `accepted criteria cannot be resolved` solely because the receiving line `base` and the historical `main` landing are diverged; evidence: fail-before and pass-after unit/CLI test output.
  - Amended 2026-11-24 by the Director's decision: divergence is the sole cause only when the base's history outside the landing decided nothing about the criteria. `TSK-1361`, which a task branch on the line added (`f47854fc23`) and moved to its `main` pull request (`bef8441920`), is outside this criterion and stays refused. The criterion's text is unchanged.
- AC-2 A task record filed on `main` (via a reviewed planning merge on `main`'s first-parent history, including a mixed planning merge carrying `docs/` or an ADR alongside task records as in PR #925 `5565469053` for `TSK-1570`) with `integration_target` naming an epic integration line shall sync cleanly onto that declared home line when the receiving head holds `main`'s exact blob, without a `NO_SOURCE` or `MOVED` `work.import_authority` refusal; evidence: fail-before and pass-after test output on a fixture preserving the PR #925 mixed planning merge shape and exact-blob check (or the real `960eb7dbf4..cd7649a358` range).
- AC-3 Settled historical merges already on `main`'s first-parent history (predating the sync) shall not be re-rejected as `work.import_authority` defects on a `main`->line sync when the receiving head takes `main`'s exact blob unmodified, while any local modification, unmerged source, or non-`main` forged import shall still be refused; evidence: positive and negative test logs.
- AC-4 Security/enforcement-surface change: an independent cross-lineage review shall approve the exact head; evidence: verdict path in the acceptance block.
- AC-5 When the installed CLI runs `codeflow ci` on a pull request that syncs `main` into an integration line, the system shall report no `work.import_authority` refusal for an unmodified settled record that AC-1 to AC-3 admit, and shall refuse a sync whose line amended that record's criteria; evidence: a log of both runs of the branch's built binary, naming the binary's source revision. (journey)
  - Amended 2026-11-24 by `coord/planning`: criterion added after a review finding, since SPC-013 R-53 requires a `(journey)` criterion on this adopter-facing change.
