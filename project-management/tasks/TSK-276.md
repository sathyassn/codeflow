# TSK-276: A planning amendment can update the project's document index

## Description

An epic amendment that adds a planning home cannot also add that home's row
to the project's documentation map. `classify::amendment_path`
(`crates/codeflow-core/src/workgraph/classify.rs:257-281` at v3.1.0) admits
records, plans and non-product files under `docs/`, but not a root index
such as `DOC-INDEX.md`, so the range loses the planning class and fails
`work.criteria_frozen` (https://github.com/sathyassn/codeflow/issues/136). The `docs/research/` half of https://github.com/sathyassn/codeflow/issues/83 was
fixed by PR 61 (TSK-229, ADR-0078); its index half and its request that the
refusal name the admitted path set remain. The two issues are the same gap,
so they are one task. This task lets a project declare its document index
files in policy, admits them into a planning amendment, and makes the
refusal name the path and the admitted set. Product globs keep precedence,
so `docs/portal/**` stays out by design. Non-goal: a general configurable
planning-path list (issue 83 option 1); one declared index is the narrower
change and covers both reports.

## Deliverables

- the policy key and the admission: `crates/codeflow-core/src/hooks/policy_schema.rs`, `crates/codeflow-core/src/workgraph/classify.rs`
- the refusal text: the classification message in `crates/codeflow-cli/src/cmd/ci/` and its remedy in `crates/codeflow-core/src/remedy.rs`
- tests: `classify.rs` unit tests and `crates/codeflow-cli/tests/ci_cli/`
- docs: `docs/policy-reference.md`; cf-method's planning reference `assets/base/claude/skills/cf-method/references/project-organization.md`, its mirrors and baseline
- release note: `changelog.d/TSK-276.md`

## Acceptance Criteria

- AC-1 When a project declares its document index in policy and an epic
  amendment changes task criteria and adds a row to that index, `codeflow
  ci` shall class the range as an epic amendment; evidence: a ci fixture
  replaying issue 136 steps 1 to 4. (serves EPC-022 AC-1)
- AC-2 When no index is declared, classification shall be as at v3.1.0: a
  `docs/research/` packet stays admitted and a root `DOC-INDEX.md` stays
  refused; and a path under a product glob such as `docs/portal/**` stays
  refused even when declared; evidence: classify unit tests.
- AC-3 When a range loses the planning class, the refusal shall name the
  path that caused it and the admitted path set, the declared index
  included; evidence: a ci message test. (serves EPC-022 AC-1)
- AC-4 The new key shall be placed by the rule TSK-280 writes and pass its
  check, and `docs/policy-reference.md` and cf-method's planning reference
  shall state what a planning amendment may carry; evidence: TSK-280's
  check on this branch and the doc diff.
- AC-5 (journey) When a fresh `codeflow init --standard` project uses the installed
  build, a `plan/` branch that amends a criterion and adds a declared index
  row shall pass `codeflow ci` and pre-push; evidence: a CLI
  journey on a scratch repository.
