# TSK-282: Test fixtures stay in their own folder and never hang on pipes

## Description

Running the tests with `TMPDIR` inside a git repository made two commits on
that repository's branch and rewrote its `core.hooksPath`, because fixtures
create a project folder without `git init` and git discovers the enclosing
repository (https://github.com/sathyassn/codeflow/issues/104; `crates/codeflow-core/tests/scaffold_test.rs:22-28`,
`:249-260`, `:280`, `:1787-1788` at v3.1.0). Separately, a test that polls a
child before reading its piped output hangs when the host pipe buffer is
small (https://github.com/sathyassn/codeflow/issues/100). The named estimate test was fixed in PR 84; the
`read_bounded_regular` FIFO unit test and a durable check for the class
remain. Both issues are test-harness hygiene in the same helpers, so they
are one task. It changes no shipped behaviour.

## Deliverables

- isolation: `isolate_git` in `crates/codeflow-core/tests/scaffold_test.rs` and its copies in `permission_presets_update.rs`, `rule_map_contract.rs` and `rule_reinjection_update.rs`
- the FIFO unit test: `crates/codeflow-core/src/bounded_file.rs`
- the pipe sweep and its check: `crates/*/tests`, the check beside the existing test contracts in `crates/codeflow-core/tests/`

## Acceptance Criteria

- AC-1 (journey) When the suite runs with `TMPDIR` inside a git repository, that
  repository's refs, index, config and files shall be unchanged afterwards;
  evidence: a scripted run of `cargo test -p codeflow-core` and
  the CLI estimate tests with `TMPDIR` in a scratch repository, comparing
  its state before and after. (serves EPC-022 AC-6)
- AC-2 The shared isolation helpers shall set `GIT_CEILING_DIRECTORIES`, or
  every fixture that runs git shall `git init` first, and code paths that
  use libgit2 discovery shall be given the fixture's own repository;
  evidence: the helper diff and the run in AC-1.
- AC-3 The test `git()` helpers shall fail the test when git fails;
  evidence: a test of the helper.
- AC-4 `read_bounded_regular` shall return an error promptly for a FIFO;
  evidence: a unit test with a time bound.
- AC-5 Every test that spawns a child with piped output and waits or polls
  before reading shall drain its pipes, and a check shall hold that;
  evidence: the sweep table in the pull request and the check failing on a
  planted undrained loop. (serves EPC-022 AC-6)
