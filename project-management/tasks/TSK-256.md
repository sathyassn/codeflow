# TSK-256: The quick gate runs the repository update replay

## Description

`codeflow update` must be a no-op on this repository, and the test that checks it, `codeflow_update_is_a_no_op_on_this_repository` (`crates/codeflow-core/tests/repository_update_noop.rs`), runs only in hosted CI (`cargo nextest run --workspace`) and in the local full gate through `rust-coverage`. The local quick gate, which the pre-push hook runs, does not run it, so PR 112 (TSK-249) put `git.claim_remotes` in `assets/base/policy.json` without resyncing the install and the failure first appeared in hosted CI. This task adds one quick-mode target, `repository-update-noop`, that runs only that test file, requires nothing outside the quick set, and leaves the `journey-gate` and `rust-coverage` targets as they are. The gate contracts that list the quick set are updated in the same change. Non-goal: the installed-key half of the PR 112 failure, which only the base-binary `commit standards` job reproduces.

## Deliverables

- the quick target: `.codeflow/test-config.json`
- the quick-set pins: `scripts/test_gate_contracts.py`, `crates/codeflow-cli/tests/journey_gate.rs`

## Acceptance Criteria

- AC-1 When a shipped asset changes in a way that makes `codeflow update` rewrite this repository's install, `codeflow test --mode quick` shall fail and name the changed file. Evidence: a scratch worktree at `2981d46e5` (the `git.claim_remotes` template key) with this change's test-config applied fails the quick gate on `repository-update-noop`, and the same quick gate passes at this branch head.
- AC-2 When the pre-push hook runs the push set, it shall run `repository-update-noop` with the other quick targets and shall not pull a build producer or `rust-coverage` into the quick set. Evidence: `scripts/test_gate_contracts.py` and `the_quick_gate_runs_only_the_light_targets` in `crates/codeflow-cli/tests/journey_gate.rs` pass with the new quick set, and the pre-push hook's quick run on this branch lists the target. (journey)
- AC-3 When the quick gate runs, the target shall add a measured cost that is reported. Evidence: wall-clock of `cargo test -p codeflow-core --test repository_update_noop` warm and as the target's duration in the quick gate run, with the host load named.
