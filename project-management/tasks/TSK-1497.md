# TSK-1497: The docs portal takes the astro release that fixes two advisories

## Description

Advisories GHSA-mh32-jxcr-mh9f (fixed in astro 7.4.5) and GHSA-r3h5-4585-7x3w (fixed in 7.4.7) affect `astro` 7.3.8, which the docs portal and the shipped starter pin exactly in their `package.json` and lockfile pairs on `main` at ad5971c8d. The hosted security review job's osv-scanner step reports both advisories on both lockfiles, so it fails on every pull request into `main` and every line (for example PR 777, run 43542792650, job 132286963897). This task moves `astro` to 7.4.7 in both pairs, with the smallest lockfile change npm produces, and re-pins the portal state and the runtime script lists where the lockfile hash changes, as TSK-410 did for the 7.3 release. It adds no audit suppression, because a fixed release exists. astro 7.4.7 requires `vite` ^8.3.5 and `@astrojs/markdown-remark` ^7.3.0; `@astrojs/starlight` 0.41.6 accepts `astro` ^7.0.2 (npm registry, 2026-11-13). Effect on adopting projects: `codeflow update` installs the starter's new `package.json` and lockfile.

Non-goals: other dependency upgrades beyond what astro 7.4.7's own ranges require.

## Outcome

After this merges, the docs portal and the shipped starter resolve `astro` 7.4.7, osv-scanner reports neither advisory on either lockfile, and the hosted security review no longer fails on them.
