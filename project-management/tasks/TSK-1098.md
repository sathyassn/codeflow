# TSK-1098: codeflow report progress renders the figure-led progress document and its plain-text form

## Description

The operator asked on 2026-10-30 that status be presented in a visually
rich way with supporting text, never as long text tables or text in
boxes, on `cf-present`. TSK-1095 computes the facts; this task renders
them so the same facts open as a `cf-present` document on any adopting
project and print as a plain-text form for terminals, pull request bodies
and chat. The rendering is in the binary so it is deterministic, tested
and the same in every project; the skill (TSK-1099) adds only the
session's context.

```text
  codeflow report progress --present <document.json>
        |
        v
  anchor (narrative: scope, why it matters, state in one line)
        |
        v
  orienting figure: extent, one row per level (scope, epics), to 100
        |
        v
  order: graph figure, open tasks ranked, critical path heavier,
         blocked nodes dashed
        |
        v
  lanes: extent, one row per lane, plus the overall row   (when any)
        |
        v
  tasks: encoded table, grouped by epic, cells: stage mark, percent bar,
         estimate with basis, issue mark; exact values as text
        |
        v
  issues: status block, one row per item with its check time
        |
        v
  disclosures: the ladder, the estimate bases, the raw facts table
```

Figure: the fixed block order of the progress document, from the anchor
to the reachable detail; every number appears first as a mark and stays
as text.

Decisions, each reversible and disclosed here:

- `--present <path>` writes a `schema_version: 2` document the skill opens
  with `codeflow present open`; `--md` prints the plain-text form with the
  fenced ASCII chat forms of the same families (`figure-grammar.md`
  section 7) and the ladder, for a terminal, a PR body or a reply; the
  default text output of TSK-1095 is unchanged.
- The document follows the bar of TSK-1097: anchor first, each section a
  titled narrative with a lead line, the figure or encoded visual, short
  acting text; plain tables in disclosures only. The anchor's "what is
  being worked on" line is the scope and the ready set; the skill may
  prepend one context block, and the document carries a `summary`.
- Percent per level is an extent figure with `max` 100 and limit ticks at
  the stage boundaries, one row per level; lanes are a second extent;
  order is a graph figure with the critical path heavier and blocked
  nodes dashed; tasks are the encoded table of TSK-1096 with the stage
  mark (`done`, `todo`, `blocked`, `stop`), a bar for the percent, the
  estimate as text with its basis in the row group, and an issue mark;
  issues are a `status` block (fail for blocked and red, pending for
  waiting and unverified, not_run for unknown). No `html` stage and no
  callout per task.
- Governing path in accent: the critical path and the scope row; warn
  for an estimate marked stale; stop for a blocker; never hue alone.
- A scope with more than 24 open tasks groups tasks by epic in the table
  and draws the graph for the critical path and its neighbours only,
  saying so in the caption; the full order stays in a disclosure table.
- Every figure fact names its source in the facts JSON, so the twin and
  the description hold the exact values; nothing is drawn that the facts
  do not state, and `unknown` draws as the `na` mark, never as zero.

Non-goals: the facts (TSK-1095); the skill, its wiring and its context
prose (TSK-1099); opening the browser (the skill does); a stored or
scheduled report; new figure families or blocks.

## Outcome

After this merges, one command turns the progress facts of any adopting
project into a present document a reader grasps in a few seconds, with
every value reachable, and into a plain-text form for terminals and pull
requests.

## Deliverables

- the renderer: `crates/codeflow-core/src/progress/present.rs` and `progress/text.rs` (new), wired to `codeflow report progress --present <path>` and `--md` in `crates/codeflow-cli/src/cmd/report.rs`
- the figure declarations: the extent, graph and encoded-table builders from the facts, with `facts` entries naming the JSON fields, validated by `codeflow present check` in the tests
- tests: unit tests per block over the fixtures of TSK-1095 (four stages, a cancelled task, an unknown value, no lanes, two lanes, more than 24 open tasks, a stale forecast), a `present check` run with no warning on each document, a rendered capture of the four-stage fixture in light and dark at wide and 390 px, and the `--md` form checked against `.codeflow/rules/writing.md` "Figures by surface" (printable ASCII, under 78 columns, a legend line and one caption per figure)
- docs: `docs/cli.md` (the two flags), `docs/present-guide.md` (the progress document as a worked example of the bar)
- release note: `changelog.d/TSK-1098.md`
