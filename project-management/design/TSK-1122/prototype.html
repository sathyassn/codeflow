What it is

The 4.0.0 release plan addresses issues filed by this repository and by adopters. The original 2026-10-12 scope covered 26 issues against CodeFlow 3.0.0 and 3.1.0. The combined scope covers codeflow ci verdicts that depend on how a range is spelled, planning and exemption pull requests that cannot be classified, guards that miss commands, writers and history reads that can be redirected in a local clone, CodeFlow's own pushes using a personal credential, managed CI steps an adopter must edit by hand, a landing mode, tests that touch an enclosing repository, and one post-release evaluation.
