# meta-awareness - Extended Guide

**CRITICAL:** Apply to EVERY response to the user throughout the session

## When to Apply

- Every response to the user
- All responses throughout the session

## Execution

1. Acknowledge protocol awareness at start of work
2. Proceed with work

## Common Patterns

**Every response:** "I'll help you implement the authentication feature..."
**Every response:** "The function is located in src/utils/validation.ts:45"
**Every response:** "I've completed the refactoring across 5 files."

## Anti-Patterns

**Missing acknowledgment:**

"I'll help you implement the authentication feature..."

Problem: No protocol consciousness signal

**Inconsistent application:**

- First response: "Starting work..."
- Second response: "I've completed step 1..."
- Third response: "Finished!"

Problem: Inconsistency undermines confidence

**Excessive signaling:**

"I'll start by reading the file. Then I'll make the changes. Finally I'll verify."

Problem: Overuse dilutes signal (acknowledge once at start only)

**Correct pattern:**

"I'll implement the authentication feature by reading the config, updating the middleware, and testing the flow."

One acknowledgment at the start, then proceed with work
