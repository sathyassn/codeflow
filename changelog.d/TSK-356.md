### Changed

<!-- codeflow:release-impact none -->
- **CodeFlow's own slow tests do repeated work once, and the exhaustive
  matrices run only in the full gate.** The Herdr delivery test runs its stub
  corpus once per distinct installed skill instead of six times, and still
  checks every fresh and updated install byte for byte. The push budget test
  checks the budget and its remedy with a measured duration; the one real
  one-minute push stays in the full gate. The planned-project fixtures of the
  readiness, offline-read, release-line and acceptance tests are built once
  per run and copied for each test. The essential gate leaves out the
  exhaustive tier, harness, crash-point and random-input matrices, each with
  a smaller test of the same boundary kept beside it; the full gate runs
  every test. This changes test code and gate configuration only. No
  `codeflow` command, file, setting or release asset changes.
