  through nested repositories, submodules, unrelated checkouts and commands
  started outside a repository. Keep checkout pointers subject to discovery
  checks after an external move and prune. Refuse persistent Git settings
  that relocate discovery, shell worktree moves and removal of worktree
  sources by rsync. Ordinary Git worktree lifecycle commands remain available.
  Registration mismatch messages name `git worktree repair` in the operator's
  own terminal outside the harness.
  Plain Git repositories without CodeFlow adoption receive these target
  protections too. Build cleanup stays available inside worktrees and in
  build folders under configured worktree locations. Malformed enclosing
  markers cannot lock ordinary nested-project files, and agent writes
  cannot plant ancestor markers. The checks cover expanded discovery keys,
  Git through arch or xargs, non-interactive editors, submodule and separate
  Git directories, source-removing rsync spellings and checkout gitfiles,
  and Git-native creation inside enforcement directories. Refusals identify
  hidden checkouts and unreadable markers with the relevant recovery route.
