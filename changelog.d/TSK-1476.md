### Changed

<!-- codeflow:release-impact minor -->
- **Only the operator installs or refreshes a project's enforcement
  files.** The guards now refuse an agent's run of the init and update
  verbs, with any binary and in any folder, and name the operator as the
  one who runs them; the forms that only print help or the version stay
  allowed. The shipped Claude presets also deny the native edit tools each
  linked worktree's copy of the harness settings, hooks and policy, as they
  do the root checkout's. Guard and hook messages that pointed to the
  update verb now say the operator runs it. An agent that ran either verb
  before now asks the operator instead. The release notes list the accepted
  over-refusals and the remaining limits.
