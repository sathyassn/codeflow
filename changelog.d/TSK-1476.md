### Changed

<!-- codeflow:release-impact minor -->
- **Only the operator installs or refreshes a project's enforcement
  files.** The guards now refuse an agent's run of the init and update
  verbs through the binary named `codeflow`, in every path spelling, launcher
  and folder the guards read, and name the operator as the one who runs
  them. The binary's own help and version forms, called by its bare name,
  stay allowed. Text that names the verbs stays allowed only in a small set
  of forms that print or search, such as `echo`, a `printf` of plain
  strings and `grep`; the same text anywhere else, a commit message
  included, is refused, so put it in one of those forms or leave the
  binary's name out of a search. The text is judged as the shell passes
  it, as plain `printf`, `echo` and `print` output writes it, and as a value
  the line assigns. Where a line hands text it produces to a shell or
  interpreter on the same line, through a pipe, a here-string, a
  substitution, `eval` or a similar route, that text must be one `printf`,
  `echo` or `print` of plain literal text, or a literal here-string or
  here-document. Text the line spells that any other program on the line
  receives, by its input, a file operand, an argument or an output stream,
  takes the same form unless the guard knows that program only reads it as
  data. A plain file counts
  as running that file on a line that writes no file, and a line of more
  than one command that writes a file and also runs one, or names a file
  it writes to a program the guard does not know, refuses. Any other such line refuses
  whatever it names, so write the commands literally, or put them in a
  file the line does not write and run that on a line of its own. Guard, hook, doctor
  and remedy messages that pointed to either verb now say the operator runs
  it. An agent that ran either verb before now asks the operator instead. A
  renamed or copied binary, text a line writes to a process started
  earlier that runs what it reads, and another program's output that
  reaches a program the guards do not know, are not identified by the
  guards; the
  release notes list them with the other limits and the accepted
  over-refusals, and the policy reference names the layers that still
  hold.
