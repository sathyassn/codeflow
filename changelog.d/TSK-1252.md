### Fixed

<!-- codeflow:release-impact minor -->
- **The pull request policy check passes on a hardened checkout of a private
  repository.** Every shipped checkout now sets `persist-credentials:
  false`, so no token stays in the checkout for later steps or repository
  code. `codeflow ci` asks the destination for its default branch with the
  run's read-only token, passed to its step only as `CODEFLOW_CI_TOKEN`,
  sends it only to the run's own repository over HTTPS, follows no redirect
  with it and writes it nowhere. The fetch steps get the token for
  themselves the same way. A missing, rejected or unpermitted token fails
  closed and names the missing input. Run `codeflow update` to take the new
  workflows.
