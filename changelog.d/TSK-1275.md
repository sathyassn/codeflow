### Changed

<!-- codeflow:release-impact patch -->
- **Guard calls and git hooks stay fast in a repository with many linked
  worktrees.** One `git-guard`, `exec-guard` or `edit-guard` call, and each
  git hook's repository lookup, now lists the repository's worktree
  registrations once, keeps each directory listing it reads for case
  recovery on macOS while that directory is unchanged, and opens one linked
  checkout fully per shared git directory: another linked checkout whose own
  files are proven the same skips its second open. Every check each
  checkout received before still runs, and nothing is kept from one call to
  the next. On a release build with 175 linked worktrees and an 18 KB
  config, the median guard call fell from about 250 ms to about 60 ms.
