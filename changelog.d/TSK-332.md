### Fixed

<!-- codeflow:release-impact patch -->
- **A killed docs portal run no longer blocks the next one.** The workflow
  lease for `check`, `build`, `dev` and `preview` now records its owner, the
  coordinator process, each writer it starts and the process group each
  writer leads. When the coordinator and every writer group on the same host
  have exited, for example after `kill -9` or a timed-out gate target, the
  next run reclaims the lease at once and prints one line naming the dead
  owner. A live coordinator or writer always blocks, whatever the lease age,
  and its process ids are named. A coordinator killed while starting a writer,
  a lease from another host, an older lease without an owner, or a failed
  liveness check keeps the four-hour age rule.
