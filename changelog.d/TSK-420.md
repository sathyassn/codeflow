### Added

<!-- codeflow:release-impact minor -->
- **Session orientation shows integration-line drift and open epics.**
  `codeflow orient` and the SessionStart digest list each fetched line's
  commits behind the target, latest own sync or creation state, and oldest
  unlanded task age. Offline rows use local refs and say so. Creation stays
  unknown without ref-creation evidence; inherited history never supplies
  a sync date. `git.line_sync_interval` optionally enables reminders in
  days, default off, naming the sync route pending TSK-421. Open epics show
  how many distinct tasks have visible unlanded branch claims.
