### Fixed

<!-- codeflow:release-impact none -->
- **The decision-map figure no longer goes stale as the decision count grows.** The
  technical figure on the decision map repeated the map's decision count as
  fixed text, so each new decision broke the docs portal check until the
  figure was edited by hand, and a planning pull request could not carry that
  edit. The figure's fact now reads the decision table's superseded row,
  which a new decision never changes. A unit test adds one decision to the
  map and checks that every decision-map figure fact still holds, and that a
  fact whose text or section is gone is still refused. A decision that starts
  a new supersession chain still needs the architecture figure's chain count
  updated, and the portal check refuses until it is. This changes this
  repository's docs portal only. No `codeflow` command, file, setting or
  release asset changes.
