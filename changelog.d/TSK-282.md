### Changed

<!-- codeflow:release-impact none -->
- **The test suite no longer changes a repository that holds its temporary
  directory.** With `TMPDIR` inside a git repository, fixtures that ran git in
  a project folder without a repository of its own found the enclosing one
  and committed to it or configured it (sathyassn/codeflow#104). Fixture
  folders now get a repository of their own when one encloses them, the shared
  test helpers set `GIT_CEILING_DIRECTORIES`, and the scaffold test `git`
  helper fails the test when git fails. A test that waits for a child no
  longer leaves the child's piped output unread, and a new source check fails
  when one does (sathyassn/codeflow#100). A unit test now holds that
  `read_bounded_regular` refuses a fifo without opening it. This changes test
  code only. No `codeflow` command, file, setting or release asset changes.
