### Fixed

<!-- codeflow:release-impact patch -->
- **The exec guard now judges what an interpreter is given, not only its
  inline code.** In 3.1.1 and earlier, `exec-guard` never read an
  interpreter's arguments, so `python3 - "<repo>/.claude/settings.json"`
  with a heredoc that wrote `sys.argv[1]` was allowed, and an agent could
  change the settings file where the guard hooks are wired
  (sathyassn/codeflow#173). The guard now judges the arguments and inline
  code of `python`, `node`, `perl` and `ruby` from every directory the
  line may run them in, including through launchers, `xargs` and
  `find -exec`; on a line where a shell or interpreter runs, it judges
  every quoted string as possible code, and every word when the program
  itself comes from a pipe, a here-string, a descriptor or a substitution.
  Text the line composes (assignments, `printf`, `echo` and zsh `print`,
  command substitution over those builtins, arrays, loops and child
  shells) is read closed-world, as bash and zsh build it: a value resolves
  only from literals read exactly through a construct the guard models,
  and any other construct that feeds it refuses as cannot-verify, named
  by its family. Grammar the guard does not model makes the directory set
  unknown, and every word is then judged by its trailing components. A
  path that names an enforcement file refuses under `git.hook_integrity`,
  and one naming policy authority metadata refuses whatever the level;
  reading an enforcement file with an interpreter now needs a reader
  (`cat`, `jq`, `grep`) or a redirect into its stdin. The guard models
  shell grammar (operator decision, 2026-10-15): text a program produces
  at run time, a path the interpreter's own code builds, and code in a
  file the guard does not read are the stated residual, judged like an
  unassigned variable, by its trailing components and as if empty, with
  the OS sandbox and permission preset as the backstop. Some ordinary
  lines that run an interpreter now refuse: a composition the guard
  cannot read exactly (a parameter operator on an assigned value, an
  escape or option cluster it does not model, an array element
  assignment, a declaration builtin with options), `read` from text the
  line spells, a glob or unquoted program output given to `printf`,
  program output between spelled pieces that would join to a protected
  path if empty, `cd .claude && cd .. && python3 tool.py settings.json`,
  and a repo-root `find . -execdir`. Installing the 3.2.0 `codeflow` on
  `PATH` brings the refusal.
