### Security

<!-- codeflow:release-impact patch -->
- **Remote branch names are shown escaped.** A remote names its default
  branch and its other branches itself, and can put characters a terminal
  acts on in those names: git accepts the C1 control CSI (U+009B), bidi
  overrides, the line separator U+2028, the soft hyphen and the invisible
  tag characters, and a server that is not git can send any byte. What the
  CodeFlow binary prints through its print macros, and the error it exits
  with, now shows each control character as `\xNN` and each Unicode
  default-ignorable, format or separator character as `\u{NNNN}`, keeping
  line breaks, tabs and backslashes; a ref name also shows a backslash as
  `\\`. Combining marks stay as they are. JSON output writes those
  characters as JSON escapes, so each value is unchanged. Refusals, notes,
  printed errors and record titles indent a message's further lines, and
  every print indents a further line that a quoted value starts, so a
  title, a path or a policy value cannot forge a line of CodeFlow's
  output. A line that could begin with checkout text starts with a fixed
  label: the orient product line (`product:`), test gate results
  (`target`), feedback topics (`topic:`), `models` participants
  (`participant:`), remote protect branches (`branch`) and docs lint
  errors. Every further line of the `doctor` model-bindings result (its
  rows, warnings and notes) is now indented under the result. Panic
  messages and command-line usage errors are not covered. Ordinary names
  print unchanged, and every check still uses the exact name.
  - Changed output. These human-readable lines now start with a fixed
    label. JSON output is unchanged and is the format to parse.
    - `codeflow orient` and the session-orient hook: `<purpose>` is now
      `product: <purpose>`.
    - `codeflow test` results: `<name>: ok (exit 0, 12 ms)` is now
      `target <name>: ok (exit 0, 12 ms)`.
    - `codeflow feedback list` topic headings: `<topic>` is now
      `topic: <topic>`.
    - `codeflow models resolve` participants and open gaps:
      `<participant>: ...` is now `participant: <participant>: ...`.
    - `codeflow remote protect` plan lines: `<pattern> [<mechanism>]:` is
      now `branch <pattern> [<mechanism>]:`.
    - `codeflow validate --docs` lint errors: `<file>:<line>: <message>`
      is now `validate --docs: error: <file>:<line>: <message>`.
    - `codeflow doctor --check model-bindings`: the result's further lines
      (rows, warnings and notes) are now indented two spaces.
