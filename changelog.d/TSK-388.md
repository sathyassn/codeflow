### Security

<!-- codeflow:release-impact patch -->
- **Remote branch names are shown escaped.** A remote names its default
  branch and its other branches itself, and can put characters a terminal
  acts on in those names: git accepts the C1 control CSI (U+009B), bidi
  overrides and the line separator U+2028, and a server that is not git can
  send any byte. The pre-push hook and its refusals, `codeflow ci`, the
  release checks, the guards' policy source, `codeflow status` and
  `codeflow work next` now show each control character in a branch name as
  `\xNN`, each format or separator character as `\u{NNNN}` and a backslash
  as `\\`, so the name cannot write a terminal escape sequence or reorder
  its line. Refusals and notes escape the same characters in every message
  and indent a message's further lines, so a policy value from a remote
  cannot forge a line of the guard's output; the pre-push hook escapes them
  in the check output it relays. Ordinary names print unchanged, and every
  check still uses the exact name.
