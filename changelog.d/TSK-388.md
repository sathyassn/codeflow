### Security

<!-- codeflow:release-impact patch -->
- **Remote branch names are shown escaped.** A remote names its default
  branch and its other branches itself, and can put characters a terminal
  acts on in those names: git accepts the C1 control CSI (U+009B), bidi
  overrides, the line separator U+2028, the soft hyphen and the invisible
  tag characters, and a server that is not git can send any byte. What the
  CodeFlow binary prints through its print macros, and the error it exits
  with, now shows each control character as `\xNN` and each Unicode
  default-ignorable, format or separator character as `\u{NNNN}`, keeping
  line breaks, tabs and backslashes; a ref name also shows a backslash as
  `\\`. Combining marks stay as they are. JSON output writes those
  characters as JSON escapes, so each value is unchanged. Refusals, notes,
  printed errors and record titles indent a message's further lines, so a
  title or a policy value cannot forge a line of CodeFlow's output. Panic
  messages and command-line usage errors are not covered. Ordinary names
  and text print unchanged, and every check still uses the exact name.
