### Security

<!-- codeflow:release-impact patch -->
- **Remote branch names are shown escaped.** A remote names its default
  branch and its other branches itself, and can put characters a terminal
  acts on in those names: git accepts the C1 control CSI (U+009B), bidi
  overrides, the line separator U+2028, the soft hyphen and the invisible
  tag characters, and a server that is not git can send any byte. Every
  line the CodeFlow CLI prints now shows each control character as `\xNN`
  and each Unicode default-ignorable, format or separator character as
  `\u{NNNN}`; a ref name also shows a backslash as `\\`. Combining marks
  stay as they are. JSON output writes those characters as JSON escapes,
  so each value is unchanged. Refusals, notes and printed errors indent a
  message's further lines, so a record title or a policy value cannot
  forge a line of CodeFlow's output. Ordinary names and text print
  unchanged, and every check still uses the exact name.
