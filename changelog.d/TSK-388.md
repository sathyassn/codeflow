### Security

<!-- codeflow:release-impact patch -->
- **Remote branch names are shown escaped.** A remote names its default
  branch and its other branches itself, and can put control characters in
  those names: git accepts the C1 control CSI (U+009B), and a server that is
  not git can send any byte. The pre-push hook, `codeflow ci`, the release
  checks, the policy source and `codeflow status` now show each control
  character in such a name as `\xNN` and a backslash as `\\`, so the name
  cannot write a terminal escape sequence into their output. The pre-push
  hook also escapes control characters in the output of the checks it
  relays. Ordinary names print unchanged, and every check still uses the
  exact name.
