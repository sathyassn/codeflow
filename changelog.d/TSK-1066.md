### Fixed

<!-- codeflow:release-impact patch -->
- **A task pull request into an epic line judges its sync merges as the
  line push does.** `codeflow ci` for a pull request from a task branch
  into an epic line now checks each merge on the branch against that line,
  so a sync of `main` that hand-edits a `main` task's file blocks and names
  the merge and the file. Before, only the line's own push ran this check.
  A sync merge that edits a task's acceptance block is refused with a
  message that names that edit and the merge, never an unrelated file
  changed on `main`. A refusal calls a merge a task's "landing merge"
  only when it is on a trusted receiving line; a sync is "the merge". A clean sync still
  passes in every form (issue #394).
