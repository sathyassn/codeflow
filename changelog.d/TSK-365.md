### Changed

<!-- codeflow:release-impact none -->
- **The CI pin journey exercises the installed candidate.** The local release
  fixture contains the actual candidate executable and its archive checksum.
  The journey checks the installed digest, accepts valid pull request data,
  and verifies that head edits cannot suppress the authority's commit-format
  refusal. An always-approving executable passes the old version-only check
  and fails the strengthened journey. This changes repository tests and their
  documentation; shipped installer behavior is unchanged.
