### Changed

<!-- codeflow:release-impact none -->
- **The CI pin journey exercises the installed candidate.** The local release
  fixture contains the actual candidate executable and its archive checksum.
  The journey runs the authority workflow's install and verdict steps, and
  proves each hostile head by its own evidence: a lowered pin leaves the
  candidate installed rather than the head's 1.0.0 executable, a forged
  workflow leaves the executed steps byte for byte the shipped ones, and a
  relaxed policy still gets the authority's refusal naming the commit's
  fresh subject. An always-approving executable and one that prints a fixed
  refusal both fail the journey. This changes repository tests and their
  documentation; shipped installer behavior is unchanged.
