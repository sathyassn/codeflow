### Security

<!-- codeflow:release-impact patch -->
- **Remote-tracking base anchors.** `codeflow ci` and the pre-push hook read
  a base branch named by CI metadata, `CODEFLOW_DEFAULT_BRANCH` or the policy
  protected branches only as `refs/remotes/origin/<name>`, then
  `refs/heads/<name>`, spelled in full. A local branch named `origin/main`
  no longer stands in for the fetched `origin/main`, so it cannot hide
  commits from a bare run or bind a local-only epic line.
