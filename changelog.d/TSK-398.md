### Security

<!-- codeflow:release-impact patch -->
- **Remote-tracking base anchors.** `codeflow ci` and the pre-push hook read
  a base branch named by CI metadata, `CODEFLOW_DEFAULT_BRANCH` or the policy
  protected branches only as the exact ref `refs/remotes/origin/<name>`, then
  `refs/heads/<name>`. A local branch or tag named `origin/main`, or one whose
  full name is `refs/remotes/origin/main`, no longer stands in for the fetched
  `origin/main`, so it cannot hide commits from a bare run, bind a local-only
  epic line, or empty the epic-line check of a line's first push. Status
  verbs and `epic new --integration` read the default target the same way.
  A base variable with revision syntax, such as `main~1`, is ignored with a
  warning.
