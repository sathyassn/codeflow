### Security

<!-- codeflow:release-impact patch -->
- **Remote-tracking base anchors.** `codeflow ci` and the pre-push hook read
  every base branch by its exact ref. The policy protected branches read
  `refs/remotes/origin/<name>`, then `refs/heads/<name>`. A local branch or
  tag named `origin/main`, or one whose full name is
  `refs/remotes/origin/main`, no longer stands in for the fetched
  `origin/main`, so it cannot hide commits from a bare run or a pre-push
  range, bind a local-only epic line, or empty the epic-line check of a
  line's first push. Status verbs and `epic new --integration` read the
  default target the same way. A base named by CI metadata,
  `CODEFLOW_DEFAULT_BRANCH` or `--into` is read as written when it is a full
  `refs/` name, as `refs/remotes/origin/<name>` for `origin/<name>`, and
  otherwise like a protected branch; a value that breaks Git's branch-name
  rules, such as `main~1`, is ignored with a warning.
