### Changed

<!-- codeflow:release-impact patch -->
- **CodeFlow's own policy check reuses a build that main saved.** In this
  repository's hosted pipeline, a push to main now builds the policy binary
  from main's code and saves it under a key made of the exact commit and the
  build environment, and attests it. A pull request on main runs the restored
  binary only after `gh attestation verify` authenticates it against main's
  workflow and commit; the embedded source identity check then catches a
  stale entry. Anything else rebuilds. No other run saves into main's cache,
  so integration output cannot reach it.
