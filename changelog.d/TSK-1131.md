### Changed

<!-- codeflow:release-impact minor -->
- **Sessions start at each model's recommended effort.** The shipped model
  catalog no longer binds the host, the planning primaries, the designer,
  the executor and the reviewers at high. Each seat starts at its model's
  vendor-recommended default (medium for Opus, Sonnet and the Codex lines;
  high for Fable and Grok) and rises to high only when a named need (a hard
  build, a security review or a stuck diagnosis) is applied to that lane;
  the orchestrating session is never raised by a trigger. A project binding
  now accepts the medium default and keeps a higher bound effort. The
  highest-cost reasoning model is kept for review, analysis and direction,
  and no execution route binds it (ADR-0095).
