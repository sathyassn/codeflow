### Added

<!-- codeflow:release-impact minor -->
- **A project can run each model family's seats under its own account
  folder and read the limit state of each family.** An untracked profile,
  `.codeflow/local/accounts.toml` (or `accounts.toml` in the CodeFlow home),
  maps Claude, Codex and Grok to a config home and, optionally, to a capped
  API-key fallback by variable name. It never holds a token: a credential
  key name, a secret-shaped value or an unknown key refuses the file. A seat
  launches with only its own family's variable (`CLAUDE_CONFIG_DIR`,
  `CODEX_HOME` or `GROK_HOME`) through `codeflow models launch-env`, and
  `codeflow delegate init --config-home` records the folder in each turn's
  provenance. `codeflow models limits` shows each family's used share and
  reset time for the 5-hour and weekly windows, or `not exposed`, from
  Claude Code's statusline, a Codex app-server rate-limit payload or a Grok
  limit-hit error stored by `codeflow models record-limits`. The managed
  `.gitignore` now ignores `.codeflow/local/`. CodeFlow does not switch
  accounts or move a sign-in.
