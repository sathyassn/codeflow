### Changed

<!-- codeflow:release-impact none -->
- **Gate runs of an unchanged tree still execute every target.** Reusing a
  passed result from an earlier local run is not enabled: no local run
  record earns credit (ADR-0089), and no recorder that agent sessions and
  candidate tests cannot write has been adopted. A new test drives three
  explicit quick runs at three commits of one tree and checks that each
  executes every target, names the reason and cites no earlier run, and
  that a check which starts failing on the same tree is caught. Reuse is
  deferred until a sound recorder, such as hosted CI attestation, is
  adopted. No `codeflow` command, file, setting or release asset changes.
