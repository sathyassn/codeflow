### Fixed

<!-- codeflow:release-impact patch -->
- **Qualification trials with the shipped status line.** The repository's
  qualification runner refused every Claude trial whose fixture ships
  CodeFlow's status line, because it did not know the row the line draws
  under the editor. It now accepts that row only when it shows the requested
  `--model` id, the fixture's folder and the fixture's branch, including a
  row Claude Code cut after the branch in a narrow pane. Any other row still
  refuses. Pass the full model id, such as `claude-opus-5-5`, to a Claude
  trial whose fixture shows the line.
