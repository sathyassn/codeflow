### Fixed

<!-- codeflow:release-impact patch -->
- **Qualification trials with the shipped status line.** The repository's
  qualification runner refused every Claude trial whose fixture ships
  CodeFlow's status line, because it did not know the rows Claude Code draws
  under the editor. It now accepts only the known sets of rows for each
  frame: the status line when it shows the requested `--model` id, the
  fixture's folder and the fixture's branch (also when Claude Code cut it
  after the branch in a narrow pane), the mode row, and the transient editor
  hint only while the editor holds input. Any other row still refuses. Pass
  the full model id, such as `claude-opus-5-5`, to a Claude trial whose
  fixture shows the line.
