- **Research pins survive a deleted line.** A research or decision
  dependency stays met after the producer's integration branch is deleted:
  `work next`, `work claim` and `work start` accept a pin that holds the
  producer's completed record when it is on the producer's target, the
  consumer's target or the default branch. In a repository with any
  remote, each target is read at a remote-tracking ref: the branch's
  configured upstream when it is a `refs/remotes/<remote>/<branch>` ref of a
  configured remote, else `origin/<branch>`. A local `main` that is behind
  no longer refuses a landed pin, and no local branch, ahead, unpushed or set
  as an upstream, proves a landing; a local branch counts only in a
  repository with no remote. A missing object, an open or absent record at
  the pin and a pin on no target still refuse, and the refusal names the
  refs it read (#236).
