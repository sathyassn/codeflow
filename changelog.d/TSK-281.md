### Security

<!-- codeflow:release-impact patch -->
- **Temporary writes refuse planted links.** The test-config schema, locked
  JSON state and ledger compaction now write through unique files created
  exclusively, so a link at an old temporary name cannot redirect their
  contents. Template checks and ignore-rule probes use exclusively created
  scratch directories, and the test gate creates its run directory
  exclusively. Temporary files are removed after a failed write or replace.
  Existing scaffold and record writers retain their exclusive creation.
