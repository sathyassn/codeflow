- **Essential gates and heavy quick checks share the full-gate lock.**
  A conflicting run names the holder's process, mode and directory. Quick
  checks can declare light work that still runs, and a bounded wait for
  heavy work. `codeflow reserve -- <command>` reserves the same locks for
  direct commands and cleans up their descendants. An optional worker
  budget divides nested tool workers across concurrent heavy targets.
  Existing full-gate lock files remain compatible with 3.1 full gates;
  3.1 essential gates still take no lock.
