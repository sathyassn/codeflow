### Added

<!-- codeflow:release-impact minor -->
- **Pull requests can check capability declarations against their catalog
  changes.** The opt-in `git.pr_capability_impact` policy reads the authority,
  merge base and head as pinned Git data. It checks added and changed entries,
  names, user context and improvement clauses, and refuses removed identities.
  Local push preflight checks catalog data without requiring a PR body; hosted
  enforcement checks the actual target and rejects a changed PR snapshot.
  Tree catalog reads are limited to 10,000 input files and 64 MiB in total,
  alongside the existing per-file bounds.
