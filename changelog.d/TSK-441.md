### Changed

<!-- codeflow:release-impact minor -->
- **`cf-present` is the default visual surface.** In a CodeFlow project, a
  figure or explanation that needs more than an inline reply now opens
  `cf-present`. A harness page or widget, such as a Claude Artifact page, is
  used only when the operator asks for one or the content must be shared,
  since `cf-present` is local. The managed "show something complex" rows, the
  Claude harness row, "Figures by surface" in `.codeflow/rules/writing.md`
  and the `cf-present` skill description say so.

### Fixed

<!-- codeflow:release-impact minor -->
- **The review window lifecycle.** The review header has an End review
  control: it sends any queued notes as a review first, then ends the session
  and quits the isolated browser, as `codeflow present close` does. Closing
  the last review window keeps the session open, and the isolated browser
  quits 15 seconds later unless a window reopens. `codeflow present show` on
  a running browser opens a new window in it instead of refusing; on macOS
  the refusal left a running browser with no window.
