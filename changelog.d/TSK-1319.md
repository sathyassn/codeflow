### Fixed

<!-- codeflow:release-impact patch -->
- **Windows test plan when a pull request adds tests.** CodeFlow's own
  Windows CI no longer refuses its test plan when a pull request adds a few
  fast tests to a large test binary. Such tests now run with the rest of
  their binary, so no partition's command line has to exclude them by name,
  and a refusal names the binary and the list of excluded tests that caused
  it. The measurements are refreshed from recent green runs. This
  repository's CI scripts and data only; the `codeflow` binary and the
  shipped scaffold are unchanged.
