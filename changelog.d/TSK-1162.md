## Shared presentation tokens

The presentation runtime and documentation portal use one generated token
source for themes, modes, accents, type, spacing, radii, elevation and motion.
Graphite remains neutral; deep green is the default accent, with plum for
Graphite and Sage and violet for Slate as alternate accents.

Token checks enforce contrast and colour separation. Project palette imports
warn about close figure inks and recommend a second channel such as a shape,
pattern or label. The kits include shared minimum-size bar and ring geometry.
