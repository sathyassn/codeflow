### Added

<!-- codeflow:release-impact minor -->
- **Shared presentation tokens.** The presentation runtime and documentation
  portal draw themes, modes, accents, type, spacing, radii, elevation and motion
  from one generated token source. Graphite stays neutral, with deep green as
  the default accent and plum for Graphite and Sage or violet for Slate as the
  alternate accent. Token builds enforce contrast and colour separation.
  Project palette imports warn about close figure inks and recommend a shape,
  pattern or label as a second channel. The kits include shared bar and ring
  geometry that keeps small positive counts visible without changing labels.

### Changed

<!-- codeflow:release-impact major -->
- **The portal's runtime script list is version 2.** `scripts/runtime-scripts.mjs`
  now records the pre-paint script's hash for every portal theme in
  `scripts/runtime-scripts.json`, and `validate --portal` and the browser gate
  look that hash up instead of rebuilding the script. A version 1 list, an
  unknown theme or a missing hash is refused with the command to regenerate.
  Managed portals receive the new list through `codeflow update`. A
  transferred portal adopts the new `scripts/runtime-scripts.mjs` from the
  starter and regenerates the list:
  `npm run build && node scripts/runtime-scripts.mjs dist`.
