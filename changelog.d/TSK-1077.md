### Changed

<!-- codeflow:release-impact major -->
- **The default branch is the only local policy authority (4.0.0).** The
  guards and pre-commit's path checks read policy at the commit
  `refs/remotes/<remote>/HEAD` names; pre-push judges with the default
  branch the destination advertises; `codeflow ci` judges with the commit
  it is given (`--policy-from`, else `--base`), which the hosted jobs set to
  the pull request's target. An integration line, a task record or
  `git.root_branch` no longer adds path exceptions, denials or levels, and
  two task records that disagree on their `integration_target` no longer
  stop every git command. Nothing is guessed: an unset remote `HEAD`
  refuses, naming `git remote set-head <remote> -a`, instead of taking
  `origin/main` or `origin/master`; a remote `HEAD` naming a tag, a local
  branch or a short name refuses; a remote with refs but no tracking refs
  here refuses with `git fetch <remote>`; a remote that advertises no refs
  is labelled initialization and no remote is labelled local only. Telling
  those apart asks the remote with no configuration, so no configured
  command runs. When the authority holds no `.codeflow/policy.json`, the
  shipped defaults judge, in pre-push and `codeflow ci` too, never the
  working copy: an adoption pull request meets the shipped defaults,
  including the shipped PR sections, until its policy lands, and pre-push
  runs its commit checks from that default branch's tip as it does for a
  landed policy. Pre-push refuses with the fetch route when a destination
  advertises no branches but this clone still holds a tracking ref for it
  under any fetch mapping. `codeflow doctor --check policy-source` names
  the authority ref and its commit. The commit hooks still take their
  levels from the working copy until TSK-1078 lands. Migration: move any
  exception or level kept only on a line into the default branch's
  `.codeflow/policy.json` through a reviewed pull request, and run `git
  remote set-head origin <default>` once in a clone whose remote `HEAD` is
  unset, including after a new repository's first push. ADR-0091 records
  the whole content policy authority model.
