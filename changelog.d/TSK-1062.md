### Fixed

<!-- codeflow:release-impact none -->
- **The Windows killed-gate test reports its cause and leaves nothing
  running.** The test waited a fixed 60 seconds for its target's pid file with
  the helper's output discarded, so a slow runner and a failed helper looked
  the same, and a failed wait left the gate and its target running. It now
  stops at once when the helper exits, shows the helper's status and output,
  names what it could not observe when the 60 second bound is reached, and
  ends the gate and its target tree on every exit path. The journey test that
  drives the same PowerShell target through the real binary gets the same
  wait. This changes test code only. No `codeflow` command, file, setting or
  release asset changes.
