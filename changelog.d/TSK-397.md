### Fixed

<!-- codeflow:release-impact patch -->
- **Interpreter arguments after changing directory.** A leading literal
  `cd src && python3 tool.py ..` now resolves the interpreter's arguments
  from `src`, allowing a parent path that stays in the checkout. Protected
  files still refuse. Other joins and unproven shell forms keep the
  conservative directory set; symbolic links and `CDPATH` destinations are
  included when judging relative paths.
