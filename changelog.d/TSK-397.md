### Fixed

<!-- codeflow:release-impact patch -->
- **Interpreter arguments after changing directory.** A leading literal
  `cd src && python3 tool.py ..` now resolves the interpreter's arguments
  from `src`, allowing a parent path that stays in the checkout. Protected
  files still refuse. Only a bare interpreter name followed directly by its
  script is narrowed, and only when the logical and physical destinations
  of the `cd` agree; any other command, option, join or shell form keeps
  the conservative directory set. A line that names `CDPATH` or `cdpath`,
  however it is quoted, is judged as running in an unknown directory, and
  `ruby -C` resolves symbolic links before `..`.
