### Fixed

<!-- codeflow:release-impact patch -->
- **Interpreter arguments after changing directory.** A leading literal
  `cd src && python3 tool.py ..` now resolves the interpreter's arguments
  from `src`, allowing a parent path that stays in the checkout. Protected
  files still refuse. Only a single interpreter call after the `cd` is
  narrowed; any other command, join or shell form keeps the conservative
  directory set, because an alias or function may change directory.
  Symbolic links resolve physically, and a line that names `CDPATH` or
  `cdpath` is judged as running in an unknown directory.
