### Fixed

<!-- codeflow:release-impact patch -->
- **A doubled slash in a path is judged like its plain spelling.** A
  `HOME`, worktree, gate-lock directory or candidate path spelled with `//`
  or a `.` component is now compared as the plain path, so a secret read
  through such a `HOME` is refused and an absent worktree with a repeated
  separator gets its recovery message. The essential gate builds its run
  directory without a doubled slash under a `TMPDIR` that ends in `/`.
