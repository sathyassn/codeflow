### Changed

<!-- codeflow:release-impact minor -->
- **A push no longer runs the test gate.** The pre-push hook runs `codeflow
  ci` over each pushed range (which holds the conflict-marker check) and the
  release preflight where adopted, and no longer runs `codeflow validate
  --docs` or any test-config target, so a push never waits for the heavy-work
  lock. Run `codeflow test --mode quick` yourself and cite it when the pull
  request is made ready. `git.test_gate_on_push` keeps its levels and now
  governs that push set; the remedies for the removed tree checks are gone.
<!-- codeflow:release-impact minor -->
- **The shipped CI template runs essential on pull requests and full
  elsewhere.** Pull requests run `codeflow test --strict --mode essential`
  when a target defines an essential mode, and full otherwise; pushes to the
  protected branch, the weekly schedule and manual runs run full. An existing
  test config keeps working. The shipped `codeflow-policy.yml` also reruns
  when a draft is marked ready.
