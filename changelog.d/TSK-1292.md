### Changed

<!-- codeflow:release-impact minor -->
- **The model catalog ships new default seats and efforts.** `codeflow
  models resolve` now returns `claude-opus-5-5` at high for the Claude
  seat, `gpt-6.1-sol` at medium for the Codex seat, falling back to
  `gpt-6-sol` and then `gpt-5.6-sol`, and `grok-4.7` at medium for the Grok
  seat. The Grok seat rises to high when a security, release or
  extra-family review trigger applies. Sonnet and Luna still resolve when a
  route names them.
- **Model usage rules are catalog fields instead of skill prose.** Each
  product line carries `launch` (`seat`, `subagent-only` or `either`); a
  seat request for a `subagent-only` line, such as Fable or GPT-6 Astra, is
  refused with a message that names the field, and an override route that
  names one is refused the same way. Each seat carries its default
  `effort` and the `high_when` policies that raise it, and the catalog's
  `effort_floors` set each worker duty's floor, with a required `default`.
  `cf-model-orchestrator` now reads these values from `codeflow models
  resolve` instead of stating them.

### Added

<!-- codeflow:release-impact minor -->
- **The harness choice of model and effort applies, and CodeFlow records
  it.** `codeflow models resolve --effective <model>@<effort>` records the
  model and effort the session's harness runs at as an `effective_model`
  event in the sessions ledger. The resolution is unchanged and CodeFlow
  never re-launches a session to change its model or effort. The skill
  and `docs/delegation.md` state the rule.
