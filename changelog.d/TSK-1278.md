### Changed

<!-- codeflow:release-impact minor -->
- **Heavy gate deadlines.** Heavy targets have an activity deadline and a
  ceiling four times their base timeout. Stalls, ceiling timeouts and incomplete cleanup report distinct
  failure causes; dependent targets preserve them. Progress lines show tests
  done and CPU state every five minutes. Cleanup has a five-second bound.
  Windows uses job CPU accounting. Linux uses existing cgroup v2 delegation
  when available, falling back to the ceiling when delegation is missing or
  accounting, population or membership observations become uncertain. macOS
  is ceiling-only, an accepted limitation for 4.0.0.
