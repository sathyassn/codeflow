### Fixed

<!-- codeflow:release-impact patch -->
- **Hard-secret shell paths match without a directory prefix.** The shared
  glob matcher now includes zero directories for `**/`, so bare `id_rsa`,
  `id_ed25519`, key and certificate names receive the same refusal as nested
  paths. Relative paths to configured home stores are checked from the hook
  working directory. The `.env` and source-name groups keep their existing
  shell limitations and file-tool exceptions. Installing the updated binary
  activates the fix; no policy migration is needed.
