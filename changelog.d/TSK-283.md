### Security

<!-- codeflow:release-impact minor -->
- **Git configuration used by guards.** Alias and follow-tags checks share
  a bounded reader for effective Git configuration. Exec-guard alone refuses
  release aliases supplied through configuration environment variables.
  `codeflow doctor --check git-config-includes` reports include files that
  may be writable or configuration it cannot verify; include-file writes
  remain unguarded. Guards may now refuse configuration-dependent commands
  they allowed before.
  Migration: the operator repairs unreadable configuration or include paths;
  run guarded Git operations without command-local configuration environment
  changes.
