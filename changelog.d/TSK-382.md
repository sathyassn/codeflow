### Fixed

<!-- codeflow:release-impact patch -->
- **Amended criteria keep their tags.** An amendment note under a
  criterion, an indented dash sub-bullet whose first word is exactly
  `Amended` or `Moved` followed by a `YYYY-MM-DD` date, no longer hides a
  `(journey)`, `(serves EPC-NNN AC-n)` or `(after release)` tag that closes
  the head line, so `codeflow ci` accepts a task with an amended journey
  criterion, or one serving an amended epic journey criterion. Other
  sub-bullets stay criterion text. When a sub-bullet hides a tag, or a tag
  sits only in a note, the refusal names it and says to move the tag to
  the start. A reflow that keeps the words but changes which tags count is
  now a criteria change (issue #199).
