### Fixed

<!-- codeflow:release-impact patch -->
- **A quick or essential gate with no comparison base says local narrowing is
  unavailable.** On a branch with no task, a detached head, or a task with no
  declared target, the gate runs every target and states that reason; it never
  recommends `--since`, which narrows nothing. A push has run no test target
  since TSK-449 removed them from the push, so the cost reported for 3.1.1 in
  issues 371 and 494 (a push running the quick gate, and a failing test
  refusing a records-only push or the push `codeflow work claim` makes) is
  gone on this line; tests cover records-only pushes, task branch creation,
  and the refused-push shape reported in issue 515.
