### Fixed

<!-- codeflow:release-impact patch -->
- **The `codeflow` build takes the fixed `libz-sys` release.** Advisory
  RUSTSEC-2026-0418 affects `libz-sys` 1.1.29, which the workspace resolved,
  and fails a blocking dependency audit. Its build script can write the build
  environment, secrets included, to the build output under `target/` when
  built with `cc` 1.6.0 or later. The checked workspace lock resolves `cc`
  1.4.0, which does not trigger the leak. Builds that did not use that lock
  are not covered by this check. If you built CodeFlow from source without
  `--locked` (for example `cargo install --path crates/codeflow-cli`) on or
  after 2026-10-03, when `cc` 1.6.0 was released, treat that build's `target/`
  directory and any cache of it as possibly holding environment values: delete
  them, and rotate any secret that was in the build environment. The lockfile
  now resolves 1.1.31, and the README and install guide now build from a
  checkout with `cargo install --locked`. No command or output changes.
