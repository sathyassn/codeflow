### Security

<!-- codeflow:release-impact major -->
- **Breaking: the guards judge a command run through the Herdr app as if
  it were typed bare, and every `hc run` refuses.** exec-guard and git-guard
  now read `hc exec`, `hc machine add --via`, `herdr pane run` and
  `herdr agent start`, and judge the command each carries by the same rules
  as the bare command: headless peer runs, every Git rule, and the
  destructive, privileged and outward rules. `hc exec --cwd <dir>` is judged
  against the repository in that directory. `hc file write` and
  `hc file edit` are held to the Edit tool's path rules, and `hc file read`,
  `hc put` and `hc update --from` are judged as reads of the file they name.
  An `hc` subcommand or option the guard does not know, a word it cannot
  fill in, and any carried command whose directory it cannot establish are
  refused and named: `--on` another machine, `herdr pane run`,
  `herdr agent start`, and `herdr pane split` with `--cwd` or `--env`. Text
  typed into a terminal by `hc send` or `hc keys` is not judged; the policy
  reference states why and which floor holds.
  `hc run` can start a template instead of the words given, and the guard
  cannot verify from the command which one, so every `hc run` refuses,
  whatever its options and operands, including the interactive seat launch
  lines, and a help word does not pass. The refusal holds behind `sudo`,
  `doas`, `gsudo`, `pkexec`, `busybox` and the other wrappers, including
  when they run it from a shell command string. More generally, a terminal
  carrier name (`hc`, `herdr`) the guard finds in any command's words refuses
  unless it is the program word of the call parsed at that exact position,
  with its own parent launch and directory. Search patterns, messages and
  printed operands have no exemption. A wrapper, launcher or supplier whose
  command cannot be read refuses too, as does an incomplete traversal.
  This is a breaking restriction on previously accepted inline text.
  Keep that text in a file and use `--body-file`, `git commit -F` or `grep -f`;
  ordinary read and execution checks still apply. Commands hidden in files
  or external programs remain outside a text rule. Migration: start the program outside
  a guarded session, or through the host's own terminal. A guarded `hc run`
  form returns when the Herdr app's dispatch contract is known. `herdr pane
  run` and `herdr agent start` also refuse in a guarded session, because the
  directory they run in is unknown. Forms that passed before may now be
  refused.
- **Terminal and app input carriers now share one text rule.** The listed
  programs that type into, or start a command in, another terminal or app
  have their carried text checked as a command line. Guarded names and
  unread text refuse. Shell commands also meet their bare-command rules.
  Migration: launch an interactive seat in an established directory, keep
  instructions in a brief file and send its literal path. Terminal-management
  calls without carried text remain available. The policy reference names
  the inventory and the limit: typing programs absent from the list, and
  commands hidden in files or external programs, remain outside this rule.
