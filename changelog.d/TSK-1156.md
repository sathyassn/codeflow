### Fixed

<!-- codeflow:release-impact patch -->
- **A Codex builder seat can claim a task without writing the shared git
  config file.** `codeflow work claim` no longer pushes with `-u`, so it
  records no upstream, and a standalone claim renames the checked-out branch
  with ref operations when the branch has no tracking settings. A branch with
  tracking settings is checked first and refused before anything moves when
  the write probe catches the refusal (a lock file it cannot create or one
  already held, a config file the seat cannot open for writing). A refusal
  the probe cannot see, such as the final rename onto the config file, can
  still leave the branch renamed.
  Plain `git push` on the claimed branch needs the remote named
  (`git push origin HEAD`) until you set an upstream yourself.
  `codeflow doctor --builder-write-probe` reports the shared git config file
  (it opens the existing file for appending, never through a link and never
  creating or writing it),
  `codeflow doctor --check permissions` and `--preflight` say what a builder
  seat can and cannot do (it cannot write the shared git config file or
  `~/.codeflow/gate-runs`; only a full run copies its record there), and
  inside a Codex seat the preflight points to `--builder-write-probe` where
  its nested probe cannot start.

<!-- codeflow:release-impact patch -->
- **The tests that looked up a host no longer do, so a gate can get further in
  a Codex seat.** Test repositories use a `file://` origin, or a closed
  loopback port when the transport is the subject. A lint
  (`test_remotes_contract`) reports a literal network remote in a test that
  registers a remote (including a literal `git config remote.<name>.url`
  write) or sits in a registering call, with each reviewed
  exception bound to its file, host and count. It is a lint: it does not see
  a URL built at run time, and it does not prove that no test reaches the
  network. On Unix the `git::ci` smoke test runs a fake `gh` instead of
  calling `api.github.com`; on Windows it still reaches the real `gh`. Tests
  that start their own loopback server still need a seat that allows binding.
