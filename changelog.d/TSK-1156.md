### Fixed

<!-- codeflow:release-impact patch -->
- **A Codex builder seat can claim a task without writing the shared git
  config file.** `codeflow work claim` no longer pushes with `-u`, so it
  records no upstream, and a standalone claim renames the checked-out branch
  with ref operations when the branch has no tracking settings. A branch with
  tracking settings is checked first and refused before anything moves, so a
  claim that cannot write the config file no longer half renames the branch.
  Plain `git push` on the claimed branch needs the remote named
  (`git push origin HEAD`) until you set an upstream yourself.
  `codeflow doctor --builder-write-probe` reports the shared git config file,
  `codeflow doctor --check permissions` and `--preflight` say what a builder
  seat can and cannot do (it cannot write the shared git config file or
  `~/.codeflow/gate-runs`; only a full run copies its record there), and
  inside a Codex seat the preflight points to `--builder-write-probe` where
  its nested probe cannot start.

- **Tests no longer look up a host, so a gate can finish in a Codex seat.**
  Test repositories use a `file://` origin, or a closed loopback port when
  the transport is the subject, and a new scan
  (`test_remotes_contract`) fails when a test registers a remote on another
  host. `git::ci` tests run a fake `gh` instead of calling `api.github.com`.
