### Fixed

<!-- codeflow:release-impact patch -->
- **File swap checks compare the full 128-bit file id on Windows.** The
  full-gate lock check, the model qualification record reader and the
  commit-graph cache check now compare the volume and the full 128-bit file
  id from handles CodeFlow opened, so two files on `ReFS` that share the low
  64 bits of their id no longer compare as one. The commit-graph cache check
  now detects a file replaced by another with the same size, time and
  contents on every platform, not only on Unix. A file whose identity cannot
  be read, or whose id is zero, including inode 0 on Unix, is treated as
  changed and refused. No command or output changes otherwise.
