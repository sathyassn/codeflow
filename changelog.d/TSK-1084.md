### Changed

<!-- codeflow:release-impact none -->
- **The guard test suite no longer depends on the host's Git state.** A
  guard test could pass on a developer machine and fail on a hosted runner
  because the guard reads the pager and editor variables of its own process,
  and the tests inherited `PAGER`, `GIT_PAGER`, the `GIT_CONFIG_*` settings,
  the home directory's Git files and the agent-session marker `CLAUDECODE`
  (hosted run 41026268442). One shared helper now removes those from every
  command the `hooks_cli` tests start, points the system and global
  configuration at `/dev/null` and gives each run an empty home, and a new
  canary test shows the verdicts of a fixed set of `git log` lines unchanged
  when a pager is planted in every source. This changes test code only. No
  `codeflow` command, file, setting or release asset changes.
