### Security

<!-- codeflow:release-impact patch -->
- **Incomplete shell wildcard checks.** Versions 3.1.0 and 3.1.1 could
  discard unreadable glob results as absent or allow an incomplete expansion
  based on its starting directory even when the pattern could leave it.
  Unreadable results now refuse. At the unchanged 4096-entry limit, the
  starting directory is sufficient only when it holds no enforcement paths
  or registered checkouts and the pattern cannot escape through parent
  components or symbolic links. Ordinary contained globs remain allowed;
  other incomplete expansions report the limit as the refusal reason.

<!-- codeflow:release-impact patch -->
- **Linked worktree pointers through aliases.** Versions 3.1.0 and 3.1.1
  could allow writes to a linked worktree's `.git` file through a symbolic
  link outside the repository. Both shell guards now resolve these aliases
  against the registered checkout paths.

### Fixed

<!-- codeflow:release-impact patch -->
- **Interpreter enforcement arguments.** The interpreter argument guard
  added in this release checks each resolved literal, brace alternative and
  wildcard result with the shell writer's directory and worktree protections.
  Windows verbatim paths retain those protections with mixed separators.
  Quoted ordinary text remains literal, ordinary source globs avoid repeated
  repository checks, and pattern-based directory changes are unresolved.
