### Changed

<!-- codeflow:release-impact minor -->
- **One landing rule reaches `main` in every project.** A task pull request
  targets `main` when a human can merge it as it becomes ready. Otherwise
  the epic's tasks land on its integration line, where agents merge, and a
  checkpoint pull request from the line to `main` is opened or refreshed at
  every green line tip for a human to merge when available. Each task or
  epic record changes only on its own epic's line or on `main`, and a line
  takes `main` only through the sync `codeflow ci` admits. The managed
  `cf-method`, `cf-plan`, git rules and map rows state the rule (ADR-0098);
  they no longer say an epic reaches `main` only once, when it is finished.
