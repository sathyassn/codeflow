### Added

<!-- codeflow:release-impact minor -->
- **Secret-scan exemptions can land before their integration line.**
  `codeflow ci` gives a pull request changing only `.gitleaksignore` a named
  secret-scan exemption class with either `Task: EPC-NNN` or `Task: TSK-NNN`.
  An incomplete predecessor at the planning anchor no longer blocks this
  range, allowing a reviewed false-positive fingerprint to reach the trusted
  base before the line whose scan needs it (sathyassn/codeflow#139). Mixed
  ranges keep their usual classification. Deletions, type changes and mode
  changes do not qualify; the head entry must be a regular file. Such a
  range naming a task stays ordinary tracked work, and one naming an epic is
  refused. Commit, record and PR-body checks, secret scanning, security review and configured repository approvals still
  apply. The class does not change the scanner's trusted-base rule.
