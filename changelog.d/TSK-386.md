### Fixed

<!-- codeflow:release-impact patch -->
- **CI temporary folders.** The shipped CI templates remove the temporary
  folders they make when a step or script ends, after a failure or a
  hangup, interrupt or terminate signal too, so a self-hosted runner no
  longer fills up with them; a folder they did not make is never removed.
  The GitLab, Bitbucket and generic scripts keep their downloads, binaries
  and target checkout in one folder under `TMPDIR`, which macOS's
  `mktemp -d` ignored. The GitHub install steps use the runner's temp
  directory. `codeflow update` brings the GitHub workflows; copy the new
  GitLab, Bitbucket or generic file to get the fix there, and so that
  `codeflow doctor` recognizes its pinned install again.
