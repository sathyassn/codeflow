### Added

<!-- codeflow:release-impact minor -->
- **`codeflow test --config <path>` runs the gate from a named test config.**
  The run reads its targets from that file only, never from
  `.codeflow/test-config.json` or stack detection, and binds its evidence to
  that file. A missing path, a symbolic link, or a file that is not regular
  or readable is refused before any target starts. CI can run a trusted
  copy of the config against a candidate checkout this way.
