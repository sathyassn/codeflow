### Fixed

<!-- codeflow:release-impact patch -->
- **The guard's glob matcher no longer stalls on a full pattern cache.** The
  cache of compiled patterns stopped admitting entries after 128, so in a
  long process every later pattern compiled again on each call and one
  secret-path test ran past 600 seconds against 6 seconds alone. A full cache
  is now cleared and refills. The matcher also has a fixed bound (a pattern
  of 1024 bytes, a path of 32 KiB and a compiled program of 256 KiB); an
  input past it is refused with a message naming the bound, never allowed.
