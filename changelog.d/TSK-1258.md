### Fixed

<!-- codeflow:release-impact patch -->
- **The guard's glob matcher no longer stalls on a full pattern cache, and it refuses an input it cannot finish.**
  The cache of compiled patterns stopped admitting entries after 128, so in a
  long process every later pattern compiled again on each call and one
  secret-path test ran past 600 seconds against 6 seconds alone. A full cache
  is now cleared and refills. The matcher also has a fixed bound (a pattern
  of 1024 bytes, a path of 32,000 bytes and a compiled program of 256 KiB). A guard
  refuses an input past it, in the secret-read check and in the edit guard,
  with a message that names the bound. A `[scaffold] ignore` pattern past the
  bound still opts its file out, so `update` does not manage it. A search
  selector over 1024 bytes refuses, and brace expansion no longer scans a long
  word of unmatched braces once per brace.
  A long path that does not exist no longer stalls a guard either: the reads
  grew with the square of the path's depth, which held a Windows run past 1200
  seconds, and they now stay small at any depth.
