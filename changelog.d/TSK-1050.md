### Fixed

<!-- codeflow:release-impact patch -->
- **The guard opens each repository once per hook call.** Exec-guard checks
  every word of the code a nested shell runs (`bash <<< ...`,
  `bash <(...)`, `... | bash`, `source <(...)`) from every directory the
  line may run in, and each check opened the owning repository again. A
  long line of nested shells could take many seconds to judge. The guard
  now opens each repository once per hook call and reuses the result for
  every word, including a failed open, so every verdict and error is
  unchanged.
