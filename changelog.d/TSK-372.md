### Fixed

<!-- codeflow:release-impact patch -->
- **Windows repository paths.** Interpreter commands using a verbatim drive
  path now treat the namespace marker as part of the path. Ordinary source
  arguments remain allowed, while enforcement files and actual wildcard
  targets retain their checks.

<!-- codeflow:release-impact none -->
- **Hosted gate parity.** Script dependency discovery retains Windows drive
  paths, backslash separators and quoted paths containing spaces, so a script
  using the built binary must declare its producer on Windows too.
