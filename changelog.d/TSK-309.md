### Fixed

<!-- codeflow:release-impact patch -->
- **Update preserves a newer pin.** `codeflow update` refuses before changing
  project files when its binary is older than the project's `scaffold_version`,
  names both versions and asks you to install the pinned version. An
  unparsable pin also refuses and shows its value. The refusal preserves
  release digests and managed files, including with `--force`. Only binaries
  carrying this fix enforce it; older released binaries can still lower the
  pin and install older scaffold assets.
