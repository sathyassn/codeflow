### Fixed

<!-- codeflow:release-impact patch -->
- **Scaffold writes preserve a newer pin.** `codeflow update` and a repeated
  `codeflow init`, including tier upgrades, refuse before changing
  project files when the binary is older than the project's `scaffold_version`.
  The refusal names both versions and asks you to install the pinned version. An
  unparsable pin also refuses and names its value, file and correction.
  The refusal preserves
  release digests and managed files, including with `--force`. Only binaries
  carrying this fix enforce it; older released binaries can still lower the
  pin and install older scaffold assets.
