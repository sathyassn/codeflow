### Added

<!-- codeflow:release-impact minor -->
- **Convert a legacy capability catalog with `codeflow capability migrate`.**
  One run registers each fence's number with a new uid, writes one record per
  entry under `docs/capabilities/` with the fence's fields and the prose that
  followed it unchanged, and removes the converted sections from
  `docs/capabilities.md` last. An entry that already has a page keeps the
  page and its anchors. Missing facets get plain defaults to classify later.
  An ambiguous prose span, an unknown fence key, an ambiguous page, an entry
  that would not validate or an already registered number refuses the run
  before the registry or any file changes.
