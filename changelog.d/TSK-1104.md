### Fixed

<!-- codeflow:release-impact patch -->
- **Read-only git stays allowed while the policy authority is
  unresolved.** When the default branch of the remote cannot be read, for
  example `refs/remotes/origin/HEAD` is unset, `git status`, `log`, `diff`,
  `show`, `rev-parse` and the other plain read-only commands now pass the
  git and exec guards. Every other command, edit, program option and shell
  construct is still refused, and the refusal names the ref and the step
  that clears it.
