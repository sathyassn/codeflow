### Security

<!-- codeflow:release-impact patch -->
- **The design-system kit writes review data and heading ids as text.** The
  kit `chrome.js` that the cf-present and cf-docs-portal skills ship wrote an
  earlier review note's kind from the page's `#cf-data` JSON, a local note's
  kind, and each heading `id` in the table of contents into HTML without
  escaping, so markup or a double quote in those values became elements or
  attributes in the kit's chrome. All three now go through the kit's escape
  helper. The kit renders only data and content its page author supplies,
  so the change is hardening; no attack path to it was found. CodeQL found
  the first of these on its first scan of the repository; its other alerts on
  that scan are false positives or test-only code.
