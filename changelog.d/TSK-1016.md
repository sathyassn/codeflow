### Security

<!-- codeflow:release-impact patch -->
- **The release binary no longer links `zstd` releases with known
  advisories.** RUSTSEC-2026-0391, RUSTSEC-2026-0395 to 0406 and
  RUSTSEC-2026-0410 affect `zstd` 0.13.3, `zstd-safe` 7.2.4 and `zstd-sys`
  2.0.16, which `rust-embed`'s compressed asset embedding pulled in. The build
  now takes `include-flate-compress` from its upstream repository at the
  commit that moves it to `zstd` 0.14, so the lockfile resolves `zstd` 0.14.3,
  `zstd-safe` 8.2.0 and `zstd-sys` 2.1.2. No command or output changes.
