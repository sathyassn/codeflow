### Changed

<!-- codeflow:release-impact minor -->
- **Claude sessions compact at 35 percent of the 1M window (issue 358).**
  The shared `.claude/settings.json` now sets
  `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` to 35 in place of 50, so a session on a
  1M-window model compacts near 350K tokens and a session limited to 200K
  near 70K. `codeflow update` moves a shared value equal to the recorded
  shipped 50 to 35, whether or not the project chose 50 on purpose; a
  project that wants 50 sets it again after the update, or a person sets it
  in `.claude/settings.local.json`, which update never touches. A value
  that differs from the shipped one stays, and the report names its key.
  The `cf-customize` context policy now states the tradeoff: per-turn input
  grows with the context carried, a lower point compacts more often, the
  point matters most for long orchestrator sessions, and detail kept only
  in the conversation may be lost, while durable records let a session
  recover when it rereads them. The value is revisited once the adopter's
  measurement is posted on issue 358.
- **`codeflow update --diff` and update's report no longer show project
  values.** The export is judged only against the assets inside the
  binary, never the project's files or the recorded baseline. For JSON,
  TOML and YAML it lists each changed key path with the shipped value and
  a marker for the project's side, and counts keys the project added
  without naming them; for Markdown and other text it shows the shipped
  lines the update writes and counts the rest; any other format, or a file
  that does not parse, is withheld. Update's report names a step before
  the secret scan by its position, a policy key without its value, and a
  malformed `.codeflow/project.toml` by line and column, without the
  quoted source line.
