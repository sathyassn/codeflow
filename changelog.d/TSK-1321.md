### Changed

<!-- codeflow:release-impact none -->
- **CodeFlow's own CI no longer needs test time measurements.** The Windows test
  partitions and the Linux coverage shards place each test by the hash of its
  name, so a new test cannot make the plan stale. The Windows partitions go from
  twelve to sixteen, end a test that runs past 12 minutes, and still fail a
  partition that passes the 24 minute margin. The Windows reduced tier now
  applies only when every changed file is on a short list of Markdown paths:
  task records, `docs/` and `changelog.d/` Markdown and the README, less the
  files Rust compiles in. Everything else takes the full tier. This changes this repository's CI only. No `codeflow` command, file,
  setting or release asset changes.
