### Changed

- **CodeFlow's hosted test plan splits tests by the hash of their name, and a check confirms each listed test ran exactly once.**

<!-- codeflow:release-impact patch -->
- **A pull request into an integration line runs only the short checks in a workflow of its own and reports `codeflow gates (line)`, so a required check never passes on a suite that did not run; a push to a line runs the full Linux suites and no Windows job, and pull requests into main, pushes to main and the daily and weekly runs keep the full suites.**

- **`codeflow remote protect` requires `codeflow gates (line)` on lines where a workflow on the default branch declares it, and the shipped settings and guards protect the two line workflows like `codeflow-ci.yml`; a repository without those workflows sees only the two new deny entries.**
