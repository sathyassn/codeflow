<!-- codeflow:release-impact patch -->
- **The edit guard protects a guarded path however a link spells it.** When
  a protected path, such as a git configuration file, the coordination
  ledger or the operator-authority directory, sits behind a link to a place
  that does not exist yet, the edit guard now judges an edit at that place
  too, and a name that does not exist yet in any spelling the volume may
  store as the same entry. A protected path it cannot place in any spelling
  refuses every edit and names the path and the reason, except a protected
  path of the generated `Edit` denies, which keeps its written spelling with
  a warning that alias coverage is reduced. An edit whose target, or a
  repository holding it, the guard cannot read is refused with the reason,
  and a path now resolves the same way whatever the guard resolved before
  it.
