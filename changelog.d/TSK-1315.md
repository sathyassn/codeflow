### Fixed

<!-- codeflow:release-impact minor -->
- **A sandbox can no longer turn a generated branch name into a broken ref.**
  `work claim` and `epic new --integration` leave the words in the new policy
  key `git.branch_name_omit_words` (default `secret` and `credentials`) out of
  a generated branch name and say which ones they left out.
  `doctor --check repo-integrity` names a ref, reflog or tracked file this
  process is refused, `status` names a refused ref or reflog, and both say
  that this is not evidence of repository damage.

<!-- codeflow:release-impact none -->
- **The `work claim` code passes the clippy line limit again.** The check that
  refuses a task already claimed or already landed moves into its own
  function, so `claim_on` is back under 100 lines. No command, message or
  behaviour changes.
