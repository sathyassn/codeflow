### Fixed

<!-- codeflow:release-impact major -->
- **Pull requests are scanned by the default branch.** The
  `trusted: secret scan` job runs the authority's scan and configuration
  over every introduced commit, including a finding later deleted. A pull
  request cannot replace its scan step or exempt its own finding. Git reads
  ignore replace refs, and push and scheduled scans include octopus-merge
  additions. Legacy-fingerprint advice now requires a remerge conflict
  header naming the path. Migration: once `codeflow-policy.yml` reaches the
  default branch, required checks must name `trusted: secret scan` instead
  of `secret scan`. Push, scheduled and manual scans use `history scan`.
  Exemptions for integration-line scans must land on the default branch.
