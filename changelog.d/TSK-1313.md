### Changed

<!-- codeflow:release-impact none -->
- **A newer push to an integration line cancels the older push run on that
  line.** This repository's `codeflow-ci` workflow now cancels a superseded
  first-attempt push run on an `integration/**` line, running or pending, so
  only the newest tip's run uses runners. A push rerun runs in a group of its
  own and cancels nothing. Pushes to `main` and `master`, schedule and
  dispatch runs are never cancelled in progress, and pull request runs keep
  their rule. Runs may start out of order, so a late older run can still
  cancel the newest one; rerun the newest tip's run to recover. This changes
  this repository's own workflow only. The managed `codeflow-ci.yml` that
  adopters receive, and every `codeflow` command, are unchanged.
