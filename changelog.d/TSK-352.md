### Added

<!-- codeflow:release-impact minor -->
- **Test gates compare against the task's declared line.** `codeflow test`
  and the pre-push quick gate can skip unchanged content checks only when a
  clean full candidate run proves the same command, mode and declared
  dependencies. Evidence includes the Git tree ID, tools, environment
  fingerprints, test membership and producer outputs. Unknown evidence
  continues to run the check and names the reason. Existing configurations
  remain valid and execute their targets until their input and dependency
  audits are declared; `--all` continues to execute every target.
