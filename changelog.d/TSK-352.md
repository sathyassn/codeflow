### Added

<!-- codeflow:release-impact minor -->
- **Test gates compare against the task's declared line.** `codeflow test`
  and the pre-push quick gate can skip unchanged content checks only when a
  clean full candidate run proves the same command, mode and declared
  dependencies. Evidence includes the Git tree ID, tools, environment
  fingerprints, test membership and producer outputs. Unknown evidence
  continues to run the check and names the reason. Existing configurations
  remain valid and execute their targets until their input and dependency
  audits are declared; `--all` continues to execute every target.

### Fixed

<!-- codeflow:release-impact patch -->
- **Landing gates execute every target.** Default full runs are non-selective and
  both integration modes refuse failed, skipped or incomplete runs. A repository
  with no targets retains the loud warning and may land, preserving 3.1 behavior.
  Local skip credit requires owner-held records without group or world write access and is
  disabled by `CODEFLOW_HOME` or a `HOME` different from the effective account
  database home. A record MAC under a `denyRead` key was considered
  and deferred; skip credit remains local convenience, never landing evidence.
  Summaries show executed and skipped counts; strict mode rejects empty
  execution or candidate-evidence skips. Explicit `--only` and mode exclusions
  are not skips and do not fail strict mode. Redaction covers literal, XML-,
  JSON- and URL-escaped sensitive and fingerprint inputs, including JSON Unicode
  and HTML-safe forms, XML/HTML numeric references, XML attributes with raw
  apostrophes, slash-safe and double URL encoding, and padded standard and
  URL-safe base64. Other transformations remain the producing tool's duty.
  Redaction preserves non-secret values and leaves tool source reports untouched.
  Selection and fingerprint fallback reasons now identify their causes; the capability rule and decision date are corrected.

<!-- codeflow:release-impact patch -->
- **Requested-mode summaries distinguish execution from landing evidence.**
  Successful quick and essential runs with no skips say "not full-gate evidence";
  skipped or empty execution still says "not complete". The task's Outcome and
  AC-1 now state the quick and essential comparison default and full mode's
  explicit `--since` rule, and the repair record attributes the hook-summary
  authorization to the primary. The documented non-Unix limit and unused
  `allows_proceed` helper remain unchanged after review.

<!-- codeflow:release-impact patch -->
- **Gate evidence tests run without host-specific Git or text defaults.**
  Fixtures set repository-local commit identities and write encoded-marker
  reports as UTF-8. Windows and other non-Unix platforms keep executing checks
  without selection credit because trusted account-home and record-ownership
  checks are unavailable; the guide and ADR now state this limit explicitly.
