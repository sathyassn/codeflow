### Changed

<!-- codeflow:release-impact minor -->
- **The scaffold ships a useful status line and leaves effort to each
  person (issue 351).** The shipped Claude Code status line now shows the
  model name and id, the Claude Code version, the output style, the folder,
  the git branch and the context used out of the window, with the
  percentage green below 50, yellow below 80 and red from 80. It reads the
  status JSON with `jq`; without `jq` it prints the folder and branch.
  `.claude/settings.json` no longer sets `effortLevel` and
  `.codex/config.toml` no longer sets `model_reasoning_effort`, so a
  contributor's own effort applies again (ADR-0087 supersedes ADR-0056's
  settings pin). Seat launches still pass their effort. `codeflow update`
  moves a status line still at the line CodeFlow last shipped to the new one,
  removes an effort pin still at the shipped value, keeps and reports a
  value the project changed, and no longer adds back a status line the
  project deleted. The attribution controls are still restored whenever a
  project lacks them. `cf-customize` says where a person sets their own line
  and effort, and how a project opts in to a shared effort.
