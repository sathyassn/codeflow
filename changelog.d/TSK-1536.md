### Fixed

<!-- codeflow:release-impact patch -->
- **A leading assignment before the environment launcher's split string no
  longer causes a refusal.** The guard read the assignment in
  `FOO=1 env -S 'git config --global user.name Probe'` as the program word
  and refused the command. It now keeps leading assignments as assignments,
  so the command gets the verdict the same command gets without them. A
  split string that is refused on its own, and an assignment that rewrites
  hook runner settings, stay refused.
