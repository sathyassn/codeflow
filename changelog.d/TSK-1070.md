### Changed

<!-- codeflow:release-impact minor -->
- **The shipped Claude status line shows effort, pull request, plan usage
  and worktree (issue 402).** When Claude Code supplies them, the line adds
  the effort level beside the model, `PR <n>` with its review state, the
  5-hour and 7-day usage as `5h <n>%` and `7d <n>%` coloured like the
  context, and `wt:<name>` after the branch. A field Claude Code does
  not supply is left out, so a session without any of them prints the same
  line as before. The line makes no network or `gh` call. `codeflow update`
  moves a line still equal to a shipped one and keeps and reports a line the
  project changed; a person's own line goes in `.claude/settings.local.json`.
