### Fixed

<!-- codeflow:release-impact patch -->
- **The installed `cf-ship` release-integration reference no longer sends an
  adopter to a CodeFlow-only runner.** The reference told every project to
  reproduce a release integration with
  `cargo run -p codeflow-cli --example release_integration`, a runner that no
  scaffold installs. CodeFlow also retired that runner and its repository-only
  integration workflow, because its releases ship from `main`. The reference
  keeps the conditional rule: read the configured integration result after an
  epic-line landing, and route a failure to the open `role: release-integration`
  task. Run `codeflow update` to refresh the installed skill.
