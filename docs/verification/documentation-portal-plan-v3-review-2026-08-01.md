## Settled Plan v3 change

Automatic ancestor-page recovery is removed. When one current committed
Markdown blob cannot parse, the portal retains its stable route but emits only
a bounded visible current-source error page. The page records the current path,
blob hash, commit, output/twin hashes, and bounded diagnostic. It carries no
active identity, relationship, backlink, snippet, status, preview, search, or
normal `llms.txt` claim. Healthy siblings continue.

Git history and previous generated bytes are never content inputs. A future
allowlisted historical-publication feature would require a separate approved
contract and demonstrated user need.

## Other required corrections

- Batch and bound Git inventory/blob reads; disable prompts, lazy fetching,
  fsmonitor, pagers, optional locks, and inherited Git redirection.
- Recompute exact identities and forward relationships from committed source
  blobs in the independent Rust verifier.
- Verify bounded raster headers, dimensions, pixel counts, per-file bytes, and
  aggregate bytes for PNG, JPEG, GIF, and WebP.
- Preserve unknown public files only through stable no-follow handles with
  actual-byte accounting and identity checks.
- Use stable cross-platform file identity checks and include Unix ctime in
  read-stability evidence.
- Treat committed-but-excluded document links as pinned provider references or
  visible source/commit text, while absent documents remain failures.
