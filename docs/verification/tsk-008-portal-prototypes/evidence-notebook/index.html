01

Orientation

A repository can remember why it changed.

CodeFlow gives agentic development a durable record and a small set of hard boundaries—without turning the repository into an orchestration platform.

Agents keep their native tools and judgment. The repository carries the product intent, accepted work, architecture decisions, policy, and evidence needed to review the result.

Flexible execution in the middle. Explicit inputs and verifiable outputs at the edges.

02

Work journey

Follow one change from question to merge.

Agent operating contract
  1. DiscussClarify the outcome

    Ask only when intent, authority, risk, or an irreversible tradeoff is genuinely unresolved.

  2. PlanMaterialize durable work

    An epic owns a coherent outcome; a spec pins behavior when needed; tasks carry acceptance and dependencies.

  3. BuildWork in an isolated branch

    The producer implements the smallest coherent solution and first-verifies the changed unit.

  4. ReviewChallenge across lineages

    The other model family reviews the unit; the qualified Claude judgment primary settles integrated quality.

  5. LandMerge through evidence

    Deterministic gates and human review form the authoritative perimeter.

Two crates, one deterministic core

codeflow-core owns policy, records, scaffold behavior, guards, and delegation state. codeflow-cli exposes those operations without duplicating their rules.
