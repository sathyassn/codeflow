# Cross-candidate convergence, recorded as hypothesis

`registry.json` carries the machine-readable version of this; the prose is here.

## The observation

Five of the eleven candidates independently render **absence as a positive visual state**
rather than as nothing:

| Candidate | How absence is drawn |
|---|---|
| `p2/a-stopped-provenance` | the stages a claim did not travel stay on the rail as an open dotted remainder, with the stop drawn as a bar |
| `p2/b-absence-by-cause` | every missing run is a tile with a dashed edge, grouped and sized so the absences occupy most of the page |
| `p3/a-convergence-with-source-depth` | the cause that did not come from a round gets a hatched region behind a dashed boundary, explicitly off the axis |
| `d1/c-write-authority-map` | the layer with no path in the working tree gets its own dotted region rather than being left out |
| `d2/b-evidence-margin` | the claim with no evidence keeps a full-height reserved margin with its own edge and a hatched field |

`p1/a-critical-path-and-room` belongs to the same family in a weaker form: a task with no
later start still carries a cap on the shared scale, at zero, so having none is drawn.

## Why this is not recurrence evidence

It fails all three tests in the composition reference, and it fails them badly enough that
recording it as anything stronger would be a mistake:

1. **One hand, one sitting.** Every candidate above was authored by the same session for
   the same study on the same day. That is authorial habit. It says something about the
   author and nothing about the product.
2. **They do not coexist.** Candidates within a case are mutually exclusive by
   construction — at most one ships per case, and D2's pair is a decomposition of one
   surface. Even if all five were selected, they would land on two different utilities with
   no shared runtime: `SPC-005` says in terms that portal tokens and runtime components are
   never shared with `cf-present`.
3. **No accepted product surface repeats it.** The nearest thing in the presentation
   contract is the `status` block's `not_run` state, which carries a word and no geometry.
   The documentation portal ships no absence treatment at all. There is nothing to be
   coherent with yet.

## What would change that

A real reuse need in **two accepted surfaces that will actually coexist**, evidenced from
shipped work rather than from a sixth candidate agreeing with the first five. If that
arrives, what would be taken is the primitive and its state vocabulary named by meaning —
*reserved*, *untravelled*, *off-axis*, *no environment* — never the subject-specific forms
built on it. Flattening a rail, a tile grid, an off-axis region and an evidence margin into
one generic "absence component" would destroy the layer where the design value actually
lives.

## What this study does instead

Nothing. The selected form is implemented locally, in its own subject's geometry, and this
file waits. That is the deliberate outcome, and it supersedes an earlier formulation in the
W2 design judgment that called candidate convergence recurrence evidence and asked for a
primitive before implementation — a claim that was challenged, upheld as a material defect,
and corrected in the doctrine.
