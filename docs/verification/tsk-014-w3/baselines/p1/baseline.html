How the waves are computed

  • A task's earliest wave is one more than the latest wave of any dependency of its own that is still open; a task with none is in wave 1.
  • A task's latest wave is the last wave of the epic minus the longest run of tasks that still has to follow it.

Derived from the same shared/plan-model.js the candidates use, so the facts are identical and only the presentation differs.
