Findings across rounds — and whether a later round answered an earlier one

Rounds run left to right. A cell says what happened to that finding in that round, and every row keeps a clear band beneath its words for the arcs. A solid arc returns from a round that re-opened a finding to the round whose fix did not hold. A round that only widened a check draws no arc, because nothing had failed. One column is deliberately not a round: it holds the single cause that arrived from outside this axis, next to the round it arrived at.

Seven findings, eight rounds, and one origin that is not a round. Empty cells mean the round did not touch that finding.

raised + fixed — the finding first appears together with its fix.
re-opened — the earlier fix did not hold. A solid arc in the row's band runs back to the round it answers.
the off-axis column — an origin that is not a round. Its dashed arc enters the round the cause arrived at; from there the solid arc carries on to the round that was re-opened. Six rows are empty because only one re-opening came from outside.
extended — the round widened what the check proves. No arc: the earlier fix did not fail.
residual — a bounded remainder the closing round recorded and left open.
