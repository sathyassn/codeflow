From “I have a task” to a merged change — one line, and every branch off it is a refusal

The vertical line is the only path. Everything that leaves it sideways is a gate that stops you and does not put you back. The widest branch is the answer to which gate refuses you: one rule carrying six separate reasons, and you meet it again at every later station.

    Solid branch — the first station where that rule can refuse you, with every reason it carries.
    Dashed branch — the same rule again, in a later plane. Not a new gate: the same read-only check.
    Stop bar — the branch ends. No gate here is advisory; each one blocks and names its cause.

    Source: AGENTS.md, crates/codeflow-core/src/workgraph/work_start.rs, crates/codeflow-cli/src/cmd/ci.rs and crates/codeflow-core/src/hooks/git_hook.rs, through the shared subject source shared/repo-entry.js. Every rule id is checked against the source that emits it by tools/verify.mjs.
