Only unfinished tasks are placed. Columns are readiness waves computed from real depends_on frontmatter; lines are dependencies between remaining tasks. The heavy left edge marks the longest chain to TSK-010; a double edge marks work with room to wait.

Wave — 1 + the highest wave of a task's unfinished dependencies. Wave 1 is startable today.
Longest chain — the longest remaining path to TSK-010. Every task on it has zero room.
Room — how many waves a task can start later without moving the finish.
Met — the completed prerequisites each remaining task already satisfies, kept as proof without drawing history into the field.
