EPC-005 — the chain that sets the finish, and the work that has room

Every unfinished task is placed at its earliest possible wave; anything reaching wave 1 is startable today. A task with room can start later without moving the finish; a task with none cannot. The tasks with no room form one chain — that chain is the remaining schedule.

No room — moves the finish

Has room

The solid block is the earliest wave the task could start; the dashed extension is how far it can slip before it joins the chain above.

Room = latest wave − earliest wave, where the latest wave is fixed by the longest remaining path to TSK-010. Both are computed here from depends_on and status; nothing is asserted by hand.
