EPC-005 — who is blocked by whom, and what that leaves free

One cell per real depends_on edge. Read a row for what a task still needs and how much room it has; read a column for how much of the epic one task is holding. Rows on the longest chain to TSK-010 carry a solid left rule.

Rows: all ten EPC-005 tasks. Columns: every task that appears in another task's depends_on.
waitsthe dependency exists and is not finished — this is what still holds the row back.
metthe dependency exists and is already complete, so it no longer blocks.
outstanding 0nothing unfinished remains in that row: the task is startable today.
roomwaves the task could start later without moving the finish. sets the finish means none — the row is on the longest chain.
