## Overall verdict

**Reject the current board as sufficient production-selection evidence.** Three
cases contain a direction worth revising, D1 needs a corrected task question,
and D2 has a survivor rather than a winner because its sibling pair failed
distinctness. No candidate may be promoted from this evidence as it stands.

The study strongly proves provenance, reproducibility, isolation and
accessibility automation. It does not yet prove comprehension. The material
reason is that the rendered candidates visibly state much of the expected
answer in prose, so the observation can succeed without decoding the visual
form.

## Blocking protocol findings

1. **Visible answer confounds comprehension.** P1-C prints the full chain, P2-B
   prints the number of stopped rails, P3 prints the multi-round findings, and
   D2-B prints the empty claim. The machine channel already publishes the
   derived answer invisibly; visible restatement was not required. G2 is
   therefore suspect and G3 is confounded.
2. **Responsive information survival is weaker than idea survival.** Several
   mobile candidates retain all labels while losing the spatial encoding that
   made the candidate useful: P1-C loses its wave axis, P3-B turns arcs into
   prose, and D2-B turns reserved absence into a labelled box.
3. **No tablet evidence exists.** The untested intermediate width is where
   matrices, margins and multi-column explanations commonly fail.
4. **Reduced-motion PNGs are not motion evidence.** Representative reduced and
   normal files are byte-identical. Motion remains not observed.
5. **D1 asks the wrong question.** It tests exact precondition lookup against a
   portal orientation surface. A numbered baseline wins that question by
   construction, so it cannot settle the intended orientation composition.
6. **Sibling distinctness is discovered too late.** D2 was fully authored and
   rendered before G6 exposed that both candidates use the same primary content
   units.
7. **Carrier feasibility is evaluated too late.** Six candidates need a new
   typed block. Some candidates described as expressible would lose precisely
   the visual relationship worth selecting when flattened into the current
   contract.

## Per-case design judgment

### P1 — revise P1-C, critical ribbon

Preserve the float-bar encoding, no-room/has-room split, wave axis and
fill-versus-dashed-room distinction. Remove the sentence that states the chain.
Connect consecutive critical-chain bars so the relationship can be verified
visually. Create a genuinely narrow composition that still encodes wave
position; full-width boxes labelled with wave numbers do not do that.

Reject P1-A because mobile reduces its cross-stream thesis to a label and its
dependency curves are too faint. Reject P1-B because mobile hides the blocker
columns and the matrix is sparse relative to its scanning cost.

### P2 — revise P2-B, provenance rail

P2-A is strong on desktop, but its thesis is the shape of missing coverage and
mobile deletes that shape. P2-B rotates rather than truncates the evidence
journey and uses filled/open nodes plus an untravelled remainder to render
absence as absence.

Preserve rail geometry, the three-state node vocabulary, stage count and the
cause-specific “why it stops” note. Remove the lede that gives away the count
before re-observation. Add an explicit platform attribute at each rail head and
a compact coverage signal, because the current rail answers platform coverage
only through prose scanning.

### P3 — P3-B overview with P3-A as row-level evidence

The off-axis “not a round” column is the strongest composition on the board: it
makes an external cause spatial rather than a footnote. Preserve the
finding-by-round matrix, reserved arc lanes, off-axis boundary, distinct
self-caused/external arcs, settlement column and extended-versus-reopened
distinction. Remove the generic detached details rows and the answer sentence.
Increase light-mode arc weight and contrast.

P3-A is not a defeated sibling: it uses code region as its primary unit and is
the only candidate that makes repeated changes to the same lines visible. Use
it as the row-level expansion rather than a generic details list.

### D1 — no promotion; re-register and re-explore

D1-A scatters the nine preconditions; D1-C cannot enumerate them; D1-B contains
them but repeats many branches that say no new check. The baseline winning an
exact lookup question does not mean it is the right orientation design. Replace
the registered question with the portal's actual orientation job, then create
and observe materially distinct candidates.

Carry forward D1-A's “readable from here — N of 9” relationship, D1-C's visibly
unarmed plane treatment, and a simplified D1-B task path with only material
refusal branches as inputs—not settled directions.

### D2 — revise D2-B as survivor, not winner

D2-A and D2-B use the same claim/decision/evidence units and fail sibling
distinctness. D2-B's reserved empty margin makes missing evidence difficult to
miss, but weakly communicates which decision governs and loses its margin on
mobile. Combine D2-A's decision-reach idea with D2-B's evidence adjacency, then
create a narrow composition that preserves meaningful reserved space. Do not
flatten it into a two-column table: an empty cell would make deliberate absence
indistinguishable from omission.

## Cross-candidate system hypothesis

Four candidates independently render **absence as a positive visual state**:

- an open dotted track after an evidence stopping point;
- a hatched, struck-through unarmed plane;
- an off-axis region behind a dashed boundary; and
- a reserved evidence margin with a visible edge.

This convergence is worth retaining as a **hypothesis**, not as recurrence
evidence. The candidates were created in one study, compete for a small set of
decisions and need not coexist in production. Rejected work should still be
mined for transferable ideas, but a shared system layer is earned only when
subject independence, expected coexistence/lifetime and a real reuse need in
accepted product surfaces support it. Until then, implement the selected form
locally and preserve its subject-specific geometry.

This wording supersedes the design lead's first returned formulation, which
incorrectly called candidate convergence recurrence evidence and asked for a
primitive before implementation. A third exact turn challenged that inference;
Claude upheld the challenge as a material defect and amended the doctrine and
eval accordingly. The correction is part of the same native session, prompt
digest `bbb979ccb720e41fadfda66a6d60727fb47a7979ca711df48bc9bc82797c12b5`.

## Required doctrine and evaluation amendments

1. Require the governing idea—not merely all text—to survive each applicable
   viewport, with an explicit viewport-specific composition when it cannot.
   Include tablet/intermediate width by default when responsive composition is
   material.
2. Keep the expected answer in a machine channel. A comprehension gate is void
   when visible prose states the answer the composition is meant to convey.
3. Qualify the registered question before authoring: it matches the surface's
   real job, every candidate can answer through its encoding, and it can
   discriminate between forms.
4. Declare each candidate's primary unit and primary axis before authoring so
   sibling distinctness is an input, not an expensive late discovery.
5. Qualify the technical carrier before investing in rendered candidates and
   state any material degradation honestly.
6. Harvest recurrent primitives across all explored candidates, not only the
   selected one, while preserving subject-specific composition.
7. Add non-browser evidence paths and platform conventions for native mobile,
   tablet and desktop work; a headless web path cannot substantiate those
   claims.
8. Decompose compound design questions whose parts require different
   encodings, or state which part is optimized and how the other is carried.
