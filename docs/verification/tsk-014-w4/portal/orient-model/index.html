Orient — a model, not a link list

A reader who has never seen this repository should leave the Orient layer with a usable model of where knowledge lives and what may be done to it — not with three links and a sentence.

What the shipped portal does today

The built portal renders /orient/ as a one-line description, an unordered list of three links, and a "Next" card, with every ADR title dumped into the sidebar in file order. It is a correct index of the source tree and it carries no model at all.

The control is a real capture, not a caricature. The shipped build was served from docs-portal/dist and captured headless at the same three viewports and both modes as this page. The capture is reproduced in board.html; the finding is that nothing on it encodes a relationship.

The family

Vertical order is the operating contract's own row order, which runs from the layer that changes most rarely to the one that changes with nobody touching it. Bar length is that cadence. Edge and fill carry write authority, from the contract's own three-band vocabulary. Each layer names the paths it really occupies, and a "path" that is not a file in the checkout says so rather than being quietly dropped.
