Curated semantic primitives

The product ships a closed set of named typed blocks, each modelling one kind of subject relationship rather than one chart type. The document supplies typed data and no geometry at all — no coordinate, no scale, no mark, no colour.

Three primitives are implemented, which is what a first shipped set would plausibly contain: extent_on_axis, travel_and_stop and coverage_grid. Every figure below is emitted at load by primitives.js from the typed record printed beneath it.

What it cannot express

A record page needs to show how far a governing decision reaches across a record's own claims, and which claims have nothing behind them. That is neither an extent on an ordered axis, nor a travel through stages, nor a grid of lanes. There is nowhere for it to go.

The runtime's own refusal, printed rather than described. The honest options at this point are: ship the subject as a table and lose the finding, or open a product change — a new block type, a schema version, a renderer, tests and a release — before the explanation can exist at all.
